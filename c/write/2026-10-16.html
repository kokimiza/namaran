reverse.c

void reverse(int *first, int *last) {
}

同じ配列を指すポインタ first と last を受け取り、first が指す要素から last が指す要素の1つ手前までの範囲を、その場で逆順に並べ替える reverse を書いてください。last は配列の末尾の1つ先を指すこともあります。first == last なら範囲は空で、何もしません。出力例には、呼び出したあとの配列 a の中身を書いています。

入力例 1

int a[] = {1, 2, 3, 4, 5}; reverse(a, a + 5);

出力例 1

{5, 4, 3, 2, 1}

入力例 2

int a[] = {1, 2, 3, 4, 5}; reverse(a + 1, a + 4);

出力例 2

{1, 4, 3, 2, 5}

入力例 3

int a[] = {7}; reverse(a, a);

出力例 3

{7}
Reference 
void reverse(int *first, int *last) {
    while (first != last && first != --last) {
        int t = *first;
        *first = *last;
        *last = t;
        first++;
    }
}

ループの条件は、左から順に2つのことを確かめます。first != last で要素が残っているかを見て、残っていれば --last で last を最後の要素へ動かし、first と同じ要素を指していないかを比べます。同じ要素なら、要素が奇数個のときの真ん中で、入れ替える相手がいないので止まります。違えば両端を入れ替え、first を1つ進めて内側の組へ移ります。

--last を && の右に置いたのは、空の範囲で last を戻さないためです。reverse(a, a) で last を1つ戻すと、配列の先頭の1つ手前を指すポインタができます。C でポインタの足し引きが許されるのは、結果が同じ配列の中か末尾の1つ先に収まるときだけで、先頭の1つ手前は計算した時点で未定義動作です。&& は左が偽なら右を評価しないので、first == last のときは --last が実行されません。while (first < last - 1) と書くと、空の範囲を渡されたときにこのポインタを作ってしまいます。

掲載したのは参考実装で、唯一の正解ではありません。last - first で要素数を求め、添字で前後の組を入れ替えても同じ結果になり、先頭より手前を指すポインタも作りません。
