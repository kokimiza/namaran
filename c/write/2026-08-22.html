void swap(int *a, int *b) {
    int tmp = *a;
    *a = *b;
    *b = tmp;
}

一時変数に*aを退避し、*bを*aへ、退避しておいた値を*bへ代入します。これは参考実装であり、唯一の正解ではありません — 自分の実装と比較してみてください。
