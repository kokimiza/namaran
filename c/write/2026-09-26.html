insert_at.c

void insert_at(int *a, size_t len, size_t pos, int value) {
}

要素が len 個入っている配列 a の添字 pos に value を差し込み、もとの a[pos] 以降を1つずつ後ろへずらす insert_at を書いてください。a には len + 1 個分の領域があり、pos は 0 以上 len 以下です。pos が len なら末尾に足すだけで、len が 0 のときも動くようにします。{1, 2, 3, 4} に insert_at(a, 4, 1, 9) → {1, 9, 2, 3, 4}、{1, 2, 3, 4} に insert_at(a, 4, 4, 9) → {1, 2, 3, 4, 9}、空の配列に insert_at(a, 0, 0, 9) → {9}

#include <string.h>

void insert_at(int *a, size_t len, size_t pos, int value) {
    memmove(&a[pos + 1], &a[pos], (len - pos) * sizeof a[0]);
    a[pos] = value;
}

a[pos] から a[len - 1] までを、1つ後ろの a[pos + 1] から a[len] へ動かします。コピー元とコピー先は同じ配列の中で1要素ずれて重なっているので、memcpy は使えません。memcpy は2つの範囲が重ならないことを前提にしており、重なる範囲を渡すと未定義動作です。memmove は重なっていても、いったん別の場所へ写してから書き戻したのと同じ結果になることが保証されています1。

ループで書くなら、後ろから前へ進みます: 

    for (size_t i = len; i > pos; i--) {
        a[i] = a[i - 1];
    }

前から a[i + 1] = a[i] と進めると、1周目に書いた a[pos + 1] を2周目で読むことになり、a[pos] の値が末尾まで並んでしまいます。後ろから進めれば、読む要素はどれもまだ書き換えていない場所です。len - pos が 0 なら memmove は何も写さないので、末尾への追加も空の配列も同じ1行で扱えます。掲載したのは参考実装で、唯一の正解ではありません。

  1. 規格は memmove のコピーを、コピー元ともコピー先とも重ならない一時的な配列へいったん写し、そこからコピー先へ写したかのように行う、と定めています。実際の実装は一時配列を使わず、重なり方を見てコピーの向きを選ぶのが普通です。
