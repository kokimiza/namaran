times_table.c

#include <stdlib.h>

void *times_table(size_t n) {
}

n 行 n 列の掛け算の表を、malloc 1回で確保した int の2次元配列として返す times_table を書いてください。i 行 j 列には (i + 1) * (j + 1) を入れ、行も列も0から数えます。呼び出し側は int (*t)[n] = times_table(n); で受け取って t[i][j] で読み、使い終えたら free(t) で解放します。n は1以上で、確保に失敗したときは NULL を返します。出力例には、返された配列の中身を初期化子の形で書いています。

入力例 1

times_table(3)

出力例 1

{{1, 2, 3}, {2, 4, 6}, {3, 6, 9}}

入力例 2

times_table(2)

出力例 2

{{1, 2}, {2, 4}}

入力例 3

times_table(1)

出力例 3

{{1}}
Reference 
void *times_table(size_t n) {
    int (*t)[n] = malloc(sizeof(int[n][n]));
    if (t == NULL) {
        return NULL;
    }
    for (size_t i = 0; i < n; i++) {
        for (size_t j = 0; j < n; j++) {
            t[i][j] = (int)((i + 1) * (j + 1));
        }
    }
    return t;
}

確保する大きさは sizeof(int[n][n]) で求めています。int[n][n] は可変長配列の型なので、この sizeof はコンパイル時の定数にならず、呼ばれたときの n を使って実行時に計算されます。

確保した領域は、1行ぶんの配列 int[n] を指すポインタ int (*t)[n] で受けます。t[i] が i 行目の配列、t[i][j] がその j 番目の要素で、t を1つ進めたときに何バイト進むかも実行時の n で決まります。呼び出し側が同じ型で受け取れば、番地の計算はすべてコンパイラに任せられます。掲載したのは参考実装で、唯一の正解ではありません。int * で受けて t[i * n + j] と自分で番地を計算しても、同じ表ができます。

C には p = malloc(n * sizeof *p) と大きさを書く慣用句がありますが、ここでは使えません。int (*t)[n] = malloc(n * sizeof *t); と書くと、*t の型が可変長配列の int[n] なので、sizeof は被演算子の *t を評価します。初期化の途中の t はまだ値を持っておらず、規格の文言どおりに読むと、値の決まっていないポインタをたどることになります。型名だけで書く sizeof(int[n][n]) なら、評価されるのは n だけです。
