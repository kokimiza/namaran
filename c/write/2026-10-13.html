put_varint.c

size_t put_varint(unsigned char *out, uint32_t v) {
}

v を可変長整数として out に書き、書いたバイト数を返す put_varint を書いてください。各バイトは v の下位から順に7ビットずつを持ち、後ろにまだバイトが続くときだけ最上位ビットを立てます。v が0のときも1バイト書きます。out には5バイト以上の大きさがあるものとし、例の buf は unsigned char buf[5]; です。

入力例 1

put_varint(buf, 300); printf("%02x %02x", buf[0], buf[1]);

出力例 1

ac 02

入力例 2

put_varint(buf, 128)

出力例 2

2

入力例 3

put_varint(buf, 0)

出力例 3

1

size_t put_varint(unsigned char *out, uint32_t v) {
    size_t n = 0;
    while (v >= 0x80) {
        out[n++] = (unsigned char)(v | 0x80);
        v >>= 7;
    }
    out[n++] = (unsigned char)v;
    return n;
}

ループは、残りの v が7ビットに収まらない(0x80 以上の)あいだ、続きの印 0x80 を付けて1バイト書き、v を7ビット右へずらします。unsigned char への変換で残るのは下位8ビットだけで、その最上位のビットは | 0x80 で立てた印になります。300 なら下位7ビットの 0x2C に印が付いた 0xAC を書き、残りの 2 がそのまま最後のバイトになります。

ループを抜けたとき v は 0x7F 以下なので、印を付けずにそのまま書けば最後のバイトになります。v が0のときも、ループは回らずにここで1バイト書きます。while (v != 0) で1バイトずつ書く形にすると、0のときはループが1回も回らず、何も書かないまま0を返してしまいます。

掲載したのは参考実装で、唯一の正解ではありません。do 〜 while (v != 0) で書き、右へずらしたあとの v が0でなければ印を立てる、という形もよく使われます。
