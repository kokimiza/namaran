parse_count.c

#include <assert.h>
#include <stdio.h>

int parse_count(const char *s) {
}

文字列 s の先頭にある整数を sscanf で読んで返す parse_count を書いてください。整数が読めなかったときは assert で止めますが、NDEBUG を定義したリリースビルドでは止まらずに 0 を返します。整数が読めたときは、どちらのビルドでも同じ値を返すようにします。parse_count("42") → 42、parse_count(" -3 apples") → -3、parse_count("x") → assert が失敗(NDEBUG なら 0)

Reference 
int parse_count(const char *s) {
    int n = 0;
    int got = sscanf(s, "%d", &n);
    assert(got == 1);
    (void)got;
    return n;
}

sscanf は assert の外で呼び、戻り値だけを assert で確かめます。assert(sscanf(s, "%d", &n) == 1) と1行にまとめると、NDEBUG を定義したビルドでは assert が中の式ごと消え、sscanf が呼ばれなくなります。n は初期値の 0 のままなので、parse_count("42") まで 0 を返します。

NDEBUG のビルドでは got を読む式が消え、使われない変数の警告(-Wunused-variable)が出ます。(void)got; はそれを抑えるための行です。読めなかったときに 0 を返せるのは n を 0 で初期化してあるからで、sscanf は読めなかった引数に何も書きません。

掲載したのは参考実装で、唯一の正解ではありません。strtol で読み、返ってきた終わりの位置が s から進んだかどうかで読めたかを確かめる書き方もできます。
