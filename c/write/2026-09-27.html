row_pointers.c

#include <stddef.h>

enum { COLS = 4 };

void row_pointers(int g[][COLS], size_t n, int *out[]) {
}

2次元配列 g の先頭 n 行について、各行の先頭要素を指すポインタを out[0] から out[n - 1] に入れる row_pointers を書いてください。int ** を受け取る関数に2次元配列を渡すための下準備で、n が 0 のときは out に何も書きません。int g[3][COLS] に対して row_pointers(g, 3, out) → out[i] == &g[i][0](i は 0 から 2)、row_pointers(g, 0, out) → out は変わらない

Reference 
void row_pointers(int g[][COLS], size_t n, int *out[]) {
    for (size_t i = 0; i < n; i++) {
        out[i] = g[i];
    }
}

g[i] は int[COLS] 型の1行で、式の中では先頭要素を指す int * に変わります。それを out[i] に入れていけば、out は int ** として渡せる行ポインタの配列になります。

(int **)g とキャストして済ませることはできません。g の中にあるのは int の並びだけで、行を指すポインタはどこにも格納されていないからです。int ** を受け取った側は m[i] をポインタとしてメモリから読むので、int の値をアドレスと取り違えます。行ポインタを実際にメモリ上へ並べる out が要るのはそのためです。

パラメータの int g[][COLS] は、コンパイラには int (*g)[COLS](COLS 個の int からなる行へのポインタ)として扱われます。列数が型に含まれているので、g[i] は i * COLS 個先の行を正しく指します。掲載したのは参考実装で、唯一の正解ではありません。out[i] = &g[i][0]; と書いても同じです。
