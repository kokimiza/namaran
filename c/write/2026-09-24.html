次の規則でエスケープされた文字列を読み、元の文字列に戻すunescapeを書いてください: エスケープされた文字列では"(ダブルクォート)は\"に、\(バックスラッシュ)自身は\\に、それぞれ2文字へ展開されています。それ以外の文字はそのまま1文字です。復号した文字列をdstに書き込み、書き込んだ文字数を返してください。入力が空文字列のときはdstも空文字列、戻り値は0です(境界: 空文字列)。入力に対応しない孤立した\は来ない前提です。入力a\"\\b → dstはa"\b、戻り値4。入力(空文字列) → dstは(空文字列)、戻り値0。入力xyz → dstはxyz、戻り値3。

size_t unescape(const char *src, char *dst) {
    size_t j = 0;
    for (size_t i = 0; src[i] != '\0'; i++) {
        if (src[i] == '\\') {
            i++;
        }
        dst[j++] = src[i];
    }
    dst[j] = '\0';
    return j;
}

unescapeはescapeより単純です。バックスラッシュを見つけたら1文字読み飛ばし、次の1文字を(それが"だったか\だったかを区別せず)そのままdstへコピーするだけで、\" → "と\\ → \の両方を同じコードで復号できます。escape側は「この文字はエスケープが必要か」を判定する必要がありましたが、unescape側はバックスラッシュの直後を無条件に1文字コピーすればよいだけです。対になる処理でありながら、復号のほうが対称的で単純になっています。これは参考実装であり、唯一の正解ではありません。
