decimal.c

bool is_decimal(const char *s) {
}

文字列sの全体が10進数の形になっているときだけtrueを返すis_decimalを書いてください。形は「省略できる符号(+か-)、1桁以上の数字、そして省略できる『.と1桁以上の数字』」です。空文字列はfalseです。is_decimal("-12.5") → true、is_decimal("3.") → false、is_decimal("") → false

Reference 
bool is_decimal(const char *s) {
    enum { START, SIGN, INT, DOT, FRAC } st = START;
    for (const char *p = s; *p != '\0'; p++) {
        bool digit = *p >= '0' && *p <= '9';
        switch (st) {
        case START:
            if (*p == '+' || *p == '-') {
                st = SIGN;
            } else if (digit) {
                st = INT;
            } else {
                return false;
            }
            break;
        case SIGN:
            if (!digit) {
                return false;
            }
            st = INT;
            break;
        case INT:
            if (*p == '.') {
                st = DOT;
            } else if (!digit) {
                return false;
            }
            break;
        case DOT:
        case FRAC:
            if (!digit) {
                return false;
            }
            st = FRAC;
            break;
        }
    }
    return st == INT || st == FRAC;
}

「いまどこまで読んだか」をSTART(何も読んでいない)・SIGN(符号だけ)・INT(整数部の途中)・DOT(小数点の直後)・FRAC(小数部の途中)の5つの状態で持ち、1文字ごとに遷移させます。遷移先がない文字が来たらその場でfalseです。ループを抜けたあとの判定が要で、文字列が数字で終わる状態(INTかFRAC)だけを受理状態にします。これで"3."(DOTで終わる)、"+"(SIGNで終わる)、""(STARTのまま)が自然に弾かれ、境界ごとに特別扱いのifを足さずに済みます。DOTとFRACは「数字しか受け付けず、次はFRAC」という同じ遷移なので、caseを並べて共有しています。C23ではboolがキーワードなので<stdbool.h>は要りません。これは参考実装であり、唯一の正解ではありません(strtodは指数表記や前後の空白も受け付けるので、この形の判定には使えません)。
