at.c

int at(const int *a, int n, int i) {
}

長さ n の配列 a から、添字 i の要素を返す at を書いてください。i が0以上なら先頭から数え、負なら末尾から数えます(-1 が最後の要素、-n が最初の要素)。i が -n 以上 n 未満であることは、呼び出し側が保証します。

入力例 1

at((int[]){10, 20, 30, 40}, 4, 1)

出力例 1

20

入力例 2

at((int[]){10, 20, 30, 40}, 4, -1)

出力例 2

40

入力例 3

at((int[]){10, 20, 30, 40}, 4, -4)

出力例 3

10
Reference 
int at(const int *a, int n, int i) {
    return (i < 0 ? a + n : a)[i];
}

a[i] は *(a + i) と定義されていて、[] の左に書けるのは配列の名前に限りません。ポインタになる式なら何でもよいので、i が負のときは配列の最後の次を指す a + n を起点にし、そこから i 個戻ります。(a + n)[-1] は *(a + n - 1) で、最後の要素です。

負の添字そのものは誤りではありません。p[-1] が正しいかどうかは、p - 1 がまだ同じ配列の中を指しているかどうかだけで決まります。a[i] に負の i をそのまま渡すと配列の先頭より前を読むことになり、こちらは未定義動作です。起点に使った a + n は配列の最後の次を指すポインタで、読み書きせずに指すだけなら規格が認めています。

掲載したのは参考実装で、唯一の正解ではありません。a[i < 0 ? n + i : i] と添字の側で直しても同じ結果になります。i % n で折り返すのは誤りで、C の % の結果は割られる数と同じ符号になるため、-1 % 4 は -1 のままです。
