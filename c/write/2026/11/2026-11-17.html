most_frequent.c

unsigned char most_frequent(const char* s) {
}

文字列 s の中で最も多く現れるバイトの値を返す most_frequent を書いてください。バイトの値は 0 から 255 の整数として扱い、最も多いバイトが複数あるときは値の小さいほうを返します。s が空文字列なら 0 を返します。

入力例 1

most_frequent("banana")

出力例 1

97

入力例 2

most_frequent("\xc3\xa9t\xc3\xa9")

出力例 2

169

入力例 3

most_frequent("")

出力例 3

0

unsigned char most_frequent(const char* s) {
    int counts[256] = {0};
    for (; *s; s++)
        counts[(unsigned char)*s]++;
    int best = 0;
    for (int c = 1; c < 256; c++)
        if (counts[c] > counts[best])
            best = c;
    return best;
}

バイトの値は 256 通りしかないので、キーを探す表は要らず、値そのものを添字にした int counts[256] がそのまま「値から個数を引く表」になります。ただし、文字をそのまま添字にはできません。char が符号付きか符号なしかは処理系が決め、符号付きの処理系では 128 以上のバイトが負の値として読まれます。counts[*s] と書くと、入力例 2 の先頭のバイト 0xc3 は -61 になり、配列の外を書き換えてしまいます。(unsigned char)*s と変換してから添字にすれば、どの処理系でも 0 から 255 に収まります。掲載したのは参考実装で、唯一の正解ではありません。

数え終えたら、best を 0 から始め、1 から 255 までを小さい順に見て、個数が best より真に多いときだけ置き換えます。同じ個数では置き換えないので、最も多いバイトが複数あれば値の小さいほうが残ります。入力例 2 は「été」の UTF-8 表現で、0xc3（195）と 0xa9（169）が2回ずつ、t が1回現れ、小さいほうの 169 が返ります。空文字列ではどの個数も 0 のままなので、置き換えは一度も起きず、0 が返ります。
