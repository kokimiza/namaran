to_base.c

void to_base(uint32_t n, uint32_t base, char* out) {
}

n を base 進数で表した文字列を out に書き込む to_base を書いてください。base は2以上16以下で、10以上の桁は小文字の a〜f で表します。先頭に余分な 0 は付けず、n が0のときは "0" にします。out には33バイト以上の領域があるものとします。例では、呼び出したあとの out の中身を書きます。

入力例 1

to_base(255, 16, out)

出力例 1

"ff"

入力例 2

to_base(493, 8, out)

出力例 2

"755"

入力例 3

to_base(0, 2, out)

出力例 3

"0"

void to_base(uint32_t n, uint32_t base, char* out) {
    char buf[33];
    int len = 0;
    do {
        buf[len++] = "0123456789abcdef"[n % base];
        n /= base;
    } while (n > 0);
    for (int i = 0; i < len; i++) {
        out[i] = buf[len - 1 - i];
    }
    out[len] = '\0';
}

n を base で割った余りは、base 進数で表したときの一番下の桁です。商の n / base は残りの桁を表す数なので、割り算を繰り返すと余りが下の桁から順に1つずつ出てきます。文字列は上の桁から書くので、参考実装では出てきた桁をいったん buf にためて、最後に逆の順で out へ写しています。余りから文字への変換は、文字列リテラル "0123456789abcdef" を配列として添字で引けば、10以上の桁も同じ式で書けます。これは参考実装で、唯一の正解ではありません。out の末尾から前へ向かって書き、最後に先頭へ詰める書き方もあります。

while (n > 0) で回すと、入力例3の n が0のときに一度も桁が出ず、空文字列になります。do〜while にすれば本体が少なくとも1回実行されるので、0から余り0が1つ出て "0" になります。入力例2では、493を8で割ると余り5・商61、61を8で割ると余り5・商7、7を8で割ると余り7・商0となり、出た順の 5, 5, 7 を逆に並べて "755" です。out に求めた33バイトは、32ビットの最大値を2進数で表した32桁と終端の '\0' の分です。
