crc8.c

#include <stddef.h>

unsigned char crc8(const unsigned char* p,
                   size_t n) {
}

p から n バイトの8ビット CRC を返す crc8 を書いてください。生成多項式は 0x07（x8 + x2 + x + 1 から x8 の項を除いた係数を、上の次数から1ビットずつ並べたもの）、初期値は 0 で、ビットの並びの反転も最後の XOR もしません。各バイトは最上位ビットから処理します。n が 0 のときは初期値の 0 を返します。

入力例 1

crc8((const unsigned char*)"123456789", 9)

出力例 1

0xF4

入力例 2

crc8((const unsigned char*)"A", 1)

出力例 2

0xC0

入力例 3

crc8(NULL, 0)

出力例 3

0x00

unsigned char crc8(const unsigned char* p,
                   size_t n) {
    unsigned char crc = 0;
    for (size_t i = 0; i < n; i++) {
        crc ^= p[i];
        for (int k = 0; k < 8; k++) {
            if (crc & 0x80)
                crc = (crc << 1) ^ 0x07;
            else
                crc <<= 1;
        }
    }
    return crc;
}

CRC は、データのビット列を多項式の係数とみなし、生成多項式1で割った余りです。係数の足し算と引き算は繰り上がりのない XOR で行うので、割り算の「引く」は生成多項式との XOR になります。参考実装は、この筆算を1ビットずつ進めます。crc に次のバイトを XOR で重ね、8回、1ビットずつ左へずらします。ずらす前の最上位ビットが 1 なら、そのビットは x8 の位に出て、生成多項式の x8 の項で割れることになります。そこで、残りの係数 0x07 を XOR で引きます。掲載したのは参考実装で、唯一の正解ではありません。256通りのバイトについて結果をあらかじめ表にしておき、1バイトを1回の表引きで済ませる書き方もよく使われます。

crc << 1 は int に昇格してから計算されるので、x8 の位に出たビットは 0x100 として値に残ります。unsigned char の crc に代入すると 256 で割った余りになり、このビットは消えます。生成多項式から x8 を除いた 0x07 を XOR すればよいのはこのためです。入力例2の "A" は 0x41 で、1回目のシフトで 0x82 になります。2回目は最上位ビットが 1 なので、0x04 と 0x07 の XOR で 0x03 になり、残りの6回は最上位ビットが 0 のままずれるだけで、0xC0 が残ります。n が 0 なら外側のループは1回も回らず、初期値の 0 がそのまま返ります。

  1. 生成多項式（せいせいたこうしき、generator polynomial）は、CRC の計算で割る数にあたる、係数が 0 か 1 の多項式です。どれを選ぶかで、見逃さずに検出できる破損の種類が変わります。
