names.c

void sort_names(char names[][8], size_t n) {
}

1行に1つずつ、ヌル終端の名前(7文字以内)が入った n 行の配列 names を、strcmp の順で昇順にその場で並べ替える sort_names を書いてください。同じ名前が複数あってもかまいません。n が0か1なら何もしません。例では、呼び出す前の配列の中身を初期化子の形で書き、出力例には呼び出したあとの中身を同じ形で書きます。

入力例 1

{"pear", "fig", "apple"}

出力例 1

{"apple", "fig", "pear"}

入力例 2

{"kiwi"}

出力例 2

{"kiwi"}

入力例 3

{"plum", "date", "plum", "banana"}

出力例 3

{"banana", "date", "plum", "plum"}

void sort_names(char names[][8], size_t n) {
    for (size_t i = 1; i < n; i++) {
        char key[sizeof names[0]];
        memcpy(key, names[i], sizeof key);
        size_t j = i;
        while (j > 0 && strcmp(names[j - 1], key) > 0) {
            memcpy(names[j], names[j - 1], sizeof key);
            j--;
        }
        memcpy(names[j], key, sizeof key);
    }
}

names の各行は char[8] の配列です。配列は代入できないので、names[j] = names[j - 1] のように行を入れ替えることはできず、中身の8バイトを memcpy で動かします。ポインタの配列 const char *names[] なら指す先を入れ替えるだけで済みますが、ここでは文字そのものが行に並んでいるので、動かすのも文字です。参考実装は挿入ソートで、これが唯一の正解ではありません。

行の大きさは sizeof names[0] で取れます。仮引数の char names[][8] は char (*)[8]、つまり8文字の行へのポインタに置き換わるので、sizeof names はポインタの大きさになりますが、names[0] は行そのもので8になります。挿入する行を key に写してから前の行を1つずつ後ろへずらし、空いた位置に key を書き戻します。

key を配列ではなく、行 i を指すポインタにすると、名前は写されません。前の行をずらした時点で行 i は上書きされ、key から読める名前も変わります。入力例1では、"fig" を挿入するときに key の指す先が "pear" に変わり、名前が失われます。strcmp(...) > 0 のときだけずらすので、入力例3の2つの "plum" のように等しい名前は元の順のまま残ります。n が0か1ならループが一度も回らず、配列は変わりません。
