verbosity.c

int verbosity(int argc, char* argv[]) {
}

コマンドライン引数 argc・argv を受け取り、-v が何回指定されたかを返す verbosity を書いてください。argv[0] はプログラム名で、読むのは argv[1] からです。- で始まる要素はオプションで、オプションの文字は v と o だけとします。1つの - のあとに文字を続けて -vv のようにまとめて書けます。o は値を1つ取り、同じ要素の中で o のあとに文字が続けばその残りが、続かなければ次の要素が値です。値になった部分は、- で始まっていてもオプションとしては読みません。- で始まらない要素は読み飛ばし、ちょうど -- の要素があれば、それより後ろは何も読みません。例では、プログラムに渡したコマンドラインをそのまま書きます。

入力例 1

prog -vv -ov x -v

出力例 1

3

入力例 2

prog -vo -v

出力例 2

1

入力例 3

prog -- -v

出力例 3

0

int verbosity(int argc, char* argv[]) {
    int v = 0;
    for (int i = 1; i < argc; i++) {
        const char* a = argv[i];
        if (strcmp(a, "--") == 0) {
            break;
        }
        if (a[0] != '-') {
            continue;
        }
        for (int k = 1; a[k]; k++) {
            if (a[k] == 'v') {
                v++;
            } else if (a[k] == 'o') {
                if (a[k + 1] == '\0') {
                    i++;
                }
                break;
            }
        }
    }
    return v;
}

外側のループが要素を1つずつ、内側のループが1つの要素の中の文字を1つずつ読みます。-- を見たら外側のループを抜け、- で始まらない要素は内側に入らずに飛ばします。内側のループは v を見るたびに数え、o を見たらそこで止まります。o のあとにまだ文字があれば、それは値なので、同じ要素の残りを読まずに次の要素へ進みます。o がその要素の最後の文字なら、値は次の要素なので i++ で1つ飛ばし、外側の i++ と合わせて値の次の要素から読み直します。掲載したのは参考実装で、唯一の正解ではありません。

入力例1では、-ov の v は o の値なので数えません。値を同じ要素から取ったので、次の x は値にはならず、- で始まらない要素として読み飛ばされます。-vv の2つと最後の -v を合わせて 3 です。入力例2の -vo は、v を数えたあと o が要素の最後なので次の -v を値として飲み込み、1 になります。- で始まる要素をすべてオプションとして数える実装はここで 2 を返します。入力例3は -- で読むのを止めるので 0 です。argc が 1 のときは外側のループに一度も入らず、0 を返します。
