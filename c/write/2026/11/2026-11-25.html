cmp_int.c

int cmp_int(const void* a, const void* b) {
}

qsort で int の配列を昇順に並べるときに渡す比較関数 cmp_int を書いてください。a と b はどちらも int を指し、a の指す値のほうが小さければ -1、等しければ 0、大きければ 1 を返します。値は INT_MIN から INT_MAX までのどれでもあり得ます。関数の中では if、switch、条件演算子 ?: を使いません。

入力例 1

cmp_int(&(int){INT_MIN}, &(int){1})

出力例 1

-1

入力例 2

cmp_int(&(int){5}, &(int){5})

出力例 2

0

入力例 3

cmp_int(&(int){INT_MAX}, &(int){-1})

出力例 3

1

int cmp_int(const void* a, const void* b) {
    int x = *(const int*)a;
    int y = *(const int*)b;
    return (x > y) - (x < y);
}

qsort は要素の型を知らないので、比較関数には const void* が渡ります。まず const int* に変換して値を x と y に取り出します。比較演算子 > と < の結果は int の 1 か 0 なので、そのまま引き算に使えます。x が大きければ 1 - 0 で 1、等しければ 0 - 0 で 0、小さければ 0 - 1 で -1 になり、分岐を書かずに3通りの値が出ます。掲載したのは参考実装で、唯一の正解ではありません。

分岐を使わない比較関数としてよく見る return x - y; は、この問題の条件を2つの点で満たしません。返す値が -1、0、1 に限られないうえに、入力例1では INT_MIN - 1 が int の範囲を下に外れます。符号付き整数のオーバーフローは未定義動作で、2の補数で折り返したとすると結果は INT_MAX になり、INT_MIN のほうが大きいという答えが返ります。入力例3の INT_MAX - (-1) も同じく範囲を上に外れます。比較の結果どうしの引き算なら、引かれる数も引く数も 0 か 1 なので、結果は -1 から 1 の間に収まり、どの int の組でも溢れません。
