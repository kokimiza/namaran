max_odd.c

#include <stddef.h>

bool max_odd(const int* a, size_t n, int* out) {
}

配列 a の先頭 n 個に含まれる奇数のうち最大のものを *out に書き、true を返す max_odd を書いてください。奇数が1つも無いとき(n が0のときも含む)は *out を変えずに false を返します。要素には負の数も入ります。

入力例 1

max_odd((int[]){4, -3, -7, 2}, 4, &m)

出力例 1

true(m は -3)

入力例 2

max_odd((int[]){2, 8}, 2, &m)

出力例 2

false

入力例 3

max_odd(NULL, 0, &m)

出力例 3

false

#include <stddef.h>

bool max_odd(const int* a, size_t n, int* out) {
    bool found = false;
    for (size_t i = 0; i < n; i++) {
        if (a[i] % 2 != 0 && (!found || a[i] > *out)) {
            *out = a[i];
            found = true;
        }
    }
    return found;
}

最大値を探すループでよく使う初期値は、この問題ではどれも誤った答えを残します。a[0] は奇数とは限らず、入力例1で best = a[0] から始めると、偶数の4がそのまま答えとして残ります。0から始めると、奇数がすべて負の入力例1では0が残ります。そこで初期値を置く代わりに、奇数をもう見つけたかどうかを found で持ちます。まだ見つけていなければ最初の奇数をそのまま *out に入れ、見つけたあとは大きいときだけ書き換えます。found は返り値も兼ねるので、奇数が無ければ *out には一度も書かずに false が返ります。これは参考実装で、唯一の正解ではありません。

奇数の判定は a[i] % 2 != 0 で書きます。C の整数の除算は0の方向へ切り捨てるので、余りは割られる数と同じ符号になり、-3 % 2 は1ではなく -1 です。a[i] % 2 == 1 と書くと負の奇数がすべて外れ、入力例1は奇数が無いとみなされて false になります。正しい判定で入力例1を追うと、奇数は -3 と -7 で、先に出てくる -3 が *out に入り、-7 は -3 より小さいので書き換えず、true と -3 が返ります。入力例2は奇数が無く、入力例3はループが1回も回らないので、どちらも false です。n が0なら a[i] は1度も読まれないので、a が NULL でもかまいません。
