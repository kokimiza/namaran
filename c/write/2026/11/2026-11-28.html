count_options.c

int count_options(int argc, char* argv[]) {
}

main が受け取ったままの argc と argv を受け取り、コマンドライン引数のうち - で始まるもの(オプション)の個数を返す count_options を書いてください。-- だけの引数があれば、そこでオプションは終わりとし、-- 自身もその後ろも数えません。引数が1つも無ければ 0 を返します。例では、argv の指す文字列を argv[0] から順に空白で区切って書きます。

入力例 1

ls -l src -a

出力例 1

2

入力例 2

rm -f -- -x

出力例 2

1

入力例 3

-bash

出力例 3

0

Reference

int count_options(int argc, char* argv[]) {
    int n = 0;
    for (int i = 1; i < argc; i++) {
        if (strcmp(argv[i], "--") == 0)
            break;
        if (argv[i][0] == '-')
            n++;
    }
    return n;
}

argv[0] はプログラムの名前で、コマンドライン引数は argv[1] から argv[argc - 1] までに入っています。argc もプログラムの名前を含めた個数なので、ループは i = 1 から i < argc まで回します。各引数については、先に strcmp で -- と内容を比べ、一致したらループを抜けます。argv[i] == "--" と書くとポインタどうしの比較になり、内容が同じでも一致しません。-- でなければ先頭の1文字が - かどうかを見て数えます。これは参考実装で、唯一の正解ではありません。argv[argc] が NULL であることを使い、ポインタで NULL までたどる書き方もできます。

入力例 2 では -f を数えたあと -- で止まるので、オプションのように見える -x は数えません。入力例 3 は argc が 1 で、ループは1度も回らずに 0 を返します。argv[0] を数えに入れると、ここで 1 になってしまいます。ログインシェルは自分の名前の先頭に - を付けた argv[0] で起動されるので1、この違いは実際に起こります。空文字列の引数は先頭の文字が '\0' なので数えません。数える値は argc を超えないので、int の n があふれることもありません。

  1. ログインシェルかどうかを、シェル自身が argv[0] の先頭の - で判断するという慣習です。login などがこの形でシェルを起動します。
