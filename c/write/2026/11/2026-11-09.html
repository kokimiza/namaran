next_token.c

char* next_token(char** cursor, char delim) {
}

書き換えてよい文字列を区切り文字 delim で区切り、先頭からトークンを1つずつ返す next_token を書いてください。トークンは元の文字列の中に置いたまま、区切り文字を '\0' に書き換えて終端します。呼び出し側が持つ状態は *cursor だけなので、次に読む位置は *cursor に残します。区切り文字が続く所や末尾の区切り文字の後ろにある空のトークン "" も1つと数え、トークンを返し終えたあとの呼び出しでは NULL を返します。delim は '\0' ではありません。例では、char s[] に入れた文字列の先頭を指す p から始めて next_token(&p, ',') を NULL が返るまで呼び、返った値を順に書きます。

入力例 1

"a,,b"

出力例 1

"a" "" "b" NULL

入力例 2

"x,"

出力例 2

"x" "" NULL

入力例 3

""

出力例 3

"" NULL

#include <string.h>

char* next_token(char** cursor, char delim) {
    char* start = *cursor;
    if (start == NULL) {
        return NULL;
    }
    char* end = strchr(start, delim);
    if (end == NULL) {
        *cursor = NULL;
    } else {
        *end = '\0';
        *cursor = end + 1;
    }
    return start;
}

返すトークンは元の文字列の一部なので、戻り値はトークンの先頭 start を指すポインタで足ります。この領域は呼び出し側の配列で、関数から戻っても寿命は続きます。strchr で区切り文字を探し、見つかればそこへ '\0' を書いてトークンを終端し、次の位置 end + 1 を *cursor に書きます。C の引数は値渡しなので、cursor 自身を進めても呼び出し側の p は動きません。p のアドレスを受け取っているから、*cursor への代入で p を進められます。これは参考実装で、唯一の正解ではありません。

終わりの判定では、空のトークンとトークンが無いことを区別します。*cursor が文字列の終端 '\0' を指していても、そこにはまだ空のトークンが1つ残っていることがあります。入力例2では、"x" を返したあとの *cursor は終端を指しており、ここで NULL を返すと末尾の "" が落ちます。そこで、区切り文字が見つからずに最後のトークンを返すときに *cursor を NULL にし、次の呼び出しは *cursor が NULL であることで終わりを知ります。入力例1では "a" を返したあと *cursor は2つ目の , を指し、そこですぐ区切り文字が見つかるので "" が返ります。残りの "b" には区切り文字が無いので *cursor が NULL になり、4回目で NULL が返ります。入力例3の空文字列も、区切り文字の無い最後のトークンとして "" を1回返します。
