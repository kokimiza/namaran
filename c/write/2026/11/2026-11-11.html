power_of_two.c

bool is_power_of_two(unsigned x) {
}

x が2の累乗(1, 2, 4, 8, …)なら true、そうでなければ false を返す is_power_of_two を、<stdbit.h> の関数を使って書いてください。x が0のときは false です。

入力例 1

is_power_of_two(64)

出力例 1

true

入力例 2

is_power_of_two(0)

出力例 2

false

入力例 3

is_power_of_two(96)

出力例 3

false

Reference

#include <stdbit.h>

bool is_power_of_two(unsigned x) {
    return stdc_count_ones(x) == 1;
}

2の累乗 2k を2進数で書くと、2k の位だけが1で、ほかの桁はすべて0です。逆に、1のビットがちょうど1つの数は、その桁の 2k そのものです。そこで stdc_count_ones で1のビットを数え、1と比べます。これは参考実装で、唯一の正解ではありません。

入力例を追うと、64 は 1000000 で1が1つなので true、96 は 1100000 で1が2つなので false です。0 は1のビットが1つも無いので、数えた結果は0になり、特別扱いしなくても false になります。stdc_count_ones は引数の型に合わせて働く総称の関数で、unsigned int を渡すと stdc_count_ones_ui と同じ結果を返します。

<stdbit.h> を使わない昔ながらの書き方は x != 0 && (x & (x - 1)) == 0 です。x - 1 は最下位の1を0にしてその下を1で埋めるので、1が1つだけなら & の結果が0になります。こちらは0を別に除く必要があります。C23 の stdc_has_single_bit を使えば、判定そのものを1回の呼び出しで書けます。
