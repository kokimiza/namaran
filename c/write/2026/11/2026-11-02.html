round_div.c

unsigned round_div(unsigned a, unsigned b) {
}

0以上の整数 a を正の整数 b で割った商 a/b を、小数第1位で四捨五入した整数を返す round_div を書いてください。ちょうど .5 になるときは切り上げます。浮動小数点数は使わず、unsigned の計算だけで求めます。a と b は1000000以下とします。

入力例 1

round_div(7, 2)

出力例 1

4

入力例 2

round_div(5, 3)

出力例 2

2

入力例 3

round_div(0, 4)

出力例 3

0
Reference 
unsigned round_div(unsigned a, unsigned b) {
    return (a + b / 2) / b;
}

unsigned どうしの割り算は小数部分を切り捨てます。切り捨ての前に割る数の半分 b / 2 を足しておくと、小数部分が .5 以上だった商だけが1つ繰り上がります。入力例1では 3.5 になる 7/2 が (7 + 1) / 2 = 4 に、入力例2では 1.66… になる 5/3 が (5 + 1) / 3 = 2 になります。

b が奇数のときは b / 2 が (b - 1)/2 に切り捨てられますが、結果は変わりません。余り a % b は整数なので、小数部分が .5 以上になる、余りが b/2 以上という条件は、余りが (b + 1)/2 以上という条件と同じです。余りに (b - 1)/2 を足して b に届くのも、ちょうどこのときです。

掲載したのは参考実装で、唯一の正解ではありません。(2 * a + b) / (2 * b) と書いても同じ値になりますが、2 * a が unsigned の範囲を超えないかを別に考える必要があります。
