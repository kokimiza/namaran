preorder.c

void preorder(const int* tree,
              int n,
              int* out) {
}

n 個の値を持つ二分木が配列 tree に入っています。tree[0] が根で、tree[i] の左の子は tree[2 * i + 1]、右の子は tree[2 * i + 2] です(添字が n 以上なら、その子はありません)。各節点を、自分、左の部分木、右の部分木の順にたどり、出会った値を順に out へ書く preorder を、再帰を使わずに書いてください。n は 0 以上 63 以下で、0 のときは何も書きません。例では tree と、呼び出し後の out の中身を {…} で書きます。

入力例 1

tree = {1, 2, 3, 4, 5}

出力例 1

out = {1, 2, 4, 5, 3}

入力例 2

tree = {7}

出力例 2

out = {7}

入力例 3

tree = {1, 2, 3, 4, 5, 6, 7}

出力例 3

out = {1, 2, 4, 5, 3, 6, 7}

void preorder(const int* tree,
              int n,
              int* out) {
    int stack[64];
    int top = 0;
    if (n > 0)
        stack[top++] = 0;
    while (top > 0) {
        int i = stack[--top];
        *out++ = tree[i];
        if (2 * i + 2 < n)
            stack[top++] = 2 * i + 2;
        if (2 * i + 1 < n)
            stack[top++] = 2 * i + 1;
    }
}

再帰で書けば、preorder は自分の値を書いてから左の子、右の子の順に自分を呼びます。左の子を呼んでいるあいだ、右の子を後で訪ねることはコールスタック上の自分のフレームが覚えています。参考実装はこの「あとで訪ねる節点」を配列 stack に積み、取り出した節点の値を書いてから、その子を積みます。掲載したのは参考実装で、唯一の正解ではありません。

スタックは最後に積んだものから取り出されるので、左の子を先に訪ねるには右の子を先に積みます。入力例 1 では、0 番の 1 を書いて 2 番(値 3)と 1 番(値 2)を積み、1 番を取り出して 2 を書き、4 番と 3 番を積みます。続いて 4、5 を書き終えると、最初に積んだ値 3 の節点が最後に残り、{1, 2, 4, 5, 3} になります。n が 0 なら根を積まないので、ループは一度も回りません。積まれたまま残る節点は、根から葉までの各段につき高々1個(右の子)と取り出し待ちの1個なので、63 個の木でも stack の 64 要素で足ります。
