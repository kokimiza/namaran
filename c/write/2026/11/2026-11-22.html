build.c

void build(int* t, int n) {
}

配列 t の t[n] から t[2 * n - 1] に、n 個の値が入っています。節点 k の子を 2 * k と 2 * k + 1 とし、t[n] 以降を葉とする木だと考えて、t[1] から t[n - 1] のそれぞれに、その節点の2つの子の小さいほうの値を入れる build を書いてください。t[0] は使いません。n が 1 のときは、埋める節点がありません。例では、build を呼ぶ前と後の t の中身を t[0] から順に書きます。

入力例 1

{0, 0, 0, 0, 7, 3, 9, 1}, n = 4

出力例 1

{0, 1, 3, 1, 7, 3, 9, 1}

入力例 2

{0, 0, 0, 4, 6, 2}, n = 3

出力例 2

{0, 2, 2, 4, 6, 2}

入力例 3

{0, 5}, n = 1

出力例 3

{0, 5}

void build(int* t, int n) {
    for (int k = n - 1; k >= 1; k--) {
        int l = t[2 * k], r = t[2 * k + 1];
        t[k] = l < r ? l : r;
    }
}

節点 k の値は、子の t[2 * k] と t[2 * k + 1] が決まっていないと計算できません。子の番号は親より必ず大きいので、k を n - 1 から 1 へ向かって小さくしながら埋めれば、どの節点に来たときも2つの子はもう埋まっています。k を 1 から増やす向きに回すと、t[1] を計算する時点で t[2] と t[3] はまだ 0 で、根に 0 が入ります。掲載したのは参考実装で、唯一の正解ではありません。子2つの小さいほうを返す関数を別に用意してもかまいません。

入力例2の n = 3 では、葉が t[3] から t[5] です。k = 2 で t[4] と t[5] の小さいほうの 2 が入り、続く k = 1 では t[2] の 2 と t[3] の 4 を比べて 2 が入ります。t[3] は葉のまま根の子になっていて、n が2の累乗でなくても、根には全体の最小値が入ります。n が 1 のときはループが1回も回らず、葉の t[1] はそのまま残ります。
