digits.c

int digits(unsigned n) {
}

unsigned の値 n を10進数で書いたときの桁数を返す digits を、ループを使わずに再帰で書いてください。0 は1桁と数えます。

入力例 1

digits(2026)

出力例 1

4

入力例 2

digits(7)

出力例 2

1

入力例 3

digits(0)

出力例 3

1
Reference 時間計算量 𝒪(d) 空間計算量 𝒪(d) d は n の桁数

Reference

int digits(unsigned n) {
    if (n < 10)
        return 1;
    return 1 + digits(n / 10);
}

n / 10 は n の一の位を切り捨てた数で、桁がちょうど1つ少なくなります。そこで、n の桁数を「n / 10 の桁数に 1 を足したもの」と考え、再帰で n を小さくしていきます。止めるのは n が1桁になったときで、そこでは答えが 1 と分かっています。掲載したのは参考実装で、唯一の正解ではありません。

基底ケースを n == 0 にして 0 を返す書き方もよく見かけますが、その形では digits(0) が 0 になり、入力例3を満たしません。0 を1桁と数えるには、「1桁の数」を基底ケースにして 1 を返すのが素直です。digits(2026) は 2026, 202, 20, 2 と4回呼ばれ、2 で止まって 1 + 1 + 1 + 1 = 4 を返します。

unsigned の最大値は環境によって違いますが、どの値でも呼び出しは桁数の回数だけしか重ならず、32ビットなら最大でも10回です。値が大きくても再帰が深くなりすぎることはなく、足し算も桁数までしか増えないので、あふれることもありません。
