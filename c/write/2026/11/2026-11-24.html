long long binom(int n, int k) {
}

異なる n 個から k 個を選ぶ組合せの数 nCk を返す binom を書いてください。k が 0 か n のときは 1、それ以外は binom(n - 1, k - 1) + binom(n - 1, k) として再帰的に求めます。引数は 0 <= k <= n <= 60 を満たします。同じ (n, k) を二度計算しないよう、求めた値はグローバル配列 memo に覚えてください。memo の要素は最初すべて 0 です。

入力例 1

binom(5, 2)

出力例 1

10

入力例 2

binom(60, 30)

出力例 2

118264581564861424

入力例 3

binom(4, 0)

出力例 3

1

long long memo[61][61];

long long binom(int n, int k) {
    if (k == 0 || k == n) {
        return 1;
    }
    if (memo[n][k] == 0) {
        memo[n][k] = binom(n - 1, k - 1) +
            binom(n - 1, k);
    }
    return memo[n][k];
}

memo[n][k] には nCk を覚えます。組合せの数は 1 以上なので、0 のままの要素は「まだ計算していない」印に使えます。0 なら関係式で計算して memo[n][k] に入れ、どちらの場合も最後に memo[n][k] を返します。値が決まるのは n と k の組なので、表も2つの添字で引く2次元配列にします。掲載したのは参考実装で、唯一の正解ではありません。

入力例1の binom(5, 2) は binom(4, 1) と binom(4, 2) の和になり、それぞれがさらに n が1小さい組を呼び出して、最後は 10 になります。入力例2の binom(60, 30) は、表が無いと同じ組を何度も計算し直し、呼び出しの回数は答えと同じ 1017 程度になって終わりません。表があれば、各 (n, k) を計算するのは1回だけなので、計算は 60 × 61 個以下の組で済みます。入力例3は k が 0 なので、表を見る前に 1 を返します。
