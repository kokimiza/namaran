write_all.c

bool write_all(size_t (*write_some)(const char*, size_t), const char* data, size_t len) {
}

write_some(p, n) は、p から始まる n バイトのうち先頭の一部(1バイト以上 n バイト以下)を書き、書いたバイト数を返します。何も書けなかったときは0を返します。この write_some を使って、data の len バイトを順に最後まで書く write_all を書いてください。全部書けたら true を、途中で write_some が0を返したら false を返します。len が0のときは何も書かずに true です。例の up_to_3 は1回に最大3バイトまで書く関数、full は常に0を返す関数です。

入力例 1

write_all(up_to_3, "hello", 5)

出力例 1

true

入力例 2

write_all(full, "hi", 2)

出力例 2

false

入力例 3

write_all(full, "", 0)

出力例 3

true
Reference 
bool write_all(size_t (*write_some)(const char*, size_t), const char* data, size_t len) {
    while (len > 0) {
        size_t n = write_some(data, len);
        if (n == 0) {
            return false;
        }
        data += n;
        len -= n;
    }
    return true;
}

write_some が一度に全部を書くとは限らないので、書けたバイト数 n だけ data を進め、len を減らして、残りがなくなるまで呼び直します。入力例1では "hel" の3バイト、"lo" の2バイトと2回に分けて書かれます。data を進め忘れると、2回目にまた先頭の "he" を書いてしまいます。

0が返ったときに止めないと、data も len も変わらないまま同じ呼び出しを繰り返し、ループが終わりません。入力例2がその場合で、ここで false を返します。len が0なら最初から while の条件が偽なので、入力例3は write_some を1度も呼ばずに true を返します。

掲載したのは参考実装で、唯一の正解ではありません。data を書き換えずに、書き終えた位置を表す添字を別の変数で持ってもかまいません。
