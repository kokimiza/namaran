for_all.c

bool for_all(int lo,
             int hi,
             bool (*p)(int)) {
}

lo 以上 hi 以下のすべての整数 x で p(x) が真なら true、1つでも偽になる x があれば false を返す for_all を書いてください。lo が hi より大きく、調べる整数が1つも無いときは true を返します。例の is_pos は、引数が正のときに真を返す関数です。

入力例 1

for_all(1, 10, is_pos)

出力例 1

true

入力例 2

for_all(-1, 1, is_pos)

出力例 2

false

入力例 3

for_all(5, 4, is_pos)

出力例 3

true

bool for_all(int lo,
             int hi,
             bool (*p)(int)) {
    for (long long x = lo; x <= hi; x++) {
        if (!p((int)x)) {
            return false;
        }
    }
    return true;
}

引数の bool (*p)(int) は、int を受け取って bool を返す関数へのポインタです。呼び出すときは普通の関数と同じく p(x) と書けます。範囲の整数を小さい順に試し、偽を返す x が見つかった時点で false を返します。最後まで見つからなければ true です。掲載したのは参考実装で、唯一の正解ではありません。

入力例2では、最初の -1 で is_pos が偽を返すので、0 と 1 を調べずに false になります。入力例3は lo が hi より大きいので、ループ本体が一度も実行されず、そのまま true を返します。反例が1つも無いことが「すべてで成り立つ」ことなので、調べる整数が無い範囲は成り立つ側に入ります。ループ変数を long long にしたのは、hi が INT_MAX のときに x++ が int の範囲を越えないようにするためです。int のままだと、INT_MAX を調べたあとの x++ が未定義動作になります。
