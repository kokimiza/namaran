lex_number.c

long lex_number(const char **cursor) {
}

字句解析器の一部として、*cursor が指す位置から10進の数字が続く限り読み、その値を返す lex_number を書いてください。呼び出し後の *cursor は、読んだ数字の直後を指すようにします。*cursor の先頭は必ず数字で、値は long に収まるものとします。"123+4" → 戻り値 123、*cursor は "+4"。"7" → 7、*cursor は終端の ""。"08x" → 8、*cursor は "x"。

#include <ctype.h>

long lex_number(const char **cursor) {
    const char *p = *cursor;
    long value = 0;
    while (isdigit((unsigned char)*p)) {
        value = value * 10 + (*p - '0');
        p++;
    }
    *cursor = p;
    return value;
}

const char **cursor は、字句解析器が持っている「どこまで読んだか」を指すポインタへのポインタです。関数の中では *cursor をローカルの p に写して読み進め、最後に *cursor = p で呼び出し側のカーソルを書き換えます。Cの関数が返せる値は1つだけなので、読んだ値は戻り値で、次のトークンの開始位置は引数のポインタ越しに返しています。

isdigit に char をそのまま渡さず unsigned char にキャストしているのは、char が符号付きの処理系で負の値を渡すと未定義動作になるからです。数字1文字の値は *p - '0' で求まります。'0' から '9' までが連続した値であることは規格が保証しているので、文字コードには依存しません。

これは参考実装で、唯一の正解ではありません。strtol を基数10で呼び、第2引数で受け取った終了位置をカーソルに書き戻す方法もあります。ただし strtol は先頭の空白や符号も読むので、字句解析器の中で使うなら、その分の違いを意識しておく必要があります。
