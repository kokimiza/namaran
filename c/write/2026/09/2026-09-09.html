unique_ids.c

#include <stdlib.h>

size_t unique_ids(int *ids, size_t n) {
}

N+1クエリを1本の WHERE id IN (...) にまとめるために、注文が参照するユーザーIDの配列から重複を除きます。ids の先頭 n 要素を昇順に並べ替え、重複を除いた値を配列の先頭に詰めて、残った個数を返す unique_ids を書いてください。n が0のときは何もせず0を返します。{7, 3, 7, 9, 3}, n = 5 → 戻り値 3、先頭は {3, 7, 9}、{5, 5}, n = 2 → 戻り値 1、先頭は {5}、n = 0 → 0

static int cmp_int(const void *a, const void *b) {
    int x = *(const int *)a;
    int y = *(const int *)b;
    return (x > y) - (x < y);
}

size_t unique_ids(int *ids, size_t n) {
    if (n == 0) {
        return 0;
    }
    qsort(ids, n, sizeof ids[0], cmp_int);
    size_t k = 1;
    for (size_t i = 1; i < n; i++) {
        if (ids[i] != ids[k - 1]) {
            ids[k++] = ids[i];
        }
    }
    return k;
}

並べ替えは標準ライブラリの qsort に任せます。k はそこまでに残した個数で、ids[k - 1] が最後に残した値です。並べ替えたあとは同じ値が隣り合うので、ids[k - 1] と違う値だけを前へ詰めていけば重複が消えます。

比較関数は void * で受け取った引数を const int * に戻して比べ、負・0・正のどれかを返します。return x - y; と書くと、INT_MIN と INT_MAX のように符号の違う大きな値どうしで引き算が int の範囲を超えます。符号つき整数のオーバーフローは未定義動作です。(x > y) - (x < y) なら0か1の比較結果どうしの引き算なので、どんな値でも -1、0、1 のどれかになります。

n == 0 を先に返しているのは、ids が NULL のときに qsort へ渡さないためです1。これは参考実装であり、唯一の正解ではありません。元の並び順を保ちたいなら、既に残した値の中にあるかを二重ループで確かめる書き方もあり、IDが数十件ならそれで十分です。

  1. C23までは、要素数が0でも qsort に渡すポインタは有効でなければならず、NULL を渡すと未定義動作です。
