int increment(char* s) {
}

s は数字の文字だけからなる1文字以上の文字列で、走行距離計のように桁数の決まった10進数を表します。s の表す数に1を足し、同じ桁数のまま s に書き戻す increment を書いてください。返り値はふだん 0 です。すべての桁が 9 だったときは桁があふれるので、全桁を 0 にして 1 を返します。

入力例 1

char s[] = "0129";
increment(s)

出力例 1

0
s == "0130"

入力例 2

char s[] = "0999";
increment(s)

出力例 2

0
s == "1000"

入力例 3

char s[] = "999";
increment(s)

出力例 3

1
s == "000"
Reference 
int increment(char* s) {
    for (size_t i = strlen(s); i-- > 0;) {
        if (s[i] != '9') {
            s[i]++;
            return 0;
        }
        s[i] = '0';
    }
    return 1;
}

文字列を数に直してから1を足すと、"0129" の先頭の 0 が消えるうえ、桁数が long long に収まらない長さの文字列も扱えません。そこで文字のまま、一の位から足していきます。C の規格は '0' から '9' の文字コードが連続して並ぶことを保証しているので、'0' から '8' までの文字は s[i]++ でそのまま次の数字になります。

この保証は '9' の次までは届きません。'9' に1を足した文字は数字ではなく、ASCII なら ':' です。'9' の桁は '0' に戻し、1を1つ上の桁へ繰り上げます。参考実装では、'9' 以外の桁に出会うまでループを続けることが繰り上がりにあたり、出会った桁を進めた時点で 0 を返して終えます。ループを最後まで回りきるのは全桁が '9' のときだけで、そのときは全桁が '0' になっているので、そのまま 1 を返せば済みます。

i は size_t なので、i >= 0 を条件にすると常に真になります。i-- > 0 と書くと、比べてから減らすので、本体の中の i は strlen(s) - 1 から 0 までを動きます。掲載したのは参考実装で、唯一の正解ではありません。int の添字で後ろから回す書き方や、繰り上がりを変数に持って全桁を回す書き方もあります。
