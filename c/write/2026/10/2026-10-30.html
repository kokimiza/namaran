count_if.c

size_t count_if(const int* a, size_t n, bool (*pred)(int)) {
}

配列 a の先頭 n 個の要素のうち、pred に渡すと true が返るものの個数を返す count_if を書いてください。n が0のときは0を返し、a の要素を読みません。例の is_even は偶数のときに、is_positive は正の数のときに true を返す関数です。

入力例 1

count_if((int[]){1, 2, 3, 4}, 4, is_even)

出力例 1

2

入力例 2

count_if((int[]){-3, 5, 0}, 3, is_positive)

出力例 2

1

入力例 3

count_if(nullptr, 0, is_even)

出力例 3

0
Reference 
size_t count_if(const int* a, size_t n, bool (*pred)(int)) {
    size_t count = 0;
    for (size_t i = 0; i < n; i++) {
        if (pred(a[i])) {
            count++;
        }
    }
    return count;
}

count_if が受け持つのは、要素を先頭から順に見て数えることだけです。どの要素を数えるかは pred が決めるので、偶数を数えるときも正の数を数えるときも、ループを書き直す必要はありません。関数ポインタを通した呼び出しは、普通の関数と同じく pred(a[i]) と書けます。

引数の型 bool (*pred)(int) は、int を1つ受け取って bool を返す関数へのポインタです。*pred を囲む括弧を外すと、bool * を返す関数を表す別の型になります。n が0のときはループの本体が一度も実行されないので、a が nullptr でも要素を読むことはなく、0が返ります。

掲載したのは参考実装で、唯一の正解ではありません。添字の代わりにポインタを進めて走査する書き方や、count += pred(a[i]); のように bool を数として足す書き方でも同じ結果になります。
