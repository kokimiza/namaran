xor_swap.c

void xor_swap(unsigned *a, unsigned *b) {
}

一時変数を使わず、XOR演算子 ^ だけで *a と *b の値を入れ替える xor_swap を書いてください。a と b が同じ変数を指しているときは、その変数の値を変えずに残します。

入力例 1

unsigned x = 3, y = 5; xor_swap(&x, &y);

出力例 1

x == 5, y == 3

入力例 2

unsigned z = 7; xor_swap(&z, &z);

出力例 2

z == 7

入力例 3

unsigned p = 0, q = 9; xor_swap(&p, &q);

出力例 3

p == 9, q == 0
Reference 
void xor_swap(unsigned *a, unsigned *b) {
    if (a == b) return;
    *a ^= *b;
    *b ^= *a;
    *a ^= *b;
}

値が x と y なら、1行目で *a が x ^ y になり、2行目の *b は y ^ x ^ y で、同じ値どうしのXORが打ち消し合って x になります。3行目の *a も同じように x ^ y ^ x から y になり、入れ替えが済みます。

この計算は、*a と *b が別の場所にあることを前提にしています。同じ変数を指していると、1行目の *a ^= *b がその変数を自分自身とXORし、元の値を0で上書きしてしまいます。そこで最初にポインタどうしを比べ、同じ場所なら何もせずに戻ります。比べるのが値でなくポインタなのは、壊れるのが同じ場所を指すときだけだからです。別々の変数なら、値が等しくても3行の計算は正しく働きます。

掲載したのは参考実装で、唯一の正解ではありません。たとえば if (a != b) { … } で3行を囲んでも同じです。実際のコードで交換が必要なら、一時変数を使う方が読みやすく、同じ場所どうしの交換でも壊れません。
