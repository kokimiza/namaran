append.c

char *append(char *end, const char *src) {
}

src の文字列を終端のヌル文字まで end の位置へ写し、写したヌル文字を指すポインタを返す append を書いてください。返り値を次の呼び出しの end に渡せば、連結を重ねても書き込み先を先頭から探し直さずに済みます。src が空文字列なら、ヌル文字だけを写して end をそのまま返します。書き込み先の大きさは足りているものとし、例の buf は char buf[16] = ""; です。

入力例 1

append(append(buf, "ab"), "cde") - buf

出力例 1

5

入力例 2

append(buf, "") - buf

出力例 2

0

入力例 3

append(append(buf, "na"), "ran"); puts(buf);

出力例 3

Reference 
char *append(char *end, const char *src) {
    while ((*end = *src++))
        end++;
    return end;
}

ループの条件 (*end = *src++) は、代入した文字そのものを値に持ちます。偽になるのはヌル文字を写した回だけなので、end++ はヌル文字の手前までしか進まず、返す end は写したヌル文字の上で止まります。条件の中で *end++ = *src++ と書くと、ヌル文字を写した回にも end が進み、ヌル文字の1つ先を返してしまいます。次の連結はヌル文字の後ろに書かれ、文字列としては見えなくなります。

標準の strcat(dst, src) は dst を返すので、続けて連結するたびに dst の先頭からヌル文字を探し直します。同じ長さの文字列を n 回つなぐと、探し直しで読む文字数の合計は n の2乗に比例して増えます。append は末尾を返すので、どの文字も一度写すだけで済みます。

掲載したのは参考実装で、唯一の正解ではありません。strlen で長さを測ってから memcpy でヌル文字ごと写し、end + n を返す書き方もあります。POSIX には同じ働きの stpcpy があります。
