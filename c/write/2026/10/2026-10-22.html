double の値を受け取り、それが -0.0 なら +0.0 を、それ以外なら受け取った値をそのまま返す normalize_zero を書いてください。+0.0 を受け取ったときは +0.0 を返します。出力例は、返り値を printf("%g", ...) で書いたものです。

入力例 1

normalize_zero(-0.0)

出力例 1

0

入力例 2

normalize_zero(0.0)

出力例 2

0

入力例 3

normalize_zero(-2.5)

出力例 3

-2.5
Reference 
double normalize_zero(double x) {
    return x == 0.0 ? 0.0 : x;
}

-0.0 を見分けようとして x < 0.0 と書くと、-0.0 < 0.0 は偽なので、負の0はそのまま返ってしまいます。比較演算は +0.0 と -0.0 を等しい値として扱うからです。この規則を逆に使えば、x == 0.0 は2つの0のどちらでも真になります。そのときは符号を気にせず、リテラルの 0.0(正の0)を返せば揃います。0でない値は比較が偽になり、そのまま返ります。

掲載したのは参考実装で、唯一の正解ではありません。return x + 0.0; の1行でも同じ結果になります。IEEE 754 の既定の丸めでは、-0.0 + 0.0 の和は +0.0 と決まっているからです1。符号だけを調べたいときは、<math.h> の signbit が -0.0 に対して0でない値を返します。

  1. 符号の違う0どうしの和は、最も近い値への丸め(既定の丸めモード)では +0.0、負の無限大方向への丸めでは -0.0 と IEEE 754 が定めています。丸めモードを fesetround で変えるプログラムでは、x + 0.0 の書き方は使えません。
