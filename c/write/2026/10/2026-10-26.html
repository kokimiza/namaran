color_name.c

#define COLORS(X) X(red) X(green) X(blue)
#define AS_ENUM(name) COLOR_##name,
enum color { COLORS(AS_ENUM) };

const char* color_name(enum color c) {
}

COLORS は色の一覧を1か所に持つマクロで、enum color はそこから COLOR_red などの列挙子を作っています。列挙値 c を受け取り、その色の名前(COLOR_green なら "green")を返す color_name を書いてください。COLORS に色を足したとき、color_name を直さなくても新しい色の名前を返せるようにします。どの列挙子にも当たらない値には "?" を返します。

入力例 1

color_name(COLOR_green)

出力例 1

"green"

入力例 2

color_name(COLOR_red)

出力例 2

"red"

入力例 3

color_name((enum color)3)

出力例 3

"?"
Reference 
const char* color_name(enum color c) {
#define AS_CASE(name)  \
    case COLOR_##name: \
        return #name;
    switch (c) { COLORS(AS_CASE) }
#undef AS_CASE
    return "?";
}

COLORS(X) は、渡されたマクロ X を色ごとに1回ずつ呼びます。color_name の中で色1つ分の case を作るマクロ AS_CASE を定義して COLORS に渡すと、switch の中に case COLOR_red: return "red"; のような行が色の数だけ並びます。COLOR_##name は COLOR_ と色の名前を貼り合わせて列挙子の名前にし、#name は色の名前を文字列リテラルにします。

どの case にも当たらない値は switch を抜け、最後の return "?"; に届きます。AS_CASE はこの関数の中でしか使わないので、使い終わったら #undef で消しておきます。色を COLORS に足せば、enum color の列挙子と case が同じ一覧から一緒に増えます。

掲載したのは参考実装で、唯一の正解ではありません。#name, を並べた文字列の配列を作り、c が範囲内かを確かめてから添字で引く書き方もあります。
