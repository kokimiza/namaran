elapsed.c

int64_t elapsed_ns(struct timespec start, struct timespec end) {
}

処理の前後に取った2つの時刻 start と end から、経過時間をナノ秒で返す elapsed_ns を書いてください。どちらの tv_nsec も0以上10億未満で、end は start と同じか、それより後の時刻です。同じ時刻なら0を返します。例では struct timespec の値を {tv_sec, tv_nsec} の形で書きます。

入力例 1

elapsed_ns({1, 900000000}, {2, 100000000})

出力例 1

200000000

入力例 2

elapsed_ns({5, 250}, {5, 250})

出力例 2

0

入力例 3

elapsed_ns({3, 0}, {10, 500})

出力例 3

7000000500
Reference 
int64_t elapsed_ns(struct timespec start, struct timespec end) {
    return (int64_t)(end.tv_sec - start.tv_sec) * 1000000000 + (end.tv_nsec - start.tv_nsec);
}

秒の差に10億を掛けてナノ秒にし、そこにナノ秒の差を足します。入力例1のように秒の境目をまたぐと、ナノ秒の差は 100000000 - 900000000 = -800000000 と負になります。秒の差の1秒を10億ナノ秒にしてから足すので、繰り下がりを自分で書かなくても 1000000000 - 800000000 = 200000000 になります。

掛け算の前に int64_t へ変換しているのは、time_t が32ビットの処理系でも掛け算を64ビットで行うためです。入力例3の7秒は、10億を掛けると約70億になり、32ビットの整数には収まりません。

掲載したのは参考実装で、唯一の正解ではありません。tv_nsec の差が負のときに秒から1を借りて10億を足す、と繰り下がりを書いてから単位をそろえてもかまいません。
