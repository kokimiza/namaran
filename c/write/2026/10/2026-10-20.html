swap.c

#define SWAP(a, b) \

2つの変数の値を入れ替えるマクロ SWAP(a, b) を、1行目に続けて書いてください。a と b には同じ型の左辺値が来て、型は int に限らず double や構造体でもかまいません。どちらの引数の式もちょうど1回だけ評価し、if と else の間に SWAP(x, y); と書いても1つの文として働くようにします。

入力例 1

int x = 1, y = 2; SWAP(x, y);

出力例 1

x == 2, y == 1

入力例 2

int a[] = {10, 20, 30}; int i = 0; SWAP(a[i++], a[2]);

出力例 2

a == {30, 20, 10}, i == 1

入力例 3

double p = 0.5, q = 1.5; if (p < q) SWAP(p, q); else p = 0;

出力例 3

p == 1.5, q == 0.5
Reference 
#define SWAP(a, b) \
    do { \
        auto swap_pa_ = &(a); \
        auto swap_pb_ = &(b); \
        auto swap_t_ = *swap_pa_; \
        *swap_pa_ = *swap_pb_; \
        *swap_pb_ = swap_t_; \
    } while (0)

両方の引数のアドレスを最初に1回ずつ取り、そのあとはポインタを通して読み書きします。&(a) を auto で受けると、a が int なら int *、double なら double * になるので、型を引数で渡さなくても1つの定義でどの型にも使えます。

値を一時変数に移す auto t = (a); (a) = (b); (b) = t; でも型は合いますが、展開すると a が2回現れます。入力例 2 では a[i++] が2回評価されて i が2まで進み、t に読み出すのは a[0] なのに、a[2] の値を書き込む先は a[1] になり、結果は {10, 30, 10} です。アドレスを先に取っておけば、添字の計算も i++ も1回で済みます。

全体を do と while (0) で包むのは入力例 3 のためです。波括弧だけで包むと、if の文は } で終わり、SWAP(p, q); の最後の ; は別の空の文になります。その後ろの else には対応する if がなく、コンパイルできません。do { ... } while (0) は後ろに ; を1つ要求する1つの文なので、関数呼び出しと同じ書き方で置けます。

内部の変数に swap_pa_ のような名前を付けているのは、呼び出し側の名前と重ならないようにするためです。内部の名前が pa だと、SWAP(pa, x) は auto pa = &(pa); に展開され、初期化子の pa は呼び出し側の変数ではなく、いま宣言している変数を指してしまいます。

掲載したのは参考実装で、唯一の正解ではありません。C23 の typeof を使い、typeof(a) *swap_pa_ = &(a); のように書いても同じように動きます。
