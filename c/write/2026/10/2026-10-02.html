max_of.c

#include <stddef.h>

bool max_of(const int *a, size_t n, int *out) {
}

長さ n の int の配列 a の最大値を *out に書き、true を返す max_of を書いてください。n が 0 のときは *out に書き込まずに false を返します。このとき a は NULL のこともあります。

入力例 1

int m = -1; bool ok = max_of((int[]){3, 9, 4}, 3, &m); printf("%d %d\n", ok, m);

出力例 1

1 9

入力例 2

int m = -1; bool ok = max_of((int[]){-5, -8}, 2, &m); printf("%d %d\n", ok, m);

出力例 2

1 -5

入力例 3

int m = -1; bool ok = max_of(NULL, 0, &m); printf("%d %d\n", ok, m);

出力例 3

0 -1
Reference 
#include <stddef.h>

bool max_of(const int *a, size_t n, int *out) {
    if (n == 0)
        return false;
    int best = a[0];
    for (size_t i = 1; i < n; i++)
        if (a[i] > best)
            best = a[i];
    *out = best;
    return true;
}

先に n == 0 を調べて false を返します。この判定より前に a[0] を読むと、例3のように a が NULL のときにヌルポインタを参照してしまいます。空でないと分かってから best を a[0] で初期化し、残りの要素と比べます。

best を 0 や INT_MIN のような決まった値から始める書き方は使えません。0 から始めると、例2の -5 が 0 に負けます。INT_MIN は配列に入っていてもおかしくない値なので、空の配列と {INT_MIN} を返り値で区別できなくなります。成否は返り値で、値は *out で返すと分けておけば、どの int も最大値として返せます。

掲載したのは参考実装で、唯一の正解ではありません。最大値の代わりに添字を返す書き方や、ループを 0 から回して最初の要素だけ別に扱う書き方もあります。
