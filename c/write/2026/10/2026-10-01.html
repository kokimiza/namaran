resume.c

void resume_reverse(int *a, size_t n, size_t done) {
}

長さ n の配列をその場で反転する処理は、i = 0 から順に a[i] と a[n - 1 - i] を交換していきます。この処理が done 組の交換を終えたところで中断されました。中断された時点の配列 a を受け取り、残りの交換だけを行って反転を完成させる resume_reverse を書いてください。done は 0 以上 n / 2 以下で、n / 2 に等しいときは反転がもう終わっているので、配列を変えません。

入力例 1

int a[] = {5, 2, 3, 4, 1}; resume_reverse(a, 5, 1);

出力例 1

{5, 4, 3, 2, 1}

入力例 2

int a[] = {6, 5, 3, 4, 2, 1}; resume_reverse(a, 6, 2);

出力例 2

{6, 5, 4, 3, 2, 1}

入力例 3

int a[] = {4, 3, 2, 1}; resume_reverse(a, 4, 2);

出力例 3

{4, 3, 2, 1}
Reference 
void resume_reverse(int *a, size_t n, size_t done) {
    for (size_t i = done; i < n / 2; i++) {
        int t = a[i];
        a[i] = a[n - 1 - i];
        a[n - 1 - i] = t;
    }
}

中断されるまでに、i が 0 から done - 1 までの交換は済んでいます。残っているのは i が done から n / 2 - 1 までの交換なので、ループの初期値を 0 から done に変えれば、元の反転の続きになります。例3のように done が n / 2 なら、ループは一度も回りません。

最初から反転し直してはいけません。交換はもう一度行うと元に戻る操作なので、済んだ組まで交換すると、そこだけ中断前の並びに戻ります。例1の配列を頭から反転すると {1, 4, 3, 2, 5} になり、両端が崩れます。

n が奇数のとき、真ん中の要素は動かしません。ループの終わりを n / 2 にしておけば、整数の割り算で真ん中が数えられず、自分自身との交換も起きません。

掲載したのは参考実装で、唯一の正解ではありません。左右の添字を done と n - 1 - done から始め、両側から内側へ近づけていく書き方もあります。
