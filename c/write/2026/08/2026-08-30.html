stats_restart.c

struct stats {
    int count;
    int min;
    int max;
    long sum;
};

void stats_restart(struct stats* s, int first) {
}

件数・最小値・最大値・合計を持つ struct stats を、値 first の1件だけを数えた状態に戻す stats_restart を書いてください。呼ぶ前に *s に入っていた値は使いません。例では、呼んだあとの *s の中身を {count, min, max, sum} の順で書きます。

入力例 1

stats_restart(&s, 5)

出力例 1

{1, 5, 5, 5}

入力例 2

stats_restart(&s, -2)

出力例 2

{1, -2, -2, -2}

void stats_restart(struct stats* s, int first) {
    *s = (struct stats){.count = 1, .min = first, .max = first, .sum = first};
}

struct stats s = {.count = 1, .min = 5, .max = 5, .sum = 5}; のような波括弧の初期化子は、宣言で変数を作るときにしか書けません。すでにある *s に *s = {.count = 1, ...}; と書くとコンパイルエラーです。そこで (struct stats){...} と型名を括弧で前に置き、複合リテラルにします。複合リテラルは、その初期化子で初期化した名前の無い struct stats のオブジェクトを作る式です。構造体は配列と違って代入できるので、このオブジェクトを *s へ丸ごとコピーすれば、初期化子の形のまま全メンバを書き換えられます。

複合リテラルの中身は宣言の初期化子と同じ規則で決まり、指定しなかったメンバは 0 になります。あとで struct stats にメンバを足したとき、stats_restart を直し忘れても、そのメンバは前の値を引きずらず 0 に戻ります。入力例 2 の -2 も、.sum = first で int から long へ変換されて -2 のまま入ります。掲載したのは参考実装で、唯一の正解ではありません。s->count = 1; から s->sum = first; までメンバごとに4行で代入しても、同じ結果になります。
