finish_time.c

int finish_time(const int arrive[], const int work[], int n) {
}

窓口が1つだけの受付に、仕事が到着順に並んで届きます。i 番目の仕事は時刻 arrive[i] に届き、片付けるのに work[i] だけ時間がかかります。窓口は届いた順に1件ずつ片付け、手が空いていれば届いた仕事にすぐ取りかかり、前の仕事が終わっていなければ終わるまで待たせます。最後の仕事が終わる時刻を返す finish_time を書いてください。時刻は0から始まり、arrive は小さい順に並んでいます。仕事が1件もない（n が0の）ときは0を返します。

入力例 1

finish_time((int[]){0, 1, 5}, (int[]){3, 2, 1}, 3)

出力例 1

6

入力例 2

finish_time((int[]){2, 2}, (int[]){4, 1}, 2)

出力例 2

7

入力例 3

finish_time(nullptr, nullptr, 0)

出力例 3

0
Reference 
int finish_time(const int arrive[], const int work[], int n) {
    int now = 0;
    for (int i = 0; i < n; i++) {
        if (now < arrive[i])
            now = arrive[i];
        now += work[i];
    }
    return now;
}

now は、窓口の手が空く時刻です。仕事 i に取りかかれるのは、その仕事が届いた時刻 arrive[i] と、前の仕事が終わった時刻 now の遅いほうです。窓口が先に空いていれば届くまで待つので now を arrive[i] まで進め、仕事のほうが先に届いていれば now のまま取りかかります。どちらの場合も、そこから work[i] だけ進んだ時刻に手が空きます。

入力例 1 では、1件目が時刻0から3まで、2件目は時刻1に届いて3まで待ち、3から5までかかります。3件目は時刻5に届き、窓口はちょうど空いているので5から6までで、6を返します。入力例 2 は2件が同じ時刻2に届く場合で、2件目は1件目が終わる6まで待ち、7に終わります。n が0ならループは1回も回らず、now の初期値0が返ります。

掲載したのは参考実装で、唯一の正解ではありません。if の代わりに、取りかかる時刻を三項演算子で now = (now < arrive[i] ? arrive[i] : now) + work[i]; と1行で書くこともできます。
