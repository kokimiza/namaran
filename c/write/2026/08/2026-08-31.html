add_months.c

struct date {
    int y, m, d;
};

struct date add_months(struct date t, int n) {
}

年 y、月 m(1〜12)、日 d の正しい日付 t に、0以上の整数 n か月を足した日付を返す add_months を書いてください。行き先の月は m から n か月進めた月で、12月を越えたら年が進みます。日は次の決まりで選びます。t がその月の末日なら、行き先の月の末日にします。そうでなければ d のままにし、行き先の月に d 日が無ければその月の末日にします。n が0なら t をそのまま返します。閏年は、4で割り切れる年のうち、100で割り切れて400で割り切れない年を除いたものです。

入力例 1

add_months((struct date){2025, 1, 31}, 1)

出力例 1

{2025, 2, 28}

入力例 2

add_months((struct date){2025, 2, 28}, 1)

出力例 2

{2025, 3, 31}

入力例 3

add_months((struct date){2024, 2, 28}, 1)

出力例 3

{2024, 3, 28}

struct date {
    int y, m, d;
};

static int days_in(int y, int m) {
    static const int days[] = {31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
    bool leap = y % 4 == 0 && (y % 100 != 0 || y % 400 == 0);
    return m == 2 && leap ? 29 : days[m - 1];
}

struct date add_months(struct date t, int n) {
    int k = t.m - 1 + n;
    struct date r = {t.y + k / 12, k % 12 + 1, t.d};
    int last = days_in(r.y, r.m);
    if (t.d == days_in(t.y, t.m) || r.d > last) {
        r.d = last;
    }
    return r;
}

日を選ぶには月の日数が2回要ります。起点が月末かどうかを決める t の月の日数と、頭打ちにする行き先の月の日数です。そこで月の日数を返す days_in を先に用意し、2月だけは閏年の規則で29日にします。行き先の年と月は、月を0始まりに直した k = t.m - 1 + n を12で割った商と余りで求めます。1始まりのまま (t.m + n) % 12 とすると、12月が0月になってしまいます。n は0以上なので、k も負にならず、C の / と % をそのまま使えます。これは参考実装で、唯一の正解ではありません。

入力例1の1月31日は月末なので、行き先の2025年2月の末日の28日になります。入力例2の2025年2月28日も月末で、3月の末日の31日へ進みます。入力例3は同じ2月28日でも、2024年は閏年なので2月の末日は29日で、28日は月末ではありません。日は28日のまま残り、3月には28日があるので {2024, 3, 28} です。t.d == 28 && t.m == 2 のように日付の形で月末を判定すると、この例を間違えます。n が0のときは行き先が t と同じ月になり、月末なら同じ末日に、そうでなければ同じ日になるので、t がそのまま返ります。
