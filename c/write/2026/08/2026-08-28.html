stack.c

struct Stack {
    int items[16];
    int top;
};

void push(struct Stack* s, int x) {
}

int pop(struct Stack* s) {
}

配列 items と、積んである個数 top で作るスタックの push と pop を書いてください。push は x を積み、pop は最後に積んだ値を取り除いて返します。空のスタックは top が0で、空のときに pop を呼ぶことと、16個を超えて push することはないものとします。例の s は空のスタックで、出力例は入力例の最後の式の値です。

入力例 1

push(&s, 4); push(&s, 9); pop(&s)

出力例 1

9

入力例 2

push(&s, 4); push(&s, 9); pop(&s); pop(&s)

出力例 2

4

入力例 3

push(&s, 5); pop(&s); s.top

出力例 3

0
Reference 
void push(struct Stack* s, int x) {
    s->items[s->top++] = x;
}

int pop(struct Stack* s) {
    return s->items[--s->top];
}

top は積んである個数なので、次に書き込む空きの位置の添字でもあります。push の s->items[s->top++] では、後置の ++ が増やす前の top を添字として返すので、空きの位置に x を書いてから top が1増えます。

pop では、最後に積んだ値は top - 1 の位置にあります。前置の -- は減らしたあとの値を返すので、s->items[--s->top] は top を1減らしてから、その位置の値を読みます。2つを入れ替えて push に ++s->top を書くと、items[0] を飛ばして items[1] から積むことになります。

掲載したのは参考実装で、唯一の正解ではありません。s->items[s->top] = x; と s->top++; の2文に分けても同じ動きになります。++ を単独の文として書くなら、前置でも後置でも結果は変わりません。
