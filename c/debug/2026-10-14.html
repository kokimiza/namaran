join.c

#include <stdio.h>
#include <string.h>

static void join(const char *a, const char *b) {
    size_t n = strlen(a);
    char buf[n + 1];
    n += strlen(b);
    snprintf(buf, sizeof buf, "%s%s", a, b);
    puts(buf);
}

int main(void) {
    join("note", "book");
}

join は、2つの文字列をつないだものを1行に出力する関数です。join("note", "book") を呼ぶと、いまは note と出力されます。本来の出力は notebook です。

Answer

Wrong

size_t n = strlen(a);
char buf[n + 1];
n += strlen(b);
snprintf(buf, sizeof buf, "%s%s", a, b);

可変長配列 buf の大きさは、宣言を実行したときの n + 1 で決まります。その時点の n は "note" の長さの4なので、buf は5バイトです。次の行で n に "book" の長さを足して8にしても、作り終えた buf は大きくなりません。

sizeof buf は実行時に評価されますが、返すのは宣言のときに決まった5で、n をもう一度読み直すわけではありません。snprintf は終端の '\0' を含めて5バイトまでしか書かないので、"notebook" は先頭の4文字で切れ、note が出力されます1。

Right

size_t n = strlen(a);
n += strlen(b);
char buf[n + 1];
snprintf(buf, sizeof buf, "%s%s", a, b);

n が2つの長さの合計になってから buf を宣言すれば、buf は9バイトで作られ、sizeof buf も9になります。notebook の8文字と終端がちょうど収まり、切り捨ては起きません。

  1. snprintf の代わりに sprintf を使っていたら、5バイトの buf に9バイトを書き込み、未定義動作になっていました。sizeof buf で上限を渡していたので、壊れ方が切り捨てで済んでいます。
