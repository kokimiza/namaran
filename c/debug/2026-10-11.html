2026-10-11

changes.c

#include <stdio.h>

struct tracker { float last; int changes; };

static void record(struct tracker *t, double value) {
    if (value == t->last)
        return;
    t->last = value;
    t->changes++;
}

int main(void) {
    struct tracker t = {0};
    double samples[] = {0.5, 0.5, 0.1, 0.1, 0.1};
    for (int i = 0; i < 5; i++)
        record(&t, samples[i]);
    printf("%d\n", t.changes);
}

record は、計測値が前回の値から変わったときだけ changes を1つ増やすつもりの関数です。0.5, 0.5, 0.1, 0.1, 0.1 を順に記録すると、値が変わったのは2回なので本来は 2 を出力するはずですが、いまは 4 を出力します。

Answer

Wrong

if (value == t->last)
    return;
t->last = value;

t->last = value は double の値を float のメンバに代入します。代入では右辺が左辺の型に変換されるので、0.1 は float で表せるいちばん近い値に丸められて入ります。次の呼び出しの value == t->last では、逆に float の t->last が double に変換されてから比べられます1。丸めた値を double に戻しても元の 0.1 にはならないので、この比較は偽になり、同じ 0.1 が届くたびに変化として数えられます。0.1 の3回すべてと 0.5 の1回で、4 になります。

0.5 が正しく扱われるのは、2進数で割り切れて float でも誤差なく表せるからです。代入したあとの t->last が元の value と等しくなるかどうかは、その値が float で正確に表せるかどうかで決まります。

Right

float v = (float)value;
if (v == t->last)
    return;
t->last = v;

比べる前に value を float に変換しておくと、比較の両辺も代入する値も、同じ丸めを通った float になります。2回目の 0.1 は前回代入したのと同じ float の値になるので比較が真になり、変化は 0.5 と 0.1 の最初の1回ずつ、2 回だけ数えられます。last を double に変えても直りますが、記録を float で持つ設計のままなら、比べる値を記録する型にそろえるのが最小の修正です。

  1. float と double が IEEE 754 の単精度と倍精度である一般的な処理系では、0.1 の double は約 0.1000000000000000055、float に丸めた値は約 0.1000000014901161 で、double に戻してもこの差は残ります。
