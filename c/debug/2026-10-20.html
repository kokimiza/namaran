mean.c

#include <stdio.h>

static double mean(const double *xs, size_t n) {
    auto sum = 0;
    for (size_t i = 0; i < n; i++) {
        sum += xs[i];
    }
    return sum / n;
}

int main(void) {
    const double xs[] = {0.5, 1.25, 2.75};
    printf("%.2f\n", mean(xs, 3));
}

mean は、double の配列 xs の先頭 n 個の平均を返すつもりの関数です。main は {0.5, 1.25, 2.75} の平均を小数点以下2桁で表示します。いまの出力は 1.00 で、本来の出力は 1.50 です。

Answer

Wrong

auto sum = 0;
for (size_t i = 0; i < n; i++) {
    sum += xs[i];
}
return sum / n;

auto の型は初期化子 0 から決まり、0 は int の定数なので、sum は int になります。sum += xs[i] の足し算そのものは double で行われますが、結果を sum に戻すときに int へ変換され、小数部が切り捨てられます。0.5 を足しても sum は0のまま、1.25 を足して1、2.75 を足すと 3.75 から3になります。

最後の sum / n も、int と size_t の割り算なので整数の割り算です。3を3で割った1が double に変換されて返り、1.00 と表示されます。割り算だけを (double)sum / n に直しても、sum はすでに3なので結果は 1.00 のままです。

Right

auto sum = 0.0;

初期化子を 0.0 にすると sum は double になり、足すたびの切り捨てが起きなくなります。sum / n でも n のほうが double に変換されて浮動小数点数の割り算になるので、4.5 を3で割った 1.50 が返ります。型を直す場所は1か所で、足し算と割り算の両方が直ります。auto を使わずに double sum = 0; と型を書けば、初期化子の書き方で型が変わることもありません1。

  1. GCC は -Wconversion を付けると、sum += xs[i] の行に「double から int への変換で値が変わりうる」という警告を出します。この警告は -Wall にも -Wextra にも含まれないので、このコードは警告なしでコンパイルされます。
