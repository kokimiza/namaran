vowels.c

#include <stdio.h>
#include <string.h>

void count_vowel(char c, int* n) {
    if (strchr("aeiou", c) != NULL) {
        *n++;
    }
}

int main(void) {
    int n = 0;
    for (const char* p = "education"; *p != '\0'; p++) {
        count_vowel(*p, &n);
    }
    printf("%d\n", n);
}

count_vowel は、文字 c が母音なら n の指す数を1増やすつもりの関数で、main は "education" の母音を数えます。いまの出力は 0 で、本来の出力は 5 です。

Answer

Wrong

if (strchr("aeiou", c) != NULL) {
    *n++;
}

後置の ++ は単項の * より強く結びつくので、*n++ は *(n++) と読まれます。増えるのはポインタ n のほうです。* は増やす前のアドレスにある値を読みますが、その値はどこにも使われずに捨てられます1。n は main の &n をコピーした引数なので、関数の中でポインタを進めても呼び出し側には何も残らず、main の n は0のままです。

Right

if (strchr("aeiou", c) != NULL) {
    (*n)++;
}

括弧で先に *n を作ると、++ が増やす対象は n の指す int である main の n になります。"education" の e、u、a、i、o で1ずつ増え、5が出力されます。++*n と前置で書いても同じで、こちらは ++ が *n の外側にあるので括弧が要りません。

  1. 読んだ値を使わない式なので、GCC は -Wall で value computed is not used という警告を出します。警告を読んでいれば、この欠陥はコンパイルの時点で見つかります。
