job_ring.c

#include <stdio.h>

#define N 4

int main(void) {
    int ring[N] = {1, 2, 3};
    int head = 0, tail = 3;
    while ((tail - head) % N > 0) {
        int job = ring[head];
        head = (head + 1) % N;
        printf("%d ", job);
        if (job == 1) {
            ring[tail] = 4;
            tail = (tail + 1) % N;
        }
    }
    printf("\n");
}

長さ N の配列 ring を輪のように使い、head から取り出して tail に足すキューで、仕事を到着順に処理するプログラムです。仕事 1 は、処理されると後続の仕事 4 をキューに足します。最初に 1、2、3 が待っているので、本来は 1 2 3 4 と出力されるはずが、いまは 1 とだけ出力されて終わります。

Answer

Wrong

while ((tail - head) % N > 0) {

(tail - head) % N は待っている仕事の数のつもりですが、tail が折り返して head より小さくなると負になります。C の整数の割り算は0の方へ切り捨てるので、余り a % b は割られる数 a と同じ符号を持ち、-1 % 4 は 3 ではなく -1 です1。

最初は head が0、tail が3です。仕事 1 を取り出すと head は1になり、続けて仕事 4 を ring[3] に入れると、tail は (3 + 1) % 4 で0に戻ります。このとき (0 - 1) % 4 が -1 になって条件が偽になり、2、3、4 を残したままループを抜けます。添字を進める (tail + 1) % N は正の数の余りなので、こちらは正しく折り返しています。

Right

while ((tail - head + N) % N > 0) {

tail - head は -(N - 1) 以上 N - 1 以下なので、N を足せば必ず正になり、その余りは0以上 N 未満の、待っている仕事の数になります。仕事 1 のあとは (0 - 1 + 4) % 4 が 3 になってループが続き、2、3、4 を処理して head と tail がともに0になったところで止まります。

  1. C89 では、負の数を含む割り算をどちらへ丸めるかは処理系が決めてよいことになっていました。C99 で0の方への切り捨てに決まり、C23 も同じです。Python の % は割る数と同じ符号になるので、-1 % 4 は 3 です。
