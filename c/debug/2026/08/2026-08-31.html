2026-08-31

billing.c

#include <stdio.h>

static const int days_2028[] = {31, 29, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};

int main(void) {
    int day = 31;
    for (int m = 2; m <= 5; m++) {
        if (day > days_2028[m - 1]) {
            day = days_2028[m - 1];
        }
        printf("2028-%02d-%02d\n", m, day);
    }
}

2028年1月31日に始めた月額契約の、2月から5月までの請求日を出すつもりのプログラムです。請求日は毎月、契約した日と同じ日で、その月にその日が無ければ月末にします。いまは 2028-02-29 2028-03-29 2028-04-29 2028-05-29 が1行ずつ出ます。本来は 2028-02-29 2028-03-31 2028-04-30 2028-05-31 です。

Answer

Wrong

int day = 31;
for (int m = 2; m <= 5; m++) {
    if (day > days_2028[m - 1]) {
        day = days_2028[m - 1];
    }

day は契約した日と、いま出している月の請求日の2役を兼ねています。2月は31日が無いので、day は2月の日数の29に削られます。この29が契約した日として3月に持ち越され、3月の31日とも4月の30日とも比べて小さいので、もう削られも戻されもしません。3月以降の請求日が29日に張り付くのはこのためです。

29という数から閏年の扱いを疑いたくなりますが、days_2028 は2028年の正しい日数で、2月を29日にしたのも正しい結果です。月末に合わせて削る処理も、1か月分だけ見れば正しく動いています。壊れているのは、削った結果を次の月の入力にしたことで、削る前の31は1回目の代入で消えています。

Right

const int start = 31;
for (int m = 2; m <= 5; m++) {
    int day = start;
    if (day > days_2028[m - 1]) {
        day = days_2028[m - 1];
    }

契約した日を書き換えない start に分け、毎月その日から請求日を作り直します。2月に29へ削っても、その29はその月の day にしか残らず、3月はまた31から始まるので、3月31日、4月30日、5月31日と月ごとの末日に戻ります。月末に合わせて削る処理は、削られた分の情報を捨てるので、前の結果に1か月ずつ足していく形では、一度削られた日を取り戻せません。
