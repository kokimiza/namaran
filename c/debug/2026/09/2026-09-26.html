rebase.c

#include <stddef.h>
#include <stdio.h>

void rebase(int *a, size_t n) {
    for (size_t i = 0; i < n; i++) {
        a[i] -= a[0];
    }
}

int main(void) {
    int v[] = {5, 7, 9};
    rebase(v, 3);
    printf("%d %d %d\n", v[0], v[1], v[2]);
    return 0;
}

rebase は、配列の各要素から先頭の値を引いて、先頭を 0 とした相対値に直すつもりの関数です。入力は {5, 7, 9} で、rebase(v, 3) のあと v を表示します。いまの出力は 0 7 9 ですが、本来の出力は 0 2 4 です。どこを直せばよいでしょうか?

Answer

最初の周は i が 0 なので、a[i] -= a[0] の a[i] と a[0] は同じ要素です。この周で a[0] は 5 - 5 で 0 になり、2周目からは a[0] を読むたびに 0 が返るので、7 と 9 からは何も引かれません。ループの中で読む a[0] は「最初に見た先頭の値」ではなく「いまの先頭の値」で、その場所をループ自身が書き換えています。

直すには、ループに入る前に先頭の値を別の変数へ写します: 

    const int base = a[0];
    for (size_t i = 0; i < n; i++) {
        a[i] -= base;
    }

base は配列とは別の場所にあるコピーなので、ループが配列をどう書き換えても 5 のままです。i を 1 から回し、最後に a[0] = 0 とする直し方もありますが、先頭の値を写しておく方が「最初の値を基準にする」という意図がそのままコードに残ります。
