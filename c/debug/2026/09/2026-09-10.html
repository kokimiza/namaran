trace.c

#include <stdio.h>

int trace(int **m, int n) {
    int t = 0;
    for (int i = 0; i < n; i++) {
        t += m[i][i];
    }
    return t;
}

int main(void) {
    int grid[3][3] = {
        {1, 2, 3},
        {4, 5, 6},
        {7, 8, 9},
    };
    printf("%d\n", trace(grid, 3));
    return 0;
}

traceは、正方行列の対角成分の和を返すつもりの関数です。入力はtrace(grid, 3)で、本来は15を表示するはずですが、いまはコンパイルが通りません。どこを直せばよいでしょうか?

Answer

traceの引数int **mをint (*m)[3]に直します。関数に渡した配列は先頭要素へのポインタに変わりますが、int grid[3][3]の先頭要素はintではなく行int[3]です。そのためgridはint (*)[3](int3個の行を指すポインタ)になり、int *を指すポインタであるint **とは型が合いません。

int (*m)[3]を受け取るように直すと、m[i][i]はi行目の先頭からi個進んだ要素になり、1 + 5 + 9で15が出ます。int m[][3]と書いても同じ型です1。(int **)gridとキャストすればコンパイルは通りますが、m[i]がgridの中のintをポインタとして読むことになるので、未定義動作です。

  1. C23では、int trace(int n, int m[n][n])のように列数を引数から取る書き方もできます。可変長配列の変数は処理系が省けますが、このような引数の型はC23で必須になりました。
