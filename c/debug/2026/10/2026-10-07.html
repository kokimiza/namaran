recent.c

#include <stdio.h>

static void swap(int *a, int *b) {
    *a ^= *b;
    *b ^= *a;
    *a ^= *b;
}

static void touch(int *v, int n, int x) {
    for (int k = 0; k < n; k++)
        if (v[k] == x) swap(&v[0], &v[k]);
}

int main(void) {
    int v[] = {7, 8, 9};
    touch(v, 3, 9);
    touch(v, 3, 9);
    printf("%d %d %d\n", v[0], v[1], v[2]);
}

touch は、配列 v から値 x を探し、見つけた要素を先頭の要素と入れ替えて、最近使った値が前に来るようにするつもりの関数です。main は {7, 8, 9} に対して 9 を2回続けて使います。引数も標準入力も使いません。いまは 0 8 7 が出ます。本来は 9 8 7 が出るはずです。

Answer

Wrong

static void swap(int *a, int *b) {
    *a ^= *b;
    *b ^= *a;
    *a ^= *b;
}

1回目の touch(v, 3, 9) は v[2] で 9 を見つけ、v[0] と入れ替えて {9, 8, 7} にします。2回目は 9 がもう先頭にあるので k が0のときに見つかり、swap(&v[0], &v[0]) が呼ばれます。

a と b が同じ v[0] を指しているので、1行目の *a ^= *b は v[0] を自分自身とXORし、9 ^ 9 で0にします。続く2行も0と0のXORなので、v[0] は0のまま戻らず、0 8 7 が出力されます。

Right

static void swap(int *a, int *b) {
    if (a == b) return;
    *a ^= *b;
    *b ^= *a;
    *a ^= *b;
}

同じ場所を指しているときは、入れ替えるものがないので何もせずに戻ります。2回目の touch では v[0] に触らなくなり、9 8 7 が残ります。touch の側で k != 0 を確かめても直りますが、swap を使うほかの呼び出し元でも同じことが起きうるので、swap の中で防ぐ方が確実です。一時変数を使った交換に書き換えても直ります1。

  1. 一時変数を使った交換は、a と b が同じ場所を指していても、値を読んで同じ場所に書き戻すだけなので壊れません。XORによる交換が速くなるわけでもないので、実際のコードではこちらで十分です。
