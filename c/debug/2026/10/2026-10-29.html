landing.c

#include <stdio.h>

static double height(double t) {
    return 3 + 2 * t - t * t;
}

static double slope(double t) {
    return 2 - 2 * t;
}

static double landing_time(void) {
    double t = 0;
    for (int i = 0; i < 20; i++) {
        t -= height(t) / slope(t);
    }
    return t;
}

int main(void) {
    printf("%.3f\n", landing_time());
}

投げ上げたボールの t 秒後の高さ height(t) が0になる時刻、つまり地面に落ちる時刻を求めるつもりのコードです。t から height(t) / slope(t)(slope は高さの式を t で微分したもの)を引く操作を20回繰り返します。高さの式 3 + 2t − t2 は t = 3 で0になるので、本来は 3.000 と出力されるはずが、いまは -1.000 と出力されます。

Answer

Wrong

    double t = 0;
    for (int i = 0; i < 20; i++) {
        t -= height(t) / slope(t);
    }

この反復は Newton法1で、いまの点で高さの式に接線を引き、接線が高さ0と交わる時刻へ移ります。3 + 2t − t2 = 0 の解は t = 3 と t = -1 の2つあり、どちらへ向かうかは初期値で決まります。t = 0 では高さが3、傾きが2で、右へ行くほど高くなる接線は左側の t = -1.5 で0と交わります。そこからは -1.05、-1.0006……と負の解 -1 に近づき、20回のあとには -1.000 を出力します。

放物線の頂点は傾きが0になる t = 1 で、接線は頂点より左ではいつも左の解へ、右ではいつも右の解へ向かいます。投げた瞬間の0は頂点の左にあるので、何回繰り返しても t = 3 には着きません。

Right

    double t = 2;
    for (int i = 0; i < 20; i++) {
        t -= height(t) / slope(t);
    }

初期値を頂点より右の t = 2 にすると、高さ3、傾き−2の接線は右側の 3.5 で0と交わり、3.05、3.0006……と 3 に近づきます。頂点の右なら初期値は2でなくてもかまいませんが、頂点の t = 1 そのものは傾きが0で割り算ができないので選べません。

  1. Newton法(ニュートン法、Newton's method)は、関数の値が0になる点を、接線が横軸と交わる点へ移る操作を繰り返して求める方法です。解が複数あるとき、どの解に着くかは初期値で決まり、3次以上の式では初期値のわずかな違いで行き先が入れ替わることもあります。
