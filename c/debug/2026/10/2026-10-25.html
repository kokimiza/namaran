jittered_ttl.c

#include <stdio.h>

long expires_at(long now, long ttl, unsigned key) {
    return now + ttl + ttl / 100 * (key % 10);
}

int main(void) {
    for (unsigned key = 3; key <= 7; key += 2)
        printf("%ld\n", expires_at(0, 60, key));
}

expires_at は、時刻 now に保存したキャッシュの有効期限を返すつもりの関数です。同じ時刻に保存した項目が一斉に切れないよう、ttl 秒にキーの1の位に応じたばらつき(ttl の0〜9%)を足します。main は now を 0、ttl を 60 として、キー 3、5、7 の期限を1行ずつ出力します。いまの出力は 60、60、60 です。本来の出力は 61、63、64 です。

Answer

Wrong

return now + ttl + ttl / 100 * (key % 10);

/ と * は優先順位が同じで左から結合するので、ttl / 100 が先に計算されます。ttl も 100 も整数なので、この割り算は小数部を切り捨てた整数除算で、60 / 100 は 0 です。どのキーでも 0 * (key % 10) が足されるだけになり、期限は全部 60 に揃います。ttl が100秒未満のキャッシュでは、ばらつきが常に消え、一斉に切れた項目をすべての呼び出しが同時に計算し直すことになります。

Right

return now + ttl + ttl * (key % 10) / 100;

掛け算を先にします。キー 5 なら 60 * 5 の 300 を 100 で割って 3 になり、切り捨てられるのは最後の割り算の端数だけです。キー 3 と 7 では 180 / 100 と 420 / 100 がそれぞれ 1 と 4 になり、期限は 61、63、64 とずれます。
