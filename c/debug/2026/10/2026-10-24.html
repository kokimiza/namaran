elapsed.c

#include <stdint.h>
#include <stdio.h>

double elapsed_ms(int64_t start_ns, int64_t end_ns) {
    double start = (double)start_ns;
    double end = (double)end_ns;
    return (end - start) / 1e6;
}

int main(void) {
    printf("%.6f\n", elapsed_ms(1761264000000000000, 1761264000001234567));
}

elapsed_ms は、ナノ秒単位の2つの時刻 start_ns と end_ns から、経過時間をミリ秒の double で返すつもりの関数です。main は2026年の時刻と、その1234567ナノ秒後の時刻を渡します。いまの出力は 1.234688 です。本来の出力は 1.234567 です。

Answer

Wrong

double start = (double)start_ns;
double end = (double)end_ns;
return (end - start) / 1e6;

double の仮数部は53ビットなので、整数を正確に表せるのは 253(約9.0×1015)までです。2026年のナノ秒の時刻は約1.76×1018 で、260 以上 261 未満にあり、この範囲の double は256おきの値しか表せません。start_ns はたまたま256の倍数なので正確に変換されますが、end_ns は近い方の256の倍数へ丸められ、121ナノ秒大きくなります。

引き算は丸めたあとの値どうしで行われるので、差は 1234567 ではなく 1234688 になります。経過時間そのものは7桁なので double で正確に表せますが、その前に19桁の時刻を double に入れた時点で下の桁が失われています。

Right

return (double)(end_ns - start_ns) / 1e6;

引き算を int64_t のまま先に行います。整数の引き算は誤差なく 1234567 を出し、この値は 253 よりずっと小さいので、double へ変換しても丸めは起きません。
