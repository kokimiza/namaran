append_text.c

#include <stdio.h>
#include <string.h>

struct text {
    char* buf;
    size_t len;
};

static void append(struct text t, const char* s) {
    memcpy(t.buf + t.len, s, strlen(s));
    t.len += strlen(s);
}

int main(void) {
    char storage[16] = {0};
    struct text t = {storage, 0};
    append(t, "ab");
    append(t, "cd");
    append(t, "e");
    printf("%s\n", t.buf);
}

append は、t.buf にある長さ t.len の文字列の後ろに s を書き足すつもりの関数です。main は "ab"、"cd"、"e" の順に書き足すので、本来は abcde と出力されるはずが、いまは ed と出力されます。

Answer

Wrong

static void append(struct text t, const char* s) {
    memcpy(t.buf + t.len, s, strlen(s));
    t.len += strlen(s);
}

ed は、3回の書き込みがどれも storage の先頭から始まったときにできる文字列です。ab が0番目と1番目に入り、cd が同じ2文字を上書きし、最後の e が0番目だけを上書きするので、1番目には d が残ります。書き込み先がいつも先頭だったということは、append の中の t.len が3回とも0だったということです。

append は構造体を値で受け取るので、呼ばれるたびに main の t の複製を作ります。t.len += strlen(s); が増やすのはこの複製の len で、main の t.len は0のままです。一方、複製された buf は元と同じアドレスを持つので、memcpy の書き込みは storage に届きます。文字は残るのに長さだけが戻らないため、出力は空にならず ed になります。

Right

static void append(struct text* t, const char* s) {
    memcpy(t->buf + t->len, s, strlen(s));
    t->len += strlen(s);
}

int main(void) {
    char storage[16] = {0};
    struct text t = {storage, 0};
    append(&t, "ab");
    append(&t, "cd");
    append(&t, "e");

append に t のアドレスを渡せば、t->len += strlen(s); は main の t.len そのものを増やします。2回目の書き込みは2番目から、3回目は4番目から始まり、storage には abcde が並びます1。

  1. 値渡しのまま、更新した構造体を return で返し、呼び出し側で t = append(t, "ab"); と受け取る形でも直ります。どちらの形でも、書き足した長さを呼び出し側の t に戻すことが直し方の中身です。
