best_seller.c

#include <stdio.h>

int main(void) {
    int ids[8] = {0}, counts[8] = {0};
    int sales[] = {9, 6, 9, 6, 3};
    for (int i = 0; i < 5; i++) {
        int h = sales[i] % 8;
        while (counts[h] != 0 && ids[h] != sales[i])
            h = (h + 1) % 8;
        ids[h] = sales[i];
        counts[h]++;
    }
    int best = 0;
    for (int h = 1; h < 8; h++)
        if (counts[h] > counts[best])
            best = h;
    printf("%d\n", ids[best]);
}

売れた商品IDの並び sales から、最も多く売れたIDを出力するプログラムです。売れた回数が同じIDが複数あるときは、小さいほうのIDを出すつもりです。sales が {9, 6, 9, 6, 3} のとき、9 と 6 が2回ずつで並ぶので、本来は 6 と出力されるはずが、いまは 9 と出力されます。

Answer

Wrong

    int best = 0;
    for (int h = 1; h < 8; h++)
        if (counts[h] > counts[best])
            best = h;

このループは枠の番号の小さい順に回り、回数が真に多いときだけ best を替えます。回数が同じなら先に見た枠が残るので、同数のときに選ばれるのはIDの小さいほうではなく、枠の番号の小さいほうです。

IDは枠 id % 8 に入るので、8 未満のIDだけなら枠の順とIDの順は一致し、このループでも正しく動きます。9 は8で割った余りが1なので枠1に入り、枠6の 6 より先に見られます。9 と 6 はどちらも2回なので best は枠1のまま替わらず、9 が出力されます。

Right

    int best = 0;
    for (int h = 1; h < 8; h++)
        if (counts[h] > counts[best] || (counts[h] == counts[best] && ids[h] < ids[best]))
            best = h;

回数が同じときにもIDを比べ、小さいほうを選ぶ条件を足します。これで、どのIDがどの枠に入っていても、選ばれるIDは回数とIDの大小だけで決まります。空きの枠は回数が 0 なので、売れたIDと同数になって選ばれることはありません。
