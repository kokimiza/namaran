daily_max.c

#include <stddef.h>
#include <stdio.h>

static size_t argmax(const int *a, size_t n) {
    size_t best = 0;
    for (size_t i = 1; i < n; i++)
        if (a[i] > a[best])
            best = i;
    return best;
}

int main(void) {
    int temp[] = {12, 18, 15, 9, 11};
    size_t start[] = {0, 3, 3, 5};
    for (size_t d = 0; d < 3; d++) {
        size_t len = start[d + 1] - start[d];
        size_t i = argmax(temp + start[d], len);
        printf("day %zu: %d\n", d, temp[start[d] + i]);
    }
}

temp は3日分の気温の記録を日付順に並べた配列で、d 日目の記録は temp[start[d]] から temp[start[d + 1]] の手前までです。このコードは日ごとの最高気温を出力するつもりで、記録の無い日には - と出すべきです。引数も標準入力も使いません。本来は day 0: 18、day 1: -、day 2: 11 の3行が出力されるはずが、いまは day 0: 18、day 1: 9、day 2: 11 と出力されます。

Answer

Wrong

size_t len = start[d + 1] - start[d];
size_t i = argmax(temp + start[d], len);
printf("day %zu: %d\n", d, temp[start[d] + i]);

1日目は start[1] と start[2] がどちらも 3 なので、len は 0 です。argmax は best = 0 から始め、i = 1 からのループは1回も回らないので、空の範囲にも添字 0 を返します。この 0 は「先頭が最大」とも「要素が無い」とも読めますが、main は前者として扱います。

main が読むのは temp[start[1] + 0]、つまり temp[3] です。1日目の範囲は空でも、start[1] の位置には2日目の最初の記録 9 が置かれています。配列の内側を読んでいるのでクラッシュもせず、サニタイザも何も報告しないまま、翌日の値が1日目の最高気温として出力されます1。

Right

size_t len = start[d + 1] - start[d];
if (len == 0) {
    printf("day %zu: -\n", d);
    continue;
}
size_t i = argmax(temp + start[d], len);

argmax を呼ぶ前に長さを調べ、空の日はそこで - を出して次の日へ進みます。argmax に渡るのは要素が1つ以上ある範囲だけになるので、返ってくる添字は必ずその日の記録を指します2。

  1. 空の日が最終日だと start[d] は 5 になり、temp[5] は配列の外です。そのときは翌日の値ではなく未定義動作になります。同じ欠陥でも、空の範囲が配列のどこにあるかで症状が変わります。
  2. argmax の側で、空なら n を返すと決める方法もあります。C++ の std::max_element は空の範囲に終端を返し、呼び出し側は終端と比べて空かどうかを見分けます。
