scale.c

#include <stdio.h>

static int scale_all(int *v, int n, int k) {
    for (int i = 0; i < n; i++) {
        if (v[i] < 0)
            return -1;
        v[i] *= k;
    }
    return 0;
}

int main(void) {
    int v[] = {1, 2, -3, 4};
    if (scale_all(v, 4, 10) != 0) {
        v[2] = 3;
        scale_all(v, 4, 10);
    }
    printf("%d %d %d %d\n", v[0], v[1], v[2], v[3]);
}

scale_all は配列の各要素を k 倍し、負の値が1つでもあれば -1 を返して失敗を知らせるつもりです。main は失敗したら負の値を直して呼び直します。引数も標準入力も使いません。本来は 10 20 30 40 と出力されるはずが、いまは 100 200 30 40 と出力されます。

Answer

Wrong

for (int i = 0; i < n; i++) {
    if (v[i] < 0)
        return -1;
    v[i] *= k;
}

1回目の呼び出しは v[0] と v[1] を 10 倍したあとで v[2] の -3 に出会い、-1 を返します。失敗を返しても、それまでの書き込みは取り消されません。main に戻ったとき、配列はもう {10, 20, -3, 4} です。

main は v[2] を 3 に直して呼び直しますが、2回目の scale_all は配列を先頭から掛け直します。1回目で 10 倍済みの v[0] と v[1] はもう一度掛けられて 100 と 200 になり、1回目で届かなかった v[2] と v[3] だけが正しく 30 と 40 になります。

Right

for (int i = 0; i < n; i++)
    if (v[i] < 0)
        return -1;
for (int i = 0; i < n; i++)
    v[i] *= k;

すべての要素を調べ終えてから書き込みを始めれば、-1 を返す時点では配列にまだ何も書いていません。失敗した呼び出しが配列をまったく変えないので、値を直して呼び直しても、各要素はちょうど1回だけ k 倍されます1。

  1. 検証をまとめて先に済ませられない処理では、書き込む前の値を控えておき、失敗したらそこへ戻します。データベースのトランザクションが、途中で失敗したときに変更をすべて取り消すのと同じ考え方です。
