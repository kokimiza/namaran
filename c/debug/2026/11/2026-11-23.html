nibbles.c

#include <stdio.h>

unsigned char swap_nibbles(unsigned char x) {
    return (unsigned char)(x << 4 | x >> 4);
}

int main(void) {
    for (unsigned char x = 0; x <= 255;
         x++) {
        if (swap_nibbles(swap_nibbles(x)) !=
            x) {
            printf("fail: %d\n", x);
            return 1;
        }
    }
    puts("ok");
}

0 から 255 までのすべての unsigned char について、上下4ビットを入れ替える swap_nibbles を2回かけると元の値に戻ることを確かめるプログラムです。引数も入力も無く、そのまま実行します。本来は 256 通りを調べ終えて ok を出して終わるはずが、いまは何も出力しないまま終わりません。

Answer

Wrong

    for (unsigned char x = 0; x <= 255;
         x++) {

unsigned char で表せるのは 0 から 255 までです。x が 255 のとき x++ を実行すると、足した結果の 256 は表せないので、256 で割った余りの 0 に戻ります。比較の前に x は int に変換されますが、値は 0 から 255 のどれかなので、x <= 255 はいつも真になり、ループを抜ける機会がありません。性質はすべての値で成り立つので fail も出ず、puts("ok") には届かないまま回り続けます。

Right

    for (int x = 0; x <= 255; x++) {

ループ変数を int にすると、x は 255 の次に 256 になれます。256 で x <= 255 が偽になり、ループは 256 回で終わって ok を出します。swap_nibbles には int から unsigned char へ変換して渡されますが、x は 0 から 255 までしか取らないので値は変わりません。全部の値を順に試すループでは、ループ変数の型に、最後の値の次の値まで入る必要があります。
