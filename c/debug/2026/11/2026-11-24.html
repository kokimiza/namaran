tilings.c

#include <stdio.h>

long long tilings(int n) {
    long long memo[100] = {0};
    if (n < 3) {
        return 1;
    }
    if (memo[n] == 0) {
        memo[n] =
            tilings(n - 1) + tilings(n - 3);
    }
    return memo[n];
}

int main(void) {
    printf("%lld\n", tilings(90));
}

tilings(n) は、長さ1と長さ3の板を並べて長さ n の床を埋める並べ方の数を、一度求めた値を配列 memo に覚えながら計算するつもりの関数です。main は tilings(90) を出力します。本来は 533352837917926 を出してすぐ終わるはずが、いまは何も出力しないまま終わりません。

Answer

Wrong

long long memo[100] = {0};

memo は関数の中で宣言した、static の付かない配列です。このような変数は呼び出しのたびに新しく作られ、関数から戻ると消えます。tilings(90) が tilings(89) を呼ぶと、tilings(89) は自分用の新しい memo を 0 で初期化して使い、そこに書いた値は戻った時点で消えます。どの呼び出しから見ても memo[n] はいつも 0 なので、覚えた値が使われることは一度もありません。そのため同じ n を何度も計算し直し、呼び出しの回数は答えの数と同じ 1014 以上の規模になって、終わらなくなります。

Right

static long long memo[100];

static を付けると、memo はプログラムの開始から終了まで1つだけ存在する配列になり、すべての呼び出しが同じ表を共有します。初期化子が無くても、static の配列は最初に 0 で初期化されます。一度 memo[n] に書いた値は次の呼び出しでも残るので、各 n を計算するのは1回だけになり、tilings(90) は90回程度の計算で終わります。並べ方の数は 1 以上なので、0 を「まだ計算していない」印に使っても値とぶつかりません。
