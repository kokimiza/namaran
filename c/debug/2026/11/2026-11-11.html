binary.c

#include <stdbit.h>
#include <stdio.h>

void print_binary(unsigned n) {
    for (int i = stdc_bit_width(n); i >= 0; i--) {
        putchar('0' + ((n >> i) & 1));
    }
    putchar('\n');
}

int main(void) {
    print_binary(6);
}

print_binary は、1以上の n を先頭に0を付けずに2進数で表示する関数です。print_binary(6) は 110 と表示するはずが、いまは 0110 と表示します。

Answer

Wrong

    for (int i = stdc_bit_width(n); i >= 0; i--) {
        putchar('0' + ((n >> i) & 1));
    }

stdc_bit_width(n) は n を表すのに要るビットの数で、6 (110) なら3です。3ビットの数が使う桁は 20, 21, 22 の位で、最上位のビットの番号は2です。ところがループは i = 3 から始まるので、最初に (6 >> 3) & 1、つまり存在しない 23 の位の0を表示し、そのあとに 110 が続いて 0110 になります。

Right

    for (int i = stdc_bit_width(n) - 1; i >= 0; i--) {
        putchar('0' + ((n >> i) & 1));
    }

幅が w ビットなら、ビットの番号は0から w − 1 までです。開始を stdc_bit_width(n) - 1 にすれば、最初に表示するのは最上位の1になり、6 は 110 と表示されます。ビットの個数はそのままでは番号にならず、0から数える番号の最後は個数から1を引いた値になります。1

  1. 直す前のコードには、表示が崩れるだけでは済まない入力もあります。n が 231 以上なら stdc_bit_width(n) は32で、最初の n >> 32 は unsigned の幅以上のシフトになり、未定義動作です。直したあとは最大でも31ビットのシフトで済みます。
