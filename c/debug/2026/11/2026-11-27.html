sum_down.c

#include <stdio.h>

int sum_down(int n, int step) {
    if (n == 0)
        return 0;
    return n + sum_down(n - step, step);
}

int main(void) {
    printf("%d\n", sum_down(10, 3));
}

sum_down(n, step) は、n から step ずつ減らしていった値 n, n - step, n - 2 * step, … のうち、正のものをすべて足した和を返すつもりの関数です。n は 0 以上 200 以下、step は 1 以上とします。main は sum_down(10, 3) を出力します。

いまの出力

（何も出力せずに異常終了する）

本来の出力

22
Answer

Wrong

if (n == 0)
    return 0;

sum_down(10, 3) は n を 10, 7, 4, 1 と減らしながら自分を呼び、次は n が -2 になります。基底ケースは n == 0 の1点だけなので、3 ずつ減る n は 0 を踏まずに通り過ぎ、-5, -8, … と呼び出しが止まらなくなります。足し算は呼び出しが戻ってきてから行われるため、どの段も結果を待ったまま積み重なり、やがてスタックを使い切って異常終了します。printf まで進まないので、何も出力されません。

Right 時間計算量 𝒪(k) 空間計算量 𝒪(k) k は足す値の個数 

if (n <= 0)
    return 0;

基底ケースを n <= 0 にすると、0 を飛び越えて負になった n もそこで受け止められます。-2 に来た呼び出しが 0 を返し、そこから 1, 4, 7, 10 が順に足されて 22 になります。step が 1 以上なら n は呼ぶたびに必ず減るので、どの n と step でも、いつかは 0 以下になって止まります。

呼び出しの深さは足す値の個数より1多いだけで、n が 200、step が 1 のときでも約200段です。そのときの和は 1 から 200 までの和 20100 で、規格が int に保証する 32767 までに収まります。
