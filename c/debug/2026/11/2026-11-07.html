sum_to.c

#include <stdio.h>

typedef struct Bounce {
    struct Bounce (*next)(struct Bounce);
    long n, sum;
} Bounce;

static Bounce add(Bounce b) {
    b.sum += b.n;
    return (Bounce){b.n > 1 ? add : NULL, b.n - 1};
}

int main(void) {
    Bounce b = {add, 4, 0};
    while (b.next)
        b = b.next(b);
    printf("%ld\n", b.sum);
}

1から n までの和を、add が自分を呼ぶ再帰ではなく、次に呼ぶ関数と状態を Bounce に詰めて返すループで求めるつもりのプログラムです。main のとおり n を4、和を0から始めると、いまは 0 が表示されます。本来の出力は 10 です。

Answer

Wrong

static Bounce add(Bounce b) {
    b.sum += b.n;
    return (Bounce){b.n > 1 ? add : NULL, b.n - 1};
}

add は Bounce を値で受け取るので、b.sum += b.n が書き換えるのは引数のコピーです。このコピーは add から戻ると消え、main に届くのは return に書いた複合リテラルだけです。その複合リテラルは next と n の2つしか書いておらず、C では初期化子を書かなかったメンバは0で初期化されます。そのため返る Bounce の sum は毎回0です。

n が4、3、2、1の各段で b.sum は 4、3、2、1 になりますが、どれも次の段には渡りません。n が1の段が返すのも {NULL, 0, 0} なので、ループを抜けた main は b.sum の0を表示します。再帰なら呼び出し元の局所変数が残りますが、このループでは段と段の間に残るのは返した Bounce だけです。

Right

static Bounce add(Bounce b) {
    b.sum += b.n;
    return (Bounce){b.n > 1 ? add : NULL, b.n - 1, b.sum};
}

複合リテラルに3つ目の初期化子として b.sum を書けば、足し込んだ和が次の段の Bounce に入ります。和は 4、7、9、10 と積み上がり、最後の段が {NULL, 0, 10} を返すので 10 が表示されます。b をそのまま書き換えて b.next と b.n を更新し、return b; とする書き方にすれば、メンバを書き落とすこと自体が起きません。
