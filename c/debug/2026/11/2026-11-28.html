parse_flags.c

#include <stdio.h>

static int verbose;
static const char* out = "a.out";

static void parse(const char* arg) {
    for (const char* c = arg + 1; *c; c++) {
        if (*c == 'v')
            verbose = 1;
        if (*c == 'o')
            out = c + 1;
    }
}

int main(void) {
    parse("-ovideo.mp4");
    printf("%d %s\n", verbose, out);
}

parse は、- で始まるコマンドライン引数を1つ受け取り、オプションを1文字ずつ解析するつもりの関数です。v があれば verbose を 1 にし、o があれば、その直後から引数の終わりまでを出力先のファイル名として out に入れます。-vofile のように、複数のオプションを1つの引数にまとめて書けます。main は引数 -ovideo.mp4 を解析し、verbose と out を出力します。

いまの出力

1 .mp4

本来の出力

0 video.mp4
Answer

Wrong

for (const char* c = arg + 1; *c; c++) {
    if (*c == 'v')
        verbose = 1;
    if (*c == 'o')
        out = c + 1;
}

ループは o を見つけて out を決めたあとも止まらず、残りの文字もオプションとして読み続けます。-ovideo.mp4 では、o の直後の video.mp4 はファイル名の文字ですが、その先頭の v で verbose が 1 になります。さらに video の最後の o でもう一度 out = c + 1 が実行され、out はその次の文字を指し直します。そこから引数の終わりまでが .mp4 です。出力の 1 と .mp4 はどちらも、ファイル名の中の v と o から来ています。

Right 時間計算量 𝒪(n) 空間計算量 𝒪(1) n は arg の文字数 

for (const char* c = arg + 1; *c; c++) {
    if (*c == 'v')
        verbose = 1;
    if (*c == 'o') {
        out = c + 1;
        return;
    }
}

o の後ろは、引数の終わりまでがまるごとファイル名なので、そこから先にオプションの文字はありません1。out を決めたら return で解析を終えれば、ファイル名の文字がオプションとして読まれることはなくなります。-vofile でも v を読んでから o で止まるので、verbose は 1、out は file になります。o を含まない引数は、これまでどおり最後の文字まで読みます。

  1. POSIX の getopt も同じ決まりで動きます。値を取るオプションの文字が見つかると、同じ引数の残りをその値とし、残りが空なら次の引数を値にします。
