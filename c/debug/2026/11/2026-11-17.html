word_count.c

#include <stdio.h>

const char* keys[8];
int counts[8];

int add(const char* w) {
    int i = 0;
    while (keys[i] && keys[i] != w)
        i++;
    keys[i] = w;
    return ++counts[i];
}

int main(void) {
    char a[] = "to", b[] = "to";
    add(a);
    printf("%d\n", add(b));
}

add は、単語を表に登録してその単語の出現回数を1増やし、増やしたあとの回数を返すつもりの関数です。main は同じ綴りの "to" を2回 add するので、2回目の呼び出しは 2 を返し、2 が出力されるはずですが、いまは 1 が出力されます。

Answer

Wrong

int add(const char* w) {
    int i = 0;
    while (keys[i] && keys[i] != w)
        i++;
    keys[i] = w;
    return ++counts[i];
}

keys[i] != w は、2つの const char* を比べています。ポインタどうしの == と != が比べるのは指している場所で、その先の文字列の中身ではありません。a と b は別々の配列なので、中身がどちらも "to" でも先頭の場所は違います。

1回目の add(a) で keys[0] には a の場所が入り、回数は1になります。2回目の add(b) では keys[0] != b が真なので探索は先へ進み、空いている keys[1] に b を新しいキーとして登録します。counts[1] は0から1になり、その 1 が出力されます。

Right

#include <stdio.h>
#include <string.h>

int add(const char* w) {
    int i = 0;
    while (keys[i] && strcmp(keys[i], w))
        i++;
    keys[i] = w;
    return ++counts[i];
}

strcmp は2つの文字列を1文字ずつ比べ、中身が同じなら0を、違えば0以外を返します。条件の strcmp(keys[i], w) は「中身が違う間は先へ進む」という意味になり、add(b) は中身が "to" の keys[0] で止まります。counts[0] が2になり、2 が出力されます。strcmp を使うので <string.h> を読み込みます。
