query.c

#include <stdio.h>
#include <threads.h>

static void open_db(void) {
    puts("connect");
}

static void query(const char* sql) {
    once_flag once = ONCE_FLAG_INIT;
    call_once(&once, open_db);
    puts(sql);
}

int main(void) {
    query("a");
    query("b");
}

最初の query のときだけデータベースに接続し(ここでは connect と出すだけです)、以後はその接続を使い回すつもりのプログラムです。query("a") と query("b") を続けて呼ぶと、connect、a、b の3行が出るはずが、いまは connect、a、connect、b の4行が出て、2回目の呼び出しでも接続し直しています。

Answer

Wrong

static void query(const char* sql) {
    once_flag once = ONCE_FLAG_INIT;
    call_once(&once, open_db);
    puts(sql);
}

call_once が「もう実行した」と覚えておく場所は、渡された once_flag そのものです。ところが once は query の自動変数なので、呼び出しのたびに新しい変数が作られ、ONCE_FLAG_INIT で「まだ実行していない」状態から始まります。1回目の旗は query から戻った時点で消えていて、2回目の call_once は初めて見る旗を受け取ります。そのため open_db は呼ぶたびに実行され、本物の接続なら、呼んだ回数だけ接続が作られて捨てられないまま残ります。

Right

static void query(const char* sql) {
    static once_flag once = ONCE_FLAG_INIT;
    call_once(&once, open_db);
    puts(sql);
}

static を付けると、once はプログラムの開始から終了まで生きる1つの変数になり、初期化子 ONCE_FLAG_INIT が効くのもプログラムの開始前の1回だけです。2回目の query は1回目と同じ旗を call_once に渡すので、open_db は呼ばれません。ブロックの中に書いたままなので、旗に触れるのは query だけです。
