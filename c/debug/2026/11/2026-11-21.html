record_sum.c

#include <stdio.h>
#include <string.h>

static unsigned checksum(const char* data) {
    unsigned sum = 0;
    for (size_t i = 0; i < strlen(data); i++)
        sum += (unsigned char)data[i];
    return sum;
}

int main(void) {
    char sent[] = {16, 0, 32, 48};
    char got[] = {16, 0, 33, 48};
    printf("%u\n", checksum(sent));
    printf("%u\n", checksum(got));
}

4バイトのレコードの全バイトを足したチェックサムを表示し、送ったレコード sent と受け取ったレコード got の値を比べて破損に気付くためのコードです。got は3バイト目が 32 から 33 に化けています。いまは 16 と 16 が表示されて、2つの値が一致してしまいます。本来は 96 と 97 が表示されるはずです。

Answer

Wrong

static unsigned checksum(const char* data) {
    unsigned sum = 0;
    for (size_t i = 0; i < strlen(data); i++)
        sum += (unsigned char)data[i];
    return sum;
}

strlen は、先頭から値が 0 のバイトを探し、その手前までのバイト数を返します。文字列なら 0 は終わりの印ですが、レコードはただのバイトの並びで、{16, 0, 32, 48} の2バイト目の 0 は中身の一部です。strlen(data) はここで止まって 1 を返すので、ループは先頭の 16 だけを足して終わります。

3バイト目の破損は足されないまま、sent も got も 16 になり、化けたレコードが正しいものとして通ってしまいます。0 のバイトより後ろがどう壊れても、このチェックサムは変わりません。

Right

static unsigned checksum(const char* data,
                         size_t n) {
    unsigned sum = 0;
    for (size_t i = 0; i < n; i++)
        sum += (unsigned char)data[i];
    return sum;
}

バイトの並びは、中身を見ても長さが分からないので、長さを呼び出し側から受け取ります。main では checksum(sent, sizeof sent) のように配列の大きさを渡します。sent と got は配列そのものなので、sizeof は4を返します。4バイトすべてが足され、sent は 16 + 0 + 32 + 48 = 96、got は 97 になって、破損が値の違いとして現れます。
