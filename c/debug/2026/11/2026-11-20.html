put_dec.c

#include <stdio.h>

static void put_dec(int n) {
    static int digit;
    digit = n % 10;
    if (n >= 10)
        put_dec(n / 10);
    putchar('0' + digit);
}

int main(void) {
    put_dec(123);
    putchar('\n');
}

0 以上の整数を10進で上の桁から1文字ずつ表示する put_dec です。put_dec(123) は 123 と表示するはずが、いまは 111 と表示します。

Answer

Wrong

static void put_dec(int n) {
    static int digit;
    digit = n % 10;
    if (n >= 10)
        put_dec(n / 10);
    putchar('0' + digit);
}

static を付けた局所変数はプログラム全体で1つしかなく、再帰でいくつ呼び出しが重なっても、すべての呼び出しが同じ digit を読み書きします。put_dec(123) は digit に 3 を入れてから put_dec(12) を呼び、そこで 2 に、さらに put_dec(1) で 1 に上書きされます。

putchar は再帰呼び出しから戻ったあとで実行されるので、最初に表示するのは一番深い put_dec(1) で、その時点の digit は 1 です。put_dec(12) と put_dec(123) も戻ってから同じ digit を読むため、どちらも 1 を表示し、111 になります。仮に putchar が再帰呼び出しの前にあれば、各段は自分で書いた直後に読むので壊れません。共有される変数と、読む時刻が深い呼び出しのあとであることが重なって、初めて欠陥になります。

Right

static void put_dec(int n) {
    int digit = n % 10;
    if (n >= 10)
        put_dec(n / 10);
    putchar('0' + digit);
}

static を外すと、digit は自動変数になり、呼び出しごとにそのフレームの中に別の digit が作られます。put_dec(1) が自分の digit を 1 にしても、put_dec(12) のフレームにある 2 には触れません。戻った各段は自分の桁を読むので、深い段から順に 1、2、3 と表示されます。

static は再帰の深さぶんの変数を節約するように見えますが、再帰の途中で値を覚えておく変数は、段ごとに別々でなければなりません。自動変数がフレームごとに作られるのは、まさにそのためです。
