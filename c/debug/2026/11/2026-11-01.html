write_report.c

#include <stdio.h>

int main(void) {
    FILE* f = fopen("report.txt", "a+");
    if (f == NULL) {
        return 1;
    }
    fputs("items: ?\napple\nbanana\n", f);
    fseek(f, 7, SEEK_SET);
    fputc('2', f);
    rewind(f);
    char line[32];
    while (fgets(line, sizeof line, f) != NULL) {
        fputs(line, stdout);
    }
    fclose(f);
}

新しいファイル report.txt に見出しと品目を書き、あとから先頭に戻って見出しの ? を品目の数 2 に書き換えてから、ファイル全体を表示するつもりのプログラムです。report.txt がまだ無い状態で実行すると、本来は items: 2、apple、banana の3行が表示されるはずが、いまは items: ?、apple、banana の3行のあとに、改行のない 2 が表示されます。

Answer

Wrong

FILE* f = fopen("report.txt", "a+");
fseek(f, 7, SEEK_SET);
fputc('2', f);

"a+" は追記モードで、このモードで開いたファイルへの書き込みは、ファイル位置がどこにあっても必ずファイルの末尾に行われます。fseek(f, 7, SEEK_SET) はファイル位置を先頭から7バイト進めた ? の位置に動かしますが、続く fputc('2', f) は末尾の banana\n の後ろに 2 を足します。見出しの ? はそのまま残り、表示の最後に改行のない 2 が付きます。

Right

FILE* f = fopen("report.txt", "w+");
fseek(f, 7, SEEK_SET);
fputc('2', f);

"w+" は、ファイルを新しく作って(あれば中身を空にして)読み書きの両方に開くモードで、書き込みはファイル位置に行われます。fseek で ? の位置に戻ってから書いた 2 は、その位置の ? を上書きします。ファイルの長さは変わらず、見出しが items: 2 になります。1

  1. すでにあるファイルの中身を残したまま一部だけを書き換えるなら、"r+" で開きます。"r+" はファイルが無いと失敗し、"w+" は中身を消してから開きます。
