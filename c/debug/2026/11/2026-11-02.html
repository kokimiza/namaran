to_int.c

#include <stdio.h>

int to_int(double x) {
    return (int)(x + 0.5);
}

int main(void) {
    printf("%d %d %d\n", to_int(2.5), to_int(-2.5), to_int(-0.7));
}

to_int は、double の値を小数第1位で四捨五入した int を返すつもりの関数です。ちょうど .5 のときは、正の数でも負の数でも0から遠い側へ丸めます。このプログラムを実行すると、本来は 3 -3 -1 と表示されるはずが、いまは 3 -2 0 と表示されます。

Answer

Wrong

return (int)(x + 0.5);

double から int への変換は、小数部分を捨てて0に近い側の整数にします。正の数なら切り捨てと同じなので、0.5 を足してから変換すると四捨五入になり、to_int(2.5) は 3.0 を変換して3です。

負の数では、0に近い側が大きい側になります。to_int(-2.5) は -2.0 を変換して -2、to_int(-0.7) は -0.2 の小数部分を捨てて0になり、どちらも本来の値より1大きくなります。

Right

return x < 0 ? (int)(x - 0.5) : (int)(x + 0.5);

負の数では 0.5 を引いてから変換します。変換が切り捨てる向きは正の数と負の数で逆になるので、0.5 の符号も x の符号に合わせます。-2.5 は -3.0 になって -3、-0.7 は -1.2 の小数部分を捨てて -1 です。math.h の lround も0から遠い側へ丸めるので、(int)lround(x) と書いてもかまいません。1

  1. 0.5 を足す書き方には、正の数でも誤る値があります。0.5 より1単位だけ小さい double の 0.49999999999999994 に 0.5 を足すと、和が丸められて 1.0 になり、四捨五入で0になるはずの値が1になります。lround はこの値も0にします。
