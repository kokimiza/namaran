escape_trace.c

#include <stddef.h>
#include <stdio.h>

size_t escape(const char *src, char *dst) {
    size_t j = 0;
    for (size_t i = 0; src[i] != '\0'; i++) {
        if (src[i] == '"' || src[i] == '\\') {
            dst[j++] = '\\';
        }
        dst[j++] = src[i];
    }
    dst[j] = '\0';
    return j;
}

int main(void) {
    char buf[32];
    size_t n = escape("a\"\\b", buf);
    printf("%s (%zu)\n", buf, n);
    return 0;
}

このプログラムを実行すると、何が出力されるでしょうか?

Answer

出力はa\"\\b (6)です。escapeは入力文字列を先頭から1文字ずつ見て、それが"または\\なら出力バッファへ\\を書き込んでから同じ文字を続けて書き込み(1文字を2文字に展開)、それ以外の文字はそのまま1文字コピーします。実行時の入力文字列"a\"\\b"は4文字a, ", \\, bです。1文字目のaはエスケープ対象ではないのでそのままdst[0]へコピーされます。2文字目の"はエスケープ対象なのでdst[1]に\\、dst[2]に"が書き込まれます。3文字目の\\も同様にdst[3]に\\、dst[4]に\\が書き込まれます。4文字目のbはそのままdst[5]へ。最後にdst[6]へ終端の'\0'を置き、書き込んだ文字数6を返します。エスケープ対象の文字が2つあったぶん、入力の4文字より出力が2文字多くなっている点にも注目してください。
