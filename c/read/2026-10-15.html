shifted_mean.c

#include <stdio.h>

static int mean(const int *x, int n) {
    int s = 0;
    for (int i = 0; i < n; i++) {
        s += x[i];
    }
    return s / n;
}

int main(void) {
    for (int k = -2; k <= 1; k++) {
        int x[] = {1 + k, 2 + k};
        printf("%d\n", mean(x, 2) - k);
    }
}

これは何を出力するでしょうか?

Answer

2、1、1、1 の4行です。

ループは {1, 2} の各要素に k を足した配列の平均を求め、そこから k を引いています。すべての要素に同じ数を足せば平均も同じだけ増えるので、平均が正しく計算できていれば、どの k でも元の {1, 2} の平均に戻るはずです。正しい出力を知らなくても、入力の変え方と出力の変わり方の関係から計算を確かめるこのやり方を、メタモルフィックテスト（metamorphic testing）といいます。

k が -1、0、1 のときは和が 1、3、5 で、s / n は 0、1、2 です。そこから k を引くと、どれも 1 になります。

k = -2 のときだけ和が -1 になります。C の整数の割り算は商の小数部を捨てて 0 の側へ丸めるので、-1 / 2 は -1 ではなく 0 です。0 - (-2) で、最初の行だけ 2 になります。割り算の結果を、それ以下の最大の整数へ丸める床関数（floor function）で求めていれば、4行とも 1 でした。0 の側への丸めは、商が正なら小さい側へ、負なら大きい側へ丸めることになるので、和が負になったところで床関数とずれます。
