index_scan.c

#include <stdio.h>

struct row {
    int dept, age;
};

int main(void) {
    struct row t[] = {
        {1, 25}, {1, 40}, {2, 22}, {3, 28}};
    int n = 0;
    for (int i = 0; i < 4; i++) {
        if (t[i].age > 30)
            break;
        n++;
    }
    printf("%d\n", n);
}

これは何を出力するでしょうか?

Answer

Output

1

配列 t は dept の昇順に並び、dept が同じ行の中だけ age の昇順に並んでいます。ループは age が 30 を超えた行で break します。i が 0 の {1, 25} で n が 1 になり、i が 1 の {1, 40} で 40 > 30 となってループを抜けます。残りの {2, 22} と {3, 28} は調べられないので、出力は 1 です。

age が 30 以下の行は 25、22、28 の3つあるので、3 と答えたくなります。それは表全体が age で並んでいると読んだときの答えです。途中で打ち切ってよいのは、その列で並んでいる範囲の中だけです。この表では dept が 1 から 2 に変わるところで、age が 40 から 22 に戻ります。2列目が昇順なのは、1列目が同じ値の行の中に限られます。

データベースの複合インデックスも、同じ順序で行を並べています。インデックスが (dept, age) の順なら、dept = 1 と age の範囲を組み合わせた条件は連続した範囲になり、そこだけ読めば済みます。age だけの条件ではこの範囲が作れないので、インデックスを先頭から最後まで読むことになります。
