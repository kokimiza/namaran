half_mean.c

#include <stdio.h>

int half(double x) {
    return x / 2;
}

double mean(int a, int b) {
    return (a + b) / 2;
}

int main(void) {
    printf("%d %.1f\n", half(-7), mean(3, 4));
}

これは何を出力するでしょうか?

Answer

Output

-3 3.0

プロトタイプで型を宣言した関数を呼ぶと、実引数は仮引数の型へ、return の式は戻り値の型へ、それぞれ代入と同じ規則で変換されます。half(-7) では、int の -7 が仮引数 x に入るときに double の -7.0 になります。x / 2 は double の割り算なので -3.5 です。この値を int で返すとき、浮動小数点数から整数への変換は小数部を捨てます。捨てる向きは0の方向なので、-3.5 は -3 になります。

mean(3, 4) は順番が逆です。(a + b) / 2 は int 同士の割り算で、7 / 2 は3になります。戻り値の型 double への変換はこの割り算が終わったあとに行われるので、返るのは3.0で、%.1f は 3.0 と表示します。戻り値の型が double でも、式の中の割り算が double で行われるわけではありません。

-3.5 を小さい方の整数へ丸めると考えると、half(-7) を -4 と答えます。戻り値の型が double なので割り算も小数で行われると考えると、mean(3, 4) を3.5と答えます。宣言した型への変換は値が関数に入るときと出るときにだけ起き、関数の中の式は、そのときのオペランドの型で計算されます。
