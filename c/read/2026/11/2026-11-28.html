count_back.c

#include <stdio.h>

int main(int argc, char* argv[]) {
    int n = 0;
    for (char** p = argv + argc; *p; p--)
        n++;
    printf("%d\n", n);
}

これは何を出力するでしょうか?

Answer

Output

0

C の規格は main の引数について、argv[argc] が NULL ポインタであると定めています。プログラム名と引数を指すポインタ argv[0] から argv[argc - 1] の後ろに、終わりの印として NULL が1つ置かれています。

ループは p = argv + argc から始まるので、最初の条件 *p で読むのはこの NULL です。条件は偽になり、本体は1度も実行されません。n は 0 のまま出力されます。引数をいくつ付けて起動しても、argc が 0 でも、最初に読むのは必ず argv[argc] なので結果は変わりません。

argv + argc を「最後の引数」と読むと、後ろから argv[0] まで数えて argc を出すように見えます。最後の引数は argv[argc - 1] で、argv + argc はその1つ先の NULL を指しています。
