shared_counter.c

#include <stdio.h>

int count(void) {
    static int n = 0;
    return ++n;
}

int twice(void) {
    static int n = 0;
    return n += 2;
}

int main(void) {
    int (*const table[])(void) = {count, twice, count};
    for (int round = 0; round < 2; round++) {
        for (int i = 0; i < 3; i++) {
            printf("%d", table[i]());
        }
    }
    printf("\n");
}

これは何を出力するでしょうか?

Answer

122344 です。

count と twice の n は static 付きのローカル変数で、静的記憶域期間を持ちます。初期化はプログラムの開始前に1度だけ行われ、値は呼び出しが終わっても残ります。count は呼ばれるたびに 1、2、3、…を、twice は 2、4、6、…を返します。static を見落として毎回 0 から数え直すと読むと、121121 になります。

もう1つの規則は、関数ポインタが関数の場所を指すだけだということです。table[0] と table[2] は同じ count を指し、どちらから呼んでも、動くのは同じ1つの count と、その中の1つの n です。C の関数ポインタには、ほかの言語のクロージャのように、値を一緒に抱えて持ち歩く仕組みがありません。枠ごとに別の数え方が続くと読むと、1周目が 121、2周目が 242 になり、121242 と答えることになります。

2つを合わせて呼ばれた順に追います。1周目は count が 1、twice が 2、もう一度の count が 2 を返します。2周目は count が 3、twice が 4、count が 4 です。続けて表示されるので 122344 になります。枠ごとに状態を持たせたいなら、関数ポインタと一緒に、状態を入れた構造体へのポインタを渡す必要があります。
