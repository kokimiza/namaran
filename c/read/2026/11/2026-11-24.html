stairs.c

#include <stdio.h>

long long memo[40] = {-1};

long long ways(int n) {
    if (memo[n] == -1) {
        memo[n] = n < 2
            ? 1
            : ways(n - 1) + ways(n - 2);
    }
    return memo[n];
}

int main(void) {
    for (int n = 0; n <= 4; n++) {
        printf("%lld\n", ways(n));
    }
}

これは何を出力するでしょうか?

Answer

Output

1
0
0
0
0

ways(n) は、1段か2段ずつ上って n 段の階段を上りきる方法の数を求め、計算した値を memo[n] に覚えておく関数です。memo[n] が -1 なら「まだ計算していない」とみなして計算し、それ以外なら覚えた値をそのまま返します。正しく動けば、出力は 1、1、2、3、5 になるはずです。

ところが、配列の初期化子 {-1} が -1 にするのは先頭の memo[0] だけです。初期化子に書かれなかった残りの要素は 0 で初期化されるので、memo[1] から memo[39] はすべて 0 から始まります。ways(0) は memo[0] が -1 なので計算し、1 を覚えて返します。ways(1) 以降は memo[n] が 0 で、-1 ではないので計算済みとみなされ、覚えてもいない 0 がそのまま返ります。

{-1} を「全要素を -1 にする」と読むと、1、1、2、3、5 と答えることになります。初期化子で全要素を同じ値にできるのは 0 のときだけで、{0} が全要素を 0 にするのも、書かれなかった要素が 0 になる規則のおかげです。-1 で埋めたいなら、使う前にループで代入します。
