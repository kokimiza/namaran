parity.c

#include <stdio.h>

bool is_odd(int x) {
    return x % 2 == 1;
}

int main(void) {
    for (int x = -3; x <= 2; x++) {
        if (is_odd(x) == is_odd(x + 1)) {
            printf("%d\n", x);
        }
    }
}

これは何を出力するでしょうか?

Answer

Output

-3
-2
-1

main は、-3 から 2 までの x について「隣り合う整数 x と x + 1 は、片方が奇数ならもう片方は偶数」という性質を確かめ、崩れた x を出力します。is_odd が正しければ何も出ないはずです。

C の整数除算は 0 の方向へ切り捨てるので、a % b は 0 でなければ、割られる数 a と同じ符号になります。正の奇数なら x % 2 は 1 ですが、-3 と -1 では -1 です。そのため is_odd は 1 と 3 にだけ真を返し、-3 と -1 には偽を返します。-3 から 0 までは is_odd がずっと偽なので、x が -3、-2、-1 のとき両隣がそろって偽になり、性質が崩れます。x が 0、1、2 のときは偽と真が交互に並び、性質は保たれます。

剰余がいつも 0 か 1 だと思って読むと、何も出力されないと答えます。0 以上の入力だけで確かめていれば、この関数は正しく見えます。負の数まで入力を広げたことで、初めて誤りが表に出ました。奇数の判定は x % 2 != 0 と書けば、符号に関係なく正しくなります。
