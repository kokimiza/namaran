digit_table.c

#include <stdio.h>

int key[4], count[4];

void add(int k) {
    int i = k % 4;
    while (count[i] && key[i] != k)
        i = (i + 1) % 4;
    key[i] = k;
    count[i]++;
}

int main(void) {
    for (const char* p = "51952"; *p; p++)
        add(*p - '0');
    for (int i = 0; i < 4; i++)
        printf("%d %d\n", key[i], count[i]);
}

これは何を出力するでしょうか?

Answer

Output

2 1
5 2
1 1
9 1

add は、キー k を k % 4 の枠から探し始めます。枠が使われていて（count[i] が0でない）、しかも別のキーが入っていれば、1つ右の枠へ進みます。右端の枠3の次は (3 + 1) % 4 で枠0に戻ります。同じキーの枠か空いた枠で止まり、そこにキーを書いて数を1増やします。

文字列 "51952" の各文字から '0' を引くので、キーは 5、1、9、5、2 の順に来ます。5 は 5 % 4 = 1 で枠1に入ります。1 も 1 % 4 = 1 ですが、枠1には 5 がいるので枠2に入ります。9 も 9 % 4 = 1 で、枠1と枠2を通り過ぎて枠3に入ります。2つ目の 5 は枠1で自分を見つけ、数が2になります。

最後の 2 は 2 % 4 = 2 なので枠2から探し始めますが、枠2には、枠1からずれてきた 1 が入っています。2 のための枠は 1 にふさがれていて、次の枠3も 9 で埋まっています。2 は右端から枠0へ回り込み、そこに入ります。キーはそれぞれ自分の枠に入ると読むと、2 は枠2にあるはずだと考えて、1行目を 0 0 と答えることになります。
