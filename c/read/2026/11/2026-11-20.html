stack_depth.c

#include <stdio.h>

static int depth, deepest;

static int visit(int n) {
    if (++depth > deepest)
        deepest = depth;
    int calls = 1;
    if (n > 0)
        calls += visit(n - 1) + visit(n - 1);
    depth--;
    return calls;
}

int main(void) {
    int calls = visit(3);
    printf("%d %d\n", calls, deepest);
}

これは何を出力するでしょうか?

Answer

Output

15 4

visit(n) は n が 0 より大きいとき visit(n - 1) を2回呼ぶので、呼び出しの数は段ごとに倍になります。visit(3) が1回、visit(2) が2回、visit(1) が4回、visit(0) が8回で、合わせて 15 回です。calls は自動変数なので、呼び出しごとに別の calls が1から始まり、子が返した数を足して自分の親へ返します。main が受け取るのは、この 15 です。

depth は関数に入ったときに1増え、戻る直前に1減ります。そのため depth はいまコールスタックに積まれている visit のフレームの数と一致し、deepest にはその最大値が残ります。1回目の visit(n - 1) が戻るまでに、その中で増えた depth はすべて減っているので、2回目の visit(n - 1) も同じ深さから始まります。スタックに同時に積まれるのは visit(3) から visit(0) までの一本の連なりだけで、深さは 4 にしかなりません。

呼び出しのたびにフレームが積まれたまま残ると考えると、深さも 15 と答えることになります。フレームは関数から戻った時点で取り除かれるので、深さは呼び出しの総数ではなく、再帰が一番深く潜った段の数で決まります。
