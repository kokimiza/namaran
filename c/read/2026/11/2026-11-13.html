copy.c

#include <stdio.h>

int main(void) {
    char a[] = "abc";
    const char* p = "abc";
    char* q = a;
    a[0] = 'x';
    printf("%s %s %s\n", a, p, q);
}

これは何を出力するでしょうか?

Answer

Output

xbc abc xbc

char a[] = "abc"; は、要素数4の配列 a を作り、文字列リテラルの 'a' 'b' 'c' '\0' をその要素へコピーします。a はリテラルとは別の、書き換えてよい自分の記憶域を持ちます。一方の p は配列ではなくポインタで、文字列リテラルそのものを指します。q は a の先頭を指すポインタです。

a[0] = 'x' が書き換えるのは配列 a の1文字目で、リテラルの "abc" には触れません。そのため a は xbc、p が指すリテラルは abc のままです。q は a と同じ記憶域を指しているので、a の変更がそのまま見えて xbc になります。

a と p を同じ "abc" を共有する名前だと読むと、3つとも xbc と答えてしまいます。共有しているのは q と a だけです。
