stale_min.c

#include <stdio.h>

int t[8] = {0, 2, 2, 6, 5, 2, 8, 6};

void set(int i, int v) {
    i += 4;
    t[i] = v;
    for (i /= 2; i >= 1; i /= 2)
        t[i] = t[i] < v ? t[i] : v;
}

int main(void) {
    set(1, 7);
    set(2, 4);
    printf("%d %d %d\n", t[1], t[2], t[3]);
}

これは何を出力するでしょうか?

Answer

Output

2 2 4

t は、4つの値 5, 2, 8, 6 を t[4] から t[7] に置いたセグメント木です。節点 k の子は 2 * k と 2 * k + 1 で、t[2] は先頭2つの最小値 2、t[3] は後ろ2つの最小値 6、根の t[1] は全体の最小値 2 を持っています。set は葉を書き換えたあと、i /= 2 で親へ上りながら、親の値を「いまの値と v の小さいほう」にします。

set(1, 7) は葉 t[5] を 2 から 7 に上げます。親の t[2] は min(2, 7) で 2 のまま、根も min(2, 7) で 2 のままです。消えたはずの 2 が親と根に残ります。set(2, 4) は葉 t[6] を 8 から 4 に下げます。t[3] は min(6, 4) で 4 になり、根は min(2, 4) で 2 です。出力は 2 2 4 です。

木が正しく保たれていると読むと、葉は 5, 7, 4, 6 なので 4 5 4 と答えます。親の最小値を新しい値とのminで直せるのは、値を下げる更新だけです。値を上げたときは、親がそれまで持っていた最小値がどの葉から来たかが分からず、もう一方の子と比べ直さないと正しい値になりません。正しい更新は、親ごとに t[i] = min(t[2 * i], t[2 * i + 1]) と2つの子から計算し直します。
