echo.c

#include <stdio.h>

void echo(int n) {
    if (n == 0)
        return;
    printf("%d", n);
    echo(n - 1);
    printf("%d", n);
}

int main(void) {
    echo(3);
    printf("\n");
}

これは何を出力するでしょうか?

Answer

Output

321123

echo(n) は、n を出力してから echo(n - 1) を呼び、その呼び出しが戻ってきたあとにもう一度 n を出力します。echo(3) は 3 を出して echo(2) を呼び、echo(2) は 2 を出して echo(1) を、echo(1) は 1 を出して echo(0) を呼びます。ここまでで出力は 321 です。

echo(0) は基底ケースで、何も出力せずにすぐ戻ります。戻った先は echo(1) の2つ目の printf で、1 を出して戻ります。続いて echo(2) が 2 を、echo(3) が 3 を出します。呼び出しは 3, 2, 1 の順に始まり、1, 2, 3 の順に終わるので、後ろの printf は呼び出しと逆の順に実行されます。出力は 321123 です。

2つの printf がどちらも呼び出しの順に出ると考えると、321321 と答えることになります。呼び出された関数は、自分の残りの文を、呼んだ echo(n - 1) がすべて終わるまで待っています。待っていた文が動き出すのは、深いほうから順です。
