print_digits.c

#include <stdio.h>

struct Bounce {
    struct Bounce (*next)(unsigned*);
};

static struct Bounce print_digits(unsigned* n) {
    struct Bounce rest = {*n >= 10 ? print_digits : NULL};
    putchar('0' + *n % 10);
    *n /= 10;
    return rest;
}

int main(void) {
    unsigned n = 1234;
    for (struct Bounce b = {print_digits}; b.next;)
        b = b.next(&n);
}

これは何を出力するでしょうか?

Answer

Output

4321

print_digits は自分を呼びません。続きがあるときは「次に print_digits を呼んでほしい」という値を rest に入れて返すだけで、実際に呼ぶのは main の for 文です。この形をトランポリンと呼びます。rest を作っても何も実行されないので、print_digits はそのまま、いまの *n の一の位を表示し、*n を10で割ってから戻ります。for 文が次の print_digits を呼ぶのは、戻ったあとです。

1234から始めると、1回目は4を表示して n を123にし、2回目は3を表示して12に、3回目は2を表示して1にします。4回目は *n が10未満なので rest.next が NULL になり、1を表示したところで for 文が終わります。表示は下の桁から順の 4321 です。改行は出しません。

「続きがあれば先に残りの桁を処理し、そのあとで一の位を表示する」という形は、再帰で桁を上から表示する定番の書き方 if (n >= 10) print_digits(n / 10); putchar('0' + n % 10); と同じに見えます。そう読むと 1234 を答えます。再帰呼び出しなら、呼び出し元は残りの桁の表示が終わるまで待ち、戻ってきてから自分の桁を表示します。トランポリンでは呼び出し元が先に戻ってしまうので、待つ場所がありません。再帰で「戻ってからする」と書いた処理は、トランポリンに直すと「次を頼む前にする」処理になり、順序が逆になります。上の桁から表示したいなら、表示する順序をデータとして持たせる必要があります。
