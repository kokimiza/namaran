column_widths.c

#include <stdio.h>

int main(void) {
    int width[] = {100, 050, 010};
    int total = 0;
    for (int i = 0; i < 3; i++) {
        total += width[i];
    }
    printf("%d\n", total);
}

これは何を出力するでしょうか?

Answer

Output

148

C の整数リテラルは、先頭の文字で基数が決まります。0x で始まれば16進数、C23 で加わった 0b で始まれば2進数、0 だけで始まれば8進数で、それ以外が10進数です。050 と 010 は先頭が 0 なので8進数として読まれ、値は 5 × 8 = 40 と 1 × 8 = 8 になります。100 は10進数のままなので、合計は 100 + 40 + 8 = 148 です。

3つの数を3桁にそろえて並べたつもりで読むと、50 と 10 を足して 160 と答えてしまいます。先頭に足した 0 は見た目を整えるだけのつもりでも、コンパイラにとっては「この数は8進数」という印です。8 や 9 を含む 090 なら8進数として読めずにコンパイルエラーになりますが、050 のように0〜7の数字だけでできていれば、黙って別の値になります。
