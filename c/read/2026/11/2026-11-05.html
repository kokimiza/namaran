line_length.c

#include <stdio.h>
#include <string.h>

int main(void) {
    char lines[][8] = {"ab\r\n", "cd\n", "ef"};
    for (int i = 0; i < 3; i++) {
        lines[i][strcspn(lines[i], "\n")] = '\0';
        printf("%zu\n", strlen(lines[i]));
    }
}

これは何を出力するでしょうか?

Answer

Output

3
2
2

strcspn(s, "\n") は、s の先頭から数えて、2つ目の引数に含まれる文字が最初に現れる位置を返します。探す文字は '\n' の1つだけで、'\r' はほかの文字と同じ扱いです。返った位置に '\0' を書くと、文字列はその '\n' の手前で終わります。

1行目の "ab\r\n" では、'\n' は先頭から4文字目にあり、strcspn は 3 を返します。そこを '\0' にすると残るのは "ab\r" で、strlen は '\r' も1文字に数えて 3 です。2行目の "cd\n" は '\n' だけが落ちて 2 になります。3行目の "ef" には '\n' が無いので、strcspn は文字列の長さ 2 を返し、もともと '\0' がある場所に '\0' を書き直すだけです。

Windows で作ったテキストの行は "\r\n" の2文字で終わります。'\n' だけを探して落とすと、1行目のように '\r' が行末に残り、見た目は ab でも長さは 3 になります。'\r' も落とすなら、2つ目の引数を "\r\n" にします。
