read_records.c

#include <stdio.h>

int main(void) {
    FILE* f = tmpfile();
    if (f == NULL) {
        return 1;
    }
    fputs("abcdefghij", f);
    rewind(f);
    char buf[12];
    size_t first = fread(buf, 4, 3, f);
    size_t second = fread(buf, 1, sizeof buf, f);
    printf("%zu %zu\n", first, second);
    fclose(f);
}

これは何を出力するでしょうか?

Answer

2 0 です。

fread(buf, 4, 3, f) は、4バイトの要素を最大3個読みます。戻り値は最後まで読めた要素の個数で、バイト数ではありません。ファイルは10バイトなので、要素は8バイト目までの2個が読めます。3個目の要素には残りの2バイトしかなく、最後まで読めないので数えません。first は2です。

ファイル位置は、要素の数ではなく、実際に読めたバイトの数だけ進みます。半端な3個目の2バイトも読んでいるので、位置は10バイト進んでファイルの終わりに着きます。そのため2回目の fread は1バイトも読めず、second は0です。

戻り値をバイト数だと考えると、10 0 と答えます。読み残した2バイトが次の fread で読めると考えると、2 2 と答えます。半端な要素のバイトは読み込まれますが、その要素の値は規格上不定で、使ってはいけません。
