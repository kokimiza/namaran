rounding.c

#include <math.h>
#include <stdio.h>

int main(void) {
    printf("%.0f %.0f %.0f\n", 0.5, 1.5, 2.5);
    printf("%.0f %.0f %.0f\n", round(0.5), round(1.5), round(2.5));
}

これは何を出力するでしょうか?

Answer

1行目が 0 2 2、2行目が 1 2 3 です。

%.0f は値を小数点以下0桁に丸めて表示します。丸め方はそのときの丸めの向きの設定に従い、プログラムの開始時の設定は「最も近い値へ。ちょうど真ん中なら偶数の側へ」です。0.5 は0と1の真ん中なので偶数の0に、1.5 と 2.5 はどちらも偶数の2になります。1

round は丸めの向きの設定に関係なく、ちょうど真ん中の値を0から遠い側へ丸めます。学校で習う四捨五入と同じで、round(0.5) は1、round(1.5) は2、round(2.5) は3です。結果はどれも整数ちょうどの double なので、%.0f はそのまま表示します。

%.0f も四捨五入だと考えると、1行目を 1 2 3 と答えます。0.5、1.5、2.5 はどれも2進数で誤差なく表せるので、1行目と2行目の違いは表し方の誤差ではなく、丸め方の違いから来ています。

  1. 規格は、__STDC_IEC_559__ を定義する処理系（GCC と glibc など）について、プログラム開始時の丸めの向きを「最も近い値へ」と定め、printf による10進数への変換もそのときの丸めの向きに従うと定めています。同じ丸めの向きは rint や nearbyint も使います。
