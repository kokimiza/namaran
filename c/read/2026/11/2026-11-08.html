max_elem.c

#include <stdio.h>

int* max_elem(int* first, int* last) {
    int* best = first;
    for (int* p = first; p != last; p++)
        if (*p >= *best)
            best = p;
    return best;
}

int main(void) {
    int a[] = {4, 7, 7, 2};
    for (int k = 0; k <= 4; k += 2)
        printf("%td ", max_elem(a + k, a + 4) - a);
    printf("\n");
}

これは何を出力するでしょうか?

Answer

Output

2 2 4

max_elem は、first から last の手前までの要素のうち最大のものを指すポインタを返します。best は first から始まり、*p >= *best のときに p へ移ります。比較が >= なので、同じ値が後ろに出てくると best はそちらへ移ります。k が0のときの範囲は 4, 7, 7, 2 で、best は a[1] の7に移ったあと、a[2] の7でもう一度移ります。返るのは a + 2 で、a を引くと2です。k が2のときの範囲は 7, 2 で、やはり a + 2 が返り、2です。

k が4のときは max_elem(a + 4, a + 4) で、要素が1つも無い範囲です。for の条件 p != last は最初から偽なので、ループは1回も回らず、*p も *best も読まれません。返るのは初期値の first、つまり a + 4 で、a を引くと4です。a + 4 は配列の最後の要素の1つ先を指すポインタです。C ではこのポインタを作ることも、同じ配列を指すポインタとの差を取ることも許されていて、参照外しさえしなければ未定義動作になりません。空の範囲に最大要素はありませんが、この関数は要素の代わりに終端の位置を返します。

比較を > と読むと、同じ7のうち先に出てくる a[1] が残ると考え、最初の値を1にして 1 2 4 と答えます。空の範囲で a[4] を読みに行くと考えると、落ちるか不定の値が出ると答えますが、空の範囲では比較が1回も行われないので、ポインタは参照外しされずに返るだけです。
