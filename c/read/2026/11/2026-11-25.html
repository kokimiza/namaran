toggle.c

#include <stdio.h>

int main(void) {
    bool a = false;
    bool b = false;
    int n = 0;
    for (int i = 0; i < 3; i++) {
        a = !a;
        b = ~b;
        n += a + b;
    }
    printf("%d %d %d\n", a, b, n);
}

これは何を出力するでしょうか?

Answer

Output

1 1 5

bool の値は、演算に使われる前に int へ昇格し、false は 0、true は 1 になります。!a は 0 と比べた結果を 0 か 1 で返すので、a = !a を繰り返すと a は true、false、true と入れ替わります。一方の ~b は、昇格した int のビットをすべて反転します。b が false なら ~0 で -1、true なら ~1 で -2 で、どちらも 0 ではありません。int を bool に代入すると 0 だけが false、それ以外はすべて true になるので、b = ~b のあとの b は毎回 true です。

n には a + b を足します。bool どうしの + も昇格した int の足し算なので、両方 true なら 2 です。1回目は a も b も true で 2、2回目は a が false、b が true で 1、3回目はまた両方 true で 2 を足し、n は 5 になります。最後の a と b はどちらも true で、printf には 1 として渡ります。

~b を !b と同じ反転と読むと、b も a と同じく true、false、true と変わり、n は 2 + 0 + 2 で 1 1 4 と答えることになります。~ の働きは分かっていても、a + b の結果が bool のように 1 で止まると考えると、n は 1 + 1 + 1 で 1 1 3 です。~ が昇格した int に働くことと、+ の結果も int のまま残ることの両方を使って、初めて 5 になります。
