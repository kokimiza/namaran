vla_sizeof.c

#include <stdio.h>

int main(void) {
    int n = 3;
    size_t row = sizeof(double[n++]);
    size_t one = sizeof(n++);
    printf("%zu %zu %d\n", row / sizeof(double), one / sizeof(int), n);
}

これは何を出力するでしょうか?

Answer

3 1 4 です。

sizeof が求めるのは被演算子の型の大きさで、型は式を実行しなくてもコンパイルの時点で決まります。そのため被演算子はふつう評価されません。sizeof(n++) の型は int なので、n++ は実行されず、one はただの sizeof(int) です。

例外は、被演算子の型が可変長配列のときです。double[n++] の大きさは要素数の式 n++ の値が分かるまで決まらないので、sizeof はこの式を実行時に評価します1。要素数には増やす前の3が使われ、そのあとで n は4になります。

2つの sizeof を同じ扱いにすると答えを外します。どちらも評価されないと読めば n は3のまま、どちらも評価されると読めば5になります。n++ が実行されるのは、それが配列の大きさを決める式になっている1行目だけです。

  1. C23 の規格は、sizeof の被演算子の型が可変長配列なら被演算子を評価し、そうでなければ評価しない、と定めています。C11 で任意の機能になった可変長配列は、C23 で型としては必須に戻りました。double[n++] のように型として使うだけなら、自動変数の可変長配列を持たない処理系でも書けます。
