drop_odd.c

#include <stdio.h>

static int *drop_odd(int *first, int *last) {
    int *out = first;
    for (; first != last; first++) {
        if (*first % 2 == 0) {
            *out++ = *first;
        }
    }
    return out;
}

int main(void) {
    int a[] = {2, 1, 4, 3, 6};
    int *end = drop_odd(a, a + 5);
    for (const int *p = a; p != a + 5; p++) {
        printf("%d", *p);
    }
    printf(" %td\n", end - a);
}

これは何を出力するでしょうか?

Answer

24636 3 です。

drop_odd は、同じ配列の中を first と out の2本のポインタで前から進みます。first は要素を1つずつ読み、偶数を見つけたときだけ、その値を out の位置に書いて out を1つ進めます。out が first を追い越すことはないので、まだ読んでいない要素を上書きすることはありません。2、4、6 が a[0]、a[1]、a[2] に順に書かれ、関数は a + 3 を返します。

書き換わったのは先頭の3要素だけで、配列の長さは5のままです。a[3] と a[4] には元の 3 と 6 が残っています。main は返された end ではなく a + 5 まで出力するので、詰め直した 246 のあとに、捨てたはずの奇数 3 を含む 36 が続きます。

a + 5 は配列の末尾の1つ先を指すポインタです。C では、このポインタを作って比べたり引き算したりすることは許されていますが、指す先を読むことは許されていません。ループは p != a + 5 で止まるので、*p で読むのは a[4] までです。end - a も同じ配列の中を指す2つのポインタの差で、値はその間にある要素の数、ここでは詰め直した偶数の個数の 3 です。関数が返す end は有効な中身の終わりを示す境目で、[a, end) の外にある要素は、読めても意味のない残り物です1。

  1. C++ の std::remove_if も同じ形で動き、要素を前に詰めて新しい終端を返すだけで、コンテナの長さは変えません。残り物を本当に消すには、戻り値を erase に渡します。
