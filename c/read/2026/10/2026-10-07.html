reverse.c

#include <stdio.h>
#include <string.h>

static void xor_swap(char *a, char *b) {
    *a ^= *b;
    *b ^= *a;
    *a ^= *b;
}

static void reverse(char *s) {
    for (int i = 0, j = (int)strlen(s) - 1; i <= j; i++, j--)
        xor_swap(&s[i], &s[j]);
}

int main(void) {
    char s[] = "abcde";
    reverse(s);
    reverse(s);
    puts(s);
}

これは何を出力するでしょうか?

Answer

de です。

1回目の reverse では strlen(s) が5なので、(i, j) は (0, 4)、(1, 3)、(2, 2) と進みます。最初の2組で両端の文字が入れ替わり、3組目では xor_swap が同じ s[2] を指すポインタを2つ受け取ります。すると1行目の *a ^= *b は s[2] ^= s[2] になり、同じ値どうしのXORで s[2] は0になります。残りの2行も0と0のXORなので0のままで、s の中身は 'e' 'd' '\0' 'b' 'a' '\0' になります。

2回目の reverse が呼ぶ strlen(s) は、最初の '\0' までの文字数を数えるので2を返します。入れ替えるのは (0, 1) の1組だけで、先頭の2文字が 'd' 'e' に戻ったところでループは終わります。長さが偶数なので i と j は重ならず、今度は文字が消えません。

puts も '\0' の手前までを出力するので、表示されるのは de だけです。配列の後ろには ba が残っていますが、'\0' より後ろは文字列として扱われません。

条件を i < j にすれば中央の文字は交換されず、2回の反転で abcde に戻ります。一時変数を使う交換なら、同じ場所どうしを交換しても値は変わりません1。

  1. XORによる交換は、一時変数のためのレジスタやメモリを惜しんだ時代の技法です。今のコンパイラは一時変数を使った交換をレジスタだけで済ませるので、XORで書いても速くはなりません。
