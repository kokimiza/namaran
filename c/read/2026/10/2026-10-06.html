dedup.c

#include <stdio.h>
#include <string.h>

static const char *seen[8];
static int nseen;

static int is_new(const char *key) {
    for (int i = 0; i < nseen; i++)
        if (strcmp(seen[i], key) == 0) return 0;
    seen[nseen++] = key;
    return 1;
}

int main(void) {
    const char *incoming[] = { "a1", "b2", "a1", "c3" };
    char buf[8];
    for (int i = 0; i < 4; i++) {
        strcpy(buf, incoming[i]);
        puts(is_new(buf) ? buf : "-");
    }
}

これは何を出力するでしょうか?

Answer

a1、-、-、- の4行です。

is_new は新しいキーを seen[nseen++] = key; で記録しますが、写しているのは key というポインタの値、つまり main の buf の先頭アドレスです。文字列の中身は写していません。1回目の呼び出しで seen[0] が buf を指すようになり、a1 は新しいキーとして出力されます。

2回目は、strcpy が buf を b2 で上書きしてから is_new(buf) を呼びます。seen[0] も同じ buf を指しているので、strcmp(seen[0], key) は b2 と b2 を比べて0を返し、b2 は処理済みと判定されます。3回目の a1 と4回目の c3 も、表にある唯一の記録が常にいま受け取ったキーそのものなので、どちらも - になります。

この表は、一度記録が入るとそれ以降のキーをすべて重複として扱い、再送だけでなく新しい要求まで捨ててしまいます。キーの中身を残すには、seen を char seen[8][8] にして strcpy(seen[nseen++], key) で写すか、strdup で複製します1。

  1. strdup は長く POSIX の関数でしたが、C23 で標準ライブラリに加わりました。複製した文字列は、使い終わったら free で解放します。
