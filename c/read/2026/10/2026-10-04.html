clear_bits.c

#include <stdio.h>

int main(void) {
    unsigned x = 0b101100;
    int n = 0;
    while (x &= x - 1)
        n++;
    printf("%d\n", n);
}

これは何を出力するでしょうか?

Answer

2 です。

x & (x - 1) は、x の最下位の1ビットを0にした値です。x - 1 では最下位の1ビットが0になり、その下の0がすべて1に変わるので、x との論理積を取るとそのビットから下がすべて0になります。0b101100 には1が3つあるので、このループは1の数を数えているように見え、3 と答えたくなります。

ところが、条件に書いてあるのは代入式 x &= x - 1 そのもので、代入式の値は代入した後の x です。x は1回目の評価で 0b101000、2回目で 0b100000、3回目で 0 になります。条件を評価した時点でビットはもう消えているので、n++ が実行されるのは結果が0でない最初の2回だけです。最後のビットを消した3回目は、数える前にループを抜けます1。

  1. 1の数を数えるなら、while (x) { x &= x - 1; n++; } のように、0かどうかを判定してから消します。C23 では <stdbit.h> の stdc_count_ones でも数えられます。0b101100 のような2進数の整数リテラルも、C23 で標準になりました。
