gauge.c

#include <stdio.h>

static double floor_at_zero(double x) {
    return x < 0.0 ? 0.0 : x;
}

int main(void) {
    double deltas[] = {-2.0, 0.0, 3.0};
    for (int i = 0; i < 3; i++) {
        printf("%g\n", floor_at_zero(deltas[i] * -0.5));
    }
}

これは何を出力するでしょうか?

Answer

1、-0、0 の3行です。

1つ目と3つ目は見たとおりです。-2.0 * -0.5 は 1.0 で、floor_at_zero はそのまま返します。3.0 * -0.5 は -1.5 なので、x < 0.0 が真になり 0.0 に置き換わります。2つ目の 0.0 * -0.5 は、0に何を掛けても0なので 0 と読みたくなりますが、ここで結果の符号が効いてきます。C の double が従う IEEE 754 の浮動小数点数は、0にも符号を持ち、+0.0 と -0.0 を別の値として表します1。掛け算の結果の符号は、結果が0でも「2つの符号が同じなら正、違えば負」で決まるので、正の0と負の数の積は -0.0 です。

-0.0 は floor_at_zero の比較を素通りします。比較演算では +0.0 と -0.0 は等しい値として扱われ、-0.0 < 0.0 は偽になるからです。関数は -0.0 をそのまま返します。printf は負の0を数値として正しく書くので、%g は符号を付けて -0 を出力します2。0より下に行かないはずの値が、画面には負の符号付きで出ます。比較を x <= 0.0 にすれば、-0.0 も 0.0 に置き換わり、0 と表示されます。

  1. C の規格は浮動小数点数の形式を IEEE 754 に限っていません。附属書 F(IEC 60559 浮動小数点算術)に従う処理系が IEEE 754 の規則で計算し、x86-64 や AArch64 の GCC と Clang はこれに従います。
  2. C の規格は printf の説明の脚注で、負の0と、丸めると0になる負の値を浮動小数点数の変換で書くと、結果にマイナス記号が付くと定めています。printf("%.0f", -0.4) も -0 になります。
