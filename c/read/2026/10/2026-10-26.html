slot_paste.c

#include <stdio.h>

#define SLOT(n) slot##n

int main(void) {
    int slot1 = 10, slot2 = 20;
    printf("%d %d\n", SLOT(2), SLOT(1 + 1));
}

これは何を出力するでしょうか?

Answer

20 11 です。

## は、両側にある字句(トークン)を貼り合わせて1つの字句にする演算子です。プリプロセッサは引数を計算せず、書かれた字句の並びのまま置き換えます。SLOT(2) は slot と 2 が貼り合わされて slot2 になり、20 が出ます。

SLOT(1 + 1) の引数は、1 と + と 1 の3つの字句です。## が slot と貼り合わせるのは引数の先頭の 1 だけなので、展開の結果は slot1 + 1 になり、10 + 1 の 11 が出ます。引数を先に 2 と計算して slot2 になると読むと、20 20 と答えることになります。
