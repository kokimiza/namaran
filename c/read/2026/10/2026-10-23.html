digits.c

#include <stdio.h>

int main(void) {
    char buf[8];
    int len = 0;
    for (int n = 120; n > 0; n /= 10) {
        buf[len++] = (char)('0' + n % 10);
    }
    buf[len] = '\0';
    printf("%s\n", buf);
}

これは何を出力するでしょうか?

Answer

021 です。

n % 10 は n の一の位なので、ループは数の下の桁から順に取り出します。n は120、12、1と進み、そのたびに一の位の0、2、1が buf[0]、buf[1]、buf[2] へ入ります。n が0になった時点でループを抜けるので、詰まった文字は3つです。

'0' + n % 10 が数字の文字になるのは、C の規格が '0' から '9' までの文字コードを連続して並べるよう定めているからです。0から9の値を '0' に足せば、どの文字コードでもその値の数字になります。このプログラムは詰めた文字を逆順に並べ直していないので、buf は下の桁から読んだ "021" のままです。先頭の 0 も文字の1つなので、%s はそれも省かずに出力します。
