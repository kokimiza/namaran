bench_macro.c

#include <stdio.h>

#define BENCH(n, stmt)              \
    for (int i = 0; i < (n); i++) { \
        stmt;                       \
    }

static volatile int sink;

int main(void) {
    int calls = 0;
    for (int i = 1; i <= 3; i++) {
        BENCH(i * 2, sink = ++calls);
    }
    printf("%d\n", calls);
}

これは何を出力するでしょうか?

Answer

0 です。

BENCH はマクロなので、引数は値として渡るのではなく、字句のまま本体に貼り込まれます。BENCH(i * 2, sink = ++calls); を展開すると、for (int i = 0; i < (i * 2); i++) { sink = ++calls; } になります。

この for の初期化節で宣言した i の有効範囲は、宣言の直後から始まり、条件式も含みます。そのため条件式の i * 2 の i は、外側のループの i ではなく、いま0で初期化したばかりの内側の i です。0 < 0 は偽なので本体は1回も実行されず、外側のループが3回まわっても calls は0のままです。

マクロを関数のように読むと、外側の i が1、2、3のときに2回、4回、6回まわると考えて 12 と答えます。同じ名前の i を宣言し直しているのでコンパイルできない、と考えるかもしれません。しかし for 文はそれ自体が1つのブロックなので、内側の i は外側の i を隠すだけで、エラーにはなりません。volatile の sink は、測る処理を最適化で消させないための書き方ですが、本体がそもそも実行されないので出力には関係しません。
