thirds.c

#include <stdio.h>

int main(void) {
    int n = 37, steps = 0;
    while ((n = n / 3))
        steps++;
    printf("%d %d\n", n, steps);
}

これは何を出力するでしょうか?

Answer

0 3 です。

(n = n / 3) は比較ではなく代入です。代入式は、左辺に代入したあとの値を式の値として持つので、while はこの代入で書き換わった n が 0 かどうかで続けるかを決めます。括弧が二重になっているのは、== の書き間違いではなく、代入した値を条件に使うつもりだと示す慣用です1。

n は 37 から 12、4、1 と変わり、どれも 0 ではないので、そのたびに steps が増えて 3 になります。次の判定では 1 / 3 の 0 が n に入り、その 0 が条件の値になってループを抜けます。判定のたびに代入も済んでいるので、ループのあとの n は最後に条件を通った 1 ではなく、偽と判定された 0 です。

  1. GCC と Clang は -Wall で、括弧が1組だけの while (n = n / 3) に「真偽値として使われている代入を括弧で囲め」という警告を出します。括弧を二重にすると、意図した代入とみなして警告を出しません。
