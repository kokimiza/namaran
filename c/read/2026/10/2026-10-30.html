label.c

#include <stdio.h>

static const char* label(int n) {
    static char buf[8];
    snprintf(buf, sizeof buf, "#%d", n);
    return buf;
}

int main(void) {
    const char* first = label(1);
    const char* second = label(2);
    printf("%s %s\n", first, second);
}

これは何を出力するでしょうか?

Answer

#2 #2 です。

label の buf には static が付いているので、呼び出しのたびに作られる配列ではなく、プログラムの実行中ずっと1つだけある配列です。label が返すのはその配列の先頭を指すポインタで、first と second はどちらも同じ buf を指します。

label(1) が buf に書いた #1 は、続く label(2) が同じ buf に #2 を書いた時点で消えます。printf が2つのポインタから文字列を読むのはその後なので、どちらの %s も #2 になります。ポインタを変数に取っておいても、残るのは場所だけで、取っておいた時点の中身は残りません。

label を「文字列を作って返す関数」とだけ読むと、呼び出しごとに別の文字列ができると考えて #1 #2 と答えてしまいます。
