auto_copy.c

#include <stdio.h>

struct pair { int v[2]; };

int main(void) {
    int raw[2] = {1, 2};
    struct pair boxed = {{1, 2}};

    auto r = raw;
    auto b = boxed;
    r[0] = 10;
    b.v[0] = 10;

    printf("%d %d %d\n", raw[0], boxed.v[0], b.v[0]);
}

これは何を出力するでしょうか?

Answer

10 1 10 の1行です。

auto で宣言した変数の型は、初期化子の式の型で決まります。式の中に配列の名前を書くと、その配列は先頭要素へのポインタに変換されるので、auto r = raw; の r は int * になって raw の先頭を指します1。そのため r[0] = 10 は、raw[0] そのものを10に書き換えます。

構造体の値にはこの変換が起きません。auto b = boxed; の b は struct pair 型の新しい変数で、メンバの配列 v ごと boxed の中身がコピーされます。b.v[0] = 10 が変えるのは b の中の配列だけなので、boxed.v[0] は1のまま、b.v[0] は10です。

  1. C23 の規格は、auto で宣言した変数の型を、初期化子に配列からポインタへの変換などを施したあとの型と定めています。auto の型が配列型になることはありません。
