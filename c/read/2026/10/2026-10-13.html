read_varint.c

#include <stdio.h>

int main(void) {
    const unsigned char buf[] = {0x96, 0x01, 0x05};
    unsigned value = 0;
    int i = 0, shift = 0;
    unsigned char b;
    do {
        b = buf[i++];
        value |= (unsigned)(b & 0x7F) << shift;
        shift += 7;
    } while (b & 0x80);
    printf("%u %d\n", value, i);
}

これは何を出力するでしょうか?

Answer

150 2 です。

ループは1バイト読むたびに、その下位7ビット b & 0x7F を shift だけ左へずらして value に重ね、shift を7増やします。最上位ビット 0x80 は続きのバイトがあるという印で、これが立っていないバイトを読んだところでループを抜けます。

1バイト目の 0x96 は最上位ビットが立っており、下位7ビットは 0x16、10進で22です。このときの shift は0なので、value は22になります。2バイト目の 0x01 は最上位ビットが立っていないので最後のバイトで、1を7ビットずらした128が足されて value は150、読んだバイト数 i は2になります。3バイト目の 0x05 は読まれません。

先に読んだバイトほど下の桁を持つので、数字を左から読む感覚とは並びが逆です。0x16 を上の桁として 0x16 << 7 | 0x01 と組み立てると、2817になってしまいます。
