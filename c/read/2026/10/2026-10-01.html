parse.c

#include <stdbool.h>
#include <stdio.h>

static bool parse(const char *s, int *out) {
    *out = 0;
    for (; *s != '\0'; s++) {
        if (*s < '0' || *s > '9')
            return false;
        *out = *out * 10 + (*s - '0');
    }
    return true;
}

int main(void) {
    int n = 99;
    bool ok = parse("12x4", &n);
    printf("%d %d\n", ok, n);
}

これは何を出力するでしょうか?

Answer

0 12 です。

parse は最初に *out = 0 と書き、数字を1文字読むたびに *out を更新します。out が指しているのは main の n そのものなので、n は 0、1、12 と順に書き換わっていきます。

3文字目の 'x' で parse は false を返しますが、それまでに n へ書いた値を元に戻す処理はどこにもありません。失敗したのだから n は呼ぶ前の 99 のまま、と読むと 0 99 と答えてしまいます。実際の n は途中まで読んだ 12 で、false の ok は printf に int の 0 として渡ります。
