shared_rows.c

#include <stdio.h>

int main(void) {
    int grid[2][3] = {{1, 2, 3}, {1, 2, 3}};
    int row[3] = {1, 2, 3};
    int *rows[2] = {row, row};
    int **m = rows;

    grid[0][1] = 9;
    m[0][1] = 9;
    printf("%d %d\n", grid[1][1], m[1][1]);
    return 0;
}

これは何を出力するでしょうか?

Answer

2 9 です。

grid は2行3列の int 6個を1つの領域に並べた配列で、grid[0] と grid[1] はその前半と後半にあたる別々の3要素です。grid[0][1] = 9 が書き換えるのは1行目の2番目だけなので、grid[1][1] は初期化したときの 2 のままです。

m のほうはポインタの配列 rows を指していて、m[0][1] は「m[0] が指す先の2番目」を意味します。rows の2つの要素はどちらも同じ row を指しているので、m[0][1] と m[1][1] は同じ int です。m[0][1] = 9 のあとは、m[1][1] を読んでも 9 が返ります。

grid[i][j] と m[i][j] は見た目が同じでも、たどり方が違います。grid[i][j] は先頭から i * 3 + j 個先の要素の位置を直接計算しますが、m[i][j] はまずメモリから m[i] というポインタを読み、その値が指す先へ進みます。そのため行ポインタの配列では、行がどこにあるのか、行どうしが重なっていないのかは、ポインタに何を入れたかで決まります。
