add_twice.c

#include <stdio.h>

static void add_twice(int *dst, const int *src) {
    *dst += *src;
    *dst += *src;
}

int main(void) {
    int a = 3, b = 3;
    add_twice(&a, &b);
    add_twice(&b, &b);
    printf("%d %d\n", a, b);
    return 0;
}

これは何を出力するでしょうか?

Answer

9 12 と出力されます。

1回目の呼び出しでは dst が a を、src が b を指しています。b は変わらないので、a には 3 が2回足されて 9 になります。2回目は dst と src がどちらも b を指します。1行目の *dst += *src で b が 6 になり、2行目の *src はその新しい値を読むので、6 + 6 で 12 です。

ポインタが渡すのは値ではなく場所なので、*dst と *src は名前が違っても、同じ場所を指していれば片方への書き込みがもう片方から見えます。1つのオブジェクトを2つの名前で参照しているこの状態を、エイリアシングと呼びます。src の const が禁じているのは src を通した書き込みだけで、指している先が別の名前から書き換えられることまでは防ぎません1。関数の最初で int v = *src; と値を写しておけば、どちらの呼び出しでも元の値の2倍が足されます。

  1. 重ならないことを関数の約束にしたいときは、引数を int *restrict dst, const int *restrict src と宣言します。restrict は呼び出し側への要求で、同じ場所を渡して書き換えたときの動作は未定義になります。その代わりコンパイラは、*src を1回だけ読むような最適化をしてよくなります。
