month_end.c

#include <stdio.h>
#include <time.h>

int main(void) {
    struct tm a = {.tm_year = 123, .tm_mon = 10, .tm_mday = 30, .tm_hour = 12, .tm_isdst = -1};
    struct tm b = a;
    a.tm_mon += 3;
    b.tm_mon += 4;
    b.tm_mday = 0;
    mktime(&a);
    mktime(&b);
    printf("%d-%02d-%02d\n", a.tm_year + 1900, a.tm_mon + 1, a.tm_mday);
    printf("%d-%02d-%02d\n", b.tm_year + 1900, b.tm_mon + 1, b.tm_mday);
}

これは何を出力するでしょうか?

Answer

Output

2024-03-01
2024-02-29

struct tm の tm_year は1900年からの年数、tm_mon は1月を0とする月です。a と b はどちらも2023年11月30日から始まります。mktime は範囲外の値を受け付け、あふれた分を上の桁へ繰り上げたり下げたりして、正しい日付に直してから構造体に書き戻します。

a は tm_mon が10から13になります。13か月は1年と1か月なので、2024年の2月です。日は30のままですが、2024年は4で割り切れて100では割り切れないので閏年で、2月は29日までしかありません。2月30日は2月29日の翌日として3月1日になります。b は tm_mon が14で2024年3月、日が0です。0日は1日の前の日なので、3月1日の前日の2月29日を指します。翌々月の0日を作ると、翌月の末日がその月の長さを調べずに得られます。

どれか1つの規則を落とすと、それぞれ別の答えになります。mktime があふれた日を月末で止めると考えると a は 2024-02-29 です。閏年を忘れると、2月30日は3月2日、3月0日は2月28日になります。0日を1日と同じに扱うと b は 2024-03-01 で、月の13と14を年に繰り上げなければ年は2023のままです。tm_hour を12にして tm_isdst を -1 にしてあるのは、夏時間の切り替えで時刻が前後しても日付が動かないようにするためです。
