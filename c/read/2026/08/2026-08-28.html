max_macro.c

#include <stdio.h>

#define MAX(a, b) ((a) > (b) ? (a) : (b))

int main(void) {
    int i = 5;
    int j = 3;
    int a = MAX(i++, j);
    int b = MAX(j++, i);
    printf("%d %d %d %d\n", a, b, i, j);
}

これは何を出力するでしょうか?

Answer

6 7 7 4 です。

MAX は関数ではなくマクロなので、引数は値として渡されず、書いた字句のまま置き換え先に埋め込まれます。MAX(i++, j) は ((i++) > (j) ? (i++) : (j)) に展開され、i++ が2か所に現れます。

条件の i++ は増やす前の5を返して i を6にし、5 > 3 は真になります。条件演算子は条件を評価し終えてから選んだ側を評価するので、2つ目の i++ が6を返し、i は7になります1。a に入るのは、比べた5でも、最後の7でもない6です。

MAX(j++, i) でも条件の j++ は評価され、3を返して j を4にします。今度は 3 > 7 が偽なので、選ばれるのは (i) の側です。条件演算子は選ばなかった側を評価しないため、2つ目の j++ は実行されず、j は4のまま、b は i の7になります。同じ MAX でも、引数に書いた ++ が実行される回数は、どちらの側が選ばれるかで1回にも2回にもなります。

  1. 条件演算子の第1オペランドの評価は、第2・第3オペランドの評価より前に順序付けられる（sequenced before）と規格で決まっています。そのため1つの式の中で i を2回変更しても未定義動作にはなりません。
