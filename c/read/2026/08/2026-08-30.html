leak.c

#include <stdio.h>

static int steps = 0;

static int check(const char* secret, const char* guess) {
    for (int i = 0; secret[i] != '\0'; i++) {
        steps++;
        if (secret[i] != guess[i])
            return 0;
    }
    return 1;
}

int main(void) {
    int a = check("pass", "pazz");
    int b = check("pass", "pass");
    printf("%d %d %d\n", a, b, steps);
}

これは何を出力するでしょうか?

Answer

Output

0 1 7

check は secret と guess を先頭から1文字ずつ比べ、食い違う文字を見つけた時点で return 0 で抜けます。steps はループの本体に入るたびに1増え、比べた文字の数を数えます。

1回目の "pazz" は p と a が一致し、3文字目で z と s が食い違うので、3回比べたところで 0 を返します。steps はファイルの先頭で一度だけ 0 に初期化される変数で、check の中では 0 に戻しません。2回目の "pass" は4文字すべてが一致し、secret の終端でループを出て 1 を返すので、steps は 3 に 4 を足した 7 になります。呼び出しのたびに 0 から数え直すと考えると最後の値は 4 になりますが、それは2回目の呼び出しだけで比べた回数です。

比べる回数は、推測の先頭から当たった文字数に1を足した数で、全部当たったときは文字数そのものです。実行にかかる時間がこの回数に比例するなら、時間を測るだけで、推測の先頭が何文字当たったかが外から分かります。"pzzz"、"pazz"、"pasz" と1文字ずつ当てていけば、全通りを試さなくても秘密の文字列にたどり着けます。
