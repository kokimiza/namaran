tick.c

#include <stdio.h>

int tick(void) {
    static int count = 0;
    int calls = 0;
    count = count + 1;
    calls = calls + 1;
    return count * 10 + calls;
}

int main(void) {
    tick();
    tick();
    printf("%d\n", tick());
}

これは何を出力するでしょうか?

Answer

Output

31

static int count = 0; の = 0 は初期化子です。static を付けた局所変数はプログラムの開始から終了まで同じ1つの場所にあり、初期化はプログラムが始まる前に1回だけ行われます。関数に入るたびにこの行が実行されて 0 に戻るわけではありません。一方、static の無い int calls = 0; は、tick に入るたびに新しく作られ、そのたびに 0 で初期化されます。

count = count + 1; は代入文なので、呼び出しのたびに実行されます。count は1回目の呼び出しで 1、2回目で 2、3回目で 3 になります。calls は毎回 0 から始まるので、どの呼び出しでも 1 です。3回目の戻り値は 3 * 10 + 1 で 31 です。

static int count = 0; を、関数に入るたびに実行される代入文と同じように読むと、count も毎回 0 に戻り、答えは 11 になります。宣言の = と代入文の = は見た目が同じでも、前者は変数ができるときに一度だけ値を与え、後者は実行されるたびに値を書き換えます。
