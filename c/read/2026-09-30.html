farewell.c

#include <stdio.h>
#include <stdlib.h>

static void first(void) {
    puts("first");
}

static void second(void) {
    puts("second");
}

int main(void) {
    atexit(first);
    atexit(second);
    puts("main");
}

これは何を出力するでしょうか?

Answer

main、second、first の3行です。

main には exit の呼び出しがありませんが、main から戻ることは exit を呼ぶのと同じ扱いです。最後の } まで進むと exit(0) と同じ終了処理が始まるので、puts("main") のあとに後始末の関数が呼ばれます。

atexit で登録した関数は、登録とは逆の順で呼ばれます。先に登録した first が最後になり、後から登録した second が先に出力されます。

後始末の関数が puts で書いた内容も失われません。exit は登録された関数をすべて呼び終えてから、開いているストリームのバッファを吐き出して閉じるからです1。

  1. 同じ終了でも _Exit は登録された関数を呼ばず、バッファを吐き出すかどうかも処理系に任されています。main の最後で _Exit(0) を呼ぶと、second も first も呼ばれません。
