max_munch.c

#include <stdio.h>

int main(void) {
    int a = 5, b = 3;
    int c = a+++b;
    printf("%d %d %d\n", a, b, c);
    return 0;
}

これは何を出力するでしょうか?

Answer

6 3 8 と出力されます。

Cの翻訳では、構文を見るより前に、字句解析がソースをトークンに分けます。このとき、残りの文字の先頭から、トークンになりうる最も長い並びを切り出します1。a を切り出したあとの +++b から取れる最長のトークンは ++ で、続く + は単独の + になります。したがって式は a++ + b です。

後置の a++ は増やす前の 5 を値にするので、c は 5 + 3 で 8、a は 6 になります。b には誰も触れないので 3 のままです。a + ++b と読んだときの 6 4 9 にはなりません。字句解析は文法を見ないので、「こう分ければ意味が通る」という理由で切り方を変えることはないからです。読み手に意図を伝えたいなら、空白を入れて a++ + b と書きます。

  1. C23 の 6.4 で、次の前処理トークンは「前処理トークンを構成しうる最長の文字の並び」と定められています。a+++++b が a++ ++ + b と切られ、左辺値でない a++ に ++ を適用しようとしてコンパイルエラーになるのも、同じ規則によります。a++ + ++b と切れば正しい式になりますが、字句解析はそちらを選びません。
