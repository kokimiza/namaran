max_of.c

#include <stdio.h>

static int max_of(const int *a, int n) {
    int best = 0;
    for (int i = 0; i < n; i++)
        if (a[i] > best)
            best = a[i];
    return best;
}

int main(void) {
    int a[] = {-4, -2, -7};
    printf("%d %d\n", max_of(a, 3), max_of(a, 0));
}

これは何を出力するでしょうか?

Answer

0 0 です。

best は 0 から始まり、a[i] がそれより大きいときだけ置き換わります。{-4, -2, -7} の要素はどれも 0 より小さいので一度も置き換わらず、最大値の -2 ではなく初期値の 0 が返ります。

長さ 0 で呼ぶとループは1回も回らないので、こちらも初期値の 0 が返ります。配列に無い 0 が最初から比べる相手に入っているせいで、負の数だけの配列と空の配列が同じ答えになり、返り値からは区別できません。

初期値を a[0] にすれば負の数だけの配列は正しく扱えますが、今度は空の配列で a[0] を読めません。空のときに何を返すかは、初期値とは別に決める必要があります。
