byte_count.c

#include <stdio.h>
#include <uchar.h>

int main(void) {
    const char8_t word[] = u8"naïve";
    size_t n = 0;
    while (word[n] != 0)
        n++;
    printf("%zu\n", n);
}

これは何を出力するでしょうか?

Answer

6 です。

u8"naïve" は UTF-8 で符号化される文字列リテラルで、配列 word の要素はそのバイト列の1バイトずつです。ループは値が 0 の要素に当たるまで n を増やすので、数えているのは文字ではなくバイトです。

n、a、v、e は ASCII の文字なので1バイトずつですが、ï(U+00EF)は UTF-8 では 0xC3 0xAF の2バイトになります。見た目は5文字でも終端の手前までに6バイトあり、n は 6 で止まります1。

  1. C23 では、u8 の付いた文字列リテラルの要素型が char8_t(unsigned char の別名)になりました。C17 までは char でした。そのため C23 で strlen に渡すには const char * へのキャストが要ります。
