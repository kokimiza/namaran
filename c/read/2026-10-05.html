reinterpret.c

#include <stdint.h>
#include <stdio.h>

union word {
    int32_t s;
    uint32_t u;
};

int main(void) {
    union word w = { .s = -8 };
    w.u >>= 28;
    printf("%ld\n", (long)w.s);
}

これは何を出力するでしょうか?

Answer

15 です。

共用体のメンバは同じ記憶域を共有するので、w.s に入れた -8 のビット列は w.u からもそのまま読めます。int32_t は2の補数で表すと決まっている型で、-8 のビット列は 0xFFFFFFF8 です。uint32_t の w.u から見ると、これは 4294967288 という正の数です。

w.u >>= 28 は uint32_t の右シフトなので、空いた上位ビットには0が入り、0xFFFFFFF8 >> 28 は 0xF になります。上位ビットが0になったので、w.s から読み直しても値は 15 のままです。-8 >> 28 を符号付きのまま計算したときのように負の数にはなりません1。

  1. 負の数の右シフトは、C23 でも結果が処理系定義です。多くの処理系は符号ビットを複製する算術シフトをするので、-8 >> 28 は -1 になります。
  2. 最後に書いたのと別のメンバを読むと、そのバイト列を読んだメンバの型で解釈し直す、と C の規格は脚注で説明しています。C++ では同じ読み方が未定義動作です。
