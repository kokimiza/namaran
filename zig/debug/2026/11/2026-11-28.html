peak.zig

const std = @import("std");

fn Peak(comptime T: type) type {
    return struct {
        best: T = 0,
        fn add(self: *@This(), x: T) void {
            self.best = @max(self.best, x);
        }
    };
}

pub fn main(init: std.process.Init) !void {
    var p: Peak(i32) = .{};
    for ([_]i32{ -5, -2, -9 }) |x| p.add(x);
    const stdout = std.Io.File.stdout();
    var w = stdout.writer(init.io, &.{});
    try w.interface.print("{}\n", .{p.best});
}

Peak(T) は、整数型 T の値を add で1つずつ受け取り、それまでに受け取った値の最大値を best に持つ struct 型を返すつもりの関数です。main は Peak(i32) の値に -5、-2、-9 を順に add し、best を出力します。

いまの出力

0

本来の出力

-2
Answer

Wrong

return struct {
    best: T = 0,

best の初期値は、T が何であっても 0 です。add は @max で今の best と新しい値の大きいほうを残すので、-5、-2、-9 はどれも 0 に負け、best は 0 のまま変わりません。受け取っていない 0 が答えになります。T が u8 や u32 なら 0 は最小値なのでこの欠陥は出ませんが、i32 のような符号付きの型では 0 より小さい値があります。

Right 時間計算量 𝒪(1) 空間計算量 𝒪(1) 

return struct {
    best: T = std.math.minInt(T),

std.math.minInt(T) は整数型 T の最小値を返します。Peak(i32) なら -2147483648、Peak(u8) なら 0 で、どちらもその型のどの値にも @max で負けるか等しいので、最初に add した値がそのまま best に入ります。-5、-2、-9 では -5 が入ったあと -2 に替わり、-9 では変わらずに -2 が残ります。minInt の引数 T は Peak の comptime 引数なので、Peak を呼んだ型ごとにその型の最小値が初期値になります。
