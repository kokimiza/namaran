tally.zig

const std = @import("std");

const Tally = struct {
    n: u32 = 0,
    fn add(self: Tally, k: u32) void {
        var t = self;
        t.n += k;
    }
};

pub fn main() void {
    const t: Tally = .{};
    t.add(3);
    std.debug.print("{d}\n", .{t.n});
}

Tally の n に k を足すメソッド add です。t.add(3) のあとで t.n を表示すると 3 になるはずが、いまは 0 と表示されます。

Answer

Wrong

const Tally = struct {
    n: u32 = 0,
    fn add(self: Tally, k: u32) void {
        var t = self;
        t.n += k;
    }
};

pub fn main() void {
    const t: Tally = .{};
    t.add(3);

add は self を Tally の値で受け取るので、self は呼び出し側の t を写した引数です。Zig の引数は変更できないため、self.n += k とは書けず、このコードは var t = self; でもう1つ写しを作ってから、その n に 3 を足しています。足した結果は add から戻ると写しごと消えます。

main の t は一度も変更されないので、const で宣言してもコンパイルが通り、t.n は初期値の 0 のままです。

Right

const Tally = struct {
    n: u32 = 0,
    fn add(self: *Tally, k: u32) void {
        self.n += k;
    }
};

pub fn main() void {
    var t: Tally = .{};
    t.add(3);

self を *Tally で受け取ると、t.add(3) は t のアドレスを渡します。メソッドを t.add(3) の形で呼ぶとき、第1引数がポインタなら &t は Zig が自動で取るので、呼び出し側の書き方は変わりません。self.n += k はポインタの先にある t そのものを書き換えます。

t は add を通して変更されるので、var で宣言します。const のままだと、変更できない値のアドレスを *Tally に渡せずコンパイルエラーになり、取り違えはそこで見つかります。
