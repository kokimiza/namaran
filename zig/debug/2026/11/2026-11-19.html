port.zig

const std = @import("std");

fn parsePort(text: []const u8) !u16 {
    return std.fmt.parseInt(u16, text, 10);
}

pub fn main(init: std.process.Init) !void {
    var buf: [64]u8 = undefined;
    const stdout = std.Io.File.stdout();
    var w = stdout.writer(init.io, &buf);
    const out = &w.interface;
    const port = try parsePort("8080\n");
    try out.print("{d}\n", .{port});
    try out.flush();
}

設定ファイル port.txt の中身からポート番号を読み、標準出力に出すつもりのプログラムです。parsePort に渡している "8080\n" は、port.txt を丸ごと読んだ中身の代わりです。8080 と出るはずが、いまは標準出力に何も出ず、標準エラーに error: InvalidCharacter とエラーの経路を出して終了します。

Answer

Wrong

fn parsePort(text: []const u8) !u16 {
    return std.fmt.parseInt(u16, text, 10);
}

テキストファイルは最後の行も改行で終わるのがふつうなので、port.txt を丸ごと読むと "8080\n" の5バイトになります。std.fmt.parseInt は先頭の + や - と _ のほかは数字しか受け付けず、前後の空白や改行も読み飛ばしません。4桁を読んだあとの '\n' が数字ではないので error.InvalidCharacter を返し、main の try がそれをそのまま返して、print に着く前にプログラムが終わります。

Right

fn parsePort(text: []const u8) !u16 {
    return std.fmt.parseInt(
        u16,
        std.mem.trimEnd(u8, text, "\r\n"),
        10,
    );
}

std.mem.trimEnd(u8, text, "\r\n") は、text の末尾から '\r' と '\n' を取り除いたスライスを返します。parseInt に渡るのは "8080" になり、8080 を返します。'\r' も取り除くので、改行が "\r\n" のファイルでも同じように読めます。数字の途中に紛れ込んだ文字は取り除かないので、壊れた設定はこれまでどおり error.InvalidCharacter で止まります。
