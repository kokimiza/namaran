wrap_each.zig

const std = @import("std");

pub fn main(init: std.process.Init) !void {
    var buf: [256]u8 = undefined;
    var stdout_writer = std.Io.File.stdout().writer(init.io, &buf);
    const stdout = &stdout_writer.interface;
    inline for (.{ @as(u8, 200), @as(i8, 100), @as(u16, 300) }) |x| {
        try stdout.print("{d}\n", .{x +% 100});
    }
    try stdout.flush();
}

これは何を出力するでしょうか?

Answer

Output

44
-56
400

.{ ... } はタプル（tuple）で、要素ごとに型を持てます。ここでは u8 の 200、i8 の 100、u16 の 300 が並び、共通の型にそろえられることはありません。型の違う要素を並べたタプルは、ふつうの for では回せず、inline for で回します。inline for はループをコンパイル時に要素の数だけ展開し、展開した各回の x はその要素の型を持ちます。同じ x +% 100 が、1回目は u8、2回目は i8、3回目は u16 の式として別々にコンパイルされます。

+% は、結果が型の範囲を超えたら回り込む足し算です。u8 の範囲は 0 から 255 なので、200 + 100 = 300 から 256 を引いた 44 になります。i8 の範囲は -128 から 127 で、100 + 100 = 200 から 256 を引いて -56 です。u16 は 65535 まで表せるので、300 + 100 は回り込まずに 400 になります。100 は型の決まっていない整数リテラルで、x の型に合わせて変換されます。

配列の for と同じ感覚で、3つの値がどれも同じ型になると読むと、たとえばすべて u8 とみなして 44、200、144 と答えることになります。
