target.zig

const std = @import("std");

pub fn main(init: std.process.Init) !void {
    const base: u32 = 10;
    var extra: u32 = 0;
    var target = &extra;
    target.* += 1;
    target = &base;
    target.* += 1;
    const stdout = std.Io.File.stdout();
    var w = stdout.writer(init.io, &.{});
    const out = &w.interface;
    try out.print("{d}\n", .{base});
    try out.print("{d}\n", .{extra});
}

これは何を出力するでしょうか?

Answer

Output

コンパイルエラー

var target = &extra; の target には型を書いていないので、初期値の型がそのまま変数の型になります。extra は var で宣言した u32 なので、&extra の型は書き換えのできるポインタ *u32 で、target も *u32 に決まります。target.* += 1 はこの型で書き換えるので通ります。

次の target = &base; がエラーになります。base は const なので、&base の型は書き換えのできないポインタ *const u32 です。*const u32 を *u32 の変数に入れると、そのポインタを通して base を書き換えられてしまうので、Zig はこの代入を認めず、expected type '*u32', found '*const u32' と報告します。

target を var で宣言してあるので、どの変数を指していても書き換えられると読むと、extra と base が1ずつ増えて 11 と 1 を出力すると答えることになります。var が許すのは target に別のアドレスを入れ直すことだけで、指す先を書き換えられるかどうかはポインタの型の const が決めます。その型は、最初にアドレスを取った extra が var だった時点で *u32 に決まっています。
