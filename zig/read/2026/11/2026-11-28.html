box_type.zig

const std = @import("std");

fn Box(comptime T: type) type {
    return struct { value: T };
}

pub fn main(init: std.process.Init) !void {
    var buf: [64]u8 = undefined;
    const stdout = std.Io.File.stdout();
    var w = stdout.writer(init.io, &buf);
    const out = &w.interface;
    try out.print("{} {} {}\n", .{
        Box(u8) == Box(u8),
        Box(u8) == Box(i8),
        Box(u8) == struct { value: u8 },
    });
    try out.flush();
}

これは何を出力するでしょうか?

Answer

Output

true false false

Zig の struct { ... } は、書かれた場所が評価されるたびに新しい型を作ります。そのため Box の本体も、T ごとに別の struct 型を返します。ただし、コンパイル時に呼ばれた関数の結果は覚えておかれ(langref の言う memoize)、同じ引数で呼ぶと前の呼び出しの結果がそのまま返ります。2回の Box(u8) は1つの型を指し、1つ目は true です。Box(i8) は引数が違うので別の呼び出しになり、フィールドの型も違う別の型で、2つ目は false です。

3つ目の struct { value: u8 } は、Box(u8) の中身と同じフィールドを持ちます。それでも main の中で書いた別の struct 式なので、そこで新しい型が作られ、Box(u8) とは別の型です。Zig は型をフィールドの並びで比べず、どこで作られたかで区別するので、3つ目も false になります。
