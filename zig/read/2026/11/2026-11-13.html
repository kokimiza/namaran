peek.zig

const std = @import("std");

var calls: u8 = 0;

fn next() u8 {
    calls += 1;
    return calls;
}

pub fn main(init: std.process.Init) !void {
    const T = @TypeOf(next());
    const x: T = next();
    var buf: [64]u8 = undefined;
    var w = std.Io.File.stdout().writer(init.io, &buf);
    try w.interface.print("{s} {d} {d}\n", .{ @typeName(T), x, calls });
    try w.interface.flush();
}

これは何を出力するでしょうか?

Answer

Output

u8 1 1

@TypeOf(next()) が返すのは、next() を呼んだら得られる値の型で、next の戻り値の型 u8 です。langref は、@TypeOf の引数の式は評価されるものの、実行時の副作用を持たない(no runtime side-effects)ことを保証しています。型を決めるために next の中身が実行されることはなく、calls は0のままです。

次の行の next() は普通の呼び出しなので、calls が1になり、x も1になります。@typeName(T) は "u8" なので、u8 1 1 が出力されます。@TypeOf の中の呼び出しも1回と数えると、x と calls がどちらも2になり、u8 2 2 と答えてしまいます。
