array_copy.zig

const std = @import("std");

pub fn main(init: std.process.Init) !void {
    var out: [64]u8 = undefined;
    var w = std.Io.File.stdout().writer(init.io, &out);
    var a = [_]u8{ 1, 2, 3 };
    const p = &a;
    var b = p.*;
    p[0] = 7;
    b[1] = 8;
    try w.interface.print("{d} {d} {d}\n", .{ a[0], a[1], b[0] });
    try w.interface.flush();
}

これは何を出力するでしょうか?

Answer

Output

7 2 1

&a で作る p は、配列 a 全体を1つの値として指す単一要素ポインタ(single-item pointer)で、型は *[3]u8 です。配列へのポインタには添字をそのまま使え、p[0] は p.*[0]、すなわち a[0] を指します。p[0] = 7 は a 自身を書き換え、a は { 7, 2, 3 } になります。

p.* は p が指す値、型 [3]u8 の配列そのものです。Zig の配列は値なので、var b = p.*; は3つの要素を b 自身の領域へ写し、b は a とは別の配列 { 1, 2, 3 } になります。写したのは p[0] = 7 より前なので b[0] は1のままで、b[1] = 8 が変えるのも b だけです。a[1] は2のまま残り、出力は 7 2 1 になります。

b もポインタを通して取り出したのだから a と同じ場所を指すと考えると、b[1] = 8 が a[1] に、p[0] = 7 が b[0] に届いて、7 8 7 と答えます。a と記憶を共有するのは p のようなポインタや a[0..] のようなスライスで、.* で取り出した配列を変数に入れた時点で共有は切れます。
