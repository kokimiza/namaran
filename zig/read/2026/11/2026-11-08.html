concat.zig

const std = @import("std");

pub fn main(init: std.process.Init) !void {
    var out: [64]u8 = undefined;
    var w = std.Io.File.stdout().writer(init.io, &out);
    const head = [_]u8{ 1, 2 };
    const all = head ++ [_]u8{7} ++ head;
    try w.interface.print("{d} {d}\n", .{ all.len, all[3] });
    try w.interface.flush();
}

これは何を出力するでしょうか?

Answer

Output

5 1

++ は、コンパイル時に値が分かる2つの配列をつないで、新しい配列を作る演算子です。結果の長さは2つの長さの和で、これもコンパイル時に決まり、型の一部になります。head ++ [_]u8{7} ++ head は左から順につながり、{ 1, 2 }、{ 7 }、{ 1, 2 } を並べた [5]u8 の配列 { 1, 2, 7, 1, 2 } になります。head を2回使っても、それぞれの場所に要素が写されるだけで、head 自体は変わりません。

all.len は2 + 1 + 2で5です。添字は0から数えるので、all[3] は2つ目の head の先頭の1です。添字を1から数えると、3番目の要素の7を答えることになります。
