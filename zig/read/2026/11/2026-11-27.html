level.zig

const std = @import("std");

const Level = enum(u2) { low = 1, high, _ };

pub fn main(init: std.process.Init) !void {
    const stdout = std.Io.File.stdout();
    var w = stdout.writer(init.io, &.{});
    const out = &w.interface;
    for ([_]u2{ 0, 1, 2, 3 }) |b| {
        const l: Level = @fromBackingInt(b);
        try out.writeByte(switch (l) {
            .low => 'L',
            .high => 'H',
            _ => '?',
        });
    }
    try out.writeByte('\n');
}

これは何を出力するでしょうか?

Answer

Output

?LH?

Level のタグの整数値は u2 で表され、low には 1 を明示しています。値を書いていない high は、直前のタグの値に1を足した 2 になります。最後の _ は、この enum を non-exhaustive enum(名前を付けていない値も持てる enum)にする印です。u2 が表せる 0 から 3 のうち、名前のない 0 と 3 も Level の正しい値になります。

@fromBackingInt は整数を、その値を持つ Level に変換します。0 と 3 にはタグの名前がありませんが、non-exhaustive enum なので変換は正しく行われ、switch の _ の腕に入ります。_ の腕は、名前のあるどのタグにも当たらない値を受け取ります。順に 0 が ?、1 が L、2 が H、3 が ? になり、出力は ?LH? です。

値を書かないタグは 0 から数えるという覚え方のまま読むと、low を 0、high を 1 として LH?? と答えることになります。0 から数えるのは先頭のタグに値を書かなかった場合で、途中に値を書くと、その後ろはそこから数え直します。_ が無い普通の enum なら、0 と 3 を変換した時点で安全検査に止められるので、_ の腕も書けません。
