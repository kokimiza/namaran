flush_even.zig

const std = @import("std");

pub fn main(init: std.process.Init) !void {
    var buf: [64]u8 = undefined;
    var stdout_writer = std.Io.File.stdout().writer(init.io, &buf);
    const stdout = &stdout_writer.interface;
    for (1..6) |i| {
        try stdout.print("{d}", .{i});
        if (i % 2 == 0) try stdout.flush();
    }
}

これは何を出力するでしょうか?

Answer

1234 です（改行はありません）。

stdout.print は標準出力へ直接は書かず、64バイトの buf に文字をためます。たまった文字が標準出力へ送られるのは、flush を呼んだときと、書く文字がバッファに入りきらないときです。書くのは合わせて5バイトなので、ここでは flush を呼んだときにしか送られません。

for (1..6) は1から5までを回し、i が偶数のときだけ flush を呼びます。i が2のときに 12 が、4のときに 34 が送られます。5を書いたあとは flush を呼ばずにループを抜け、main が終わります。Zig の Writer は、スコープを抜けるときもプログラムが終わるときも自動では flush しないので、バッファに残った 5 は表示されません。
