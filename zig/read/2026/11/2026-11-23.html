grid.zig

const std = @import("std");

pub fn main(init: std.process.Init) !void {
    var grid = [4]u8{ 1, 2, 3, 4 };
    const rows: *[2][2]u8 = @ptrCast(&grid);
    rows[1][0] = 9;
    var buf: [64]u8 = undefined;
    const stdout = std.Io.File.stdout();
    var w = stdout.writer(init.io, &buf);
    const out = &w.interface;
    try out.print("{any}\n", .{grid});
    try out.flush();
}

これは何を出力するでしょうか?

Answer

Output

{ 1, 2, 9, 4 }

@ptrCast はポインタの型だけを変え、指す先のアドレスはそのままにします。中身をコピーするわけではないので、rows は grid と同じ4バイトを、2バイトの行が2つ並んだものとして見ています。[2][2]u8 は [2]u8 の配列で、行は隙間なく順に並ぶので、rows[0] が grid[0] と grid[1]、rows[1] が grid[2] と grid[3] に重なります。

rows[1][0] は2行目の先頭で、grid[2] と同じ場所です。そこへ 9 を書くと grid の3つ目の値が 3 から 9 に変わり、{any} で配列を出力すると { 1, 2, 9, 4 } になります。@ptrCast が新しい配列を作ると読むと、grid は変わらず { 1, 2, 3, 4 } と答えることになります。
