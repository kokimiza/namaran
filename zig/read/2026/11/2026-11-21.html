round_trunc.zig

const std = @import("std");

pub fn main(init: std.process.Init) !void {
    var buf: [64]u8 = undefined;
    const stdout = std.Io.File.stdout();
    var w = stdout.writer(init.io, &buf);
    const out = &w.interface;
    const x: f64 = -2.5;
    const r: i32 = @round(x);
    const t: i32 = @trunc(x);
    try out.print("{d} {d}\n", .{ r, t });
    try out.flush();
}

これは何を出力するでしょうか?

Answer

Output

-3 -2

@round は、最も近い整数に丸めます。-2.5 は -3 と -2 のちょうど真ん中にあり、このときは 0 から遠い方の -3 を選びます。@trunc は 0 の方へ丸めるので、小数部を捨てた -2 になります。どちらも、受け取る側の型（langref の result type）が整数なら、丸めた結果の整数部をその型の値にして返します。r と t は i32 と宣言してあるので、-3 と -2 がそのまま入ります。

真ん中の値を偶数の方へ丸める規則で読むと @round は -2 に、「0.5 を足して切り捨てる」と読むと -2.5 + 0.5 = -2 で、これも -2 になります。@trunc を小さい方への切り捨てと読むと -3 です。負の数では、0 の方へ丸めることと小さい方へ丸めることが分かれます。0.17 では @intFromFloat は非推奨で、@trunc を整数の型で受けるのと同じ意味です。
