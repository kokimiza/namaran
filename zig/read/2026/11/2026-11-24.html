kinds.zig

const std = @import("std");

fn kind(x: anytype) []const u8 {
    return @typeName(@TypeOf(x));
}

pub fn main(init: std.process.Init) !void {
    const a: u8 = 7;
    var buf: [64]u8 = undefined;
    const stdout = std.Io.File.stdout();
    var w = stdout.writer(init.io, &buf);
    try w.interface.print("{s} {s} {s}\n", .{
        kind(a),
        kind(7),
        kind(a + 7),
    });
    try w.interface.flush();
}

これは何を出力するでしょうか?

Answer

Output

u8 comptime_int u8

anytype の引数は、呼び出しごとに渡された式の型をそのまま受け取ります。@TypeOf(x) はその型を返し、@typeName は型の名前を文字列にします。

a は u8 と型を書いて宣言した定数なので、kind(a) は u8 です。7 のような整数リテラルの型は comptime_int で、u8 や i32 のどれかに決まるのは、型の決まった場所へ代入したり渡したりしたときです。anytype は型を指定しないので、kind(7) の x は comptime_int のまま受け取られます。a + 7 は u8 と comptime_int の演算で、リテラルの側が u8 に合わせられるので、和の型は u8 です。

引数の型を書かない関数でも、リテラルは C のように int 相当の型になると考えると、2つ目を i32 や usize と答えることになります。また、a がコンパイル時に分かる定数なので a + 7 も comptime_int になる、と読むのも誤りで、値がコンパイル時に分かっても、a の型は宣言した u8 のままです。
