counters.zig

const std = @import("std");

fn Counter(comptime start: u32) type {
    return struct {
        var n: u32 = start;
    };
}

pub fn main(init: std.process.Init) !void {
    var out: [64]u8 = undefined;
    var w = std.Io.File.stdout().writer(init.io, &out);
    Counter(0).n += 1;
    Counter(0).n += 1;
    Counter(5).n += 1;
    try w.interface.print("{d} {d}\n", .{ Counter(0).n, Counter(5).n });
    try w.interface.flush();
}

これは何を出力するでしょうか?

Answer

Output

2 6

Counter は型を返す関数で、返す構造体にはフィールドが無く、var n だけを持ちます。var n はフィールドではなく、その構造体という名前空間に置いた変数（container-level variable）で、型1つにつき1つしかありません。Counter(0).n は「Counter(0) が返した型の名前空間にある n」です。

start は comptime 引数なので、Counter(0) の呼び出しはコンパイル時に評価されます。Zig はコンパイル時の関数呼び出しの結果を覚えておき（langref の言葉では memoized）、同じ引数でもう一度呼ばれれば同じ結果を返します。そのため Counter(0) を何度書いても同じ1つの型になり、2回の Counter(0).n += 1 は同じ n を0から2に増やします。Counter(5) は引数が違うので別の型で、n も別にあり、5から1増えて6です。

return struct { ... } を、呼ぶたびに新しい構造体を作る式と読むと、+= も表示もそれぞれ別の n に対して行われることになり、初期値のままの 0 5 を答えます。標準ライブラリの std.ArrayList(u8) をどこで書いても同じ型として扱えるのも、同じ仕組みによるものです。
