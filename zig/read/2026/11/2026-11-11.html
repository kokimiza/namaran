ids.zig

const std = @import("std");

fn Ids(comptime prefix: u8) type {
    return struct {
        var next: u8 = '0';
        fn take() [2]u8 {
            next += 1;
            return .{ prefix, next };
        }
    };
}

pub fn main(init: std.process.Init) !void {
    const a = Ids('A').take();
    const b = Ids('B').take();
    const c = Ids('A').take();
    try std.Io.File.stdout().writeStreamingAll(init.io, &(a ++ b ++ c ++ .{'\n'}));
}

これは何を出力するでしょうか?

Answer

Output

A1B1A2

Ids は comptime の引数 prefix を受け取り、struct の型を返す関数です。その中の var next はフィールドではなく、型そのものに1つだけある変数(langref の container-level variable)です。take は next を1進め、prefix と next の2文字を返します。

Zig では、型を返す関数を同じ comptime 引数で呼ぶと、同じ型が返ります。2回の Ids('A') は同じ型なので next も1つで、1回目の take が '1'、2回目が '2' を返します。Ids('B') は引数が違うので別の型になり、自分の next を '0' から進めます。したがって a は A1、b は B1、c は A2 で、3つをつないだ A1B1A2 が出力されます。

呼び出すたびに新しい struct の型が作られると考えると、c も新しい next から始まって A1B1A1 になります。next は文字 '0' から始まる u8 なので、1を足すと文字 '1' になります。
