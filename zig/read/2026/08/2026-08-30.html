skip_rest.zig

const std = @import("std");

pub fn main(init: std.process.Init) !void {
    var buf: [64]u8 = undefined;
    var stdout_writer = std.Io.File.stdout().writer(init.io, &buf);
    const stdout = &stdout_writer.interface;
    outer: for (1..4) |i| {
        for (1..4) |j| {
            if (j > i) continue :outer;
            try stdout.print("{d}", .{j});
        }
        try stdout.print("|", .{});
    }
    try stdout.print("\n", .{});
    try stdout.flush();
}

これは何を出力するでしょうか?

Answer

Output

112123|

外側の for には outer: というラベルが付いています。continue :outer は、内側のループの次の周ではなく、ラベルの付いた外側のループの次の周へ進みます。内側のループはその場で打ち切られ、外側の本体のうち内側のループより後ろにある try stdout.print("|", .{}); も実行されません。| が出るのは、内側のループが continue :outer を通らずに最後まで回り切った周だけです。

1..4 は 1 から 3 までなので、i と j はどちらも 1、2、3 を取ります。i が 1 の周は、j が 1 で 1 を出し、j が 2 で j > i になって外側の次の周へ進みます。i が 2 の周も同じで、12 を出したあと j が 3 で抜けます。i が 3 の周だけは j > i が一度も成り立たないので、123 を出して内側のループが終わり、| を出します。最後の改行と合わせて、出力は 112123| です。

continue :outer を、内側のループを抜けるだけの break と同じに読むと、どの周でも | が出て 1|12|123| と答えることになります。内側の for から抜けたあとに外側の本体の続きを実行するのは、ラベルの無い break のほうです。ラベル付きの continue は、外側の本体の残りごと飛ばして、外側の次の周を始めます。
