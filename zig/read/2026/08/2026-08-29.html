retry.zig

const std = @import("std");

const Retry = struct {
    attempts: u8 = 3,
    delay_ms: u32 = 100,
};

pub fn main(init: std.process.Init) !void {
    var buf: [256]u8 = undefined;
    var stdout_writer = std.Io.File.stdout().writer(init.io, &buf);
    const stdout = &stdout_writer.interface;
    var r: Retry = .{ .delay_ms = 250 };
    r.attempts = 5;
    r = .{ .delay_ms = 500 };
    try stdout.print("{d} {d}\n", .{ r.attempts, r.delay_ms });
    try stdout.flush();
}

これは何を出力するでしょうか?

Answer

3 500 です。

Retry の2つのフィールドには既定値があり、構造体リテラルで書かなかったフィールドには、型の宣言に書いた既定値が入ります。最初の .{ .delay_ms = 250 } では attempts が既定値の 3、delay_ms が 250 になり、次の行で attempts を 5 に書き換えます。

r = .{ .delay_ms = 500 } は、delay_ms だけを書き換える文ではありません。右辺は Retry 型の値を丸ごと1つ作るリテラルで、書かれていない attempts には、いまの r.attempts ではなく宣言の既定値 3 が入ります。その値で r 全体が置き換わるので、5 は消えて 3 500 が出力されます。代入でフィールドを1つだけ変えたいなら、r.delay_ms = 500; と書きます。
