copy_or_view.zig

const std = @import("std");

pub fn main(init: std.process.Init) !void {
    var buf: [256]u8 = undefined;
    var stdout_writer = std.Io.File.stdout().writer(init.io, &buf);
    const stdout = &stdout_writer.interface;
    var a = [_]u8{ 1, 2, 3 };
    var b = a;
    const s = a[1..];
    b[0] = 9;
    s[0] = 7;
    try stdout.print("{d} {d} {d} {d}\n", .{ a[0], a[1], b[0], b[1] });
    try stdout.flush();
}

これは何を出力するでしょうか?

Answer

1 7 9 2 です。

Zig の配列は値なので、var b = a; は a の3要素を丸ごと b へコピーします。b は a と別のメモリを持つ配列で、b[0] = 9 は b だけを変え、a[0] は1のままです。

これに対して a[1..] は、a の要素をコピーせず、a の添字1から先を指します。始まりも長さもコンパイル時に分かるので、型は2要素の配列へのポインタ *[2]u8 になり、s[0] は a[1] と同じ場所です。s は const ですが、変えられないのはポインタ s 自身で、指す先の a は var なので s[0] = 7 で書き換えられます。そのため a[1] は7になり、コピーを取ったあとの変更なので b[1] は2のままです。

配列の代入で b も a と同じ場所を指すと読むと、9 7 9 7 と答えてしまいます。逆に a[1..] もコピーを作ると読むと、a[1] が2のままの 1 2 9 2 になります。
