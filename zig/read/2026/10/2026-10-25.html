field_offsets.zig

const std = @import("std");

pub fn main(init: std.process.Init) !void {
    var buf: [256]u8 = undefined;
    var stdout_writer = std.Io.File.stdout().writer(init.io, &buf);
    const stdout = &stdout_writer.interface;
    comptime var offset = 0;
    inline for (.{ "id", "name", "email" }) |field| {
        try stdout.print("{s}@{d} ", .{ field, offset });
        offset += field.len;
    }
    try stdout.print("{d}\n", .{offset});
    try stdout.flush();
}

これは何を出力するでしょうか?

Answer

id@0 name@2 email@6 11 です。

inline for は、タプルの要素1つごとにループの本体をコンパイル時に複製します。このループは、field を "id"、"name"、"email" に置き換えた本体を3つ並べて書いたのと同じです。comptime var の offset は、コンパイラが複製した本体を上から順に解析するときに読み書きされます。

1つ目の本体を解析するとき offset は 0 なので、その print には定数の 0 が渡され、続く offset += field.len で offset は 2 になります。2つ目の本体の print には 2 が、3つ目には 2 + 4 の 6 が渡り、最後の print には 6 + 5 の 11 が渡ります。実行時のプログラムには offset という変数がもう無く、print の呼び出しにそれぞれの定数が焼き込まれているだけです。コンパイル時の計算がすべて終わってから実行されるので、どの print にも最後の 11 が渡る、と読むと id@11 name@11 email@11 11 と答えることになります。
