pad.zig

const std = @import("std");

pub fn main(init: std.process.Init) !void {
    var buf: [256]u8 = undefined;
    var stdout_writer = std.Io.File.stdout().writer(init.io, &buf);
    const stdout = &stdout_writer.interface;
    try stdout.print("[{d:>4}][{d:0<4}][{x:0>4}]\n", .{ 42, 7, 255 });
    try stdout.flush();
}

これは何を出力するでしょうか?

Answer

[ 42][7000][00ff] です。

Zig の書式指定 {d:0>4} では、コロンの前が値の表し方、コロンの後ろが埋める文字、揃える向き、幅の順です。d は10進数、x は小文字の16進数で、> は右揃え、< は左揃えを表します。埋める文字を書かなければ空白で埋めます。

{d:>4} は42を幅4に右揃えするので、左に空白が2つ付いて 42 になります。{d:0<4} は7を左揃えにし、残りの3文字を右側に 0 で埋めるので 7000 です。{x:0>4} は255を16進数の ff にしてから右揃えにし、左を 0 で埋めて 00ff になります。

Zig では 0 は数の左を埋める合図ではなく、ほかの文字と同じ埋め文字の1つです。C の printf の %04d のつもりで読むと、2つ目を 0007 と答えてしまいます。
