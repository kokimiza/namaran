half.zig

const std = @import("std");

const Num = union(enum) {
    int: u32,
    float: f64,
};

fn half(n: Num, w: *std.Io.Writer) !void {
    switch (n) {
        inline else => |v| try w.print("{d}\n", .{v / 2}),
    }
}

pub fn main(init: std.process.Init) !void {
    var buf: [256]u8 = undefined;
    var stdout_writer = std.Io.File.stdout().writer(init.io, &buf);
    const stdout = &stdout_writer.interface;
    try half(.{ .int = 7 }, stdout);
    try half(.{ .float = 7 }, stdout);
    try stdout.flush();
}

これは何を出力するでしょうか?

Answer

3 と 3.5 の2行です。

Num はタグ付き共用体(tagged union)で、int なら u32 を、float なら f64 を持ちます。ふつうの else の腕は1つの本体を1回だけ解析するので、型の違う2つのペイロードを1つの v に入れられません。|v| には Num の値がそのまま入り、v / 2 はコンパイルエラーになります。inline else にすると、コンパイラは残ったタグの1つずつについて腕を別々に展開し、それぞれの腕で v はそのタグのペイロードの型になります(langref の Inline Switch Prongs)。

同じ v / 2 と書いてあっても、展開された腕ごとに別の式として型が付きます。int の腕では v が u32 なので整数の割り算になり、7 / 2 は小数部を切り捨てた3です。float の腕では v が f64 で、2は f64 の2.0として扱われ、結果は3.5になります。{d} はどちらの型も10進で書くので、1行目が 3、2行目が 3.5 です。
