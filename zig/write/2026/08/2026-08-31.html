value_of.zig

fn valueOf(line: []const u8) ?[]const u8 {
}

key=value の形の設定行 line から、最初の = より後ろの部分を返す valueOf を書いてください。値の中にさらに = があってもそのまま含めます。= が行末にあれば空のスライスを返し、= が1つも無ければ null を返します。メモリは確保しません。

入力例 1

valueOf("port=8080")

出力例 1

"8080"

入力例 2

valueOf("a=b=c")

出力例 2

"b=c"

入力例 3

valueOf("debug")

出力例 3

null

fn valueOf(line: []const u8) ?[]const u8 {
    const i = std.mem.findScalar(u8, line, '=') orelse return null;
    return line[i + 1 ..];
}

std.mem.findScalar は、スライスを先頭から探して、指定した値が最初に現れる位置を ?usize で返し、見つからなければ null を返します。Zig 0.17 では、以前の名前の indexOfScalar もこの関数の別名として残っていますが、非推奨になっています。orelse return null で、見つからなかったときはそのまま null を返し、見つかったときは i が usize の位置になります。値は = の次の位置から行末までなので、line[i + 1 ..] で切り出します。これは参考実装で、唯一の正解ではありません。

入力例2では最初の = が位置1にあるので、位置2からの "b=c" が返ります。std.mem.splitScalar で分けて2つ目の欄を取ると "b" になり、値の中の = で切れてしまいます。= が行末にあるときは i + 1 が line.len に等しく、line[line.len..] は範囲外ではなく長さ0のスライスなので、空の値が返ります。
