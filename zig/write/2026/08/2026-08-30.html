find_row.zig

fn findRow(grid: []const []const i32, target: i32) ?usize {
}

行ごとに長さの違う整数の表 grid から、target を1つでも含む最初の行の番号（0 から数える）を返す findRow を書いてください。どの行にも無いとき、grid が空のときは null を返します。

入力例 1

findRow(&.{ &.{ 4, 1 }, &.{ 8, 3 }, &.{ 3, 9 } }, 3)

出力例 1

1

入力例 2

findRow(&.{ &.{ 4, 1 }, &.{ 8, 3 }, &.{ 3, 9 } }, 5)

出力例 2

null

入力例 3

findRow(&.{}, 1)

出力例 3

null

fn findRow(grid: []const []const i32, target: i32) ?usize {
    return outer: for (grid, 0..) |row, i| {
        for (row) |v| {
            if (v == target) break :outer i;
        }
    } else null;
}

Zig の for は値を持つ式として書けます。break に値を付けて抜ければ、その値が for 全体の値になり、一度も break せずに回り切ったときは else の後ろの値になります。ただしラベルの無い break は一番内側のループを抜けるだけなので、内側の for (row) の中で break i と書いても、外側の for の値にはなりません。外側に outer: とラベルを付け、break :outer i と書くと、内側と外側の2つのループを一度に抜け、i が外側の for の値になります。戻り値の型 ?usize には、usize の i も null もそのまま入ります。

入力例 1 では、0 行目の { 4, 1 } に 3 は無く、内側のループが回り切って外側の次の周へ進みます。1 行目の { 8, 3 } で v == target になり、break :outer 1 で抜けるので、2 行目の 3 は調べません。入力例 2 と 3 はどちらも break に一度も届かずに外側のループが終わるので、else null の null が返ります。grid が空なら、外側のループは1周もせずに else へ進みます。

掲載したのは参考実装で、唯一の正解ではありません。内側で見つけた時点で return i; と書き、ループの後ろに return null; を置いてもかまいません。各行を std.mem.findScalar(i32, row, target) != null で調べれば、内側のループ自体が要らなくなります。
