sum.zig

fn sum(args: anytype) i64 {
}

整数を並べたタプル args を受け取り、要素の和を i64 で返す sum を書いてください。要素の型はそろっていなくてもよく、どの要素も i64 に収まる整数とします。空のタプル .{} なら0を返します。

入力例 1

sum(.{ 1, 2, 3 })

出力例 1

6

入力例 2

sum(.{ -4, @as(u8, 10) })

出力例 2

6

入力例 3

sum(.{})

出力例 3

0
Reference 
fn sum(args: anytype) i64 {
    var total: i64 = 0;
    inline for (args) |x| total += x;
    return total;
}

タプルは要素ごとに型が違ってよいので、入力例 2 の args は comptime_int の -4 と u8 の 10 を持ちます。ループ変数 x の型が回ごとに変わるため、配列のような for では回せません。inline for はループ本体を要素の数だけコンパイル時に展開し、展開したそれぞれで x がその要素の型になります。total += x では、どちらの型の値も i64 に変換されて足されます。

空のタプル .{} はフィールドを1つも持たないので、inline for は本体を1回も展開せず、total の初期値の0がそのまま返ります。

掲載したのは参考実装で、唯一の正解ではありません。タプルは同じ長さの配列に変換できるので、const values: [args.len]i64 = args; で i64 の配列にしてから、ふつうの for で足す書き方もあります。
