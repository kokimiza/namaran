repeat.zig

fn repeat(comptime s: []const u8, comptime n: usize) []const u8 {
}

文字列 s を n 回つないだ文字列を返す repeat を書いてください。s と n はコンパイル時に分かる値で、n が0なら空の文字列を返します。Zig 0.17 には、配列を丸ごと繰り返す演算子はありません。

入力例 1

repeat("ab", 3)

出力例 1

"ababab"

入力例 2

repeat("-", 1)

出力例 2

"-"

入力例 3

repeat("xyz", 0)

出力例 3

""

fn repeat(comptime s: []const u8, comptime n: usize) []const u8 {
    comptime var r: []const u8 = "";
    inline for (0..n) |_| r = r ++ s;
    return r;
}

++ は、コンパイル時に値が分かる配列やスライスをつないで新しい配列を作ります。s も n も comptime の引数なので、空の文字列から始めて s を n 回 ++ でつなげば、結果はすべてコンパイル時に決まります。途中の結果を入れる r は comptime var にし、ループは inline for にします。inline for はループをコンパイル時に n 回分に展開するので、各回の r = r ++ s もコンパイル時に計算されます。普通の for は実行時のループなので、その中から comptime var を書き換えるとコンパイルエラーになります。最後にできた配列はスライス []const u8 として返せます。これは参考実装で、唯一の正解ではありません。

入力例1では、r が ""、"ab"、"abab"、"ababab" と3回伸びます。入力例2はループが1回だけ回って "-" になり、入力例3は1回も回らないので、初期値の空の文字列が返ります。値を1つだけ並べる繰り返しなら組み込み関数 @splat で const dashes: [3]u8 = @splat('-'); と書けますが、"ab" のように2文字以上の並びを繰り返すには、この関数のように ++ を重ねます。
