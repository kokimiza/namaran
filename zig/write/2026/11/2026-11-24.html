sum.zig

fn sum(comptime T: type, xs: []const T) T {
}

要素の型 T と、T のスライス xs を受け取り、要素の合計を T で返す sum を書いてください。T は整数型か浮動小数点数型で、合計は T の範囲に収まるものとします。xs が空なら 0 を返します。出力例は、返り値を {d} で出力したものです。

入力例 1

sum(u32, &.{ 1, 2, 3 })

出力例 1

6

入力例 2

sum(f64, &.{ 0.5, 0.25 })

出力例 2

0.75

入力例 3

sum(i8, &.{})

出力例 3

0

fn sum(comptime T: type, xs: []const T) T {
    var total: T = 0;
    for (xs) |x| total += x;
    return total;
}

comptime T: type の引数は、型そのものをコンパイル時の値として受け取ります。受け取った T はそのあとの引数の型 []const T や戻り値の型にも書けるので、呼び出すたびに T を当てはめた関数がコンパイルされます。本体では合計を入れる変数を var total: T = 0; と宣言し、要素を順に足して返します。掲載したのは参考実装で、唯一の正解ではありません。

入力例1では T が u32 になり、xs は []const u32 として 1、2、3 を受け取って 6 を返します。入力例2では同じ本体が f64 でコンパイルされ、total の初期値 0 も 0.0 として扱われて 0.75 になります。入力例3は空のスライスでループが一度も回らず、0 がそのまま返ります。xs を anytype で受ける書き方と違い、要素の型を呼び出し側が明示するので、&.{} のように中身から型が分からない空のスライスでも呼び出せます。
