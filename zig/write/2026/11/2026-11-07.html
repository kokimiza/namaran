area.zig

const Shape = union(enum) {
    square: u32,
    rect: struct { w: u32, h: u32 },
    point,
};

fn area(s: Shape) u32 {
}

図形 s の面積を返す area を書いてください。square は1辺の長さを持つ正方形、rect は幅 w と高さ h を持つ長方形、point は大きさの無い点で、点の面積は0です。

入力例 1

area(.{ .square = 3 })

出力例 1

9

入力例 2

area(.{ .rect = .{ .w = 2, .h = 5 } })

出力例 2

10

入力例 3

area(.point)

出力例 3

0

const Shape = union(enum) {
    square: u32,
    rect: struct { w: u32, h: u32 },
    point,
};

fn area(s: Shape) u32 {
    return switch (s) {
        .square => |side| side * side,
        .rect => |r| r.w * r.h,
        .point => 0,
    };
}

union(enum) で宣言したunionは、どのフィールドが有効かを表すタグを持ちます（langref の言葉では tagged union）。switch (s) はそのタグで腕を選び、|side| や |r| と書くと、有効なフィールドの値（ペイロード）を取り出して腕の中で使えます。square では1辺の2乗を、rect では取り出した構造体の w と h の積を返します。point は型を書いていないので void のフィールドで、取り出すものが無いのでキャプチャを書かずに0を返します。switch は式なので、腕の値をそのまま return できます。これは参考実装で、唯一の正解ではありません。

タグ付きunionの switch は、すべてのタグを扱わないとコンパイルエラーになります。あとで Shape に円を足せば、area の switch が扱っていないことをコンパイラが指摘します。else の腕で残りをまとめるとこの指摘が出なくなるので、ここでは3つのタグをすべて書きます。入力例1は 3 × 3 で 9、入力例2は 2 × 5 で 10、入力例3は point の腕の 0 です。入力例3の .point は、ペイロードの無いフィールドなので、.{ .point = {} } と書かずに名前だけで Shape の値になります。
