range.zig

const Range = struct {
    lo: i32,
    hi: i32,

    fn extend(self: *Range, x: i32) void {
    }
};

Range は lo 以上 hi 以下の整数の範囲を表します。範囲が x を含むように、必要なら lo を下げるか hi を上げて、範囲を最小限だけ広げるメソッド extend を書いてください。x がすでに範囲に入っていれば何も変えません。例では、var r: Range = .{ .lo = 3, .hi = 5 }; と作った r に対して呼び出しを順に行い、そのあとの r を書きます。

入力例 1

r.extend(8);

出力例 1

.{ .lo = 3, .hi = 8 }

入力例 2

r.extend(8); r.extend(-1);

出力例 2

.{ .lo = -1, .hi = 8 }

入力例 3

r.extend(4);

出力例 3

.{ .lo = 3, .hi = 5 }

Reference

fn extend(self: *Range, x: i32) void {
    self.lo = @min(self.lo, x);
    self.hi = @max(self.hi, x);
}

extend は呼び出し元の r を書き換えるので、self を *Range で受けます。r.extend(8) と書くと、Zig は r のアドレスを取って Range.extend(&r, 8) として呼ぶので、呼び出し側に & は要りません。self.lo のようにポインタからフィールドを読み書きするときも、.* を書かずに済みます。self: Range と値で受けると self は書き換えられない引数になり、代入はコンパイルエラーになります。

新しい下限は今の下限と x の小さいほう、新しい上限は大きいほうで、組み込み関数の @min と @max がそのまま使えます。入力例1では8が上限の5より大きいので hi だけが8になり、入力例2で続けて -1 を渡すと lo が -1 になります。入力例3の4は3以上5以下なので、@min(3, 4) は3、@max(5, 4) は5で、何も変わりません。これは参考実装で、唯一の正解ではありません。if (x < self.lo) と if (x > self.hi) で分けて代入しても同じ結果になります。
