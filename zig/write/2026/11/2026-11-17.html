count_if.zig

fn countIf(
    xs: []const i32,
    pred: *const fn (i32) bool,
) usize {
}

スライス xs の各要素に判定関数 pred を呼び、true が返った要素の個数を返す countIf を書いてください。xs が空なら 0 を返します。例の isEven は偶数のとき、isNegative は負の数のときに true を返す関数です。

入力例 1

countIf(&.{ 1, 2, 3, 4 }, &isEven)

出力例 1

2

入力例 2

countIf(&.{ -3, 5, -1 }, &isNegative)

出力例 2

2

入力例 3

countIf(&.{}, &isEven)

出力例 3

0

fn countIf(
    xs: []const i32,
    pred: *const fn (i32) bool,
) usize {
    var n: usize = 0;
    for (xs) |x| {
        if (pred(x)) n += 1;
    }
    return n;
}

pred の型 *const fn (i32) bool は、「i32 を1つ受け取って bool を返す関数」へのポインタです。関数ポインタは、ふつうの関数と同じく pred(x) と書けば呼び出せます。参考実装は xs を for で1つずつ取り出して pred を呼び、true のときだけ n を1増やします。掲載したのは参考実装で、唯一の正解ではありません。

呼び出し側は、関数名に & を付けた &isEven でポインタを渡します。入力例 1 では 2 と 4 で true が返って 2、入力例 2 では -3 と -1 で 2 です。入力例 3 の空のスライスではループの本体が一度も実行されず、初期値の 0 が返ります。n はループの中で書き換えるので、const ではなく var で宣言します。
