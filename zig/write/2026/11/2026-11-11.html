stack.zig

fn Stack(comptime T: type, comptime capacity: usize) type {
}

要素の型 T と積める最大の個数 capacity を受け取り、固定長のスタックの型を返す Stack を書いてください。返す型の値は .{} で空のスタックとして初期化できるようにします。メソッド push(x) は、空きがあれば x を積んで true を返し、満杯なら何もせずに false を返します。メソッド pop() は最後に積んだ要素を取り除いて返し、空なら null を返します。例では、空のスタックの型に続けてそのスタックに呼ぶ操作を左から順に書き、出力例にはそれぞれの戻り値を同じ順に書きます。

入力例 1

Stack(u8, 2): push(1) push(2) push(3) pop() pop()

出力例 1

true true false 2 1

入力例 2

Stack(u8, 2): pop()

出力例 2

null

入力例 3

Stack(i32, 3): push(-5) pop() pop()

出力例 3

true -5 null

fn Stack(comptime T: type, comptime capacity: usize) type {
    return struct {
        items: [capacity]T = undefined,
        len: usize = 0,

        const Self = @This();

        fn push(self: *Self, x: T) bool {
            if (self.len == capacity) return false;
            self.items[self.len] = x;
            self.len += 1;
            return true;
        }

        fn pop(self: *Self) ?T {
            if (self.len == 0) return null;
            self.len -= 1;
            return self.items[self.len];
        }
    };
}

関数の中で struct { ... } を書いて返すと、それが Stack(T, capacity) の型になります。capacity は comptime の値なので、配列 [capacity]T の長さに使えます。2つのフィールドに既定値を付けておくと、.{} だけで len が0の空のスタックができます。この struct には名前が無いので、メソッドの中では @This() で自分の型を指し、Self という名前を付けました。これは参考実装で、唯一の正解ではありません。

push は len が capacity に届いていれば何もせずに false を返し、そうでなければ items[len] に書いてから len を進めます。pop は戻り値を ?T にして、空なら null を、そうでなければ len を戻してからその位置の要素を返します。入力例1では、容量2のスタックに3つ目を積もうとした push(3) が false になり、pop は後に積んだ 2、1 の順に返します。入力例2のように空のまま pop を呼ぶと、len を減らす前に null を返すので、0から1を引くことはありません。
