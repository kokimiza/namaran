c_len.zig

fn cLen(s: [*:0]const u8) usize {
}

末尾に値 0 のバイトが置かれた文字列を指す s を受け取り、0 の手前までのバイト数を返す cLen を書いてください。0 のバイト自身は数えません。空の文字列なら0を返します。

入力例 1

cLen("hello")

出力例 1

5

入力例 2

cLen("a")

出力例 2

1

入力例 3

cLen("")

出力例 3

0

fn cLen(s: [*:0]const u8) usize {
    var n: usize = 0;
    while (s[n] != 0) n += 1;
    return n;
}

[*:0]const u8 は多要素ポインタ(many-item pointer)で、ここから先にいくつかの要素が並んでいることだけを表し、スライスと違って長さ .len を持ちません。:0 は、並びの終わりに値0の要素が置かれているという約束で、この0を番兵(sentinel)と呼びます。長さを知る手がかりはこの番兵だけなので、添字 n を0から進め、s[n] が0になったところで止まります。そのときの n が、番兵を含まない要素の数です。これは参考実装で、唯一の正解ではありません。

文字列リテラル "hello" の型は *const [5:0]u8 で、5バイトの後ろに番兵の0が付いた配列を指しています。これは [*:0]const u8 へそのまま変換されるので、例のように直接渡せます。入力例1では s[5] が番兵の0なので5が返り、入力例2では s[1] で止まって1です。空の文字列の入力例3は s[0] がすでに番兵なので、ループは1回も回らず0が返ります。標準ライブラリには同じことをする std.mem.len があり、std.mem.span を使えば、番兵までを長さとして持つスライス [:0]const u8 を得られます。
