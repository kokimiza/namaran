const std = @import("std");

const Item = struct {
    value: u32,
    node: std.SinglyLinkedList.Node = .{},
};

fn sum(list: std.SinglyLinkedList) u32 {
}

list には、いくつかの Item の node がつながっています。それらの Item の value の合計を返す sum を書いてください。std.SinglyLinkedList.Node が持つのは次のノードを指す next だけで、list.first は最初のノードか、リストが空なら null です。空のリストなら 0 を返します。例では、リストにつながっている Item の value を先頭から順に [3, 4, 5] の形で書きます。

入力例 1

[3, 4, 5]

出力例 1

12

入力例 2

[7]

出力例 2

7

入力例 3

[]

出力例 3

0

const std = @import("std");

const Item = struct {
    value: u32,
    node: std.SinglyLinkedList.Node = .{},
};

fn sum(list: std.SinglyLinkedList) u32 {
    var total: u32 = 0;
    var it = list.first;
    while (it) |node| : (it = node.next) {
        const item: *Item = @fieldParentPtr("node", node);
        total += item.value;
    }
    return total;
}

リストをたどって手に入るのは *std.SinglyLinkedList.Node だけで、ノードには value がありません。ただし、どのノードも Item の node フィールドそのものです。フィールドは構造体の先頭から決まったバイト数だけ後ろに置かれるので、ノードのアドレスからその距離を引けば、ノードを含む Item の先頭のアドレスになります。@fieldParentPtr("node", node) はこの計算をする組み込み関数で、結果の型 *Item から、どの構造体のどのフィールドかを読み取ります。掲載したのは参考実装で、唯一の正解ではありません。

同じことを @ptrCast で書くこともできます。node を [*]u8 に変換して @offsetOf(Item, "node") バイト戻り、*Item に変換します。ただし [*]u8 のアラインメントは1なので、Item が要求するアラインメントへ上げる @alignCast も要ります。@fieldParentPtr を使えば、このバイト単位の計算とアラインメントの変換をまとめて任せられます。

ループは list.first から始め、while (it) |node| : (it = node.next) で null になるまで進みます。入力例 1 では3つのノードから3つの Item を取り戻し、3 + 4 + 5 の 12 を返します。入力例 3 の空のリストでは list.first が null なのでループに入らず、total の初期値 0 を返します。
