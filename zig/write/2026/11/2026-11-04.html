hex_dump.zig

const std = @import("std");
fn writeHex(w: *std.Io.Writer, bytes: []const u8) std.Io.Writer.Error!void {
}

バイト列 bytes の各バイトを2桁の小文字の16進数で表し、間に空白を1つずつ挟んで w へ書き込む writeHex を書いてください。16 未満のバイトは、上の桁を 0 で埋めて2桁にします。改行は書かず、w の flush もしません。bytes が空なら何も書きません。例の出力は、w に書き込まれた文字列です。

入力例 1

writeHex(w, "Hi!")

出力例 1

48 69 21

入力例 2

writeHex(w, &.{ 0, 10, 255 })

出力例 2

00 0a ff

入力例 3

writeHex(w, "")

出力例 3

Reference 
fn writeHex(w: *std.Io.Writer, bytes: []const u8) std.Io.Writer.Error!void {
    for (bytes, 0..) |b, i| {
        if (i > 0) try w.writeByte(' ');
        try w.print("{x:0>2}", .{b});
    }
}

std.Io.Writer は書き込み先の種類を問わない共通の入口で、標準出力の File.Writer はこの型をフィールド interface として中に持ち、配列に書く std.Io.Writer.fixed はこの型の値そのものを返します。writeHex がそのポインタ *std.Io.Writer を受け取れば、呼び出し側は標準出力なら &stdout_writer.interface を、テストなら .fixed で作った Writer を渡せます。検証では、.fixed の Writer に書かせた文字列を w.buffered() で取り出し、"48 69 21" と比べました。

桁をそろえるのは print の書式 {x:0>2} です。x は小文字の16進数、コロンの後ろの 0>2 は、幅を2文字にして足りない分を左に 0 で埋める指定です。10 は 0a になります。空白は2つ目以降のバイトの前にだけ writeByte で書くので、末尾に余分な空白は付かず、空のバイト列なら何も書きません。

writeHex の中では flush しません。w のバッファにたまった文字をいつ書き出すかは、Writer を作った呼び出し側が、ほかの出力と合わせて決めます。戻り値の型 std.Io.Writer.Error!void は、書き込みの失敗 error.WriteFailed だけを返しうることを示します。掲載したのは参考実装で、唯一の正解ではありません。std.fmt.hex で1バイトずつ2文字の配列にしてから writeAll で書いてもかまいません。
