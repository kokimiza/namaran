count.zig

fn count(comptime T: type) comptime_int {
}

型 T の値が何通りあるか、つまり T の変数が取りうる異なる値の個数を返す count を書いてください。T は bool、整数型(符号の有無もビット数も問いません)、optional、配列、struct を任意に組み合わせた型です。struct は、フィールドのどれか1つでも値が違えば別の値と数え、配置の隙間は数えません。それ以外の型はコンパイルエラーにします。値が1つも並ばない [0]u64 や、フィールドの無い struct {} の値はどちらも1通りです。

入力例 1

count(?bool)

出力例 1

3

入力例 2

count(struct { on: bool, level: ?i2 })

出力例 2

10

入力例 3

count([0]u64)

出力例 3

1

fn count(comptime T: type) comptime_int {
    return switch (@typeInfo(T)) {
        .bool => 2,
        .int => |info| 1 << info.bits,
        .optional => |info| count(info.child) + 1,
        .array => |info| blk: {
            var n = 1;
            for (0..info.len) |_| n *= count(info.child);
            break :blk n;
        },
        .@"struct" => |info| blk: {
            var n = 1;
            for (info.field_types) |F| n *= count(F);
            break :blk n;
        },
        else => @compileError("unsupported type"),
    };
}

struct の値は、各フィールドの値を1つずつ選んだ組です。1つ目のフィールドの選び方が a 通り、2つ目が b 通りなら、組は a × b 通りあります。そのため struct の個数は、フィールドの型それぞれの個数の積になります。入力例2では bool の2通りと ?i2 の5通りを掛けて10通りです。配列は同じ型のフィールドが長さの数だけ並んだ struct と同じで、個数は要素の型の個数の、長さ乗です。optional は中の型の値に null が1つ加わるので、中の型の個数に1を足します。整数型は n ビットのどの並びも別の値なので、符号の有無に関係なく 2 の n 乗通り、bool は2通りです。

参考実装は、@typeInfo(T) で型の種類を調べ、中に型を持つ optional・配列・struct では、その型に count を再帰で適用します。Zig 0.17 の @typeInfo は struct のフィールドの型を field_types という型の並びで返すので、それを順に掛けます。積を始める値を1にしておけば、[0]u64 も struct {} も1回も掛けずに1を返し、値が1通りという条件と一致します。戻り値の型を comptime_int にしているので、u64 の 2 の64乗通りのように、どの固定幅の整数にも収まらない個数もあふれずに数えられます。これは参考実装で、唯一の正解ではありません。

フィールドの型の個数を足して、入力例2を 2 + 5 = 7 とする誤りがよくあります。足し算になるのは「どれか1つ」を選ぶ場合で、optional が中の値か null のどちらか1つなので +1 になるのがその例です。struct のフィールドはすべてが同時に値を持つので、掛け算になります。i2 を符号付きだからと 2 の1乗通りと数えると、入力例2は 2 × 3 = 6 になってしまいます。i2 は -2 から 1 までの4通りです。
