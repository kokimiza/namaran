indent.zig

fn indent(line: []const u8) usize {
}

文字列 line の先頭に続く空白 ' ' の個数を返す indent を書いてください。line がすべて空白なら line の長さを返し、空なら 0 を返します。

入力例 1

indent("  x = 1")

出力例 1

2

入力例 2

indent("y")

出力例 2

0

入力例 3

indent("   ")

出力例 3

3

fn indent(line: []const u8) usize {
    return for (line, 0..) |c, i| {
        if (c != ' ') break i;
    } else line.len;
}

Zig の for は値を持つ式として書けます。本体で break i を実行するとループを抜け、i が for 式の値になります。break せずに最後の要素まで回り終えたときは、else の後ろの式が値になります。参考実装は、空白でない最初の文字の添字を break で返し、最後まで空白だったときは else で line.len を返します。for (line, 0..) は文字と添字を並べて取り出す書き方です。掲載したのは参考実装で、唯一の正解ではありません。本体で return i; とし、ループの後ろで return line.len; としても同じ結果になります。

入力例 1 では添字 2 の 'x' で break して 2 を返し、入力例 2 では最初の 'y' で 0 を返します。入力例 3 は最後まで空白なので、else の line.len の 3 になります。空の文字列ではループが1回も回らずに終わるので、やはり else が実行され、長さの 0 が返ります。break で値を返す for 式に else を書かないと、最後まで回り終えたときの値が void になり、戻り値の usize と型が合わずにコンパイルエラーになります。
