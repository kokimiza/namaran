pair.zig

fn Pair(comptime T: type) type {
}

型 T を受け取り、T 型のフィールド a と b を持つ構造体の型を返す Pair を書いてください。その構造体には、a と b を入れ替えた新しい値を返すメソッド swapped を持たせ、p.swapped() と呼べるようにします。p 自身は変えません。a と b が等しければ、p と同じ値が返ります。例では、入力に p の値を、出力に p.swapped() の値を書きます。

入力例 1

Pair(u8){ .a = 1, .b = 2 }

出力例 1

Pair(u8){ .a = 2, .b = 1 }

入力例 2

Pair(bool){ .a = true, .b = false }

出力例 2

Pair(bool){ .a = false, .b = true }

入力例 3

Pair(i32){ .a = -5, .b = -5 }

出力例 3

Pair(i32){ .a = -5, .b = -5 }

fn Pair(comptime T: type) type {
    return struct {
        const Self = @This();
        a: T,
        b: T,

        pub fn swapped(self: Self) Self {
            return .{
                .a = self.b,
                .b = self.a,
            };
        }
    };
}

Zig では型も値なので、comptime の引数で型を受け取り、type を返す関数がそのまま総称型になります。Pair が返すのは名前の無い構造体で、中で自分の型を書く方法は @This() しかありません。参考実装はそれを Self という名前の定数に置き、メソッドの引数と戻り値の型に使っています。掲載したのは参考実装で、唯一の正解ではありません。

構造体の中で宣言した関数は、第1引数がその構造体の型なら p.swapped() と書いて呼べ、Pair(u8).swapped(p) と同じ意味になります。swapped は self を値で受け取り、.{ .a = self.b, .b = self.a } で新しい値を作って返すので、p は変わりません。入力例 3 のように a と b が等しければ、入れ替えても同じ値です。同じ引数での Pair(u8) の呼び出しはコンパイル時に1回だけ評価されるので、何度書いても同じ型を指し、例の Pair(u8){ … } どうしは比べられます。
