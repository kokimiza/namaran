eval.zig

const Expr = union(enum) {
    num: i32,
    div: [2]*const Expr,
};

const Error = error{
    DivisionByZero,
    Overflow,
};

fn eval(e: *const Expr) Error!i32 {
}

式の木 e の値を返す eval を書いてください。num は整数そのもの、div は1つ目の部分式の値を2つ目の部分式の値で割る式で、商は 0 の方向へ切り捨てます。割る数が 0 なら error.DivisionByZero、商が i32 に収まらなければ error.Overflow を返します。部分式は1つ目から順に評価し、部分式がエラーになったら、そこで最初に起きたエラーを返します。木の深さは 1000 以下です。例では、div の木を (a / b) の形で書きます。

入力例 1

(7 / -2)

出力例 1

-3

入力例 2

(1 / (2 / 3))

出力例 2

error.DivisionByZero

入力例 3

(-2147483648 / -1)

出力例 3

error.Overflow
Reference 時間計算量 𝒪(n) 空間計算量 𝒪(d) n は木の節の個数、d は木の深さ

const Expr = union(enum) {
    num: i32,
    div: [2]*const Expr,
};

const Error = error{
    DivisionByZero,
    Overflow,
};

fn eval(e: *const Expr) Error!i32 {
    return switch (e.*) {
        .num => |n| n,
        .div => |ab| std.math.divTrunc(
            i32,
            try eval(ab[0]),
            try eval(ab[1]),
        ),
    };
}

switch (e.*) で、いま有効なタグごとに腕を分け、そのタグのペイロードを |n| や |ab| で受け取ります。Expr は自分自身を含むので、部分式はポインタで持つしかなく、ab[0] と ab[1] は *const Expr です。そのまま eval に渡して再帰し、返ってくる error union(エラーか値のどちらか)を try で開きます。try はエラーならその場で eval から返すので、引数を左から評価する順のとおり、1つ目の部分式のエラーが先に返ります。掲載したのは参考実装で、唯一の正解ではありません。

割り算は std.math.divTrunc に任せます。Zig では符号つき整数の実行時の値に / を使えず、切り捨ての向きを @divTrunc か @divFloor で選ぶ必要があります。@divTrunc に 0 で割る値や minInt(i32) / -1 を渡すと illegal behavior(安全検査で止まる誤り)になりますが、std.math.divTrunc はその2つを先に調べ、error.DivisionByZero と error.Overflow を返します。返り値のエラーの集合はその2つなので、Error にそのまま収まります。入力例1の 7 ÷ (−2) は −3.5 で、0 の方向へ切り捨てると −3 です。入力例3は −2147483648 ÷ (−1) = 2147483648 が i32 の最大値を1超えるので error.Overflow になります。再帰は木の深さまでしか重ならず、問題文の 1000 段なら呼び出しのスタックに十分収まります。
