sum_list.zig

fn sumList(s: []const u8) !i64 {
}

コンマ , で区切った10進の整数の並び s を読み、その合計を返す sumList を書いてください。各整数の前後には空白があってもかまいません。s が空文字列なら0を返し、整数として読めない部分があれば std.fmt.parseInt が返すエラーをそのまま返します。

入力例 1

sumList("3, -4, 10")

出力例 1

9

入力例 2

sumList("")

出力例 2

0

入力例 3

sumList("1,,2")

出力例 3

error.InvalidCharacter
Reference 
fn sumList(s: []const u8) !i64 {
    if (s.len == 0) return 0;
    var total: i64 = 0;
    var it = std.mem.splitScalar(u8, s, ',');
    while (it.next()) |field| {
        total += try std.fmt.parseInt(i64, std.mem.trim(u8, field, " "), 10);
    }
    return total;
}

std.mem.splitScalar は s をコンマの位置で区切り、区切った部分を1つずつ返します。std.fmt.parseInt は前後の空白を読み飛ばさず、" -4" を渡すと error.InvalidCharacter を返すので、渡す前に std.mem.trim で両端の空白を取り除きます。parseInt の失敗は try でそのまま呼び出し側へ返ります。

空文字列を区切っても、区切りが無いので部分は0個にはならず、空の部分が1つ返ります。parseInt は空文字列も error.InvalidCharacter にするので、先頭の if が無いと、sumList("") は0ではなくエラーになります。コンマが続く "1,,2" の間にも同じ空の部分ができますが、こちらはエラーにするのが問題の求める動きなので、空文字列のときだけを先に除きます。

掲載したのは参考実装で、唯一の正解ではありません。空白の取り除き方は std.mem.trim に限らず、空白でない最初と最後の位置を自分のループで探してもかまいません。
