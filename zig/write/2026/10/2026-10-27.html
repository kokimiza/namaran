unescape.zig

fn unescape(dst: []u8, src: []const u8) []u8 {
}

文字列 src のバックスラッシュによるエスケープを外して dst の先頭へ書き写し、書き写した部分の dst のスライスを返す unescape を書いてください。バックスラッシュとそれに続く1文字は、続く文字が n なら改行1文字に、それ以外ならその文字そのものになります。src の最後の文字が対になる文字の無いバックスラッシュなら、そのまま書き写します。dst の長さは src の長さ以上あるものとします。入出力例は Zig の文字列リテラルで書きます。

入力例 1

unescape(&buf, "a\\nb")

出力例 1

"a\nb"

入力例 2

unescape(&buf, "\\\\n")

出力例 2

"\\n"

入力例 3

unescape(&buf, "x\\")

出力例 3

"x\\"
Reference 
fn unescape(dst: []u8, src: []const u8) []u8 {
    var n: usize = 0;
    var i: usize = 0;
    while (i < src.len) : (i += 1) {
        var c = src[i];
        if (c == '\\' and i + 1 < src.len) {
            i += 1;
            c = if (src[i] == 'n') '\n' else src[i];
        }
        dst[n] = c;
        n += 1;
    }
    return dst[0..n];
}

while の継続式 : (i += 1) が、1回ごとに src を1文字進めます。バックスラッシュを見つけたときは、本体の中で i += 1 として続く1文字に移り、その文字から書き写す1文字を決めます。継続式はそのあとにも実行されるので、次の回はバックスラッシュと続く文字の2文字ぶん先から始まります。

エスケープの回だけ i += 2 として continue する書き方は、continue でも継続式が実行されるので3文字進み、続く文字を1つ読み飛ばします。続く文字を本体の中で消費しておくことは入力例2でも要ります。\\ で1つのバックスラッシュを書いたあと、その2文字目のバックスラッシュを次の回で読み直すと、後ろの n と組になって改行に化けます。i + 1 < src.len を確かめているので、入力例3のように末尾に残ったバックスラッシュは、範囲の外を読まずにそのまま書き写されます。

掲載したのは参考実装で、唯一の正解ではありません。継続式を使わずに、本体の最後で消費した文字数だけ i を進める書き方もあります。
