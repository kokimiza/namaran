stack.zig

const Stack = struct {
    items: [8]i32 = undefined,
    len: usize = 0,

    fn push(self: *Stack, x: i32) void {
    }

    fn pop(self: *Stack) ?i32 {
    }
};

Stack は、items の先頭から len 個に値を積んだスタックです。値 x を一番上に積む push と、一番上の値を取り除いて返す pop を書いてください。空のスタックの pop は null を返します。8個を超えて積むことはないものとします。例では、空の Stack を入れた var s: Stack = .{}; から始め、最後の pop が返す値を示します。

入力例 1

s.push(1); s.push(2); s.pop()

出力例 1

2

入力例 2

s.pop()

出力例 2

null

入力例 3

s.push(1); s.push(2); _ = s.pop(); s.pop()

出力例 3

1

const Stack = struct {
    items: [8]i32 = undefined,
    len: usize = 0,

    fn push(self: *Stack, x: i32) void {
        self.items[self.len] = x;
        self.len += 1;
    }

    fn pop(self: *Stack) ?i32 {
        if (self.len == 0) return null;
        self.len -= 1;
        return self.items[self.len];
    }
};

構造体の中で宣言した関数は、その構造体を名前空間とする関数です。最初の引数がその型か、その型へのポインタなら、s.push(1) のようにメソッドの形で呼べて、Stack.push(&s, 1) と同じ意味になります。s は var なので、&s は書かなくてもコンパイラが取ります。

push と pop はどちらも len を書き換えるので、self を *Stack で受け取ります。self: Stack と書くと、Zig の引数は書き換えられない定数なので、self.len += 1 がコンパイルエラーになります。push は items[len] に値を置いてから len を増やし、pop は先に len を減らしてから items[len] を返します。戻り値の型を ?i32 にしておくと、空のときは null を返せます。

掲載したのは参考実装で、唯一の正解ではありません。pop は、先に items[len - 1] を読んでおいてから len を減らしてもかまいません。
