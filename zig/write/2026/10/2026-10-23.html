mul_wide.zig

fn Wide(comptime T: type) type {
}

fn mulWide(a: anytype, b: @TypeOf(a)) Wide(@TypeOf(a)) {
}

a と b は u8 や i32 のような同じ整数型の値です。その型と符号の有無が同じで、ビット数が2倍の整数型を返す Wide と、a と b の積をその型で返す mulWide を書いてください。積はどの値の組でも、整数のオーバーフローを起こさずに正しい値になるようにします。a に型の決まっていない整数リテラルだけを渡すことはありません。

入力例 1

mulWide(@as(u8, 200), 200)

出力例 1

@as(u16, 40000)

入力例 2

mulWide(@as(i32, -2_000_000_000), 3)

出力例 2

@as(i64, -6000000000)

入力例 3

mulWide(@as(i8, -128), -128)

出力例 3

@as(i16, 16384)
Reference 
fn Wide(comptime T: type) type {
    const info = @typeInfo(T).int;
    return @Int(info.signedness, info.bits * 2);
}

fn mulWide(a: anytype, b: @TypeOf(a)) Wide(@TypeOf(a)) {
    const W = Wide(@TypeOf(a));
    return @as(W, a) * @as(W, b);
}

Wide はコンパイル時に型を受け取り、型を返す関数です。@typeInfo(T) は型の情報を std.lang.Type の共用体で返し、整数型なら .int に signedness(符号の有無)と bits(ビット数)があります。この2つを @Int に渡すと、@Int(.unsigned, 16) が u16 になるように整数型ができます。T が整数型でなければ .int を読んだところでコンパイルエラーになるので、問題の前提に反する呼び出しは実行前に止まります。

mulWide の引数 a は anytype なので、呼び出しごとに渡された値の型で関数が作られます。b: @TypeOf(a) と Wide(@TypeOf(a)) は、その型を引数と戻り値の型に使っています。入力例 1 の 200 のようなリテラルは、b の型 u8 に合わせて変換されます。

掛け算は、広げてから行います。return a * b; と書いても戻り値の型は u16 ですが、a * b の型は被演算子の u8 で決まり、40000 は u8 に収まりません。値が実行時に決まるなら、Debug ビルドでは integer overflow の illegal behavior として panic します。結果を広い型に入れることは、計算を広い型で行うことを意味しません。@as(W, a) で両方を先に広げれば、n ビットの数どうしの積は必ず 2n ビットに収まります。符号付きでいちばん大きい積は入力例 3 の (-128) × (-128) = 16384 で、i16 の最大値32767以下です。掲載したのは参考実装で、唯一の正解ではありません。標準ライブラリにも同じ計算をする std.math.mulWide があり、こちらは型を std.math.mulWide(u8, a, b) のように最初の引数で受け取ります。
