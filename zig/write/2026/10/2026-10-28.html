largest.zig

fn largest(items: []i32) *i32 {
}

スライス items の中で最も大きい要素を指すポインタを返す largest を書いてください。呼び出し側はこのポインタを通して、その要素を元の配列の中で書き換えます。最大の値が複数あるときは、最も前にある要素を指します。items は空ではないとします。例では、配列 a を作って largest の返り値を通して書き換えたあとの a の中身を、出力例に書きます。

入力例 1

var a = [_]i32{ 3, 8, 5 }; largest(&a).* = 0;

出力例 1

{ 3, 0, 5 }

入力例 2

var a = [_]i32{ 4, 4 }; largest(&a).* = 0;

出力例 2

{ 0, 4 }

入力例 3

var a = [_]i32{-2}; largest(&a).* += 1;

出力例 3

{ -1 }
Reference 
fn largest(items: []i32) *i32 {
    var best = &items[0];
    for (items[1..]) |*item| {
        if (item.* > best.*) best = item;
    }
    return best;
}

&items[0] は、スライスが指す配列の先頭の要素を指す単一要素ポインタ(single-item pointer)*i32 です。値をコピーした変数ではなく配列の中の場所を指すので、呼び出し側が .* で書き換えると、配列の要素そのものが変わります。

残りの要素は for の |*item| で受け取ります。|item| と書くと item は要素の値のコピーで、その場所は分かりませんが、* を付けると item は要素を指すポインタ *i32 になります。比べるときは item.* と best.* で値を読み、大きければポインタ best を差し替えます。比較を > にしているので、同じ値の要素が後ろにあっても best は動かず、入力例2では前の4が書き換わります。

掲載したのは参考実装で、唯一の正解ではありません。for (items, 0..) |x, i| で添字を数えて最大の要素の添字を覚え、最後に &items[i] を返す書き方もあります。
