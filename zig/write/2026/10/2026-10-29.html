cents.zig

fn formatCents(buf: []u8, cents: i64) ![]u8 {
}

セント単位の金額 cents を、ドル単位の小数の文字列にして buf に書き、書いた部分のスライスを返す formatCents を書いてください。小数点の後ろはいつも2桁で、整数部は0でも省きません。負の金額は先頭に - を付け、0は 0.00 にします。cents は i64 のどの値でもよく、buf が足りないときはエラーを返します。

入力例 1

formatCents(&buf, 1234)

出力例 1

"12.34"

入力例 2

formatCents(&buf, -5)

出力例 2

"-0.05"

入力例 3

formatCents(&buf, -105)

出力例 3

"-1.05"
Reference 
fn formatCents(buf: []u8, cents: i64) ![]u8 {
    const sign = if (cents < 0) "-" else "";
    const abs = @abs(cents);
    return std.mem.print(buf, "{s}{d}.{d:0>2}", .{ sign, abs / 100, abs % 100 });
}

符号は、商や余りからではなく、cents そのものから決めます。商に符号を任せて @divTrunc(cents, 100) を整数部として表示すると、-105 は -1 になって -1 の後ろに余りを付ければ済みますが、-5 では商が0になり、0には符号が無いので - が消えます。@divFloor なら -5 の商は -1 になって符号は残りますが、今度は整数部が1ずれ、-1 と表示すべきでない金額になります。

参考実装は、先に符号を取り出してから絶対値を割ります。@abs は符号付き整数を受けると同じ幅の符号なし整数を返す組み込み関数(builtin function)で、i64 の最小値 -9223372036854775808 も u64 の9223372036854775808として表せます。符号なし整数なら / と % がそのまま使えるので、整数部と小数部はどちらも0以上の数として書けます。{d:0>2} は、幅2に満たない数の左を 0 で埋める書式で、5セントを 05 と書きます。std.mem.print は buf に書けなかったとき error.NoSpaceLeft を返します。

掲載したのは参考実装で、唯一の正解ではありません。cents が負かどうかで分けて、符号付きのまま @divTrunc と @rem の結果を @abs で正にしてから書く方法もあります。ただし最初に -cents で正にする書き方は、i64 の最小値で整数のオーバーフローになります。
