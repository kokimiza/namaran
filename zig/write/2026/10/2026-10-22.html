store.zig

const Field = union(enum) {
    byte: u8,
    short: i16,
    long: i64,
};

fn store(f: *Field, x: i64) bool {
}

Field は、いま有効なフィールドの型で整数を1つ持つタグ付き共用体です。f の有効なフィールドの型で x を表せるなら、そのフィールドを x に書き換えて true を返し、表せないなら f を変えずに false を返す store を書いてください。有効なフィールドは変えません。

入力例 1

var f: Field = .{ .byte = 7 };
store(&f, 300)

出力例 1

false
f == .{ .byte = 7 }

入力例 2

var f: Field = .{ .byte = 7 };
store(&f, 200)

出力例 2

true
f == .{ .byte = 200 }

入力例 3

var g: Field = .{ .short = 0 };
store(&g, -5)

出力例 3

true
g == .{ .short = -5 }
Reference 
fn store(f: *Field, x: i64) bool {
    switch (f.*) {
        inline else => |*p| {
            p.* = std.math.cast(@TypeOf(p.*), x) orelse return false;
            return true;
        },
    }
}

範囲を確かめるときの型がフィールドごとに違うので、腕を1つにまとめては書けません。.byte, .short, .long => |*p| のように腕をまとめると、p が *u8、*i16、*i64 のどれにもなりうるので、「capture group with incompatible types」というコンパイルエラーになります。inline else は腕をタグごとに展開し、展開された腕の中では p の型が1つに決まります。そのため @TypeOf(p.*) は、byte の腕では u8、short の腕では i16 というコンパイル時に決まる型になり、型を引数に取る関数に渡せます。

std.math.cast(T, x) は、x が T の範囲に収まればその値を、収まらなければ null を返します。orelse return false で範囲外のときは代入の前に関数を抜けるので、f は書き換わりません。入力例 1 の300は u8 の最大値255を超えるので false です。@intCast で済ませると、範囲外の値は Debug ビルドで panic する illegal behavior になります。

書き換えには、キャプチャを |*p| とポインタで受ける必要があります。|p| で受けた値は共用体の中身をコピーした定数で、代入すると「cannot assign to constant」になります。switch (f.*) の f.* は共用体そのものを指すので、p.* への代入は呼び出し側の f に届きます。掲載したのは参考実装で、唯一の正解ではありません。std.math.minInt と std.math.maxInt で範囲を比べてから @intCast する書き方もあります。
