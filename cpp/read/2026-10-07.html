timeout.cpp

#include <iostream>

extern int retries;
int timeout_ms = retries * 500;
int retries = 3;

int main() {
    std::cout << timeout_ms << '\n';
}

これは何を出力するでしょうか?

Answer

1500 です。

timeout_ms の初期化子は retries を読みますが、retries の定義はその後ろにあります。名前空間スコープの変数は定義の順に初期化されるので、まだ初期化されていない retries を読んで 0 になる、と考えたくなるところです。

ところが、静的記憶域期間を持つ変数の初期化は2段階で進みます。まず静的初期化として、定数式で初期化できる変数には定数初期化が、それ以外にはゼロ初期化が行われ、これがどの動的初期化よりも先に終わります。定義の順が効くのは、そのあとの動的初期化だけです。int retries = 3; の初期化子は定数式なので、retries は定数初期化され、プログラムが動き始めた時点で 3 になっています。

一方 retries * 500 は、const でない変数を読むので定数式ではなく、timeout_ms は動的初期化されます。その時点で retries はもう 3 なので、timeout_ms は 1500 になります1。

  1. retries をほかの翻訳単位の関数の戻り値で初期化すると、retries も動的初期化になり、timeout_ms がゼロ初期化されたままの 0 を読むことがあります。定数初期化されることを確かめたいなら、constinit int retries = 3; と書けば、定数初期化できないときにコンパイルエラーになります。
