coin_height.cpp

#include <iostream>

unsigned bits = 0b1101'1110;  // coin flips, lowest bit first

bool coin() {
    bool heads = bits & 1;
    bits >>= 1;
    return heads;
}

int height() {
    int h = 1;
    while (coin() && h < 3) ++h;
    return h;
}

int main() {
    for (int i = 0; i < 3; ++i) std::cout << height();
    std::cout << '\n';
}

これは何を出力するでしょうか?

Answer

132 です。

bits を下位ビットから読むと、コインは 0, 1, 1, 1, 1, 0, 1, 1 の順に出ます。height は、コインが 1 の間だけ高さを1つずつ上げ、上限の 3 で止めます。

1回目の height は、最初のコインが 0 なので 1 です。2回目は 1, 1 と続いて高さが 3 になり、そこで while の条件をもう一度評価します。&& は左から評価するので、h < 3 を見る前に coin() が呼ばれ、4枚目のコインが消費されます。この 1 が出ても h < 3 が偽なので、高さは 3 のままです。

3回目は5枚目の 1 で高さが 2 になり、6枚目の 0 で止まります。上限に達したときもコインを1枚使うことを見落とすと、3回目を4枚目から読んでしまい、133 と答えることになります。

条件を h < 3 && coin() の順に書けば、上限に達した時点で coin() は呼ばれません。どちらの順でも1つ1つの高さが出る確率は同じですが、使う乱数の列がずれるので、同じ種から作ったリストの形は変わります。
