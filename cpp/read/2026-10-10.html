port_id.cpp

#include <iostream>

struct Device {
    int id;
    explicit Device(int i = 0) : id(i) {}
};

struct Reader : virtual Device {
    Reader() : Device(1) {}
};

struct Writer : virtual Device {
    Writer() : Device(2) {}
};

struct Port : Reader, Writer {};

int main() {
    Port p;
    std::cout << p.id << '\n';
}

これは何を出力するでしょうか?

Answer

0 です。

Reader と Writer はどちらも Device を virtual で継承しているので、Port の中の Device は2つではなく1つです。p.id が曖昧にならないのもこのためです。1つしかない Device を Reader と Writer の両方が初期化しようとすると、1 と 2 のどちらを使うかが決まりません。

そこで C++ は、仮想基底クラスを初期化する役目を、実際に作られるオブジェクトの型、つまり最派生クラスに負わせています。Port p; で作られるのは Port なので、Device を初期化するのは Port です。Reader() と Writer() も呼ばれはしますが、そのメンバ初期化子にある Device(1) と Device(2) は、Port の一部として作られるときには使われません。Port は Device について何も書いていないので、Device は既定のコンストラクタで作られ、id は既定の引数の 0 になります。

同じ Reader() でも、Reader r; のように Reader 自身が最派生クラスになるときは Device(1) が使われ、r.id は 1 です。Port の id を決めたいなら、Port() : Device(3) {} のように Port 自身が Device を初期化します。
