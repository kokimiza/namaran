capture_kinds.cpp

#include <iostream>

int main() {
    int x = 10;
    auto byValue = [x]() { return x; };
    auto byRef = [&x]() { return x; };

    x = 20;

    std::cout << byValue() << " " << byRef() << "\n";
    return 0;
}

このプログラムを実行すると、何が出力されるでしょうか?

Answer

出力は10 20です。[x]はxを値でキャプチャするので、ラムダが作られた時点のx(まだ10)のコピーがクロージャの中に保存されます。以降xを20に変更しても、byValueが持っているのは独立したコピーなので影響を受けず、呼び出すと10を返し続けます。一方[&x]はxへの参照をキャプチャするので、クロージャの中にはxそのものへの参照だけが保存されます。呼び出し時に参照先の現在の値を読むため、x = 20;のあとにbyRef()を呼ぶと最新の20を返します。同じ変数を同じ場所でキャプチャしていても、値キャプチャは「その瞬間のスナップショット」、参照キャプチャは「変数そのものへの窓」という別物になります。
