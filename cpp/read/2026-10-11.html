label.cpp

#include <cstdio>
#include <iostream>
#include <string>

const char* label(int id) {
    static char buf[16];
    std::snprintf(buf, sizeof buf, "item-%d", id);
    return buf;
}

int main() {
    std::string first = label(1);
    auto second = label(2);
    auto third = label(3);
    std::cout << first << ' ' << second << ' ' << third << '\n';
}

これは何を出力するでしょうか?

Answer

item-1 item-3 item-3 です。

label は毎回同じ static 配列 buf に書き込み、その先頭を指すポインタを返します。呼び出すたびに新しい文字列ができるのではなく、1つしかない buf の中身が書き換わります。

first は std::string なので、初期化の時点で buf の中身 "item-1" が first 自身の領域にコピーされます。second と third は auto で宣言されていて、label の戻り値の型 const char* がそのまま推論されます。コピーされるのはポインタだけなので、second と third はどちらも同じ buf を指します。

出力するのは、3回の呼び出しがすべて終わったあとです。その時点の buf には最後に書いた "item-3" が入っているので、second も third も item-3 を出力し、コピーを持つ first だけが item-1 のまま残ります。auto を std::string に書き換えれば、出力は item-1 item-2 item-3 になります。
