slice_speak.cpp

#include <iostream>
#include <string>

struct Animal {
    virtual std::string speak() const { return "..."; }
    virtual ~Animal() = default;
};

struct Dog : Animal {
    std::string speak() const override { return "Woof"; }
};

void announce(Animal a) {
    std::cout << a.speak() << '\n';
}

int main() {
    Dog d;
    announce(d);
}

このプログラムを実行すると、標準出力はどうなるでしょうか?

Answer

...(その後に改行)です。announceは引数aをAnimal型の値として受け取ります。Dogのオブジェクトdを渡すと、dのAnimal部分だけがコピーされて新しいAnimalオブジェクトが作られ、Dogとしての動的型の情報は失われます。これが「オブジェクトのスライシング」です。コピーされたaの動的型は最初からAnimalそのものなので、a.speak()は仮想関数呼び出しであってもDog::speakではなくAnimal::speakを呼び、"..."を返します。スライシングを避けてDogとしての振る舞いを保ちたい場合は、値渡しではなくconst Animal&やconst Animal*のように参照・ポインタで受け取る必要があります(その場合は動的型が保たれ、Woofが出力されます)。
