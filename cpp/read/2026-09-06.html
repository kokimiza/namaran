bracket_lines.cpp

#include <iostream>
#include <sstream>
#include <string>

int main() {
    std::istringstream in("x\n\n");
    std::string line;
    while (std::getline(in, line)) {
        std::cout << '[' << line << "]\n";
    }
}

これは何を出力するでしょうか?

Answer

[x] と [] の2行です。

std::getline は次の改行の手前までを1行として読み、改行そのものは取り出して捨てます。入力 "x\n\n" の1回目は x を読みます。2回目は次の改行までに文字が1つもないので、line は空文字列になります。空の行を読めたことも成功なので、ループは続いて [] が出力されます。

3回目の呼び出しでは、読める文字がもう残っていません。何も取り出せないまま入力の終わりに着いたので getline は失敗し、while の条件が偽になります。最後の \n は2行目を終わらせる改行で、その後ろに空の3行目があるわけではありません。空行と入力の終わりを分けているのは line が空かどうかではなく、getline が成功したかどうかです。
