sum_cps.cpp

#include <functional>
#include <print>

void sum_to(int n, std::function<void(int)> k) {
    if (n == 0) {
        k(0);
        return;
    }
    sum_to(n - 1, [n, k](int s) {
        std::println("{}+{}", s, n);
        k(s + n);
    });
    std::println("<{}>", n);
}

int main() {
    sum_to(3, [](int s) { std::println("={}", s); });
}

これは何を出力するでしょうか?

Answer

0+1、1+2、3+3、=6、<1>、<2>、<3> の7行が、この順に出力されます。

sum_to(3, k0) は自分では何も足さず、「s を受け取ったら s+3 の形で表示してから k0(s + 3) を呼ぶ」という継続 k3 を作って sum_to(2, k3) を呼びます。同じように k2 と k1 が作られ、それぞれが1つ外側の継続を値としてキャプチャします。sum_to(0, k1) に着いたところで初めて k1(0) が呼ばれ、そこから k1、k2、k3、k0 と外側の継続へ呼び出しが続きます。足し算が 0+1 から順に進み、=6 まで出るのはこのためです。

この連鎖は、sum_to の呼び出しが1つも戻らないうちに、いちばん深い sum_to(0, k1) の中で最後まで走ります。sum_to(n - 1, ...) の後ろに書いた std::println("<{}>", n) はどの継続にも含まれていないので、k0 が =6 を出し終えてから、呼び出しスタックが巻き戻るときに n の小さい順で実行されます。継続渡しで「計算の残り」として扱われるのは継続に渡した部分だけで、呼び出しの後ろに書いた文は、ふつうの関数呼び出しから戻ったあとの処理として別に動きます1。

  1. 継続渡しの関数では、継続や再帰の呼び出しを末尾に置き、その後ろに何も書かないのがふつうです。後ろに文を書くと、計算の順序が継続とスタックの2本に分かれてしまうからです。
