windows.cpp

#include <print>
#include <ranges>
#include <vector>

int main() {
    std::vector<int> v{1, 2, 3, 4, 5};
    for (int k : {2, 6}) {
        auto chunks = v | std::views::chunk(k);
        auto windows = v | std::views::slide(k);
        std::println("{} {}", std::ranges::distance(chunks), std::ranges::distance(windows));
    }
}

これは何を出力するでしょうか?

Answer

3 4 と 1 0 の2行です。

views::chunk(k) は、範囲を先頭から k 個ずつの重ならない塊に分けます。要素が割り切れずに余ったときは、余りが最後の短い塊になり、捨てられません。views::slide(k) は、先頭を1つずつずらしながら、連続する k 個の窓を作ります。窓はどれもちょうど k 個の要素を持ち、短い窓は作りません。

k が2なら、塊は {1,2}、{3,4}、余りの {5} の3つです。窓は先頭が1から4までの4つで、要素数5から k を引いて1を足した数になります。

k が6だと、要素数の5より長くなります。chunk は5要素全部を短い塊1つにまとめるので1です。slide は長さ6の窓を1つも作れないので0になります。塊と同じように5要素全部の窓が1つできる、と考えると2行目を 1 1 と答えます。
