compound.cpp

#include <print>

int main() {
    int x = 20;
    x /= 2 + 3;
    x *= 7 / 2;
    x %= 4 + 3;
    std::println("{}", x);
}

これは何を出力するでしょうか?

Answer

Output

5

x op= e は、右辺の e を式としてまとめて計算してから、x = x op (e) として x に結果を入れます。代入演算子は優先順位がいちばん低いので、x /= 2 + 3 の右辺は 2 + 3 全体です。1行目は 20 / 5 で x は 4 になります。

2行目の右辺 7 / 2 は int どうしの割り算で、小数部が切り捨てられて 3 になります。この 3 を掛けるので x は 4 × 3 で 12 です。3行目の右辺は 4 + 3 の 7 で、12 を 7 で割った余りの 5 が x に残ります。

誤答は、どちらの規則を見落としたかで分かれます。x /= 2 + 3 を x = x / 2 + 3 と読むと1行目で 13 になり、2行目で 39、3行目を x % 4 + 3 と読めば 6 です。右辺をまとめて計算することは押さえていても、2行目を x * 7 / 2 のように左から計算すると、4 × 7 / 2 で 14 になり、14 は 7 で割り切れるので 0 が出ます。x *= 7 / 2 では、割り算と切り捨てが掛け算より先に済んでいます。
