engine_copies.cpp

#include <iostream>
#include <random>

int main() {
    std::mt19937 a(42);
    std::mt19937 b = a;
    a();
    std::mt19937 c = a;
    std::cout << (a() == b()) << (b() == c()) << (a == c) << '\n';
}

これは何を出力するでしょうか?

Answer

Output

011

乱数エンジンは、次に出す値を決める内部状態を持つ普通の値の型です。コピーすると状態がそのまま写り、コピーした時点から元と同じ列を出します。そのあとは別々のオブジェクトなので、片方を呼んでももう片方は進みません。std::mt19937 がシード42から出す列を x0, x1, x2, … とすると、b は何も呼ばれていない a のコピーなので、次に x0 を出します。a() で a が x0 を出したあとにコピーした c は、次に x1 を出します。

出力の式では、a() が x1、b() が x0 を返すので、1文字目は異なる値の比較で 0 です。続く b() と c() はどちらも x1 を返し、2文字目は 1 です。この時点で a も c も2つ目の値まで出し終えているので、状態を比べる a == c は真で、3文字目も 1 です。std::mt19937 b = a; を「同じエンジンにもう1つ名前を付けた」と読むと、a と b が1つの列を取り合うことになり、比べる値がすべてずれて 000 を答えます。b と c は参照ではなく値なので、それぞれ自分の状態から同じ列をたどり直します。
