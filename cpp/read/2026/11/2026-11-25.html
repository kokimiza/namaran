job_list.cpp

#include <iostream>
#include <vector>

struct Job {
    int id;
    explicit Job(int id) : id(id) {}
    Job(Job&&) = default;
};

int main() {
    std::vector<Job> jobs{Job(1), Job(2)};
    jobs.push_back(Job(3));
    std::cout << jobs.size() << '\n';
}

これは何を出力するでしょうか?

Answer

Output

コンパイルエラー

エラーになるのは jobs を初期化する行で、削除されたコピーコンストラクタ Job(const Job&) を使おうとしたと報告されます。Job(Job&&) = default; は中身をコンパイラに任せていますが、ムーブコンストラクタを自分で宣言したことに変わりはありません。ムーブコンストラクタかムーブ代入演算子を宣言したクラスでは、コピーコンストラクタとコピー代入演算子が暗黙に削除されます。Job はムーブはできてもコピーはできない型です。

波括弧で要素を並べた std::vector<Job> jobs{Job(1), Job(2)} は、std::initializer_list<Job> を受け取るコンストラクタを呼びます。Job(1) と Job(2) はまず initializer_list が指す配列の要素として作られ、この配列の要素は const Job です。vector はそこから自分の領域へ要素を写しますが、const のオブジェクトは Job&& に束縛できないのでムーブはできず、残る手段は削除されたコピーだけです。

書いたのが一時オブジェクトなのでムーブで済むと読むと、3 と答えることになります。ムーブを宣言してもコピーは暗黙に残ると考えても、やはり 3 です。次の行の push_back(Job(3)) は一時オブジェクトを Job&& で受け取ってムーブするので、こちらはコンパイルできます。初期化の行を jobs.push_back(Job(1)); のような呼び出しに分ければ、プログラムは 3 を出力します。
