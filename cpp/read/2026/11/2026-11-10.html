square.cpp

#include <iostream>

consteval int square(int x) {
    return x * x;
}

int main() {
    const int a = 3;
    int b = 4;
    std::cout << square(a) << ' ' << square(b) << '\n';
}

これは何を出力するでしょうか?

Answer

Output

コンパイルエラー

consteval を付けた関数は、呼び出しのたびにその場でコンパイル時に評価されます。呼び出し全体が定数式になれなければ、実行時に回されることはなく、プログラムがコンパイルエラーになります。

square(a) は通ります。a は const 付きの整数型の変数で、定数の 3 で初期化されているので、定数式の中でその値を使えます。square(b) は通りません。b は const の付かない普通の変数で、4 で初期化されていても、その値をコンパイル時の計算には使えないからです。GCC は「square(b) は定数式ではない」「b の値は定数式で使えない」と報告して止まり、何も出力されません。

constexpr 関数と同じように考えると、square(b) は実行時に計算されると読んで 9 16 と答えます。constexpr 関数は、定数式として評価できないときは普通の関数として実行時に呼ばれます。consteval 関数にはその逃げ道がありません。int b = 4; を const int b = 4; に変えれば、9 16 が出力されます。
