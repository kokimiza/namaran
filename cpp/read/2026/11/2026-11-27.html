column.cpp

#include <print>
#include <string>

int main() {
    std::string id = "7";
    int qty = 7;
    std::println("|{:3}|{:3}|", id, qty);
}

これは何を出力するでしょうか?

Answer

Output

|7  |  7|

{:3} は幅を3文字にする指定で、寄せ方(<、^、>)は書いていません。寄せ方を省くと、どちらに寄せるかは引数の型で決まります。文字列は左寄せ、整数や浮動小数点数のような数値は右寄せです。id は std::string なので 7 のあとに空白が2つ続き、qty は int なので空白2つのあとに 7 が来ます。

どちらの欄にも同じ 7 が見え、指定も同じ {:3} なので、2つとも同じ寄せ方で | 7| 7| や |7 |7 | になると読みがちです。表を作るときは文字列の列と数値の列で寄せ方が揃わないので、揃えたい列には {:>3} のように寄せ方を明示します。
