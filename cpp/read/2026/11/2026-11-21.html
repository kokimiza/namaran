walk_once.cpp

#include <filesystem>
#include <iostream>
namespace fs = std::filesystem;

int main() {
    auto t = fs::temp_directory_path() / "w";
    fs::remove_all(t);
    fs::create_directories(t / "a/b");
    fs::current_path(t);
    fs::create_directory_symlink("..",
                                 "a/up");
    fs::recursive_directory_iterator it(".");
    int n = std::ranges::distance(it);
    std::cout << n << '\n';
}

これは何を出力するでしょうか?

Answer

Output

3

main が作る木は、カレントディレクトリ t の下にディレクトリ a、その中にディレクトリ b と、.. を指すシンボリックリンク up があるものです。up は a の中にあるので、.. は t を指します。std::ranges::distance(it) は、it が最後まで進むあいだに返した項目の数です。

recursive_directory_iterator は、オプションを渡さずに作ると、ディレクトリを指すシンボリックリンクの中へは降りません。リンクそのものは1つの項目として返しますが、その先は読みません。中へ降りるのは directory_options::follow_directory_symlink を渡したときだけです。返る項目は a、a/b、a/up の3つで、a/up の先にある t はもう一度は読まれません。出力は 3 です。

up がディレクトリへのリンクだから中へ降りると読むと、a/up/a、a/up/a/up/a と同じ木を何度もたどり、終わらないか、リンクをたどる回数の上限に当たって例外で止まると答えることになります。逆に、リンクは降りないから数えないと読むと 2 です。降りないのはリンクの先であって、リンクの項目そのものは返ります。
