point_swap.cpp

#include <iostream>
#include <utility>

namespace geo {
struct Point {
    int x;
};

void swap(Point& a, Point& b) {
    std::cout << "geo ";
    std::swap(a.x, b.x);
}
} // namespace geo

int main() {
    geo::Point p{1}, q{2};
    using std::swap;
    swap(p, q);
    std::swap(p, q);
    std::cout << p.x << q.x << '\n';
}

これは何を出力するでしょうか?

Answer

geo 12 です。

修飾なしの swap(p, q) では、2か所から候補が集まります。1つは using std::swap; で見えるようになった std::swap の関数テンプレートです。もう1つは実引数依存の名前探索（ADL）で見つかる geo::swap で、実引数の型 geo::Point が名前空間 geo に属するので、geo の中の関数も探されます。

どちらの候補も Point& に実引数をそのまま結び付けるので、変換の良さでは差が付きません。そのときはテンプレートでない関数が選ばれるので、呼ばれるのは geo::swap です。geo と空白が表示され、p.x と q.x は2と1に入れ替わります。

次の std::swap(p, q) は名前空間を指定した呼び出しで、ADL は働きません。候補は std::swap だけなので何も表示せずに入れ替え、値は1と2に戻ります。最後の行が表示するのは 12 です。std::swap も geo::swap を呼ぶと考えると geo geo 12 と答え、修飾なしの呼び出しも std::swap だと考えると 12 だけになります。
