#include <iostream>

int main() {
    double big = 1e16;
    double a = big;
    double ones = 0.0;
    for (int i = 0; i < 4; ++i) {
        a += 1.0;
        ones += 1.0;
    }
    double b = big + ones;
    std::cout << a - big << ' ' << b - big << '\n';
}

これは何を出力するでしょうか?

Answer

Output

0 4

double の仮数部は53ビットなので、2の53乗(約9.007×10の15乗)を超えると、すべての整数は表せなくなります。1e16 は2の53乗から2の54乗の間にあり、この範囲で表せる double は2おきに並んでいます。

a += 1.0 の正確な和 10000000000000001 は、両隣の 10000000000000000 と 10000000000000002 のちょうど中間です。中間に来た値は、仮数部の最下位ビットが0になる側へ丸められ、ここでは 1e16 の側になります。1 そのため1回目の加算で a は 1e16 に戻り、2回目以降も同じことが繰り返されて、a - big は 0 です。

ones は小さい値どうしの足し算なので誤差なく 4.0 になります。big + ones の正確な和 10000000000000004 は2おきの格子の上にあるので丸めずに表せ、b - big は 4 です。足す値は同じでも、大きな値に1つずつ足すと消え、先にまとめてから足すと残ります。std::cout は 0.0 と 4.0 を 0 と 4 と出します。

  1. この丸め方を偶数丸め(round half to even)と呼びます。IEEE 754 の既定の丸め方で、ちょうど中間の値を、仮数部の最下位ビットが0、つまり偶数になる側へ寄せます。
