pick_overload.cpp

#include <iostream>

void f(long) {
    std::cout << "long\n";
}
void f(int, int = 0) {
    std::cout << "int\n";
}

int main() {
    f(1);
    f(1L);
}

これは何を出力するでしょうか?

Answer

Output

int
long

f(1) では、どちらの f も呼び出せます。f(int, int = 0) は2つ目の引数に既定の値があるので、引数1つで呼べるからです。このとき、2つの候補の優劣は実際に書いた引数 1 の変換だけで比べ、既定の値で埋まる2つ目の引数は比べる材料になりません。1 は int なので、f(int, int = 0) へは変換の要らない完全一致で、f(long) へは int から long への整数の変換が要ります。完全一致のほうが優先され、1行目は int です。

f(1L) では立場が入れ替わります。1L は long なので、f(long) が完全一致になり、f(int, int = 0) のほうは long から int への変換が要ります。2行目は long です。引数を1つだけ書いた呼び出しには、引数が1つの関数のほうがよく合うように見えます。しかし引数の数は候補に残るかどうかを決めるだけで、残った候補の優劣は書いた引数の型で決まります。
