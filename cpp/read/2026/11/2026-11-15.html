shape_scale.cpp

#include <iostream>

struct Shape {
    virtual int scale(int factor = 1) const {
        return factor;
    }
};

struct Circle : Shape {
    int scale(int factor = 2) const override {
        return factor * 10;
    }
};

int main() {
    const Shape& s = Circle{};
    std::cout << s.scale() << ' ' << Circle{}.scale() << '\n';
}

これは何を出力するでしょうか?

Answer

Output

10 20

既定の引数は関数の宣言に付いていて、呼び出し式をコンパイルするときに、その式から見える宣言で決まります。どの宣言が見えるかは、呼び出しに使った式の静的な型で決まります。一方、仮想関数のどの本体が動くかは、実行時にオブジェクトの実際の型で決まります。2つは別々に決まるので、組み合わせが食い違うことがあります。

s の静的な型は const Shape& なので、s.scale() の欠けた引数は Shape::scale の宣言にある 1 で補われます。s が指しているのは Circle なので、動く本体は Circle::scale で、1 * 10 の 10 を返します。Circle{}.scale() は静的な型も Circle なので、Circle::scale の宣言にある 2 が使われ、20 になります。

既定の引数も仮想関数と同じく実行時の型で選ばれると考えると、1つ目も 20 と答えます。逆に、基底への参照から呼べば基底の本体が動くと考えると、1つ目は 1 になります。
