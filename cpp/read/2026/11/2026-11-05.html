bump.cpp

#include <array>
#include <iostream>

template <class T> void bump(T x) {
    x[0] += 10;
}

int main() {
    int a[2] = {1, 2};
    std::array<int, 2> s = {1, 2};
    bump(a);
    bump(s);
    std::cout << a[0] << ' ' << s[0] << '\n';
}

これは何を出力するでしょうか?

Answer

Output

11 1

bump の引数 T x は値渡しなので、どちらの呼び出しも引数のコピーを受け取ります。違いが出るのは T が何に推論されるかです。値渡しの引数に組み込み配列を渡すと、推論の前に配列は先頭要素を指すポインタに変換されるので、bump(a) の T は int[2] ではなく int* になります。コピーされるのはポインタだけで、x[0] は a[0] そのものを指し、+= 10 で a[0] が 11 になります。

std::array<int, 2> は組み込み配列を1つ持つクラスで、ポインタへの変換は起きません。bump(s) の T は std::array<int, 2> になり、x は2つの要素ごとコピーされた別のオブジェクトです。書き換わるのはそのコピーの先頭要素で、s[0] は 1 のまま残ります。

T x を「配列をまるごとコピーして受け取る」と読むと、どちらも書き換わらずに 1 1 と答えることになります。組み込み配列は値渡しの引数としてはコピーできず、関数の引数に int x[2] と書いても int* x と同じ意味になります。テンプレートの推論もこれと同じ扱いで、配列をコピーして渡したいときに std::array を使う理由はここにあります。
