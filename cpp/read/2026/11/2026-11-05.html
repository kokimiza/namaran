best_digit.cpp

#include <algorithm>
#include <iostream>

int main() {
    int n = 3;
    char best = std::max('5', '0' + n);
    std::cout << best << '\n';
}

これは何を出力するでしょうか?

Answer

Output

コンパイルエラー

'0' + n の型は char ではなく int です。char と int を足すと、'0' は足し算の前に int へ変換され、結果も int になります。値は文字 '3' の番号と等しくなりますが、型は整数のままです。

std::max は template<class T> const T& max(const T& a, const T& b) の形で、2つの引数から同じ1つの T を推論します。1つ目の '5' からは char、2つ目の '0' + n からは int が推論され、食い違うので呼び出せる max がありません。テンプレート引数の推論では char から int への変換を試さないので、普通の関数なら通る呼び出しでもここで止まります。

'0' + n を文字の '3' と読むと、'5' との大きいほうで 5 が出ると考えたくなります。動くようにするには、std::max<char>('5', '0' + n) と型を明示するか、char('0' + n) と char に戻してから渡します。どちらでも 5 が表示されます。
