unwind.cpp

#include <iostream>

void f(int n) {
    if (n == 0) {
        std::cout << '|';
        return;
    }
    std::cout << n;
    f(n - 1);
    std::cout << n;
}

int main() {
    f(3);
    std::cout << '\n';
}

これは何を出力するでしょうか?

Answer

Output

321|123

f(n) は、n を出力してから f(n - 1) を呼び、その呼び出しが戻ってきたあとでもう一度 n を出力します。呼び出された側が終わるまで、呼んだ側の残りの文は待たされます。f(3) は 3 を出して f(2) を呼び、f(2) は 2 を出して f(1) を、f(1) は 1 を出して f(0) を呼びます。ここまでで 321 です。

f(0) は基底ケースで、| を出して、それ以上呼ばずに戻ります。基底ケースが実行されるのは、深さがいちばん深いところで1回だけです。そこから先は、待っていた呼び出しが新しいものから順に再開します。最初に再開するのは f(1) の2つ目の出力で 1、次が f(2) の 2、最後が f(3) の 3 なので、後半は 123 になり、全体は 321|123 です。後半も 3 から出ると考えると 321|321 と答えてしまいますが、戻る順は呼んだ順の逆です。
