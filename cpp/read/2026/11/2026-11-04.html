copied_counter.cpp

#include <functional>
#include <iostream>
#include <vector>

int main() {
    auto counter = [n = 0]() mutable {
        return ++n;
    };
    std::vector<std::function<int()>> calls{counter, counter};
    calls[0]();
    calls[0]();
    std::cout << calls[0]() << calls[1]() << counter() << '\n';
}

これは何を出力するでしょうか?

Answer

311 です。

counter は、初期化キャプチャの n をメンバとして持つクロージャで、mutable なので呼ぶたびに自分の n を1増やして返します。std::function<int()> は、int() の形で呼べるものなら型を問わず受け取れますが、受け取ったものは参照せず、自分の中へコピーして持ちます。calls を {counter, counter} で初期化した時点で、n が 0 のクロージャが3つ、counter と calls[0] の中と calls[1] の中に別々にできます。

calls[0] を2回呼ぶと、calls[0] の中の n だけが 2 になります。出力の行では、<< の左から順に評価されることが C++17 から決まっていて、calls[0]() が 3、まだ1度も呼ばれていない calls[1]() が 1、counter() も 1 を返します。3つが同じ n を共有していると読むと 345 になりますが、共有はどこにも起きていません。共有したければ、n をクロージャの外に置いて参照でキャプチャするか、std::ref(counter) を入れて counter 自体を指させます。
