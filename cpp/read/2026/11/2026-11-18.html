bool_proxy.cpp

#include <iostream>
#include <vector>

int main() {
    std::vector<bool> v{true, true};
    auto a = v[0];
    bool b = v[1];
    v[0] = false;
    v[1] = false;
    std::cout << a << ' ' << b << '\n';
}

これは何を出力するでしょうか?

Answer

Output

0 1

std::vector<bool> は、要素を1ビットずつ詰めて持つように特殊化されています。ビットにはアドレスが無いので、v[0] は bool& を返せず、代わりに std::vector<bool>::reference という小さなオブジェクトを返します。このオブジェクトは、どの語のどのビットかを覚えていて、読むとそのビットの値を、代入するとそのビットへの書き込みをします。

auto a = v[0]; の auto は、この reference 型に推論されます。a は v[0] のビットを指したままなので、あとで v[0] = false; とすると、a を読んだ値も false になります。bool b = v[1]; は型を bool と書いているので、reference がその時点の値 true に変換されて b に入ります。そのため v[1] を書き換えても b は変わりません。std::cout は bool を 0 と 1 で出すので、出力は 0 1 です。

std::vector<int> なら auto a = v[0]; は値のコピーになるので、同じ形で読むと 1 1 と答えてしまいます。auto が参照を外すのは、operator[] が本物の参照を返すときに限られます。
