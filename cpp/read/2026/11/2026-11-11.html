signs.cpp

#include <print>

const char* p = "1-2+3-4+5-6+7-8+9";

int expr() {
    int v = *p++ - '0';
    char op = *p++;
    return op == '+' ? v + expr() : op == '-' ? v - expr() : v;
}

int main() {
    std::println("{}", expr());
}

これは何を出力するでしょうか?

Answer

Output

9

expr は数字を1つと演算子を1つ読み、残りの文字列全体を自分自身の再帰呼び出しで計算してから、v とその結果に演算子を当てはめます。そのため 1-2+3-… は 1 − (2 + (3 − (4 + …))) と計算され、どの演算子も右側の全体を相手にします。

9段の入れ子を内側から開く代わりに、各数字の符号を直接決められます。- はその右側の全体の符号を反転させ、+ は何も変えません。ある数字の符号は、それより左にある - の個数が偶数なら正、奇数なら負です。左から 1 は0個で正、2 と 3 は1個で負、4 と 5 は2個で正、6 と 7 は3個で負、8 と 9 は4個で正なので、1 − 2 − 3 + 4 + 5 − 6 − 7 + 8 + 9 = 9 になります。

見慣れた左からの計算 1 − 2 + 3 − … + 9 では 5 になります。このコードでは - の直後にある + もその引き算の右側に入るので、たとえば 3 は足されずに引かれます。最後の 9 のあとで読む op は終端の '\0' で、どちらの演算子とも一致しないので 9 がそのまま返ります。このとき p は配列の末尾の1つ先を指しますが、そこを読むことはないので問題ありません。
