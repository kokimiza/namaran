half_way.cpp

#include <cmath>
#include <print>

int main() {
    for (double x : {0.5, 1.5, 2.5, -2.5})
        std::println("{} {}",
                     std::round(x),
                     std::nearbyint(x));
}

これは何を出力するでしょうか?

Answer

Output

1 0
2 2
3 2
-3 -2

4つの値はどれも、両隣の整数からちょうど 0.5 離れています。0.5、1.5、2.5 は2のべき乗の分数の和で書けるので double で正確に表せ、丸める前の値に誤差はありません。結果が分かれるのは、真ん中の値をどちらへ寄せるかの決まりが2つの関数で違うからです。

std::round は真ん中の値を 0 から遠いほうへ丸めます。正の数なら大きいほうなので 0.5、1.5、2.5 は 1、2、3 になり、-2.5 は小さいほうの -3 になります。std::nearbyint は現在の丸めモードに従い、プログラム開始時の丸めモードは最も近い値への丸めで、真ん中なら偶数のほうを選びます。そのため 0.5 は 0、1.5 は 2、2.5 も 2、-2.5 は -2 になります。

1.5 の行だけは両方とも 2 になります。0 から遠いほうの整数と偶数のほうの整数が、たまたま同じだからです。2.5 で std::round と同じ 3 を予想すると、偶数への丸めが下へ寄せる場合を見落とします。std::println は整数になった double を小数点なしで書くので、1.0 ではなく 1 と表示されます。
