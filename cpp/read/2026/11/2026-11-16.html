toggle_flags.cpp

#include <iostream>
#include <vector>

int main() {
    std::vector<bool> flags{true, false, true};
    for (auto& f : flags) {
        f = !f;
    }
    for (bool f : flags) {
        std::cout << f;
    }
    std::cout << '\n';
}

これは何を出力するでしょうか?

Answer

Output

コンパイルエラー

std::vector<int> なら、for (auto& f : flags) の f は各要素を指す int& になり、f = !f で要素が書き換わります。同じつもりで読むと 010 が出そうですが、std::vector<bool> では for の行でコンパイルが止まります。

std::vector<bool> は要素を1ビットずつ詰めて持つように特殊化されていて、1ビットにはアドレスが無いので bool& を返せません。代わりにイテレータの *it は、どのワードのどのビットかを覚えた std::vector<bool>::reference という代理オブジェクトを値で返します。範囲forは auto& f = *it; と同じ形で f を初期化するので、auto はこの代理オブジェクトの型になり、一時オブジェクト（右辺値）を非 const の左辺値参照に束縛しようとして型エラーになります。

for (auto&& f : flags) と書けば、転送参照は右辺値にも束縛できるので通ります。代理オブジェクトへの代入はもとのビットを書き換えるので、そのときの出力は 010 です。
