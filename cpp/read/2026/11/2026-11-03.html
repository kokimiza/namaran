copied_limiter.cpp

#include <iostream>

int serve(auto limiter, int requests) {
    int passed = 0;
    for (int i = 0; i < requests; ++i) {
        passed += limiter();
    }
    return passed;
}

int main() {
    auto limiter = [tokens = 3]() mutable {
        if (tokens == 0)
            return false;
        --tokens;
        return true;
    };
    std::cout << serve(limiter, 2) << serve(limiter, 2) << limiter() << '\n';
}

これは何を出力するでしょうか?

Answer

221 です。

limiter は、トークンの残りを tokens として持つラムダです。[tokens = 3] で作った tokens はクロージャ(ラムダ式が作るオブジェクト)のメンバになり、mutable が付いているので、呼び出しのたびにそのメンバが減っていきます。

serve は引数 limiter を値で受け取るので、呼び出しのたびに main の limiter のコピーが作られます。コピーされるのはクロージャ全体で、メンバの tokens も残り3のまま写されます。1回目の serve はコピーのトークンを2つ使って 2 を返しますが、減ったのはコピーの tokens だけです。2回目の serve も、残り3のままの limiter から新しくコピーを作るので、やはり 2 を返します。最後の limiter() は元のクロージャを初めて呼ぶので、true が 1 と表示されます。

3つのトークンを共有していると読むと、2回目の serve で残り1つを使って 1、最後は空で 0 となり、210 と答えることになります。同じバケットを共有させたいなら、serve を auto& limiter で受け取ります。このとき出力は 210 です。
