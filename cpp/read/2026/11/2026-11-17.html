triangle_area.cpp

#include <print>

struct P {
    int x, y;
};

int main() {
    P ps[] = {{1, 1}, {1, 4}, {5, 1}};
    int s = 0;
    for (int i = 0; i < 3; i++) {
        P p = ps[i], q = ps[(i + 1) % 3];
        s += p.x * q.y - p.y * q.x;
    }
    std::println("{}", s / 2);
}

これは何を出力するでしょうか?

Answer

Output

-6

ループの1回分 p.x * q.y - p.y * q.x は、原点から p へのベクトルと原点から q へのベクトルの外積1です。原点から見て q が p の反時計回りの側にあれば正、時計回りの側にあれば負になります。3つの辺について足した s は三角形の面積の2倍ですが、符号が付いていて、頂点を反時計回りにたどれば正、時計回りにたどれば負になります。

値を入れると、(1, 1) から (1, 4) への辺で 1 × 4 − 1 × 1 = 3、(1, 4) から (5, 1) への辺で 1 × 1 − 4 × 5 = −19、(5, 1) から (1, 1) への辺で 5 × 1 − 1 × 1 = 4 です。和は −12 で、2で割って -6 が出力されます。この和は、1つ目の頂点から残りの2つへのベクトル (0, 3) と (4, 0) の外積 0 × 0 − 3 × 4 = −12 と同じ値です。

面積の公式として読むと 6 と答えたくなります。x が右、y が上に増える座標で並びを見ると、(1, 1) から真上の (1, 4) へ進み、そこから右下の (5, 1) へ曲がっています。右に曲がりながら一周するので、たどる向きは時計回りです。面積として 6 を得るには、和の絶対値を取ります。

  1. ここでの外積（cross product）は、平面のベクトル (a, b) と (c, d) に対する a × d − b × c のことです。空間ベクトルの外積の z 成分にあたり、2つのベクトルが作る平行四辺形の面積に、向きによる符号を付けた値になります。
