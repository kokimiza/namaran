last_writer.cpp

#include <array>
#include <cstdio>

int main() {
    std::array<int, 31> spf{};
    for (int i = 30; i >= 2; i--) {
        for (int j = i; j <= 30; j += i) {
            spf[j] = i;
        }
    }
    for (int n : {12, 25, 29}) {
        std::printf("%d\n", spf[n]);
    }
}

これは何を出力するでしょうか?

Answer

Output

2
5
29

内側のループは、i の倍数の欄すべてに i を書き込みます。書き込む前に欄が空かどうかを確かめないので、1つの欄 spf[j] には、j を割り切る2以上のすべての i が順に書き込まれ、前の値は上書きされます。外側のループは i を 30 から 2 へ小さくしていくので、最後に書き込むのは j を割り切る2以上の数のうち最も小さいものです。12 なら 12, 6, 4, 3, 2 の順に書かれて 2 が、25 なら 25, 5 の順に書かれて 5 が残ります。29 を割り切る2以上の数は 29 だけなので、29 がそのまま残ります。

外側のループに素数かどうかの判定はなく、4 や 6 のような合成数も倍数の欄に書き込みます。それでも表に残るのは必ず素数です。j を割り切る2以上の最も小さい数 d がもし合成数なら、d を割り切るもっと小さい数も j を割り切るので、d が最小だったことと食い違います。こうしてこの表は、各数の最小の素因数を引ける表になっています。

i の倍数を印付けていく形は、素数を小さい順に見て、まだ空の欄にだけ書き込む作り方とよく似ています。その形を思い浮かべたまま、ループの向きと上書きを読み落とすと、各欄には最初に書かれたその数自身が残ると考えて 12、25、29 と答えることになります。
