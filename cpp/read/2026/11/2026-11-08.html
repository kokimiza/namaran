escape.cpp

#include <iostream>

int main() {
    std::cout << "say \"hi\\n\"" << '\n';
    std::cout << R"(say \"hi\n\")" << '\n';
}

これは何を出力するでしょうか?

Answer

Output

say "hi\n"
say \"hi\n\"

1行目の通常の文字列リテラルでは、バックスラッシュとその次の文字の組がエスケープシーケンスとして1文字に置き換わります。\" は二重引用符1文字に、\\ はバックスラッシュ1文字になります。hi\\n の部分は \\ と n に分かれるので、改行ではなくバックスラッシュと n の2文字が残り、say "hi\n" と表示されます。

2行目の R"( と )" で囲んだ生文字列リテラルでは、エスケープシーケンスが解釈されません。括弧の間に書いた文字がそのまま文字列になるので、\" も \n もバックスラッシュを含む2文字のまま出力され、say \"hi\n\" になります。生文字列の中では二重引用符もそのまま書けるので、コードを文字列として持ちたいときに、エスケープを書き足さずに済みます。

1行目の \\n を改行と読むと、say "hi と " の2行に分かれると答えます。2行目にもエスケープが効くと読むと、\n が改行になり、やはり say "hi と " の2行になると答えます。
