visit_pair.cpp

#include <print>
#include <variant>

template <class... F> struct match : F... {
    using F::operator()...;
};

int main() {
    std::variant<int, double> a = 1, b = 2.5;
    auto f = match{
        [](int, auto) { return 1; },
        [](auto, int) { return 2; },
        [](double, double) { return 3; },
    };
    std::println("{}", std::visit(f, a, b));
}

これは何を出力するでしょうか?

Answer

Output

コンパイルエラー

実行時の値だけを追うと、a は int の1、b は double の2.5なので、呼ばれるのは (int, auto) のラムダで、1 が出力されるように見えます。ところが std::visit は、a と b がどの型を持つかを実行時にしか知りません。そのため、2つの variant が取りうる型の組み合わせ4通りすべてについて f の呼び出しをコンパイルし、実行時にそのうちの1つを選びます。int どうしの組は、このプログラムでは一度も現れませんが、それでも f(int, int) はコンパイルされます。

4通りを順に確かめると、(int, double) は1つ目のラムダ、(double, int) は2つ目のラムダ、(double, double) は3つ目のラムダが、変換なしで受け取れるただ1つの候補です。残る (int, int) では、1つ目は auto を int に、2つ目も auto を int にして、どちらも変換なしで受け取れます。どちらもテンプレートで、片方がもう片方より特殊だとも言えないので、呼び出しはあいまいになり、コンパイルできません。

match は、3つのラムダの operator() を1つのオーバーロードの集まりにまとめるだけです。どのラムダが選ばれるかは、普通の関数呼び出しと同じ規則で、型の組み合わせごとに決まります。b を std::variant<double> にすれば (int, int) の組が消え、このプログラムは 1 を出力します。
