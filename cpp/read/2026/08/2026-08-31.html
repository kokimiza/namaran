odd_count.cpp

#include <print>

int main() {
    int odd = 0;
    for (int x = -3; x <= 3; ++x) {
        if (x % 2 == 1) {
            ++odd;
        }
    }
    std::println("{}", odd);
}

これは何を出力するでしょうか?

Answer

Output

2

-3 から 3 までの7個のうち、奇数は -3、-1、1、3 の4個ですが、x % 2 == 1 を満たすのは 1 と 3 だけです。C++ の整数の / は商の小数部分を捨てて0の方向へ切り捨て、% は (a / b) * b + a % b == a が成り立つように決まります。-3 / 2 は -1.5 を0の方向へ切り捨てた -1 なので、-3 % 2 は -3 - (-1) * 2 で -1 です。-1 % 2 も商が0なので -1 になります。負の奇数を2で割った余りは1ではなく -1 で、比較は偽になります。

余りはいつも0以上だと考えると、4と答えます。数学で余りと言うときは0以上の数を指すことが多いのですが、C++ の % の結果は割られる数と同じ符号を持ちます。奇数かどうかを調べるなら、x % 2 != 0 と0との比較にすれば、符号に関係なく正しく判定できます。
