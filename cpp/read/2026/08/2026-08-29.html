first_model.cpp

#include <bitset>
#include <iostream>

int main() {
    auto formula = [](std::bitset<3> x) {
        return (!x[0] || x[1]) && (x[0] || x[2]);
    };
    for (unsigned long m = 0; m < 8; ++m) {
        std::bitset<3> x(m);
        if (formula(x)) {
            std::cout << x << '\n';
            return 0;
        }
    }
}

これは何を出力するでしょうか?

Answer

011 です。

std::bitset<3> x(m) は、整数 m の2進数の各桁をビットとして持ち、x[i] は 2 の i 乗の位を読みます。x[0]、x[1]、x[2] を3つの変数とみると、m を0から順に増やすループは、x[0] が一番速く入れ替わる順で8通りの割り当てを試します。

論理式の前半 !x[0] || x[1] は「x[0] が真なら x[1] も真」、後半 x[0] || x[2] は「x[0] か x[2] の少なくとも一方が真」を表します。m が0と2のときは x[0] も x[2] も偽なので後半で落ち、1のときは x[0] だけが真なので前半で落ちます。m が3のとき x[0] と x[1] が真で両方を満たし、これが最初に見つかる割り当てです。x[2] だけが真の m == 4 も式を満たしますが、3のほうが先に試されます。

std::bitset を << で出力すると、整数を2進数で書くときと同じく、一番上の x[2] から x[0] の順に並びます。m == 3 は2進数で 011 なので、左から x[2] が偽、x[1] と x[0] が真という並びになります。出力の左端を x[0] と読むと、答えは 110 になります。そのうえ試す順まで左の桁から入れ替わると考えると、x[2] だけが真の割り当てが先に見つかり、答えは 001 になります。
