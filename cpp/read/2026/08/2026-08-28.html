cardinality.cpp

#include <print>
#include <tuple>
#include <variant>

template <class T> constexpr int card = 0;
template <> constexpr int card<bool> = 2;
template <class... Ts> constexpr int card<std::tuple<Ts...>> = (card<Ts> * ... * 1);
template <class... Ts> constexpr int card<std::variant<Ts...>> = (card<Ts> + ... + 0);

int main() {
    std::println("{}", card<std::tuple<bool, std::variant<bool, bool>>>);
    std::println("{}", card<std::variant<std::tuple<bool, bool>, bool>>);
}

これは何を出力するでしょうか?

Answer

1行目に 8、2行目に 6 を出力します。

card<T> は、型 T の値が何通りあるかを数えます。bool は false と true の2通りです。std::tuple の値は各要素の値を1つずつ選んだ組なので、何通りあるかは要素ごとの数の積になり、畳み込み式は * でつないでいます。std::variant の値は、選択肢のどれか1つの値なので、選択肢ごとの数の和になり、畳み込み式は + でつないでいます。集合でいえば、直積集合（Cartesian product）の要素の個数は積、共通部分のない集合の和集合（disjoint union。直和とも）の要素の個数は和、という関係です。

1行目の std::variant<bool, bool> は 2 + 2 = 4 通りです。同じ bool が2つ並んでいても、std::variant は値と一緒に何番目の選択肢かを持つので、1番目の false と2番目の false は別の値になります。これと bool の組は 2 × 4 = 8 通りです。

2行目は、std::tuple<bool, bool> の 2 × 2 = 4 通りと bool の2通りのどちらかなので、4 + 2 = 6 通りです。入れ子の順を入れ替えただけで、積と和を取る順が変わり、8と6に分かれます1。

  1. 畳み込み式の初期値の 1 と 0 は、要素が1つもない場合の値です。card<std::tuple<>> は1で、要素のない組 std::tuple<>{} というただ1つの値を数えています。
