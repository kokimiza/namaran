rank.cpp

#include <algorithm>
#include <print>
#include <utility>
#include <vector>

int main() {
    std::vector<std::pair<int, char>> v{{2, 'a'}, {1, 'b'}, {2, 'c'}, {1, 'd'}};
    std::ranges::stable_sort(v, {}, &std::pair<int, char>::first);
    std::ranges::reverse(v);
    for (auto [k, c] : v)
        std::print("{}", c);
    std::println();
}

これは何を出力するでしょうか?

Answer

Output

cadb

stable_sort の3つ目の引数 &std::pair<int, char>::first は、比べる前に各要素から first を取り出す指定です。2つ目の {} は既定の比較 std::ranges::less なので、要素は first の昇順に並び、second は比べません。stable_sort は first が同じ要素どうしの順序を元のまま残すので、1 の組は b、d、2 の組は a、c の順になり、並びは 1b 1d 2a 2c です。

続く reverse は、キーを見ずに列全体を後ろから並べ直します。first は降順の 2 2 1 1 になりますが、同じキーの中の順序も一緒に逆になり、2c 2a 1d 1b です。second だけを出力するので cadb が出ます。

「安定ソートしたのだから同点は元の順」と読むと、降順でも a が c より先に来る acbd と答えてしまいます。stable_sort が守った順序を、そのあとの reverse がひっくり返しています。同点を元の順に保ったまま降順にしたいなら、反転せずに std::ranges::stable_sort(v, std::ranges::greater{}, &std::pair<int, char>::first) と比較の向きを変えて並べます。
