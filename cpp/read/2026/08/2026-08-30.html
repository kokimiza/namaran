snapshot.cpp

#include <iostream>
#include <memory>

int main() {
    auto owner = std::make_shared<int>(42);
    std::weak_ptr<int> watcher = owner;
    bool alive = !watcher.expired();
    owner.reset();
    if (alive) {
        auto p = watcher.lock();
        std::cout << (p ? *p : -1) << '\n';
    }
}

これは何を出力するでしょうか?

Answer

Output

-1

watcher は std::weak_ptr なので、42 を持つオブジェクトを見ているだけで、所有はしていません。所有者は owner の1つだけです。watcher.expired() を呼んだ時点では owner がまだ持っているので false が返り、alive は true になります。alive はこの時点の答えを写した bool で、あとで所有者がいなくなっても書き換わりません。

次の owner.reset() で最後の所有者が手放すので、42 のオブジェクトはその場で破棄されます。if (alive) は古い答えを見て本体に入り、そこで watcher.lock() を呼びます。lock は、その時点でオブジェクトが残っていれば所有権を1つ分けた shared_ptr を、残っていなければ空の shared_ptr を返します。いまは破棄済みなので p は空で、条件演算子は -1 を選びます。

alive が true だったことから 42 と読むと間違えます。確かめてから使うまでの間に所有者が手放せば、確かめた結果は役に立ちません。weak_ptr では、expired で確かめずに lock の戻り値を確かめます。lock で受け取った p が所有者の1つになるので、p が空でなければ、p を使い終えるまでオブジェクトは破棄されません。
