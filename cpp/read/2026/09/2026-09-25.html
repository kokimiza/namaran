countdown.cpp

#include <cstdint>
#include <iostream>

int main() {
    std::uint8_t lives = 3;
    for (int i = 0; i < 5; ++i) {
        --lives;
    }
    std::cout << +lives << '\n';
}

これは何を出力するでしょうか?

Answer

254です。livesは3→2→1→0→255→254と5回減ります。符号なし整数は範囲を越えても「オーバーフロー」にはならず、2N(std::uint8_tなら256)を法として一周することが規格で決まっています。正確には、--livesの計算自体はintに昇格して0 - 1 = -1になり、それをstd::uint8_tへ戻すときに256を法とした変換で255になります。どちらにしても結果は明確で、未定義動作になる符号つき整数のオーバーフローとはここが違います。+livesの単項+はintへの昇格で、これが無いとstd::uint8_t(実体はunsigned char)は文字として出力されます。
