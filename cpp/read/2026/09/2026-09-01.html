tickets.cpp

#include <atomic>
#include <print>
#include <thread>

int main() {
    std::atomic<int> next{0}, evens{0};
    {
        auto work = [&] {
            for (int i = 0; i < 1000; i++) {
                if (next.fetch_add(1) % 2 == 0) {
                    evens++;
                }
            }
        };
        std::jthread a(work), b(work);
    }
    std::println("{} {}", next.load(), evens.load());
}

これは何を出力するでしょうか?

Answer

2000 1000 です。

next.fetch_add(1) は、next に1を足すことと足す前の値を返すことを、ほかのスレッドが割り込めない1つの操作として行います。2つのスレッドが合わせて2000回呼ぶので、返る値は0から1999までの整数がちょうど1回ずつです。実行のたびに変わるのは、どちらのスレッドがどの値を受け取るかだけです。

evens が数えるのは、受け取った値が偶数だった回数です。0から1999までの偶数は1000個あり、どれも一度だけどちらかのスレッドに渡るので、配られ方が変わっても合計は1000になります。evens++ も std::atomic への1回の操作なので、2つのスレッドが同時に足しても数え落としません。

表示は、2つの std::jthread を作ったブロックを抜けたあとに行われます。std::jthread はデストラクタでスレッドの終了を待つ（join する）ので、std::println に着いた時点で2000回の fetch_add はすべて終わっています。スレッドの進み方しだいで値が変わると考えるのも、表示がスレッドより先に走って小さい値が出ると考えるのも誤りです。
