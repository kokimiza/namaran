settle_flags.cpp

#include <iostream>
#include <vector>

void settle(std::vector<int>& counts, std::vector<bool>& dirty) {
    for (auto c : counts) {
        if (c > 1) {
            c = 1;
        }
    }
    for (auto d : dirty) {
        if (d) {
            d = false;
        }
    }
}

int main() {
    std::vector<int> counts{3, 1, 4};
    std::vector<bool> dirty{true, true, false};
    settle(counts, dirty);
    for (int c : counts) {
        std::cout << c;
    }
    std::cout << ' ';
    for (bool d : dirty) {
        std::cout << d;
    }
    std::cout << '\n';
}

これは何を出力するでしょうか?

Answer

314 000 を出力します。counts は変わらず、dirty だけがすべて false になります。

範囲for文の auto c は、要素の値で初期化された別の int です。c = 1 はこのコピーを書き換えるだけなので、counts は 3 1 4 のまま残ります。

同じ auto でも、std::vector<bool> では結果が変わります。vector<bool> は要素を1ビットずつ詰めて持つ特殊化で、1ビットを指す bool& は作れないので、イテレータの *it は std::vector<bool>::reference というプロキシのオブジェクトを値で返します。auto d が推論するのはこのプロキシの型で、コピーしても元のビットを指したままです。d = false はプロキシの operator= を呼び、dirty のビットを直接書き換えます。

counts も書き換えたいなら auto& c と書きます。逆に dirty を書き換えたくないなら bool d と型を書けば、プロキシから bool の値が取り出されてコピーになります。vector<bool> は auto& で受けることもできません。*it が一時オブジェクトなので、非constの左辺値参照を束縛できないからです。
