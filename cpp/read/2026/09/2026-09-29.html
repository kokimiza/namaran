every_other.cpp

#include <iostream>
#include <string>

int main() {
    for (std::string s : {"abcde", "wxyz", ""}) {
        for (std::size_t i = s.size() - 1; i < s.size(); i -= 2) {
            std::cout << s[i];
        }
        std::cout << '|';
    }
    std::cout << '\n';
}

これは何を出力するでしょうか?

Answer

eca|zx|| です。

i は std::size_t で、符号なし整数の引き算の結果は負になりません。0 から 2 を引くと、表せる範囲を法として回り込み、最大値の1つ手前という巨大な値になります。この値は文字列の長さより必ず大きいので、i < s.size() はそこで偽になり、ループが終わります。条件を i >= 0 にしていたら、符号なしの i では常に真になり、終わりませんでした。

"abcde" では i が 4、2、0 と進んで e、c、a を出し、0 から 2 を引いたところで終わります。"wxyz" では 3、1 と進んで z、x を出します。i はちょうど 0 を通りませんが、1 から 2 を引いた値も最大値に回り込むので、同じように止まります。

空文字列では、初期値の s.size() - 1 がすでに最大値です。条件は最初から偽になり、本体は1度も実行されないので、s[i] で範囲外を読むこともなく、| だけが出力されます。
