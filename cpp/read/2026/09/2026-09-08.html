price.cpp

#include <iostream>

struct Price {
    int yen;
    int tax = yen / 10;
};

int main() {
    Price a(1980.9);
    Price b(500, 0);
    std::cout << a.yen << ' ' << a.tax << ' ' << b.tax << '\n';
}

これは何を出力するでしょうか?

Answer

1980 198 0 です。

Price はコンストラクタを持たない集成体です。C++20 からは、集成体も Price a(1980.9) のように丸括弧で初期化でき、引数は先頭のメンバから順に渡されます。a.yen は 1980.9 から初期化されますが、yen は int なので、double からの変換で小数部が切り捨てられて 1980 になります。

波括弧の Price a{1980.9} なら、double から int への縮小変換としてコンパイルエラーになるところです。丸括弧のほうは各メンバを引数からコピー初期化するだけなので、関数に引数を渡すときと同じく縮小変換も通ります。

a には引数が1つしかないので、tax はデフォルトメンバ初期化子 yen / 10 で初期化されます。メンバは宣言順に初期化されるため、この時点の yen はすでに 1980 で、tax は整数除算の結果の 198 です。b では2つ目の引数 0 が tax に渡るので、デフォルトメンバ初期化子は使われず、b.tax は 0 です。
