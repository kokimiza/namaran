closure_copy.cpp

#include <iostream>

int main() {
    int n = 0;
    auto inc = [n]() mutable { return ++n; };
    auto copy = inc;
    inc();
    inc();
    std::cout << inc() << " " << copy() << " " << n << "\n";
    return 0;
}

これは何を出力するでしょうか?

Answer

出力は3 1 0です。ラムダ式を評価すると、キャプチャした変数をデータメンバとして持つ無名のクラスのオブジェクト、つまりクロージャができます。[n]で作ったincは、その時点のnのコピー(0)を自分のメンバとして持ちます。

auto copy = inc;はこのオブジェクトをコピーするので、copyも値が0のメンバを別に持ちます。incを3回呼ぶと増えるのはincのメンバだけで、3回目のinc()が3を返します。copy()は自分のメンバを0から1にするだけです。mutableで書き換えているのはクロージャの中のコピーなので、外側のnは0のままです。
