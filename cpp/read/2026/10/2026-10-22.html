fuzz_harness.cpp

#include <iostream>
#include <set>
#include <string>

std::set<std::string> seen;

void target(const char* input) {
    seen.insert(input);
}

int main() {
    const char bytes[] = {'a', '\0'};
    for (char first : bytes) {
        for (char second : bytes) {
            const char input[] = {first, second, '\0'};
            target(input);
        }
    }
    std::cout << seen.size() << '\n';
}

これは何を出力するでしょうか?

Answer

3 です。

二重の for は 'a' と '\0' から2バイトの並びを総当たりで作り、"aa"、"a\0"、"\0a"、"\0\0" の4通りを target に渡します。どれも中身が違うので、seen に4つ残ると読みたくなります。ところが target が受け取るのは const char* だけで、長さは渡っていません。seen.insert(input) で std::string を作るとき、ポインタからは長さがわからないので、最初の '\0' を文字列の終わりとみなし、その手前までを読みます。

すると4つの入力は、target の中では "aa"、"a"、""、"" になります。先頭が '\0' の2つはどちらも空文字列で、std::set は同じ値を1つしか持たないので、残るのは3種類です。2バイト目に何を置いても、'\0' の後ろは target に届いていません。ファジングで想定外の入力を自動生成しても、ハーネスがこうして入力を切り詰めると、生成した入力の一部は試されないまま終わります1。

  1. libFuzzer のハーネスは LLVMFuzzerTestOneInput(const uint8_t* data, size_t size) の形で、入力をポインタと長さの組で受け取ります。0のバイトを含む入力も最後まで渡すためで、std::string に移すときも std::string(reinterpret_cast<const char*>(data), size) のように長さを渡します。
