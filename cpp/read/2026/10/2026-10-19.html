clone.cpp

#include <iostream>

struct Shape {
    virtual ~Shape() = default;
    virtual Shape* clone() const { return new Shape(*this); }
    const char* name() const { return "shape"; }
};
struct Circle : Shape {
    Circle* clone() const override { return new Circle(*this); }
    const char* name() const { return "circle"; }
};

int main() {
    Circle c;
    const Shape& s = c;
    auto* p = s.clone();
    auto* q = c.clone();
    std::cout << p->name() << ' ' << q->name() << '\n';
    delete p;
    delete q;
}

これは何を出力するでしょうか?

Answer

shape circle の1行です。

s.clone() は仮想関数の呼び出しなので、実行時には s が参照している実体 c の型に従って Circle::clone が呼ばれ、p が指すのは Circle のコピーです。それでも1つ目が shape になるのは、式 s.clone() の型が実行時ではなくコンパイル時に決まるからです。s の静的な型は const Shape& なので、コンパイラが見るのは Shape::clone の宣言で、式の型は Shape* になります。Circle::clone が返した Circle* は Shape* に変換されて受け取られ、p の型も Shape* です。

name は仮想関数ではないので、p->name() はポインタの型 Shape* から Shape::name に決まり、shape を出力します。c.clone() のほうは静的な型が Circle の式から呼ぶので、コンパイラは Circle::clone の宣言を見て、式の型を Circle* とします。q は Circle* になり、q->name() は Circle::name を呼んで circle を出力します。

オーバーライドする関数の戻り値を、基底クラスの関数が返すクラスから派生したクラスへのポインタや参照に変えてよいという規則を、共変戻り値型（covariant return type）といいます。呼ばれる関数は実行時に決まり、戻り値の型は呼び出し側の静的な型で決まるので、狭めた戻り値の型を受け取れるのは、相手が Circle だとコンパイル時に分かっている呼び出し側だけです。
