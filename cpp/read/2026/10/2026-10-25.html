box_size.cpp

#include <iostream>

int main() {
    int box[2] = {1, 2};
    auto [w, h] = box;
    auto& [rw, rh] = box;
    box[0] = 10;
    rh = 20;
    std::cout << w << ' ' << h << ' ' << rw << ' ' << box[1] << '\n';
}

これは何を出力するでしょうか?

Answer

1 2 10 20 です。

構造化束縛は、まず右辺から名前のない変数を1つ作り、[ ] の中の名前をその変数の要素の別名にします。auto [w, h] = box; では、この名前のない変数が auto で宣言されるので、box の写しになります。配列は = で丸ごと代入できない型ですが、構造化束縛ではこの写しが要素ごとのコピーで作られます。w と h が指すのは写しの要素なので、あとで box[0] を 10 にしても w は 1 のままです。

auto& [rw, rh] = box; では名前のない変数が box への参照になり、rw と rh は box[0] と box[1] そのものを指します。box[0] = 10 は rw から見え、rh = 20 は box[1] を書き換えます。関数の引数のように配列がポインタに変わると考えて w と h も box を指すと読むと、10 20 10 20 と答えることになります。
