same_value.cpp

#include <atomic>
#include <iostream>

int main() {
    std::atomic<int> top{1};
    int seen = top.load();
    top.store(2);
    top.store(1);
    bool swapped = top.compare_exchange_strong(seen, 3);
    std::cout << std::boolalpha << swapped << ' ' << top.load() << '\n';
}

これは何を出力するでしょうか?

Answer

true 3 です。

compare_exchange_strong(seen, 3) は、top の値を seen と比べ、等しければ top を 3 に書き換えて true を返します。比べるのは呼び出した時点の値だけで、seen を読んでから top にどんな書き換えがあったかは見ません。

seen を読んだとき top は 1 でした。そのあと 2 が書かれ、また 1 が書かれたので、比べる時点では top も seen も 1 です。比較は成功して top は 3 になります。途中で 2 を経たことを検出して失敗すると読むと、false 1 と答えることになります。値がAからBを経てAに戻ったことを比較が見逃すこの現象を、ABA問題と呼びます。
