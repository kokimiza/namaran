twice.cpp

#include <iostream>

int main() {
    auto twice = [](auto f, int x) {
        return f(f(x));
    };
    int step = 1;
    auto add = [step](int x) {
        return x + step;
    };
    step = 10;
    std::cout << twice(add, 0) << ' ' << twice(add, step) << '\n';
}

これは何を出力するでしょうか?

Answer

2 12 です。

add の捕捉リスト [step] はコピーによる捕捉で、ラムダ式を評価したその時点の step の値1が、ラムダ式のオブジェクトの中にメンバとして写し取られます。そのあとで step = 10 と書き換えても、変わるのは main の変数だけで、add が持っている1は変わりません。add は呼ばれるたびに、引数に1を足して返します。

twice は受け取った関数を2回続けて適用するので、twice(add, 0) は0に1を2回足して2です。twice(add, step) では、引数の step は呼び出しの時点で読まれるので10が渡り、それに1を2回足して12になります。同じ step という名前でも、捕捉した1と引数で渡した10は別の値です。[&step] と参照で捕捉していれば、足すのも10になり、出力は 20 30 になります。
