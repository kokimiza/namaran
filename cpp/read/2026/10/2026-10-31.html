queue_lock.cpp

#include <iostream>
#include <mutex>

struct Noisy {
    void lock() {
        std::cout << "lock ";
    }
    void unlock() {
        std::cout << "unlock\n";
    }
};

int main() {
    Noisy queue_mutex;
    int pending = 0;
    if (std::scoped_lock lock(queue_mutex); pending > 0) {
        std::cout << "pop ";
    } else {
        std::cout << "empty ";
    }
}

これは何を出力するでしょうか?

Answer

lock empty unlock です。

if 文の初期化文で宣言した変数の有効範囲は、条件式だけでなく、else 節を含む if 文の全体です。この if 文は、{ std::scoped_lock lock(queue_mutex); if (pending > 0) { ... } else { ... } } と書いたのと同じ意味になります。

変数 lock を作った時点で queue_mutex.lock() が呼ばれ、lock と出力されます。pending は0なので else 節に進み、empty を出力します。変数 lock が破棄され、デストラクタが queue_mutex.unlock() を呼ぶのは、そのあと if 文を抜けるときです。

初期化文を、条件を調べるためだけの準備と読むと、ロックは条件を調べ終えた時点で外れると考えて、lock unlock のあとに empty が続くと答えてしまいます。
