toggle_flags.cpp

#include <print>

constexpr unsigned Read = 1u << 0;
constexpr unsigned Write = 1u << 1;
constexpr unsigned Exec = 1u << 2;

int main() {
    unsigned mode = Read | Write;
    mode ^= Write | Exec;
    mode &= ~Read;
    std::println("{} {} {}", (mode & Read) != 0, (mode & Write) != 0, (mode & Exec) != 0);
}

これは何を出力するでしょうか?

Answer

false false true です。

3つのフラグはそれぞれ1ビットで、Read が1、Write が2、Exec が4です。mode は Read | Write で始まるので、2進数で 011 です。

^= の排他的論理和は、右辺で1になっているビットを反転させ、0のビットはそのまま残します。Write | Exec は 110 なので、立っていた Write は落ち、立っていなかった Exec が立って、mode は 101 になります。Write と Exec の両方を立てる操作だと読むと、ここで 111 と考えてしまいます。

~Read は最下位ビットだけが0で、ほかが全部1の値です。これとの &= は Read のビットだけを0にするので、mode は 100 になり、残るのは Exec だけです。std::println は bool を true と false の文字で表示します。
