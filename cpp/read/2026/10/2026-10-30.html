first_match.cpp

#include <iostream>
#include <regex>
#include <string>

int main() {
    const std::string s = "aaab";
    const std::regex re("(a*)(a|ab)");
    std::smatch m;
    std::regex_search(s, m, re);
    std::cout << m[1] << '|' << m[2] << '\n';
    std::regex_match(s, m, re);
    std::cout << m[1] << '|' << m[2] << '\n';
}

これは何を出力するでしょうか?

Answer

1行目が aa|a、2行目が aa|ab です。

std::regex の既定の文法(ECMAScript)は、文字列の分け方を決まった順に1つずつ試し、最初に成功した分け方を結果にします。最も長く一致する分け方を探すわけではありません。a* はまず取れるだけの a を取り、その先が合わなければ1文字ずつ返します。(a|ab) は左の a を先に試し、それが合わなかったときだけ ab を試します。

regex_search では、a* が aaa を取ると、残りの b には a も ab も合いません。a* が1文字返して aa になると、3文字目の a に左の選択肢 a が合い、ここで一致が成立します。b が余っていても、文字列の一部が合えばよいので成功で、ab は試されないまま終わります。

regex_match は文字列の全体と一致しなければ成功になりません。同じ順に進んで aa と a まで来ても、b が残っているので失敗になり、最後に試した選択に戻って右の ab を試します。ab は3文字目から最後までと合うので、aa|ab で成功します。

最も長い一致が選ばれると考えると、1行目も aa|ab と答えてしまいます。逆に、a* が一度取った a を返さないと考えると、どの位置から始めても b の前の a を取り尽くして失敗するので、2行とも一致なしの | と答えてしまいます。
