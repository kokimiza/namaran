trace.cpp

#include <iostream>

struct Trace {
    int n;
    ~Trace() { std::cout << n; }
};

int count(int n) {
    Trace t{n};
    if (n == 0)
        return 0;
    return count(n - 1);
}

int main() {
    count(3);
    std::cout << '\n';
}

これは何を出力するでしょうか?

Answer

0123 です。

t のデストラクタが動くのは、count から抜けるときです。return count(n - 1); はまず count(n - 1) を呼んで戻り値を受け取り、そのあとで t を破棄してから関数を抜けます。count(3) の t は、count(2) が戻ってくるまで生きています。

そのため最初に破棄されるのはいちばん深い count(0) の t で、0 が出ます。そこから呼び出し元へ1段戻るたびに、1、2、3 と出ます。

return の直後に書いた呼び出しでも、デストラクタを持つ局所変数があれば、呼び出しが戻ったあとに破棄という仕事が残ります。この呼び出しは末尾呼び出しにならず、count のフレームは再帰の深さの分だけ積み上がります。
