coalesce.cpp

#include <iostream>
#include <map>
#include <string>
#include <utility>

int main() {
    std::pair<std::string, char> events[] = {
        {"a.txt", 'M'}, {"b.txt", 'C'}, {"a.txt", 'D'}, {"b.txt", 'M'}};
    std::map<std::string, char> latest;
    for (const auto& [path, kind] : events) {
        latest.insert({path, kind});
    }
    for (const auto& [path, kind] : latest) {
        std::cout << path << ' ' << kind << '\n';
    }
}

これは何を出力するでしょうか?

Answer

a.txt M と b.txt C の2行です。

std::map の insert は、同じキーの要素がすでにあれば何もしません。挿入できたかどうかを戻り値の bool で知らせるだけで、入っている値は書き換えません。a.txt では最初の 'M' が残って3つ目の 'D' が捨てられ、b.txt でも最初の 'C' が残って4つ目の 'M' が捨てられます。std::map はキーの順に並ぶので、出力は a.txt が先です。

変数名の latest が示すとおり、同じファイルへの通知をまとめるなら、残したいのは最後の通知です。このままでは、削除された a.txt を変更されたものとして扱い、もう無いファイルを読みにいきます。最後の値を残すには、latest[path] = kind; か latest.insert_or_assign(path, kind); で上書きします。
