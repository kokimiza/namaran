byte_order.cpp

#include <cstdint>
#include <print>

int main() {
    const std::uint8_t bytes[] = {0x12, 0x34, 0x56, 0x78};
    std::uint32_t be = 0, le = 0;
    for (int i = 0; i < 4; i++) {
        be = be << 8 | bytes[i];
        le = le | std::uint32_t{bytes[i]} << (8 * i);
    }
    std::println("{:08x} {:08x}", be, le);
}

これは何を出力するでしょうか?

Answer

12345678 78563412 です。

<< は | より優先順位が高いので、be << 8 | bytes[i] は、それまでの値を1バイト分だけ上へずらしてから、空いた下位8ビットに次のバイトを入れます。最初に入れた 0x12 は残り3回のシフトで最上位まで押し上げられ、be は 0x12345678 になります。先頭のバイトが最上位に来るこの読み方を、ビッグエンディアンといいます。

le のほうは、i 番目のバイトを 8 * i ビット上の位置に置きます。先頭の 0x12 は最下位に、最後の 0x78 は最上位に入るので、le は 0x78563412 です。こちらはリトルエンディアンの読み方です。どちらもシフトと論理和で値を組み立てているので、結果は動かす機械のバイト順に左右されません。
