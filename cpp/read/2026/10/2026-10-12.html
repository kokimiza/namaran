chain.cpp

#include <iostream>

int main() {
    int a = 2, b = 3, c = 4;
    a *= b += c -= a;
    std::cout << a << ' ' << b << ' ' << c << '\n';
}

これは何を出力するでしょうか?

Answer

10 5 2 です。

代入演算子は = も *= += -= も右結合なので、a *= b += c -= a は a *= (b += (c -= a)) とまとまります。いちばん内側の c -= a は、まだ 2 のままの a を引いて c を 2 にします。複合代入の式の値は代入したあとの左辺なので、この部分式の値も 2 です。

その 2 を受けた b += 2 で b は 5 になり、最後の a *= 5 で a は 10 になります。左から a *= b を先に計算したと読むと、a が 6 になったあとで c -= a が 6 を引くことになり、3つとも違う値が出てきます。
