plugins.cpp

#include <iostream>

struct Logger {
    Logger() { std::cout << "[log]"; }
};

Logger& logger() {
    static Logger instance;
    return instance;
}

char load(char name) {
    std::cout << name;
    logger();
    return name;
}

char a = load('a');
char b = load('b');

int main() { logger(); }

これは何を出力するでしょうか?

Answer

a[log]b です。改行は出ません。

名前空間スコープの a と b は、同じ翻訳単位の中では定義の順に初期化されます1。a の初期化子 load('a') は、a を出力してから logger() を呼びます。

logger() の中の static Logger instance; は、プログラムの開始時ではなく、制御が初めてこの宣言を通ったときに構築されます。それが a の初期化の途中なので、[log] は a の直後に出ます。b の初期化で logger() がもう一度呼ばれても、instance は構築済みなのでコンストラクタは走らず、出るのは b だけです。main の中の logger() も同じ理由で何も出しません2。

  1. 規格は、こうした初期化を main の最初の文より前に済ませるか、後へ遅らせるかを処理系定義としています。遅らせる場合でも、同じ翻訳単位の関数が使われる前には済ませる決まりなので、main が logger() を呼ぶ時点で a と b の初期化は終わっています。main より前に std::cout を使えるのは、<iostream> をインクルードした翻訳単位では、その後に定義した静的変数より先に標準ストリームが使える状態になると規格が定めているからです。
  2. 関数内 static 変数の初期化は C++11 からスレッドセーフで、複数のスレッドが同時に初めて宣言を通っても、構築は1回だけです。
