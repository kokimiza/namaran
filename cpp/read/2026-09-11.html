loop_sum.cpp

#include <cstdio>

int main() {
    int total = 0;
    for (int i = 0, j = 5; i < j; ++i, --j) {
        total += i * j;
    }
    printf("%d\n", total);
}

このコードは何を出力するでしょうか?

Answer

10(その後に改行)。このforは初期化・条件・更新の3か所に、カンマ演算子でiとjという2つのカウンタをまとめて詰め込んでいます。iは0から増え、jは5から減り、i < jである間だけ本体を実行します。順に追うと、(i=0,j=5)でtotalに0*5=0を足して0、(i=1,j=4)で1*4=4を足して4、(i=2,j=3)で2*3=6を足して10、更新後は(i=3,j=2)となり3 < 2が偽なので終了します。whileで同じことをするには++iと--jを本体の外(末尾)に別々の文として書く必要がありますが、forはこの「複数の変数を1周ごとに更新する」という繰り返しの構造そのものをヘッダ1行にまとめて表現できます。
