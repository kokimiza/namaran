describe.cpp

#include <print>
#include <string>
#include <variant>

template <class... F> struct overloaded : F... { using F::operator()...; };

int main() {
    using Value = std::variant<int, double, std::string>;
    auto describe = overloaded{
        [](int i) { return "int " + std::to_string(i); },
        [](const std::string& s) { return "string " + s; },
        [](auto) { return std::string("other"); },
    };
    for (Value v : {Value{3}, Value{2.5}, Value{"hi"}})
        std::println("{}", std::visit(describe, v));
}

これは何を出力するでしょうか?

Answer

int 3、other、string hi を1行ずつ出力します。

std::visit は、v がいま持っている値をその型のまま describe に渡して呼び出します。overloaded は3つのラムダの operator() を1つのオブジェクトに集めたものなので、どのラムダが呼ばれるかは、普通の関数呼び出しと同じオーバーロード解決で決まります1。

2つ目の 2.5 は double です。int を取るラムダも double から int への変換を使えば呼べるので、int 2 と出そうに見えます。しかし auto を取るラムダは引数の型を double と推論し、変換なしで受け取れます。オーバーロード解決では変換の要らない候補が勝つので、other が出ます。

1つ目の 3 では、int を取るラムダと auto を取るラムダが、どちらも変換なしで受け取れます。このように優劣がつかないときはテンプレートでない方が選ばれるので、int 3 になります。"hi" は std::string として格納されているので、同じ理由で const std::string& を取るラムダが選ばれます。

  1. overloaded{...} に推論ガイドを書かずに済むのは、C++20 から集成体にもクラステンプレートの実引数推論が働くようになったからです。
