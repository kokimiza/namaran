die_choice.cpp

#include <print>

int main() {
    int count[4] = {};
    for (int die = 1; die <= 6; ++die)
        ++count[die % 4];
    std::println("{} {} {} {}", count[0], count[1], count[2], count[3]);
}

これは何を出力するでしょうか?

Answer

1 2 2 1 です。

die は 1 から 6 まで動き、die % 4 は順に 1, 2, 3, 0, 1, 2 になります。0 と 3 は1回ずつ、1 と 2 は2回ずつ出るので、count は {1, 2, 2, 1} です。

6通りの目を4つに分けようとしても、6 は 4 で割り切れません。4 を超えた 5 と 6 の2通りが、余りの 1 と 2 にもう一度割り当てられます。サイコロが公平でも、この変換を通すと 1 と 2 は 0 と 3 の2倍の確率で選ばれます。rand() % n で乱数を範囲に収めるときも同じで、元の乱数が取りうる値の個数が n で割り切れなければ、小さい方の余りが出やすくなります。
