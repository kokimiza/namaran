print_scores.cpp

#include <iostream>

void print_scores(const int scores[]) {
    for (int s : scores) {
        std::cout << s << '\n';
    }
}

int main() {
    int scores[] = {72, 85, 90};
    print_scores(scores);
}

print_scores は、受け取った点数を1行に1つずつ出力するつもりの関数です。入力は main のとおり、int scores[] = {72, 85, 90}; をそのまま渡す呼び出しです。いまはコンパイルが通りません。本来は 72、85、90 が1行ずつ出力されます。どこを直せばよいでしょうか?

Answer

引数を const int scores[] から std::span<const int> scores に変え、#include <span> を足します。

関数の引数に配列の型を書いても、その引数は const int * として宣言されます。範囲for文は範囲の始まりと終わりを begin と end で求めますが、ポインタは要素数を持たず、scores.begin() も begin(scores) も見つからないので、コンパイルエラーになります。main の中の scores は int[3] のままなので、同じ for を main に書けば通ります。

std::span<const int> は先頭へのポインタと要素数の組で、int[3] の配列から要素数ごと暗黙に作られます。begin と end を持つので、関数の本体は範囲for文のまま変えずに済みます。要素数を型に含めてよければ、const int (&scores)[3] と配列への参照で受ける方法もあります。
