task_label.cpp

#include <iostream>
#include <string>

struct Task {
    std::string label;
    Task() : label("[" + kind() + "]") {}
    virtual ~Task() = default;
    virtual std::string kind() const { return "task"; }
};

struct Backup : Task {
    std::string kind() const override { return "backup"; }
};

int main() {
    Backup b;
    std::cout << b.label << '\n';
}

Task は、派生クラスが kind() で返す種類の名前を角括弧で囲み、label として持つ基底クラスです。Backup b; の b.label を出力すると、いまは [task] と出力されます。本来の出力は [backup] です。

Answer

Wrong

std::string label;
Task() : label("[" + kind() + "]") {}

label は Task のコンストラクタの初期化子で作られます。Backup b; は先に基底の Task を構築し、その間 Backup の部分はまだできていないので、オブジェクトは Task としてふるまいます。仮想関数の kind() もこのとき Task::kind で解決され、label には [task] が入ります。

Backup の構築が終わっても、label は作られたときの文字列のままです。あとから b.label を読むと [task] が出力されます。

Right

std::string label() const { return "[" + kind() + "]"; }

label をメンバ関数にして、呼ばれるたびに作るようにします。main が b.label() を呼ぶころには構築が終わっているので、kind() は Backup::kind に届き、[backup] が返ります。label を文字列のメンバとして持ち続けたいなら、kind() を呼ぶのをやめ、派生クラスから Task のコンストラクタへ種類の名前を引数で渡します。
