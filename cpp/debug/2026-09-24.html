make_adder.cpp

#include <functional>
#include <iostream>

std::function<int()> make_adder(int base) {
    int offset = base * 2;
    return [&offset]() { return offset + 1; };
}

int main() {
    auto f = make_adder(3);
    std::cout << f() << "\n";
    return 0;
}

make_adderが返すクロージャを呼び出して、baseから計算した値に1を足した数を表示するつもりのプログラムです。入力はmake_adder(3)。いまの出力は保証されません(make_adderのローカル変数への参照をキャプチャしたまま関数を抜けているため、AddressSanitizerがstack-use-after-returnを検出することもあれば、たまたま動いてしまうこともあります)。本来の出力は7です。何が問題で、どう直せばよいでしょうか?

Answer

[&offset]はoffsetへの参照をキャプチャしています。offsetはmake_adderのローカル変数なので、関数がreturnした時点で寿命が尽きます。返されたラムダにはその後もoffsetそのものへの参照だけが残るので、あとでf()を呼んで参照先を読むと、すでに存在しないスタック領域を読むダングリング参照になります。たまたま以前の値が残っていて動いているように見えることもありますが、これは未定義動作です。直し方は、参照ではなく値でキャプチャすることです。[offset]に変えれば、ラムダはmake_adderを呼んだ時点のoffsetの値をコピーとして持ち続けるので、関数を抜けたあとも安全に使えます。 

return [offset]() { return offset + 1; };
