summarize.cpp

#include <iostream>
#include <vector>

struct Stats {
    int count;
    int sum;
};

Stats summarize(const std::vector<int>& xs) {
    Stats s();
    for (int x : xs) {
        s.count++;
        s.sum += x;
    }
    return s;
}

int main() {
    Stats s = summarize({3, 4, 5});
    std::cout << s.count << ' ' << s.sum << '\n';
}

整数の列から要素数と合計を求める summarize です。入力は main のとおり {3, 4, 5} で、本来は 3 12 を出力します。ところが、いまはコンパイルが通りません。どこを直せばよいでしょうか?

Answer

Stats s(); を Stats s{}; に変えます。

C++20 からは Stats s(0, 0); のように集成体を丸括弧で初期化できるので、引数を省いた Stats s(); も、全メンバが 0 の s を作る文に見えます。しかしこの行は、引数を取らず Stats を返す関数 s の宣言として読まれます。関数の宣言とも変数の定義とも読める文は、関数の宣言として扱うという規則があるからです。s は関数なので、s.count や return s がコンパイルエラーになります。

空の波括弧 Stats s{}; は関数の宣言にはなりえず、値初期化によって count と sum が 0 で始まります。括弧を消して Stats s; にするとコンパイルは通りますが、count と sum が不定値のまま足し算が始まってしまいます。
