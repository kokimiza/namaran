count_blank.cpp

#include <iostream>
#include <sstream>
#include <string>

int count_blank(std::istream &in) {
    int blanks = 0;
    std::string line;
    while (!in.eof()) {
        std::getline(in, line);
        if (line.empty()) {
            ++blanks;
        }
    }
    return blanks;
}

int main() {
    std::istringstream in("a\n\nb\n");
    std::cout << count_blank(in) << '\n';
}

入力に含まれる空行を数える count_blank です。入力 "a\n\nb\n" に対して、いまは 2 を出力します。本来の出力は 1 です。どこを直せばよいでしょうか?

Answer

while (!in.eof()) と std::getline(in, line); の2行を、while (std::getline(in, line)) の1行にまとめます。

eof() が真になるのは、読もうとして入力の終わりにぶつかったあとです。b の行を読んだ getline は改行で止まり、その先を見ていないので、この時点の eof() はまだ偽です。ループはもう1周し、4回目の getline が何も読めずに失敗して、そこで初めて終わりに気付きます。

失敗した回の line は、前の "b" のままではありません。getline は読み始める前に line を空にするので、何も読めなかった回の line は空文字列になり、空行として数えられます。前の行が残ると思って読むと、1周多く回っても数は変わらないように見えてしまいます。

getline の戻り値を条件にすると、読めた回だけループの中身が動きます。末尾に改行がない "a\n\nb" なら、b を読んだ時点で終わりにぶつかって eof() が真になるので、元のコードでも 1 が返ります。このバグが表に出るのは、ふつうのテキストファイルのように最後の行が改行で終わっているときです。
