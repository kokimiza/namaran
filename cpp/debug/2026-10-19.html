doc_copy.cpp

#include <iostream>

struct Doc {
    virtual ~Doc() = default;
    virtual Doc* copy() const { return new Doc(*this); }
    virtual const char* kind() const { return "doc"; }
};
struct Sheet : Doc {
    Sheet* copy() { return new Sheet(*this); }
    const char* kind() const override { return "sheet"; }
};

int main() {
    Sheet sheet;
    const Doc& doc = sheet;
    Doc* p = doc.copy();
    std::cout << p->kind() << '\n';
    delete p;
}

Doc::copy は文書を複製する仮想関数で、Sheet はそれを、自分の型のポインタを返すようにオーバーライドしたつもりです。main は Sheet のオブジェクトを const Doc& から複製し、複製の kind() を出力します。いまの出力は doc で、Sheet を複製したのに Doc ができています。本来の出力は sheet です。

Answer

Wrong

virtual Doc* copy() const { return new Doc(*this); }
Sheet* copy() { return new Sheet(*this); }

Doc::copy は const メンバ関数ですが、Sheet::copy には const がありません。オーバーライドになるのは、名前と引数に加えて const の有無まで一致する関数だけなので、Sheet::copy は Doc::copy と別の関数として宣言され、Doc::copy を隠すだけです。戻り値の型が Doc* から Sheet* に変わっているのは、オーバーライドなら許される変え方なので、見た目では違和感がありません。

doc.copy() は const Doc& から呼ぶので、選ばれるのは仮想関数 Doc::copy です。Sheet はこれをオーバーライドしていないので、実体が Sheet でも Doc::copy が動き、new Doc(*this) が Doc の部分だけを複製します。その kind() が doc を返します。

Right

Sheet* copy() const override { return new Sheet(*this); }

const を付けると引数と const の有無が Doc::copy とそろい、Sheet::copy がオーバーライドになります。Sheet* は Doc* が指すクラスから派生したクラスへのポインタなので、戻り値の型が違っても許されます。この規則を共変戻り値型（covariant return type）といいます。override も付けておけば、オーバーライドになっていない宣言はコンパイルエラーになり、同じ付け忘れを二度と通しません1。

  1. GCC 14 では、-Wall を付けるだけでこのコードに -Woverloaded-virtual の警告が出て、Doc::copy が Sheet::copy に隠されたことを知らせます。
