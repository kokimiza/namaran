sieve.cpp

#include <cstdio>
#include <vector>

int main() {
    std::vector<int> spf(21);
    for (int i = 2; i <= 20; i++) {
        for (int j = i * i; j <= 20;
             j += i) {
            if (spf[j] == 0) {
                spf[j] = i;
            }
        }
    }
    for (int n : {12, 15, 17}) {
        std::printf("%d\n", spf[n]);
    }
}

このプログラムは、20 以下の各整数 k について、k を割り切る最も小さい素数を spf[k] に入れた表を作り、たくさんの数の素因数分解に使うつもりのものです。試しに 12、15、17 の欄を表示すると、本来は 2、3、17 を1行ずつ出力するはずが、いまは 2、3、0 が出力されます。

Answer

Wrong

for (int j = i * i; j <= 20;
     j += i) {

spf は 0 で初期化され、内側のループが i の倍数のうちまだ 0 の欄に i を書き込みます。書き込みは i * i から始まるので、i 自身の欄にはどの i も書き込みません。12 や 15 は 2 や 3 の倍数として i * i 以降に現れるので正しく埋まりますが、17 を割り切る2以上の数は 17 だけです。i が 17 のときの書き込みは 289 から始まって表の外なので、spf[17] は 0 のまま残ります。2 から 19 までのすべての素数の欄が同じ理由で 0 で、素因数分解でこの表を引くと、0 で割ることになります。

Right

for (int j = i; j <= 20; j += i) {

書き込みを i 自身から始めると、素数 p の欄には、i が p のときに p が書き込まれます。p を割り切る2以上の数は p しかないので、それより前に書き込む i はなく、欄は 0 のまま p を待っています。合成数の欄は、自分より小さい最小の素因数がすでに埋めているので、i 自身から書き始めても if が上書きを防ぎ、値は変わりません1。

  1. i * i から書き始めるのは、i より小さい素因数を持つ倍数がもう埋まっていることを使った省略です。素数を求めるだけのエラトステネスの篩では、印の付かなかった数を素数と読むので素数の欄には何も書きませんが、最小の素因数の表では、その欄にも値が要ります。i * i から始める形を残すなら、spf[i] が 0 の i を素数とみなし、ループの前で spf[i] = i と書き込みます。
