to_int.cpp

#include <print>

int to_int(double x) {
    return static_cast<int>(x + 0.5);
}

int main() {
    for (double x : {2.4, 2.5, -2.4, -2.5})
        std::println("{}", to_int(x));
}

double を四捨五入して int にする to_int です。負の数は絶対値を四捨五入して符号を付けるつもりです。2.4、2.5、-2.4、-2.5 を順に渡すと 2、3、-2、-3 と表示されるはずが、いまは 2、3、-1、-2 と表示されます。

Answer

Wrong

int to_int(double x) {
    return static_cast<int>(x + 0.5);
}

浮動小数点数から整数への変換は、小数部を捨てて 0 の側へ寄せます。正の数では 0 の側が下なので、2.4 + 0.5 = 2.9 は 2、2.5 + 0.5 = 3.0 は 3 になり、0.5 を足してから切り捨てる手口がうまく働きます。

負の数では 0 の側は上です。-2.4 + 0.5 = -1.9 は小数部を捨てて -1 になり、-2.5 + 0.5 = -2.0 は -2 のままです。足した 0.5 で値が 0 のほうへ動き、変換もさらに 0 のほうへ寄せるので、負の数の結果はどれも本来より1大きくなります。

Right

int to_int(double x) {
    return static_cast<int>(std::round(x));
}

std::round は最も近い整数を返し、ちょうど真ん中なら 0 から遠いほうを選ぶので、-2.4 は -2.0、-2.5 は -3.0 になります。返る値はすでに整数なので、static_cast<int> で捨てる小数部はありません。正の数の結果は前と同じです。

std::floor(x + 0.5) に直しても -2.4 は -2 になりますが、-2.5 は -2 になり、本来の -3 とは合いません。符号に関係なく絶対値で四捨五入するには、真ん中を 0 から遠いほうへ寄せる std::round が必要です。<cmath> のインクルードも足します。
