touching_pairs.cpp

#include <print>
#include <ranges>
#include <vector>

int touching_pairs(const std::vector<char>& cells, int width) {
    int pairs = 0;
    for (auto w : cells | std::views::slide(2)) {
        pairs += w[0] == w[1];
    }
    for (auto w : cells | std::views::slide(width + 1)) {
        pairs += w.front() == w.back();
    }
    return pairs;
}

int main() {
    std::vector<char> board{'R', 'G', 'G', 'G', 'B', 'R', 'R', 'B', 'B'};
    std::println("{}", touching_pairs(board, 3));
}

touching_pairs は、横幅 width の盤面のマスを上の行から順に1列に並べた cells を受け取り、上下または左右に隣り合う2マスのうち、同じ色の組の数を返すつもりの関数です。main の盤面は3行3列で、上の行から RGG、GBR、RBB です。本来は 3 を出力するはずが、いまは 5 を出力します。

Answer

Wrong

for (auto w : cells | std::views::slide(2)) {
    pairs += w[0] == w[1];
}

cells の上で、あるマスの右隣は添字が1大きい要素で、真下は添字が width 大きい要素です。slide(2) は添字が1違う要素の組をすべて作るので、行の右端のマスと次の行の左端のマスも組にします。この2マスは盤面では隣り合っていません。この盤面では、1行目の右端と2行目の左端がどちらも G、2行目の右端と3行目の左端がどちらも R で、余分な2組が数えられて 5 になります。

見慣れない slide(width + 1) のほうは正しく動いています。長さ width + 1 の窓の先頭と末尾は添字が width 違い、盤面では同じ列で上下に並ぶ2マスです。添字が width 違う組はどこで作っても必ずこの形になるので、行の境目をまたいでも誤りになりません。添字が1違う組だけが、行の境目で盤面の隣どうしではなくなります。

Right

for (auto row : cells | std::views::chunk(width)) {
    for (auto w : row | std::views::slide(2)) {
        pairs += w[0] == w[1];
    }
}

views::chunk(width) で cells を1行ずつに区切り、その行の中だけで slide(2) の組を作ります。窓が行をまたがなくなるので、横の組は1行目の GG と3行目の BB の2組になり、縦の組の2列目の BB と合わせて 3 を返します。
