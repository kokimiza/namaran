count_crlf.cpp

#include <iostream>
#include <string>

int main() {
    std::string tail;
    int n = 0;
    for (std::string c :
         {"a\r\nb\r", "\nc\r\n", "d"}) {
        std::string s = tail + c;
        for (auto i = s.find("\r\n");
             i != s.npos;
             i = s.find("\r\n", i + 1)) {
            n++;
        }
        tail = s.substr(s.size() - 2);
    }
    std::cout << n << '\n';
}

大きなファイルを塊に分けて読みながら、\r\n の2文字の並びがいくつあるかを数えるつもりのコードです。塊の継ぎ目をまたぐ並びも数えられるよう、前の塊の末尾を tail に残し、次の塊の前につないで探します。ここでは読み込みの代わりに、"a\r\nb\r"、"\nc\r\n"、"d" の3つの塊を順に処理します。つなげると a\r\nb\r\nc\r\nd なので本来は 3 を出力するはずが、いまは 4 を出力します。

Answer

Wrong

tail = s.substr(s.size() - 2);

数え間違いを追うには、ひとつひとつの \r\n が、どの s の中で丸ごと見つかるかを考えます。s は持ち越した tail と新しい塊をつないだものなので、tail の中に丸ごと収まっている並びは、前の s ですでに数えたものを、次の s でもう一度数えることになります。持ち越すのが2文字だと、tail はちょうど \r\n 1つ分の長さなので、塊がちょうど \r\n で終わるとそれが丸ごと持ち越されます。2つ目の塊 \nc\r\n がそうで、末尾の \r\n は2つ目の s で数えられたうえで、3つ目の s \r\nd でもう一度数えられ、合計が 4 になります。

Right

tail = s.substr(s.size() - 1);

継ぎ目をまたぐ並びは、少なくとも1文字が新しい塊の側にあるので、前の塊から借りる文字は最大で1文字で、探す並びの長さより1つ少ない数で足ります。持ち越しを1文字にすると、tail は短すぎて並びを丸ごと含むことができず、どの並びも、それが最後の文字まで揃う s でちょうど1回だけ数えられます。3つの塊では、1つ目の s が a の後ろ、2つ目が継ぎ目をまたぐものと c の後ろの2つを見つけ、3つ目の s \nd には並びが無いので、合計は 3 です。長さ m の並びを探すなら、持ち越すのは m - 1 文字です。
