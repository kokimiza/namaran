greeters.cpp

#include <functional>
#include <iostream>
#include <string>
#include <vector>

int main() {
    std::vector<std::function<void()>> greeters;
    for (std::string name : {"Alice", "Bob"}) {
        greeters.push_back([&name] { std::cout << "Hello, " << name << '\n'; });
    }
    for (const auto& greet : greeters) {
        greet();
    }
}

名前ごとの挨拶を std::function の vector にためておき、あとでまとめて実行するつもりのプログラムです。入力はなく、本来は Hello, Alice と Hello, Bob の2行を表示するはずが、いまは名前が正しく出ません。手元の g++ のビルドでは Hello, Bob が2行出ましたが、何が出るかは決まっておらず、AddressSanitizer を付けて実行すると異常終了します。

Answer

Wrong

for (std::string name : {"Alice", "Bob"}) {
    greeters.push_back([&name] { std::cout << "Hello, " << name << '\n'; });
}

[&name] は name を参照でキャプチャするので、ラムダが持つのは name を指す参照だけです。std::function はラムダをコピーして持ちますが、コピーされるのはこの参照で、文字列そのものではありません。name は範囲 for の1周ごとに作られて、その周の終わりに破棄されます。

2つ目の for でラムダを呼ぶときには、どちらの name も破棄されたあとです。破棄された変数を参照で読むのは未定義動作で、手元のビルドでは、最後の周で "Bob" が入った場所がそのまま読めたため、2行とも Bob になりました。AddressSanitizer はこの読み出しを stack-use-after-scope として止めます。

Right

for (std::string name : {"Alice", "Bob"}) {
    greeters.push_back([name] { std::cout << "Hello, " << name << '\n'; });
}

[name] とコピーでキャプチャすると、ラムダはその周の name の文字列を自分のメンバとして持ちます。std::function はそのラムダごとコピーするので、name が破棄されたあとも "Alice" と "Bob" は greeters の中に残り、2行の挨拶が順に表示されます。あとで呼ぶために保存するラムダでは、キャプチャした変数がその時点でもまだ生きているかを確かめ、生きていないならコピーで持たせます。
