snapshot.cpp

#include <array>
#include <cstring>
#include <iostream>

std::array<int, 4> snapshot(const std::array<int, 4>& live) {
    std::array<int, 4> copy{};
    std::memcpy(copy.data(), live.data(), live.size());
    return copy;
}

int main() {
    std::array<int, 4> live = {10, 20, 30, 40};
    for (int x : snapshot(live)) {
        std::cout << x << ' ';
    }
    std::cout << '\n';
}

計測値の配列 live の複製を作って返す snapshot です。{10, 20, 30, 40} を渡して複製の要素を表示すると、いまは 10 0 0 0 と表示されます。本来は 10 20 30 40 と表示されるはずです。

Answer

Wrong

    std::memcpy(copy.data(), live.data(), live.size());

std::memcpy の3つ目の引数は、写すバイト数です。live.size() が返すのは要素の個数の 4 で、int が4バイトの環境では、写されるのは先頭の4バイトで、live[0] の 10 の分しかありません。copy は {} で 0 に初期化してあるので、残りの3つは 0 のまま返り、10 0 0 0 と表示されます。

組み込み配列の int live[4] なら、memcpy(copy, live, sizeof live) と書くのが定番でした。sizeof live は配列全体のバイト数の 16 です。std::array に書き換えるときに、配列の大きさを返すものとして size() を選ぶと、意味がバイト数から要素数に変わります。

Right

    std::memcpy(copy.data(), live.data(), live.size() * sizeof live[0]);

要素数に要素1つのバイト数 sizeof live[0] を掛けると、4 × 4 の 16 バイトになり、4つの要素がすべて写ります。sizeof live[0] は要素の型から決まるので、int の大きさが環境ごとに違っても、要素の型を double に変えても正しいバイト数になります。

std::array は組み込み配列と違って代入でコピーできるクラスなので、この関数は return live; の1行でも書けます。コピーをコンパイラに任せれば、バイト数を数える必要そのものがなくなります。
