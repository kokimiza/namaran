getter.cpp

#include <format>
#include <iostream>
#include <string>

std::string getter(const std::string& type, const std::string& name) {
    std::string tmpl = "{} get_{}() const { return {}_; }\n";
    return std::vformat(tmpl, std::make_format_args(type, name, name));
}

int main() {
    std::cout << getter("int", "size");
}

型名とメンバ名から、C++ のゲッター関数を1行のコードとして組み立てるつもりの getter です。getter("int", "size") は int get_size() const { return size_; } を返すはずですが、いまは何も表示されず、terminate called after throwing an instance of 'std::format_error' と出て異常終了します。

Answer

Wrong

std::string tmpl = "{} get_{}() const { return {}_; }\n";
return std::vformat(tmpl, std::make_format_args(type, name, name));

書式文字列の中の { と } は、すべて置換フィールドの区切りとして読まれます。const { return の { も例外ではなく、直後の空白は引数の番号として読めないので、書式文字列は不正です。この誤りがいつ見つかるかは、書式文字列をいつ検査するかで決まります。std::format は書式文字列をコンパイル時に検査するので、定数式でない std::string の tmpl はそもそも渡せません。そのためここでは、書式文字列を実行時に受け取る std::vformat が使われています。std::vformat は書式文字列を実行時に解析し、不正なら例外 std::format_error を投げます。getter にも main にも catch が無いので、例外は std::terminate に届き、何も出力されないままプログラムが止まります。

Right

std::string tmpl = "{} get_{}() const {{ return {}_; }}\n";
return std::vformat(tmpl, std::make_format_args(type, name, name));

書式文字列で波括弧そのものを出すには、{{ と }} のように2つ重ねます。重ねた波括弧は置換フィールドにならずに1つの波括弧として出力されるので、置換フィールドは {} の3つだけになり、type、name、name が順に入って int get_size() const { return size_; } ができます。コードを生成する書式文字列ではコードの波括弧がいくつも混ざるので、実行時に渡す場合は、すべてを重ねたかをコンパイラが確かめてくれない点に気を付けます。
