turn.cpp

#include <print>

struct Pt {
    unsigned x, y;
};

const char* turn(Pt a, Pt b, Pt c) {
    auto cr = (b.x - a.x) * (c.y - a.y) -
        (b.y - a.y) * (c.x - a.x);
    if (cr < 0)
        return "right";
    return cr > 0 ? "left" : "straight";
}

int main() {
    std::println(
        "{}", turn({0, 0}, {0, 2}, {1, 1}));
}

turn は、点 a から b へ進んだあと c へ向かうときに、左に曲がるか、右に曲がるか、まっすぐ進むかを判定するつもりの関数です。座標は x が右、y が上に増えます。main は (0, 0) から真上の (0, 2) へ進み、右下の (1, 1) へ向かうので right が出力されるはずですが、いまは left が出力されます。

Answer

Wrong

struct Pt {
    unsigned x, y;
};

const char* turn(Pt a, Pt b, Pt c) {
    auto cr = (b.x - a.x) * (c.y - a.y) -
        (b.y - a.y) * (c.x - a.x);
    if (cr < 0)
        return "right";
    return cr > 0 ? "left" : "straight";

cr は、a から b へのベクトルと a から c へのベクトルの外積です。c が左側にあれば正、右側にあれば負になるので、その符号で向きを判定しています。ところが座標が unsigned なので、引き算も掛け算も符号なしの整数で計算され、auto で受けた cr も unsigned になります。

main の点では、外積は 0 × 1 − 2 × 1 = −2 になるはずです。符号なしの整数は負の値を表せず、結果は 232 で割った余りに回り込むので1、cr は 232 − 2 = 4294967294 という大きな正の値になります。cr < 0 はどんな値でも偽なので right は決して返らず、0 でない外積はすべて cr > 0 で left になります。

Right

struct Pt {
    int x, y;
};

座標を符号付きの int にすると、b.y - a.y などの引き算と掛け算が int で行われ、cr も int になります。外積は −2 のまま負の値として残るので、cr < 0 が真になり right が返ります。c が左側なら正、一直線上なら 0 になり、left と straight もそれぞれ判定されます。

  1. unsigned が32ビットの処理系での値です。C++ の符号なし整数の演算は、結果をその型のビット数 n について 2n で割った余りにする、と規格が定めているので、回り込みは未定義動作ではありません。g++ の -Wextra は、cr < 0 が常に偽になることを警告します。
