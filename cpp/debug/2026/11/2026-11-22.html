count_odd.cpp

#include <algorithm>
#include <print>
#include <vector>

int count_odd(const std::vector<int>& v) {
    return std::ranges::count_if(
        v, [](int x) { return x % 2 == 1; });
}

int main() {
    std::println("{}",
                 count_odd({3, -5, 8, -1}));
}

v の中の奇数の個数を返すつもりの count_odd です。count_odd({3, -5, 8, -1}) は 3, -5, -1 の3つを数えて 3 を出力するはずが、いまは 1 を出力します。

Answer

Wrong

    return std::ranges::count_if(
        v, [](int x) { return x % 2 == 1; });

C++ の整数の割り算は、商の小数部を0の方向へ切り捨てます。-5 / 2 は -2.5 を切り捨てた -2 で、余りは a == (a / b) * b + a % b が成り立つように決まるので、-5 % 2 は -5 - (-4) で -1 です。余りの符号は割られる数と同じになり、負の奇数を2で割った余りは 1 ではなく -1 です。

そのため x % 2 == 1 が真になるのは正の奇数の 3 だけで、-5 と -1 は -1 == 1 で偽になり、数えられません。正の数だけで試していると、この誤りは表に出ません。

Right

    return std::ranges::count_if(
        v, [](int x) { return x % 2 != 0; });

奇数かどうかは、余りが 0 でないかどうかで判定します。2で割った余りは、正の数なら 0 か 1、負の数なら 0 か -1 なので、!= 0 なら符号によらず奇数をすべて拾えます。偶数の判定 x % 2 == 0 が負の数でも正しく動くのも同じ理由です。
