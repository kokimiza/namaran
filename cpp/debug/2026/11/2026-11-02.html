buffer_swap.cpp

#include <utility>

struct Buffer {
    int* data;
    explicit Buffer(int v) : data(new int(v)) {}
    Buffer(Buffer&& other) noexcept : data(other.data) {}
    Buffer& operator=(Buffer&& other) noexcept {
        std::swap(data, other.data);
        return *this;
    }
    ~Buffer() {
        delete data;
    }
};

int main() {
    Buffer a(1), b(2);
    using std::swap;
    swap(a, b);
}

Buffer は new で確保した int を1つ所有し、デストラクタで解放するクラスです。このプログラムは a と b の中身を入れ替えて終わるつもりで、本来は何も表示せずに正常終了するはずです。いまは GCC と glibc でビルドして実行すると、終了時に free(): double free detected in tcache 2 と表示して異常終了します。

Answer

Wrong

Buffer(Buffer&& other) noexcept : data(other.data) {}

Buffer は自分の swap を持たないので、swap(a, b) は std::swap を呼びます。std::swap は、a からムーブして一時オブジェクト tmp を作り、a = std::move(b)、b = std::move(tmp) と代入してから tmp を破棄します。このムーブコンストラクタはポインタを写すだけでムーブ元の data を残すので、tmp を作った時点で tmp と a が同じ int を指します。

続く2回のムーブ代入はポインタを交換するので、a は b の int を受け取ります。a の元の int は、b に渡ったあとも tmp に残っています。std::swap を抜けるときに tmp のデストラクタがそれを解放し、main の終わりに b のデストラクタが同じ領域をもう一度解放します。

Right

Buffer(Buffer&& other) noexcept : data(std::exchange(other.data, nullptr)) {}

std::exchange は other.data を nullptr に置き換え、置き換える前の値を返します。ムーブ元は所有を手放した空の状態になり、tmp のデストラクタは delete nullptr になって何もしません。それぞれの int を指すのは a と b の1つずつになり、終了時に1回ずつ解放されます。1

  1. ムーブ代入の側は、data を交換しているので所有が重なりません。Buffer の中で定義したフレンド関数 swap でポインタを交換すれば、std::swap を経由せず、一時オブジェクトも作らずに入れ替えられます。
