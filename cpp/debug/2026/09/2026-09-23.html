zoo_slicing.cpp

#include <iostream>
#include <string>
#include <vector>

struct Animal {
    virtual std::string speak() const { return "..."; }
    virtual ~Animal() = default;
};

struct Dog : Animal {
    std::string speak() const override { return "Woof"; }
};

struct Cat : Animal {
    std::string speak() const override { return "Meow"; }
};

int main() {
    std::vector<Animal> zoo;
    zoo.push_back(Dog{});
    zoo.push_back(Cat{});
    for (const auto& a : zoo) std::cout << a.speak() << '\n';
}

動物園の動物たちに、それぞれの鳴き声を言わせるつもりのコードです。いまの出力は...が2行ですが、本来の出力はWoof・Meow(それぞれの動物の鳴き声)です。何が問題で、どう直せばよいでしょうか?

Answer

std::vector<Animal>はAnimal型の値だけを保持できるコンテナです。zoo.push_back(Dog{})は、一時的に作ったDogオブジェクトからAnimal部分だけをコピーしてvectorに積みます——つまりpush_backのたびにオブジェクトのスライシングが起きており、Catについても同様です。結果としてzooの中身はどちらも素のAnimalであり、動的型の情報はとうに失われているため、a.speak()はどちらの要素についてもAnimal::speakが呼ばれ、"..."が2回出力されます。ポリモーフィックな振る舞いを保ったまま複数の動物をコンテナに集めるには、値ではなくポインタ(所有権を持たせるならstd::unique_ptr<Animal>)で保持する必要があります: 

std::vector<std::unique_ptr<Animal>> zoo;
zoo.push_back(std::make_unique<Dog>());
zoo.push_back(std::make_unique<Cat>());
for (const auto& a : zoo) std::cout << a->speak() << '\n';
