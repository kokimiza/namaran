countdown.cpp

#include <functional>
#include <print>

void countdown(int n, const std::function<void()>& k) {
    if (n == 0) {
        return;
    }
    std::println("{}", n);
    countdown(n - 1, k);
}

int main() {
    countdown(3, [] { std::println("liftoff"); });
}

countdown は、n から1までの数を1行ずつ表示し、数え終わったら継続 k を呼ぶつもりの関数です。入力は countdown(3, [] { std::println("liftoff"); })。いまの出力は 3、2、1 の3行だけですが、本来は4行目に liftoff が出ます。本来の出力になるよう直してください。

Answer

n == 0 の分岐が、k を呼ばずに return しています。継続渡しの関数にとって、継続は「この関数のあとに続く残りの処理」です。どの経路で終わるときも、最後に継続を呼ばなければなりません。

countdown は再帰のたびに同じ k を次へ渡しているだけで、実際に k を呼べる場所は基底ケースしかありません。そこで呼び忘れると、残りの処理は黙って捨てられます。例外もエラーも出ないので、出力が1行足りないことでしか気づけません。基底ケースで k() を呼んでから戻れば直ります。 

    if (n == 0) {
        k();
        return;
    }
