admins.cpp

#include <cstdio>
#include <set>
#include <string>

const std::set<const char*> admins{"alice", "bob"};

bool is_admin(const std::string& name) {
    return admins.contains(name.c_str());
}

int main() {
    const std::string name = "bob";
    std::puts(is_admin(name) ? "admin" : "guest");
}

is_admin は、名前が admins に登録されていれば true を返すつもりの関数です。main のとおり "bob" を調べると、本来は admin と出力するはずですが、いまは guest と出力します。

Answer

Wrong

const std::set<const char*> admins{"alice", "bob"};

bool is_admin(const std::string& name) {
    return admins.contains(name.c_str());
}

std::set<const char*> の要素はポインタで、既定の比較関数 std::less<const char*> が比べるのもポインタの値で、これは文字列が置かれているアドレスです。contains が調べるのは、指している文字の中身が同じ要素ではなく、同じアドレスの要素です。

admins の "bob" は文字列リテラルを指し、name.c_str() は std::string が持つ別の領域を指しています。中身は同じ bob でもアドレスが違うので、等価な要素は見つかりません。

Right

const std::set<std::string> admins{"alice", "bob"};

要素を std::string にすると、比較は std::string どうしの <、つまり文字の中身の辞書順になります。contains(name.c_str()) の引数は std::string に変換されてから比べられるので、中身が同じなら見つかります1。

  1. 変換のたびに一時的な std::string を作るのを避けたいなら、std::set<std::string, std::less<>> とします。std::less<> は透過的な比較関数なので、contains や find に const char* や std::string_view をそのまま渡して、中身で比べられます。
