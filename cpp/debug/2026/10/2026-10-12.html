reading.cpp

#include <iostream>

struct Reading {
    double celsius;
    int display;
};

void set(Reading& r, double c) {
    r.celsius = r.display = c;
}

int main() {
    Reading r;
    set(r, 21.5);
    std::cout << r.display << ' ' << r.celsius * 9 / 5 + 32 << '\n';
}

set は、摂氏の温度を計算用の celsius にはそのまま、表示用の display には整数に切り捨てて入れるつもりの関数です。set(r, 21.5) のあとに表示用の値と華氏を出力すると、いまは 21 69.8 が出ます。本来の出力は 21 70.7 です。

Answer

Wrong

r.celsius = r.display = c;

代入演算子は右結合なので、この行は r.celsius = (r.display = c) です。先に r.display = c が 21.5 を int に変換して 21 を入れます。代入式の値は代入したあとの左辺なので、括弧の中の値は c ではなく int の 21 です。r.celsius にはこの 21 が入り、華氏は 21 * 9 / 5 + 32 の 69.8 になります1。

Right

r.display = r.celsius = c;

並びを入れ替えると、先に r.celsius = c が 21.5 をそのまま入れ、その値が r.display への代入で 21 に切り捨てられます。値を落とさない型のほうを右に置けば、切り捨ては最後の代入でしか起きません。r.celsius = c; と r.display = c; の2文に分ければ、並び順に気を配る必要もなくなります。

  1. GCC と Clang は、-Wconversion を付けると double から int への暗黙の変換を警告します。-Wall -Wextra だけでは警告されません。
