checksum.cpp

#include <cstdint>
#include <iostream>
#include <string>

int checksum(const std::string& data) {
    int sum = 0;
    for (std::uint8_t i = 0; i < data.size(); ++i) {
        sum += data[i];
    }
    return sum % 256;
}

int main() {
    std::string input(300, 'x');
    std::cout << checksum(input) << '\n';
}

checksum は、入力のバイトの値をすべて足し、256で割った余りを返す関数です。ファザが 'x' を300個並べた入力を作ったところ、main のように呼ぶと何も出力されず、タイムアウトするまで終わりません。本来は 160 と出力されるはずです。

Answer

Wrong

for (std::uint8_t i = 0; i < data.size(); ++i) {

添字の i は std::uint8_t で、0から255までしか表せません。255のときの ++i は、int に昇格して計算した256を std::uint8_t に戻します。符号なし整数への変換は256で割った余りを取るので、i は0に戻ります。比較の i < data.size() では i が変換されて300と比べられますが、i は255を超えないので、条件は常に真です。256バイト未満の入力ならループは正しく終わるので、手で書いた短いテストでは見つかりません。長さも中身も選ばずに入力を作るファザが、300バイトの入力で初めてこの欠陥を踏みました。

Right

for (std::size_t i = 0; i < data.size(); ++i) {

添字を data.size() と同じ std::size_t にすれば、i はどの長さの文字列でも最後の添字まで数えられ、300回で抜けます。'x' は120なので合計は36000、256で割った余りは160です。<cstdint> の代わりに、std::size_t を宣言する <cstddef> を読み込みます1。

  1. libFuzzer は、1つの入力の実行が -timeout の秒数(既定は1200秒)を超えるとその入力を保存し、timeout として報告します。-max_len で入力の長さの上限も変えられ、長い入力でしか起きない欠陥を探すときはこれを大きくします。
