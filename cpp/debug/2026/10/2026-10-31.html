count_hits.cpp

#include <iostream>
#include <mutex>
#include <thread>

long hits = 0;

void count_hits(int n) {
    std::mutex m;
    for (int i = 0; i < n; i++) {
        std::lock_guard lock(m);
        hits++;
    }
}

int main() {
    {
        std::jthread t1(count_hits, 1000000);
        std::jthread t2(count_hits, 1000000);
    }
    std::cout << hits << '\n';
}

2つのスレッドがそれぞれ count_hits(1000000) を実行し、共有の hits を合わせて200万回増やすつもりのプログラムです。hits を増やす前には毎回ロックを取っています。本来は 2000000 と出力されるはずが、いまは手元で5回実行して 1450099、1442518、1430492 のように、毎回違う200万未満の数が出力されます。

Answer

Wrong

void count_hits(int n) {
    std::mutex m;
    for (int i = 0; i < n; i++) {
        std::lock_guard lock(m);
        hits++;
    }
}

m は count_hits のローカル変数なので、t1 と t2 の呼び出しはそれぞれ自分の m を作ります。std::lock_guard は渡された mutex をロックしますが、2つのスレッドがロックするのは別々の mutex なので、互いに相手を待つことはありません。hits++ は2つのスレッドから同時に実行されます。

hits++ は値を読み、1を足し、書き戻す処理です。2つのスレッドが同じ値を読んでから書き戻すと、2回の増加が1回分にしかならず、合計が200万に届きません。同期なしに同じ変数を書き換えるのはデータ競合で、C++ では未定義動作です。

Right

long hits = 0;
std::mutex hits_mutex;

void count_hits(int n) {
    for (int i = 0; i < n; i++) {
        std::lock_guard lock(hits_mutex);
        hits++;
    }
}

mutex を hits と同じ寿命を持つ変数にして、2つのスレッドが同じ hits_mutex をロックするようにします。一方のスレッドがロックを持っている間、もう一方は std::lock_guard を作るところで待つので、hits++ が同時に実行されることはなくなり、2000000 が出力されます。
