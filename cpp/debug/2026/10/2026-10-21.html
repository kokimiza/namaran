count_passed.cpp

#include <algorithm>
#include <iostream>
#include <vector>

int main() {
    std::vector<int> scores{70, 45, 90, 30};
    int passed = 0;
    std::ranges::for_each(scores, [passed](int s) mutable {
        if (s >= 60)
            ++passed;
    });
    std::cout << passed << " passed\n";
}

60点以上の点数の個数を数えて表示するつもりのプログラムです。点数は70、45、90、30の4つで、いまは 0 passed と出力されます。本来の出力は 2 passed です。

Answer

Wrong

std::ranges::for_each(scores, [passed](int s) mutable {

[passed] はコピーによる捕捉で、ラムダ式のオブジェクトは main の passed とは別に、値0の自分用の passed をメンバとして持ちます。コピーで捕捉したメンバは、ふだんは const 扱いで ++passed がコンパイルエラーになりますが、mutable を付けるとその制限が外れ、コンパイルが通ります。ループの中で2回増えるのはこのメンバのほうで、main の passed は0のまま、0 passed が出力されます。

しかも std::ranges::for_each は関数オブジェクトを値で受け取るので、数え終えたメンバを持つのは、呼び出しの中で作られたさらに別のコピーです1。

Right

std::ranges::for_each(scores, [&passed](int s) {

[&passed] と参照で捕捉すると、ラムダ式の中の passed は main の変数そのものを指します。ラムダ式のオブジェクトが何度コピーされても参照先は同じなので、++passed は main の passed を増やし、2 passed が出力されます。参照を通して書き換えるときは、ラムダ式のメンバ自体は変わらないので mutable は要りません。

  1. std::ranges::for_each は、使い終えた関数オブジェクトを戻り値の fun メンバで返します。auto result = std::ranges::for_each(...) と受ければ、コピーの側で数えた2を取り出すこともできます。
