port_stats.cpp

#include <iostream>

struct Stats { int bytes = 0; };

struct Reader : Stats {
    void read(int n) { bytes += n; }
};

struct Writer : Stats {
    void write(int n) { bytes += n; }
};

struct Port : Reader, Writer {};

int main() {
    Port p;
    p.read(300);
    p.write(200);
    std::cout << p.Reader::bytes << '\n';
}

Port は読み取りと書き込みの両方を受け持ち、Stats の bytes に読み書きしたバイト数の合計を記録するつもりのクラスです。300バイト読んで200バイト書いたので、本来は 500 が出力されるはずですが、いまは 300 が出力されます。

Answer

Wrong

struct Reader : Stats {
struct Writer : Stats {

Reader と Writer は、それぞれ普通に Stats を継承しています。そのため Port の中には、Reader の一部としての Stats と、Writer の一部としての Stats が別々に1つずつあり、bytes も2つあります。read は Reader 側の bytes に300を足し、write は Writer 側の bytes に200を足します。p.Reader::bytes が読むのは Reader 側だけなので、300 になります。

Right

struct Reader : virtual Stats {
struct Writer : virtual Stats {

両方の継承に virtual を付けると Stats は仮想基底クラスになり、Port の中で1つだけ共有されます。read と write が同じ bytes に足すので、p.Reader::bytes は 500 です。片方だけに付けると、付けなかった側が自分の Stats を別に持ち続けるので、両方に付けます1。

  1. 修正前のコードで p.bytes と書くと、どちらの bytes か決まらないとしてコンパイルエラーになります。Reader:: を付けるとエラーは消えますが、それは2つあるうちの片方を選んだだけです。標準ライブラリの std::iostream では、std::istream と std::ostream がともに std::ios を仮想継承していて、エラー状態や書式の設定は1つを共有しています。
