check_parse.cpp

#include <charconv>
#include <cstdio>
#include <optional>
#include <string_view>

std::optional<int> parse(std::string_view s) {
    int v = 0;
    if (std::from_chars(s.data(), s.data() + s.size(), v).ec != std::errc{}) {
        return std::nullopt;
    }
    return v;
}

bool check(std::string_view in, int want) {
    std::optional<int> got = parse(in);
    return !got || *got == want;
}

int main() {
    std::printf("%d %d %d\n", check("42", 42), check("-7", -7), check("+5", 5));
}

check は parse の単体テストの判定で、parse(in) が整数 want を返したときだけ true を返すつもりの関数です。parse は先頭の + を読めずに値を返さないので、main の3つ目の判定は失敗するはずです。いまの出力は 1 1 1 です。本来の出力は 1 1 0 です。

Answer

Wrong

std::optional<int> got = parse(in);
return !got || *got == want;

std::from_chars は先頭の + を受け付けないので、parse("+5") は std::nullopt を返します。値の無い got を *got で参照すると未定義動作になるため、この行は先に !got を調べています。ところが || は左が真なら右を評価せずに真を返すので、値が無いときの判定は true です。参照外しを避けるための条件が、そのまま「合格」の条件になっています。

結果として、check が失敗を報告するのは parse が違う値を返したときだけで、値を返さなかったときは見逃します。

Right

return parse(in) == want;

std::optional<int> と int の == は、値を持っていてその値が等しいときだけ真で、値が無ければ偽になります。値の有無と中身の比較が1つの式に入るので、* による参照外しも !got の分岐も要りません。parse("+5") は値を返さないので、3つ目の判定は 0 になります。
