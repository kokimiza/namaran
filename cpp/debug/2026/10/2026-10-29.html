add_bonus.cpp

#include <cstdio>
#include <map>
#include <string>

void add_bonus(std::map<std::string, int>& scores, int bonus) {
    for (auto [name, score] : scores) {
        score += bonus;
    }
}

int main() {
    std::map<std::string, int> scores{{"ann", 70}, {"bob", 85}};
    add_bonus(scores, 10);
    for (const auto& [name, score] : scores) {
        std::printf("%s %d\n", name.c_str(), score);
    }
}

std::map に入れた全員の点数に bonus を足す add_bonus です。main は ann が70点、bob が85点の表に10点を足して、名前と点数を1行ずつ出力します。本来は ann 80 と bob 95 と出力されるはずが、いまは ann 70 と bob 85 と出力され、点数が変わっていません。

Answer

Wrong

    for (auto [name, score] : scores) {
        score += bonus;
    }

auto [name, score] は、scores の要素 std::pair<const std::string, int> を1つずつ新しいオブジェクトにコピーし、name と score をそのコピーのメンバの名前にします。score += bonus が書き換えるのはコピーの点数で、コピーはその回の終わりで捨てられます。scores の中の70と85は一度も書き換わらず、main はもとの点数を出力します。

Right

    for (auto& [name, score] : scores) {
        score += bonus;
    }

auto& にすると、コピーは作られず、name と score は scores の中の要素のメンバそのものを指します。score += bonus は表の中の点数を書き換え、ann は80、bob は95になります。std::map のキーは const なので、auto& で受けても name は書き換えられません1。

  1. 構造化束縛では、auto や auto& は name や score の型ではなく、裏で作られる1つの変数(ここでは要素のコピーか、要素への参照)の型に掛かります。name と score は、その変数のメンバに付いた名前です。
