area.cpp

#include <cstdlib>
#include <iostream>
#include <vector>

struct P { int x, y; };

double area(const std::vector<P>& ps) {
    int s = 0;
    for (std::size_t i = 0; i < ps.size(); ++i) {
        const P& a = ps[i];
        const P& b = ps[(i + 1) % ps.size()];
        s += a.x * b.y - b.x * a.y;
    }
    return std::abs(s) / 2;
}

int main() {
    std::cout << area({{0, 0}, {3, 0}, {0, 1}}) << '\n';
}

area は頂点の並びから多角形の面積を求め、double で返すつもりです。引数も標準入力も使わず、頂点が (0, 0)、(3, 0)、(0, 1) の三角形の面積を出力します。本来は 1.5 と出力されるはずが、いまは 1 と出力されます。

Answer

Wrong

return std::abs(s) / 2;

ループを終えた時点の s は 3 で、面積の2倍としては合っています。問題はその次の割り算で、std::abs(s) も 2 も int なので、/ は整数どうしの割り算になり、小数部を捨てた 1 を返します。

戻り値の型が double であることは、この割り算に影響しません。double への変換は、割り算が終わって 1 になった値を return で返すときに初めて行われます。

Right

return std::abs(s) / 2.0;

2.0 は double なので、std::abs(s) の 3 が double に変換されてから割り算が行われ、結果は 1.5 になります1。

  1. 格子点を頂点とする多角形の面積は、必ず 0.5 の倍数です。そのため面積の2倍を整数のまま持ち、表示するときだけ2で割る書き方もよく使われます。
