shape_name.cpp

#include <print>

struct Shape {
    virtual ~Shape() = default;
};
struct Rect : Shape {};
struct Square : Rect {};

int main() {
    const Shape& s = Square{};
    if (dynamic_cast<const Rect*>(&s))
        std::println("rect");
    else if (dynamic_cast<const Square*>(&s))
        std::println("square");
}

参照 s が指す図形の種類の名前を出力するつもりのコードです。s は Square のオブジェクトを指しているので square と出力するはずが、いまは rect と出力されます。

Answer

Wrong

if (dynamic_cast<const Rect*>(&s))
    std::println("rect");
else if (dynamic_cast<const Square*>(&s))
    std::println("square");

dynamic_cast<const Rect*> は、指す先のオブジェクトが Rect か、Rect から派生したクラスのオブジェクトなら成功します。Square は Rect を継承しているので、s が Square を指していても最初の if が成り立ち、rect を出力します。else if の側には、s が何を指していても届きません。Square なら1つ目が成り立ち、それ以外なら Square への変換が失敗するからです。

Right

if (dynamic_cast<const Square*>(&s))
    std::println("square");
else if (dynamic_cast<const Rect*>(&s))
    std::println("rect");

if と else if を並べた分岐は上から順に試され、最初に成り立ったところで決まります。そこで、範囲の狭い Square を先に調べます。Square のオブジェクトは1つ目で square を出力し、Square ではない Rect だけが2つ目に進んで rect になります。派生の深いクラスから順に並べれば、後ろの分岐には、前の分岐で調べたクラスとその派生クラスを除いた残りだけが届きます。
