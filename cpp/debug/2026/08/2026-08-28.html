theme.cpp

#include <optional>
#include <print>

const char* theme(std::optional<bool> dark) {
    return dark ? "dark" : "light";
}

int main() {
    std::println("{} {} {}", theme(std::nullopt), theme(false), theme(true));
}

theme は、ダークテーマの設定 dark が「オン」なら "dark" を、「オフ」か「未設定」（std::nullopt）なら "light" を返すつもりの関数です。main は未設定・オフ・オンの順に渡しています。いまの出力は light dark dark で、本来の出力は light light dark です。

Answer

Wrong

return dark ? "dark" : "light";

std::optional<bool> の値は、値なし・false・true の3通りです。条件の位置に置いた std::optional は、中の値ではなく値を持っているかどうかで bool に変換されます。theme(false) の dark は false という値を持っているので条件は真になり、オフにした設定が "dark" を返します。この条件は3通りを「値なし」と「値あり」の1通りと2通りに分けていて、false と true を区別していません。

Right

return dark.value_or(false) ? "dark" : "light";

value_or(false) は、値があればその値を、なければ false を返します。未設定はここで false にそろい、条件が真になるのは中の値が true のときだけになります1。

  1. dark == true と比べても同じ結果になります。std::optional と値の比較は、値がなければ等しくないと決まっているからです。
