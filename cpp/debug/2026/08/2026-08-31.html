ring.cpp

#include <print>
#include <vector>

int left_of(const std::vector<int>& ring, int i) {
    return ring[(i - 1) % ring.size()];
}

int main() {
    const std::vector<int> ring{10, 20, 30, 40, 50};
    std::println("{} {}", left_of(ring, 0), left_of(ring, 2));
}

left_of は、輪になって並んだ ring の i 番目の左隣の値を返すつもりの関数で、先頭の左隣は末尾です。left_of(ring, 0) と left_of(ring, 2) を表示すると、64ビット環境ではいま 10 20 が出ます。本来は 50 20 です。

Answer

Wrong

return ring[(i - 1) % ring.size()];

i が0のとき、i - 1 は int の -1 です。C++ の % は割られる数の符号を持つので、int どうしの計算なら -1 % 5 は -1 になり、0は出てこないはずです。ところが ring.size() は符号なしの std::size_t で、int と std::size_t の演算では、計算の前に int の側が std::size_t に変換されます。-1 は符号なしの最大値 264 - 1 = 18446744073709551615 になり、これは末尾が5なので5で割り切れます。余りは0で、先頭の左隣として先頭の10が返ります。i が1以上なら i - 1 は負にならないので、left_of(ring, 2) は正しく20です。

Right

return ring[(i + ring.size() - 1) % ring.size()];

先に ring.size() を足してから1を引けば、i が0でも 0 + 5 - 1 は4で、途中で負になる値がありません。符号なしのまま計算しても値は変わらず、4 % 5 で末尾の50を指します。i が1以上のときは5を足した分が % ring.size() で消えるので、これまでと同じ添字になります。
