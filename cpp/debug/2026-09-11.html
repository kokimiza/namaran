retry_count.cpp

#include <cstdio>

int retry_count(int max_attempts) {
    int attempts = 0;
    while (attempts <= max_attempts) {
        ++attempts;
    }
    return attempts;
}

int main() {
    printf("%d\n", retry_count(3));
}

retry_count(max_attempts)は、最大max_attempts回まで試行し、実際に何回試行したかを返すつもりです。retry_count(3)を呼ぶと、いまの出力は4です。本来は3になるべきです。何が問題で、どう直せばよいでしょうか?

Answer

ループの条件がattempts <= max_attemptsになっています。attemptsは0から始まり、本体に入るたびに1増えるので、条件が<=だとattemptsが0, 1, 2, 3のときにも本体が実行されてしまい、max_attempts回ではなくmax_attempts + 1回試行することになります。境界条件を1つずらしただけの、典型的なoff-by-oneです。attempts回数がちょうどmax_attemptsになった時点で止めたいので、条件は<にします: 

int retry_count(int max_attempts) {
    int attempts = 0;
    while (attempts < max_attempts) {
        ++attempts;
    }
    return attempts;
}
