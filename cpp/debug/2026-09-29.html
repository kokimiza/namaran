ticks.cpp

#include <iostream>

int main() {
    for (double x = 0.0; x != 1.0; x += 0.1) {
        std::cout << x << '\n';
    }
}

0 から 0.9 までの値を 0.1 刻みで1行ずつ出力するつもりのプログラムです。実行すると、本来は 0、0.1、……、0.9 の10行を出力して終わるはずですが、いまは 0.9 の次に 1 を出力してもまだ止まらず、1.1、1.2、1.3 と出力し続けます。

Answer

Wrong

for (double x = 0.0; x != 1.0; x += 0.1) {
    std::cout << x << '\n';
}

0.1 は2進数の浮動小数点数では正確に表せず、わずかにずれた近似値として足されます1。そのずれが積み重なり、10回足した x は 1.0 ではなく 0.9999999999999999 になります。x != 1.0 は真のままなので、ループは止まりません。

この値が 1 と表示されるのは、std::cout が既定で有効数字6桁に丸めて出力するからです。そこから先の x は 1.0 から離れていくだけなので、条件が偽になることはありません。

Right

for (int i = 0; i < 10; ++i) {
    std::cout << i / 10.0 << '\n';
}

回数は整数で数え、出力する値はそのたびに i / 10.0 で求めます。整数の比較には誤差がないので、ループはちょうど10回で終わります。値も毎回 i から計算し直すので、足し算の誤差がたまりません。

条件を x < 1.0 に変えるだけでは直りません。0.9999999999999999 は 1.0 より小さいので、もう1周して 1 を出力し、11行になります。

  1. C++ の規格は浮動小数点数の形式を定めていませんが、主要な処理系が使う IEEE 754 の倍精度では、0.1 は 0.1000000000000000055511151231257827… として保存されます。
