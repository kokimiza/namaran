to_csv.cpp

#include <format>
#include <print>
#include <string>
#include <type_traits>
#include <variant>

using Cell = std::variant<int, std::string>;

std::string to_csv(const Cell& cell) {
    return std::visit([](const auto& v) {
        using T = decltype(v);
        if constexpr (std::is_same_v<T, std::string>)
            return std::format("\"{}\"", v);
        else
            return std::format("{}", v);
    }, cell);
}

int main() {
    std::println("{},{}", to_csv(42), to_csv("Tokyo, Japan"));
}

to_csv は、整数か文字列が入るCSVのセルを1つ受け取り、文字列なら " で囲み、整数ならそのまま書き出すつもりの関数です。引数も標準入力も使いません。いまの出力は 42,Tokyo, Japan で、2列のつもりの行が、文字列の中のカンマで区切られて3列として読まれます。本来の出力は 42,"Tokyo, Japan" です。

Answer

Wrong

return std::visit([](const auto& v) {
    using T = decltype(v);
    if constexpr (std::is_same_v<T, std::string>)

v は const auto& で宣言した引数なので、文字列のセルを渡されたときの型は const std::string& です。decltype を宣言された名前に使うと宣言どおりの型が返るので、T も const std::string& になります。std::is_same_v は const や参照の有無まで含めて型が同じかを見るので、std::string とは一致しません。文字列のセルも else 側の std::format("{}", v) で書き出され、引用符が付きません。

Right

using T = std::remove_cvref_t<decltype(v)>;

std::remove_cvref_t は、型から参照と const・volatile を外します。T は文字列のセルで std::string、整数のセルで int になり、比較が意図どおりに働きます。文字列が引用符で囲まれるので、中のカンマは列の区切りとして読まれなくなります1。

  1. std::decay_t でも同じ結果になりますが、こちらは配列や関数をポインタに変える働きも持っています。参照と const を外したいだけなら、C++20 で入った std::remove_cvref_t の方が意図をそのまま表します。実際のCSVでは、文字列の中の " を "" と2つ重ねる処理も要ります。
