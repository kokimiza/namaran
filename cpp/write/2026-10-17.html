timing_row.cpp

#include <string>

void row(const std::string& name, double sec) {
}

main は最初に std::ios::sync_with_stdio(false) を呼び、見出しや最後の行を std::cout で出しながら、その間で row を何度か呼びます。row(name, sec) は、名前を幅6の左詰め、空白1つ、秒を小数点以下2桁にした幅6の右詰め、の順に並べた1行を出力する関数です。6文字より長い名前は切らずにそのまま出します。出力をファイルにリダイレクトしても、main が書いた順に行が並ぶように row を書いてください。

入力例 1

row("parse", 0.5)

出力例 1

parse    0.50

入力例 2

row("link", 12.25)

出力例 2

link    12.25

入力例 3

row("compile", 3)

出力例 3

compile   3.00
Reference 
#include <format>
#include <iostream>
#include <string>

void row(const std::string& name, double sec) {
    std::cout << std::format("{:<6} {:6.2f}\n", name, sec);
}

行の文字列は std::format で作り、出力は std::cout に任せます。{:<6} が幅6の左詰め、{:6.2f} が幅6で小数点以下2桁の右詰めで、幅は最小の幅なので、"compile" のような長い名前は切られずにはみ出します。

同じ書式は C++23 の std::print でも使えますが、ストリームを渡さない std::print(書式, ...) の書き込み先は std::cout ではなく C の stdout です。main が同期を切っているので、std::cout と stdout はそれぞれのバッファにため、どちらが先に書き出されるかは決まっていません。GCC 14 の環境でファイルにリダイレクトしたところ、見出しと最後の行が先に出て、row の3行は最後にまとめて出ました。

掲載したのは参考実装で、唯一の正解ではありません。<ostream> にある std::print(std::cout, "{:<6} {:6.2f}\n", name, sec) も std::cout に書くので、同じ結果になります。std::setw と std::fixed を使う書き方もできますが、std::fixed と std::setprecision は std::cout の状態として残り、row を呼んだあとの main の出力にまで効きます。
