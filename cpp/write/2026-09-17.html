safe_div.cpp

auto safe_div(int a, int b, auto ok, auto err) {
}

b が 0 なら err() を、そうでなければ ok(a / b) を呼び、呼んだほうの戻り値をそのまま返す safe_div を書いてください。ok と err は同じ型を返すものとします。safe_div(7, 2, [](int q) { return q * 10; }, [] { return -1; }) → 30、b を 0 にした safe_div(7, 0, ...) → -1

Reference 
auto safe_div(int a, int b, auto ok, auto err) {
    if (b == 0) {
        return err();
    }
    return ok(a / b);
}

引数の型に auto を書くと、関数は省略形の関数テンプレートになります(C++20から)。ok と err にはラムダがそれぞれ自分の型のまま渡るので、std::function に包むときのような型消去の手間がかかりません。戻り値の型も auto で推論させていますが、2つの return から推論される型が食い違うとコンパイルエラーになります。「同じ型を返す」という前提は、ここで効いています。

safe_div は割り算の結果を返す代わりに、結果を受け取る続きの処理 ok と、失敗したときの続き err を受け取り、どちらか一方だけを呼びます。呼び出し側は失敗の確認を if で書かなくても、ok の中にさらに safe_div を書けば割り算を続けられます。途中で0除算が起きればその時点で err が呼ばれ、残りの ok は呼ばれません。

これは参考実装で、唯一の正解ではありません。ok と err を auto&& で受けて std::forward する書き方や、std::function で受ける書き方もあります。
