int count_digits(unsigned n) {
    // write this: return how many decimal digits n has (0 counts as 1 digit)

count_digitsを実装してください。nを10進法で書いたときの桁数を返すこと。0は1桁として数えます。count_digits(0) → 1、count_digits(7) → 1、count_digits(1000) → 4

Reference 
int count_digits(unsigned n) {
    int count = 1;
    while (n >= 10) {
        n /= 10;
        ++count;
    }
    return count;
}

何桁になるかはnの値によって変わるので、繰り返しの回数はあらかじめ分かりません。こういう「条件を満たすまで続ける」処理は、回数を決め打ちできるforよりもwhileの方が素直に書けます。nが10未満になるまで10で割り続け、割った回数だけcountを増やしていけば、最初の1桁分(countの初期値1)と合わせて総桁数になります。nが最初から10未満(0を含む)なら、ループは一度も実行されず1を返します。これは参考実装であり、唯一の正解ではありません。
