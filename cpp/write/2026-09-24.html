make_counter.cpp

#include <functional>

std::function<int()> make_counter(int start) {
}

呼び出すたびに1ずつ増える値を返すクロージャを、startから作るmake_counterを書いてください。1回目の呼び出しはstartそのものを返し、以降は呼ぶたびに1ずつ増えます。一度も呼ばなければ何も観測されません(境界)。auto c = make_counter(5);としてc(), c(), c()の順に呼ぶと5, 6, 7。auto c2 = make_counter(0);でc2(), c2()は0, 1。auto c3 = make_counter(-1);でc3()は-1。

Reference 
std::function<int()> make_counter(int start) {
    return [start]() mutable {
        return start++;
    };
}

[start]はstartを値でキャプチャします。ラムダの呼び出し演算子はデフォルトでconstなので、キャプチャした変数を書き換えるにはmutableを付ける必要があります。mutableを付けると、そのラムダは自分だけが持つキャプチャのコピー(ここではstartのコピー)を自由に書き換えられるようになります。start++は後置インクリメントなので、まず現在の値を返してから内部のstartを1増やします。呼び出すたびにこの内部状態が更新され、次の呼び出しに引き継がれます。呼び出し元(関数の引数start)には影響しません——書き換わるのはクロージャの中にコピーされた、独立したstartだけです。これは参考実装であり、唯一の正解ではありません。
