count_files.cpp

#include <filesystem>
namespace fs = std::filesystem;

int count_files(const fs::path& root) {
}

ディレクトリ root から、シンボリックリンクもたどって行ける通常ファイルを、たどり方ごとに数えて返す count_files を書いてください。たどり方とは、root からファイルに着くまでに通るディレクトリの並びのことです。同じファイルでも、別のたどり方で着けば別々に数えます。ただし、同じディレクトリを2度通るたどり方は数えません。リンクを通って着いたディレクトリは、リンクの先にあるディレクトリと同じものです。通常ファイルを指すリンクは通常ファイルとして数え、行き先の無いリンクは数えません。root が空なら 0 です。例では root の中身を、root からの相対パスで並べます。途中の名前はディレクトリ、最後の名前は通常ファイルで、パス -> 行き先 は、そのパスにある、行き先を指すシンボリックリンクです。

入力例 1

[f, a/g, a/up -> ..]

出力例 1

2

入力例 2

[x/f, l1 -> x, l2 -> x]

出力例 2

3

入力例 3

[]

出力例 3

0

#include <filesystem>
#include <set>
namespace fs = std::filesystem;

int walk(const fs::path& dir,
         std::set<fs::path>& on_path) {
    fs::path id = fs::canonical(dir);
    if (!on_path.insert(id).second)
        return 0;
    int n = 0;
    for (auto& e :
         fs::directory_iterator(dir)) {
        if (e.is_directory())
            n += walk(e.path(), on_path);
        else if (e.is_regular_file())
            n += 1;
    }
    on_path.erase(id);
    return n;
}

int count_files(const fs::path& root) {
    std::set<fs::path> on_path;
    return walk(root, on_path);
}

数えるたどり方を決めているのは「同じディレクトリを2度通らない」という条件で、これは、いまたどっている道の上に、これから入るディレクトリがすでにあるかどうかで決まります。そこで参考実装は、いまの道の上にあるディレクトリの集合 on_path を持ち、ディレクトリに入るときに足して、そこから戻るときに外します。入ろうとしたディレクトリがすでに on_path にあれば、その先は数えません。道は同じディレクトリを含まないので、ディレクトリの数より長くはならず、走査は必ず終わります。掲載したのは参考実装で、唯一の正解ではありません。

集合に入れるのは、たどってきたパスではなく fs::canonical の結果です。canonical はシンボリックリンクと .. を解決した絶対パスを返すので、入力例1の a/up は root と同じパスになります。root は道の上にあるので、a/up の先は数えず、数えるのは f と a/g の2つです。directory_entry の is_directory() と is_regular_file() はリンクの先を調べるので、ディレクトリを指すリンクにはそのまま入り、ファイルを指すリンクはファイルとして数えます。行き先の無いリンクはどちらでもないので数えません。

戻るときに外すのは、入力例2のためです。一度でも入ったディレクトリをすべて覚えておく訪問済みの集合にすると、x を通って f を数えたあと、l1 と l2 の先は x と同じなので入らず、答えは 1 になります。l1 を通る道の上に x は無いので、2度通ってはいません。外していれば x/f、l1/f、l2/f の3つを数えます。入力例3では root の中に何も無く、ループが1回も回らずに 0 を返します。
