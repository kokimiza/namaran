std::string binary(unsigned n) {
}

n を2進数で表した文字列を返す binary を、ループを使わずに再帰で書いてください。先頭に余分な 0 を付けず、n が 0 のときは "0" を返します。

入力例 1

binary(6)

出力例 1

"110"

入力例 2

binary(0)

出力例 2

"0"

入力例 3

binary(1)

出力例 3

"1"

std::string binary(unsigned n) {
    if (n < 2) {
        return std::to_string(n);
    }
    return binary(n / 2) +
        std::to_string(n % 2);
}

n の2進表記は、n / 2 の2進表記の後ろに、最下位の桁 n % 2 を1文字付けたものです。再帰の段はこの関係をそのまま書き、binary(n / 2) の結果に std::to_string(n % 2) を連結します。残るのは、どこで再帰を止めるかです。参考実装は n が 0 か 1 の、1桁で書ける数を基底ケースにして、その数字をそのまま返します。掲載したのは参考実装で、唯一の正解ではありません。

n == 0 で止める形にすると、基底ケースが返す文字列で困ります。"" を返せば binary(6) は "110" になりますが、binary(0) が空文字列になります。"0" を返せば binary(0) は正しくなる代わりに、6 は 3、1、0 とたどって最後に "0" を拾い、"0110" になります。0 は「これ以上割れない最後の一歩」と「入力そのものとしての 0」の2つの役を持つので、1つの返り値では両方を満たせません。1桁の数を基底ケースにすれば、再帰はいつも 0 か 1 に着いて先頭の桁を1つだけ返し、余分な 0 は付きません。入力例1は 6、3、1 とたどり、"1" に "1" と "0" が付いて "110" になります。
