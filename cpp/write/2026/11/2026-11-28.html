join.cpp

std::string
join(const std::vector<std::string>& v,
     const std::string& sep = ", ") {
}

文字列の列 v の要素を、隣り合う要素の間に sep をはさんで順につないだ文字列を返す join を書いてください。呼び出しで sep を省いたときは ", " を区切りに使います。v が空なら空文字列を返し、要素が1つなら区切りは入りません。例の出力は、返した文字列を " で囲んで書きます。

入力例 1

join({"a", "b", "c"})

出力例 1

"a, b, c"

入力例 2

join({"x", "y"}, "-")

出力例 2

"x-y"

入力例 3

join({})

出力例 3

""
Reference 時間計算量 𝒪(n + m) 空間計算量 𝒪(m) n は v の要素の個数、m は返す文字列の長さ

std::string
join(const std::vector<std::string>& v,
     const std::string& sep = ", ") {
    std::string out;
    for (std::size_t i = 0; i < v.size();
         i++) {
        if (i > 0)
            out += sep;
        out += v[i];
    }
    return out;
}

既定の値は、引数の宣言に = ", " と書いて与えます。join({"a", "b", "c"}) のように2つ目の引数を省くと、コンパイラが呼び出しの側で ", " を補って join({"a", "b", "c"}, ", ") として呼びます。既定の値を持てるのは後ろの引数だけなので、省ける sep を2つ目に置きます。これは参考実装で、唯一の正解ではありません。区切りを持たない join(v) を別のオーバーロードとして書き、join(v, ", ") を呼ばせても同じように動きます。

区切りは2つ目以降の要素の前にだけ足すので、要素が1つなら区切りは入らず、v が空ならループが回らずに空文字列が返ります。入力例 2 は "x" のあとに "-" と "y" を足して "x-y" です。out は返す文字列そのものなので、空間計算量にはその長さが入ります。
