right_align.cpp

std::string
right_align(const std::vector<int>& v) {
}

v の各要素を1行に1つずつ書き、各行の末尾に改行を付けた文字列を返す right_align を書いてください。どの行も、v の中でいちばん長い数の文字数(負の数なら符号を含む)に合わせて、左を空白で埋めた右寄せにします。v が空なら空の文字列を返します。

入力例 1

right_align({3, -12, 100})

出力例 1

"  3\n-12\n100\n"

入力例 2

right_align({5})

出力例 2

"5\n"

入力例 3

right_align({})

出力例 3

""
Reference 時間計算量 𝒪(n) 空間計算量 𝒪(n) n は v の要素数

Reference

std::string
right_align(const std::vector<int>& v) {
    std::size_t w = 0;
    for (int x : v)
        w = std::max(
            w, std::formatted_size("{}", x));
    std::string out;
    for (int x : v)
        out += std::format("{:>{}}\n", x, w);
    return out;
}

幅は v を見るまで決まらないので、{:>5} のように書式文字列へ数字を書き込むことはできません。std::format では、幅の位置にもう一つ {} を入れ子にして書くと、その幅を次の引数から受け取れます。"{:>{}}\n" は1つ目の引数 x を、2つ目の引数 w の幅で右寄せします。幅を求めるのには std::formatted_size を使い、"{}" で書いたときの文字数を、文字列を作らずに数えます。掲載したのは参考実装で、唯一の正解ではありません。

入力例1では各数の文字数が 1, 3, 3 なので w は 3 になり、3 の前にだけ空白が2つ入ります。v が空ならどちらのループも回らず、w は 0 のまま空の文字列が返ります。int の1つの数は符号を含めても十数文字なので、行1つを作る手間は定数で、全体は要素数に比例します。整数の幅は既定で右寄せなので > は省いても同じ結果になりますが、意図を読み手に見せるために書いています。
