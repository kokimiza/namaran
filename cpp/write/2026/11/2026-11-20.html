divide_even.cpp

long long divide_even(long long a,
                      long long b) {
}

a を b で割った値に最も近い整数を返す divide_even を書いてください。割った値が隣り合う2つの整数のちょうど真ん中にあるときは、そのうち偶数のほうを返します。a は 0 以上、b は 1 以上で、浮動小数点数は使いません。a が 0 なら 0 です。

入力例 1

divide_even(7, 2)

出力例 1

4

入力例 2

divide_even(5, 2)

出力例 2

2

入力例 3

divide_even(8, 3)

出力例 3

3

long long divide_even(long long a,
                      long long b) {
    long long q = a / b;
    long long r = a % b;
    if (2 * r > b ||
        (2 * r == b && q % 2 == 1))
        ++q;
    return q;
}

整数の割り算で得た商 q は切り捨てた値で、本当の値との差は r / b です。この差が半分より大きいかどうかは、両辺に 2 * b を掛けた 2 * r > b で、整数のまま比べられます。大きければ上の整数のほうが近いので q を1増やし、2 * r == b ならちょうど真ん中なので、q が奇数のときだけ増やして偶数に寄せます。掲載したのは参考実装で、唯一の正解ではありません。

入力例 1 の 7 ÷ 2 は q = 3、r = 1 で、2 * r == b の真ん中にあたり、3 は奇数なので 4 を返します。入力例 2 の 5 ÷ 2 も真ん中ですが、q = 2 がすでに偶数なのでそのまま 2 です。入力例 3 の 8 ÷ 3 は r = 2 で 2 * r = 4 > 3 なので、2.67 に近い 3 になります。a が 0 なら q も r も 0 で、どの条件も成り立たず 0 を返します。真ん中を常に上へ寄せる四捨五入と違い、偶数への丸めは上下に寄せる回数がおよそ半々になるので、多くの値を丸めて足しても誤差が片方へたまりにくくなります。
