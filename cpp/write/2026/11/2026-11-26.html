factorize(int n,
          const std::vector<int>& spf) {

spf は、2 以上 spf.size() 未満の各整数 k について、k を割り切る最も小さい素数を spf[k] に入れた表です。1 以上 spf.size() 未満の n を受け取り、n を素数の積で表したときの素数を、小さい順に、同じ素数は掛けた回数だけ並べて返す factorize を書いてください。n が 1 のときは空の std::vector を返します。例の spf は、100 以下の整数の表です。

入力例 1

factorize(12, spf)

出力例 1

{2, 2, 3}

入力例 2

factorize(97, spf)

出力例 2

{97}

入力例 3

factorize(1, spf)

出力例 3

{}

std::vector<int>
factorize(int n,
          const std::vector<int>& spf) {
    std::vector<int> fs;
    while (n > 1) {
        fs.push_back(spf[n]);
        n /= spf[n];
    }

spf[n] は n を割り切る最も小さい素数なので、それが分解の最初の素数です。n をその素数で割ると、残りの素因数だけを持つ数になり、その数の最小の素因数がまた表から引けます。これを n が 1 になるまで繰り返すと、素因数が1つずつ取り出されます。割ったあとの数の最小の素因数は、割る前の最小の素因数より小さくはならないので、取り出した順がそのまま小さい順です。掲載したのは参考実装で、唯一の正解ではありません。

入力例1の 12 は、spf[12] の 2 で割って 6、spf[6] の 2 で割って 3、spf[3] の 3 で割って 1 になり、{2, 2, 3} が返ります。97 は素数で spf[97] が 97 なので、1回割って終わります。n が 1 のときはループに一度も入らないので、空の std::vector を返します。1回の割り算で n は半分以下になるので、ループの回数は多くても log2 n 回です。表を一度作っておけば、たくさんの数をそれぞれこの回数で分解できます。
