transpose.cpp

std::array<std::array<int, 2>, 3> transpose(const std::array<std::array<int, 3>, 2>& m) {
}

2行3列の行列 m の行と列を入れ替えた、3行2列の行列を返す transpose を書いてください。m[i][j] は i 行 j 列の要素で、返す行列の j 行 i 列には m[i][j] が入ります。m は書き換えません。

入力例 1

transpose({{{1, 2, 3}, {4, 5, 6}}})

出力例 1

{{1, 4}, {2, 5}, {3, 6}}

入力例 2

transpose({{{0, -1, 0}, {7, 0, 0}}})

出力例 2

{{0, 7}, {-1, 0}, {0, 0}}

std::array<std::array<int, 2>, 3> transpose(const std::array<std::array<int, 3>, 2>& m) {
    std::array<std::array<int, 2>, 3> t{};
    for (std::size_t i = 0; i < 2; ++i) {
        for (std::size_t j = 0; j < 3; ++j) {
            t[j][i] = m[i][j];
        }
    }
    return t;
}

std::array<std::array<int, 3>, 2> は、外側の std::array が要素を2つ持ち、その1つ1つが int 3つの std::array です。m[i] で行を選び、m[i][j] で列を選ぶので、外側の要素数 2 が行の数、内側の 3 が列の数になります。返す型 std::array<std::array<int, 2>, 3> は同じ読み方で3行2列です。組み込み配列の int m[2][3] と比べると、行の数と列の数を書く順番が逆になります。

本体では t を {} ですべて 0 に初期化してから、i を 0 から 1、j を 0 から 2 まで回して t[j][i] = m[i][j] を6回行います。入力例 1 の m[0][2] の 3 は t[2][0] に入り、3行目は {3, 6} になります。添字はどちらも m の大きさに合わせて回しているので、範囲の外には書きません。

組み込み配列は関数の戻り値の型にできませんが、std::array は普通のクラスの値なので、作った t をそのまま return できます。引数は const の参照で受け、6つの要素をコピーせずに読むだけにしています。掲載したのは参考実装で、唯一の正解ではありません。
