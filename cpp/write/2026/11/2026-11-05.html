int parse_digits(std::string_view s) {
}

'0' から '9' の数字だけでできた文字列 s を10進数として読み、その値を返す parse_digits を書いてください。std::stoi や std::from_chars などの標準の変換関数は使いません。s が空なら0を返します。値は int に収まるものとします。

入力例 1

parse_digits("407")

出力例 1

407

入力例 2

parse_digits("007")

出力例 2

7

入力例 3

parse_digits("")

出力例 3

0

int parse_digits(std::string_view s) {
    int n = 0;
    for (char c : s) {
        n = n * 10 + (c - '0');
    }
    return n;
}

数字1文字の値は c - '0' で得られます。C++ の規格は、'0' から '9' の文字コードが連続して小さい順に並ぶことを保証しているので、'7' - '0' はどの処理系でも7です。文字列の左から1文字ずつ読み、それまでの値を10倍してからその桁を足すと、読み終えたときに全体の値ができています。これは参考実装で、唯一の正解ではありません。std::accumulate で同じ計算を書くこともできます。

入力例1では、n は0から4、40、407と増えます。10倍すると、それまでに読んだ桁が1つずつ上の位へ移るので、右端の桁が1の位に残ります。入力例2の先頭の0は、0を10倍しても0なので値に影響せず、最後の '7' で7になります。空の文字列ではループが一度も回らず、初期値の0が返ります。
