skip_multiples.cpp

long long nth_non_multiple(long long n,
                           long long k) {
}

k の倍数でない正の整数を小さい順に並べたとき、n 番目（1番目から数えます）の数を返す nth_non_multiple を書いてください。k は 2 以上、n は 1 以上です。n は 1018 まで来るので、整数を1つずつ調べて数える方法では終わりません。答えは long long に収まります。

入力例 1

nth_non_multiple(5, 3)

出力例 1

7

入力例 2

nth_non_multiple(10, 10)

出力例 2

11

入力例 3

nth_non_multiple(1000000000000000000, 7)

出力例 3

1166666666666666666

long long nth_non_multiple(long long n,
                           long long k) {
    return n + (n - 1) / (k - 1);
}

数えるものを、残る数から飛ばされる数へ替えると、割り算1回で済みます。正の整数を1から k 個ずつの組に区切ると、どの組も k - 1 個の残る数のあとに倍数が1つ来る同じ形です。n 番目の残る数より前にある倍数の個数がわかれば、答えは n にその個数を足した数になります。n 番目の数の前で完全に終わっている組は、残る数を k - 1 個ずつ使い切った組なので、その数は (n - 1) / (k - 1) です。組が1つ終わるごとに倍数が1つ飛ばされるので、答えは n + (n - 1) / (k - 1) になります。

n - 1 で割るのは、組の最後の数を正しく扱うためです。n / (k - 1) にすると、n が k - 1 で割り切れるとき、まだ飛ばしていない倍数を1つ多く数えます。k = 3 なら残る数は 1, 2, 4, 5, 7, … で、2番目は 2 ですが、n / (k - 1) では 2 + 1 で 3 になります。入力例1では 5 + 4 / 2 で 7、入力例2では 10 + 9 / 9 で 11 です。入力例3は 1018 + (1018 - 1) / 6 で、答えは 2 × 1018 以下なので long long に収まります。

掲載したのは参考実装で、唯一の正解ではありません。x 以下に残る数の個数は x - x / k で数えられるので、この個数が n 以上になる最小の x を二分探索で探しても答えが出ます。n * k / (k - 1) のように比で求めようとすると、n * k が long long の範囲を超え、切り捨ての位置もずれます。
