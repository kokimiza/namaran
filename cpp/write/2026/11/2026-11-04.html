total_any.cpp

#include <any>
#include <vector>

double total(const std::vector<std::any>& items) {
}

items の要素のうち、int か double の値が入っているものだけを足し合わせた合計を返す total を書いてください。それ以外の型の値が入った要素と、値の入っていない要素は飛ばします。items が空なら 0 を返します。

入力例 1

total({1, 2.5, std::string("x")})

出力例 1

3.5

入力例 2

total({1.5f, 2})

出力例 2

2

入力例 3

total({})

出力例 3

0
Reference 
double total(const std::vector<std::any>& items) {
    double sum = 0;
    for (const auto& item : items) {
        if (const auto* i = std::any_cast<int>(&item)) {
            sum += *i;
        } else if (const auto* d = std::any_cast<double>(&item)) {
            sum += *d;
        }
    }
    return sum;
}

std::any は、コピーできる値なら型を問わず1つ入れておけますが、取り出すときは入れたときの型を std::any_cast に正しく指定しなければなりません。参照や値を返す std::any_cast<int>(item) は、型が違うと std::bad_any_cast を投げます。std::any へのポインタを渡す std::any_cast<int>(&item) は、型が合えば中の値を指すポインタを、合わなければ nullptr を返すので、if の初期化に置けば型を確かめることと値を取り出すことが1回で済みます。値が入っていない std::any に対しても nullptr が返るので、別に調べる必要はありません。

型は完全に一致するものしか合いません。入力例 2 の 1.5f は float として入っているので、double に変換できる値でも std::any_cast<double> では取り出せず、合計は 2 だけになります。"x" を std::string にせず文字列リテラルのまま入れた場合も、入るのは const char* です。

掲載したのは参考実装で、唯一の正解ではありません。item.type() == typeid(int) で型を比べてから値を取り出す書き方もできます。
