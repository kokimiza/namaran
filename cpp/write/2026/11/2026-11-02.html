int_buf.cpp

class IntBuf {
    std::size_t size_;
    int* data_;

public:
    explicit IntBuf(std::size_t n) : size_(n), data_(new int[n]{}) {}
    IntBuf(const IntBuf& other) : size_(other.size_), data_(new int[other.size_]) {
        std::copy(other.data_, other.data_ + size_, data_);
    }
    ~IntBuf() {
        delete[] data_;
    }
    int& operator[](std::size_t i) {
        return data_[i];
    }
    std::size_t size() const {
        return size_;
    }

    friend void swap(IntBuf& a, IntBuf& b) noexcept {
    }
    IntBuf& operator=(IntBuf other) noexcept {
    }
};

IntBuf は new[] で確保した int の配列を持つクラスです。2つの IntBuf の中身（大きさと配列）を、新しい確保をせずに入れ替える swap と、コピー代入演算子 operator= の本体を書いてください。代入のあと、a は代入元と同じ大きさと値を持つ別の配列を持ち、代入前に持っていた配列は解放されます。a = a のように自分自身を代入しても中身は変わりません。入力例は、上から順に実行する文の並びです。

入力例 1

IntBuf a(2), b(3); b[0] = 7; a = b; b[0] = 9; std::cout << a.size() << a[0];

出力例 1

37

入力例 2

IntBuf a(2); a[1] = 5; a = a; std::cout << a.size() << a[1];

出力例 2

25

入力例 3

IntBuf a(1), b(4); swap(a, b); std::cout << a.size() << b.size();

出力例 3

41
Reference 
friend void swap(IntBuf& a, IntBuf& b) noexcept {
    using std::swap;
    swap(a.size_, b.size_);
    swap(a.data_, b.data_);
}
IntBuf& operator=(IntBuf other) noexcept {
    swap(*this, other);
    return *this;
}

operator= は引数を値で受けるので、呼び出した時点でコピーコンストラクタが代入元の複製 other を作っています。本体はその複製と自分の中身を swap で入れ替えます。入れ替えたあとの other は代入前の古い配列を持っていて、関数を抜けるときに other のデストラクタがそれを解放します。複製は古い配列を手放す前にできているので、入力例2の自己代入でも、消した配列から写すことにはなりません。確保に失敗して例外が出る場合も呼び出しの前に出るので、a は元のまま残ります。

本体の swap(*this, other) は修飾なしで書きます。swap はクラスの中で定義したフレンド関数なので、名前空間の通常の探索では見えず、実引数の型 IntBuf から探す実引数依存の名前探索（ADL）でだけ見つかります。ここを std::swap(*this, other) と書くと、汎用の std::swap が一時オブジェクトを使った代入で入れ替えようとして、その代入がまた operator= を呼びます。その operator= がまた std::swap を呼ぶので、再帰が終わらずにスタックを使い切ります。

swap の中では、メンバを1つずつ入れ替えます。メンバの型 std::size_t と int* には属する名前空間がないので ADL は働かず、using std::swap; を置かずに swap(a.size_, b.size_) と書くと、呼べる関数が見つからずにコンパイルエラーになります。using std::swap; のあとに修飾なしで呼ぶ形にしておけば、メンバの型が自分の swap を持つクラスに変わっても、その swap が選ばれます。

掲載したのは参考実装で、唯一の正解ではありません。メンバが組み込み型だけのいまは、swap の中を std::swap(a.size_, b.size_) のように修飾して書いても同じように動きます。
