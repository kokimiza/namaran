bits8.cpp

#include <cstdint>

class Bits8 {
    std::uint8_t byte_ = 0;
};

Bits8 は8個の bool 値を byte_ の各ビットに詰めて持つクラスで、i 番目の値を i ビット目に置きます。Bits8 b; に対して、b[i] = true; で i 番目を書き換え、bool x = b[i]; で読み出し、b[j] = b[i]; で i 番目の値を j 番目へ写せるように、public な operator[] と、それに要る型をクラスの中に書き足してください。i と j は 0 以上 7 以下です。例では、新しく作った Bits8 b; に入力の文を順に実行したあと、b[0] から b[7] までを bool として読んだ値を 0 と 1 で並べて書きます。

入力例 1

b[2] = true; b[5] = b[2]; b[2] = false;

出力例 1

00000100

入力例 2

(何もしない)

出力例 2

00000000

入力例 3

b[0] = true; b[7] = true; b[0] = false;

出力例 3

00000001

Reference

#include <cstdint>

class Bits8 {
    std::uint8_t byte_ = 0;

public:
    struct Ref {
        std::uint8_t& byte;
        int i;

        Ref& operator=(bool x) {
            if (x) {
                byte |= 1u << i;
            } else {
                byte &= ~(1u << i);
            }
            return *this;
        }
        Ref& operator=(const Ref& other) {
            return *this = bool(other);
        }
        operator bool() const {
            return (byte >> i) & 1u;
        }
    };

    Ref operator[](int i) {
        return {byte_, i};
    }
};

1ビットにはアドレスが無いので、operator[] は i 番目の値を指す bool& を返せません。bool を値で返すと読み出しはできますが、b[i] = true; は組み込み型の一時オブジェクトへの代入になり、コンパイルできません。std::uint8_t& を返せば代入は通りますが、バイト全体を true、つまり 1 で上書きしてしまいます。そこで、どのバイトの何ビット目かを覚えた小さな型 Ref を値で返し、代入と読み出しをこの型に肩代わりさせます。std::vector<bool> の operator[] が返す std::vector<bool>::reference も、同じ考え方の代理オブジェクトです。掲載したのは参考実装で、唯一の正解ではありません。

operator=(bool) は、true なら 1u << i とのビットORで i ビット目を立て、false なら ~(1u << i) とのビットANDで i ビット目だけを落とします。operator bool は i ビット目を取り出して bool に変換するので、bool x = b[i]; も出力例を作るときの読み出しも、これを通ります。

この2つだけでは入力例 1 の b[5] = b[2]; が通りません。右辺も左辺も Ref なので、bool を受ける代入ではなく Ref どうしのコピー代入が呼ばれる形になり、参照のメンバを持つクラスでは暗黙のコピー代入が削除されているからです。operator=(const Ref&) を自分で定義し、右辺を bool として読んでから左辺のビットへ書くと、b[2] の値 1 が b[5] へ写り、そのあと b[2] = false; で2ビット目だけが落ちて 00000100 になります。入力例 3 でも、b[0] = false; は7ビット目に触れないので 00000001 が残ります。
