平面上の点 (x, y) を並べた points の全部の点を同じ向きに同じ距離だけ動かし、先頭の点が (0, 0) に来るようにする move_to_origin を書いてください。points はその場で書き換えます。points が空のときは何もしません。

入力例 1

{{2, 3}, {5, 1}, {2, 7}}

出力例 1

{{0, 0}, {3, -2}, {0, 4}}

入力例 2

{{-4, 9}}

出力例 2

{{0, 0}}
Reference 
void move_to_origin(std::vector<std::pair<int, int>>& points) {
    if (points.empty()) {
        return;
    }
    const auto [ox, oy] = points.front();
    for (auto& [x, y] : points) {
        x -= ox;
        y -= oy;
    }
}

先頭の点を (ox, oy) とすると、すべての点から ox と oy を引けば、先頭の点は (0, 0) に来ます。点を書き換えるループは auto& [x, y] で受け、x と y を points の要素そのものを指す名前にします。

基準の ox と oy は、逆に const auto でコピーとして受けます。const auto& [ox, oy] = points.front(); と書くと、ox と oy は先頭の要素を指す名前になります。const が禁じるのはこの名前を通した書き換えだけで、ループの1回目が x を通して先頭の要素を (0, 0) にすると、ox と oy も0に変わります。2つ目以降の点からは0を引くことになり、入力例1は {{0, 0}, {5, 1}, {2, 7}} で終わります。コピーなら、ループの前に読んだ値が最後まで残ります。

掲載したのは参考実装で、唯一の正解ではありません。auto [ox, oy] = points.front(); と const を付けずにコピーしても同じ結果になり、基準を points[0].first と points[0].second から2つの int 変数に写してもかまいません。
