erase_first.cpp

#include <vector>

void erase_first_value(std::vector<int>& v) {
}

v から、先頭の要素と等しい値をすべて取り除く erase_first_value を書いてください。残る要素の順序は元のままにします。v が空なら何もしません。出力例は、呼び出したあとの v の中身です。

入力例 1

std::vector v{1, 2, 1, 3, 1}; erase_first_value(v);

出力例 1

{2, 3}

入力例 2

std::vector v{5, 5}; erase_first_value(v);

出力例 2

{}

入力例 3

std::vector<int> v; erase_first_value(v);

出力例 3

{}
Reference 
#include <vector>

void erase_first_value(std::vector<int>& v) {
    if (!v.empty())
        std::erase(v, auto{v.front()});
}

素直に書けば std::erase(v, v.front()); の1行ですが、手元の libstdc++ では、入力例1の v がこれで {2, 1, 3, 1} になりました。std::erase は比べる値を const U& の参照で受け取るので、渡っているのは値の 1 ではなく、要素 v[0] そのものです。

std::erase は std::remove と同じく、残す要素を前へ詰めていきます。入力例1では先頭の 1 が消す対象と分かり、次の 2 がその位置、つまり v[0] へ移されます。その時点から参照の先は 2 になり、残りの要素は 2 と等しいかどうかで選り分けられます。後ろの 1 は消されずに残ります。

参考実装は、auto{v.front()} で先頭の値をコピーしてから渡します。C++23 から使える書き方で、auto{x} は x の値をコピーした一時オブジェクトを作り、その型は auto t{x}; と同じ規則で推論されます。auto x{1} が int になるのと同じで、ここでも int になり、auto x = {1} のような std::initializer_list<int> にはなりません。この一時オブジェクトは v の要素とは別の場所にあるので、要素がどう動いても比べる値は 1 のままです1。

空の v で v.front() を呼ぶのは未定義動作なので、先に empty() を確かめます。

掲載したのは参考実装で、唯一の正解ではありません。int first = v.front(); と名前の付いた変数にコピーしてから std::erase(v, first); と渡しても、同じように動きます。

  1. auto(x) と auto{x} を導入した提案 P0849 も、動機の例に erase へ front() を渡す同じ形のコードを挙げています。
