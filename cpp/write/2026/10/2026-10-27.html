std::int32_t read_i24_be(const std::array<std::uint8_t, 3>& p) {
}

音声ファイルなどでは、1つの標本(サンプル)を3バイトで持つ形式があります。上位のバイトから順に並んだ3バイト p を、24ビットの2の補数で表された整数として読み、その値を返す read_i24_be を書いてください。返す値は -8388608 以上 8388607 以下です。

入力例 1

read_i24_be({0x00, 0x01, 0x00})

出力例 1

256

入力例 2

read_i24_be({0xff, 0xff, 0xfe})

出力例 2

-2

入力例 3

read_i24_be({0x80, 0x00, 0x00})

出力例 3

-8388608
Reference 
std::int32_t read_i24_be(const std::array<std::uint8_t, 3>& p) {
    std::int32_t v = p[0] << 16 | p[1] << 8 | p[2];
    return v >= 0x800000 ? v - 0x1000000 : v;
}

p[0] などの std::uint8_t は、シフトの前に int へ昇格します。上位のバイトから順に16ビット、8ビット、0ビットずらして論理和を取ると、3バイトが並んだ24ビットの値 v ができます。ただしこれは 0 から 0xffffff までの符号なしの値で、入力例2なら 16777214 です。

24ビットの2の補数では、24ビット目が立っている値(0x800000 以上)は負の数を表し、本来の値は v から2の24乗を引いたものです。2の24乗の 0x1000000 を引けば、入力例2は -2、入力例3は -8388608 になります。int32_t は32ビットあるので、3バイトを並べただけでは24ビット目の符号が32ビットの符号ビットまで届かず、この引き算が要ります。

掲載したのは参考実装で、唯一の正解ではありません。C++20 から符号つき整数のシフトは2の補数として定義されているので、(v << 8) >> 8 のように、符号ビットの位置まで上げてから算術右シフトで戻す書き方もあります。
