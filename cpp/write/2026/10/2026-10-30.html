s が、1文字以上の数字(0 から 9)の並びを、コンマ , 1つで区切って1個以上つないだ文字列なら true、そうでなければ false を返す is_number_list を、std::regex を使わずに書いてください。空文字列、コンマで始まる・終わる文字列、コンマが2つ続く文字列は false です。s の各文字は1回だけ読むようにします。

入力例 1

is_number_list("12,7,300")

出力例 1

true

入力例 2

is_number_list("12,,7")

出力例 2

false

入力例 3

is_number_list("")

出力例 3

false

bool is_number_list(std::string_view s) {
    bool after_digit = false;
    for (char c : s) {
        if (c >= '0' && c <= '9') {
            after_digit = true;
        } else if (c == ',' && after_digit) {
            after_digit = false;
        } else {
            return false;
        }
    }
    return after_digit;

先頭から1文字ずつ見ていくとき、次の文字が許されるかどうかは、直前の文字が数字だったかどうかだけで決まります。数字はいつでも置けますが、コンマを置けるのは直前が数字のときだけです。そこで after_digit に直前が数字だったかを持たせ、数字を読んだら true、コンマを読んだら false にします。それ以外の文字が来たら、その場で false を返します。

最後に after_digit を返すのは、文字列が数字で終わっているかを確かめるためです。空文字列はループを一度も回らないので初期値の false が返り、5, のようにコンマで終わる文字列も false になります。コンマで始まる文字列は、1文字目で after_digit がまだ false なので弾かれます。各文字を1回ずつ見るだけなので、時間は文字列の長さに比例し、どんな入力でも急に遅くなることはありません。

掲載したのは参考実装で、唯一の正解ではありません。コンマで区切ってから、どの部分も空でなく数字だけでできていることを確かめる書き方もあります。
