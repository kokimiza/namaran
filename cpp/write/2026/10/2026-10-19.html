clone_ptr.cpp

#include <memory>

struct Shape {
    virtual ~Shape() = default;
    std::unique_ptr<Shape> clone() const { return std::unique_ptr<Shape>(clone_impl()); }
private:
    virtual Shape* clone_impl() const { return new Shape(*this); }
};

struct Circle : Shape {
    double r = 1;
    std::unique_ptr<Circle> clone() const;
private:
    Circle* clone_impl() const override { return new Circle(*this); }
};

std::unique_ptr<Circle> Circle::clone() const {
}

Circle::clone を書いてください。*this のコピーを新しく作り、その所有権を std::unique_ptr<Circle> で返します。Circle を継承したクラスが clone_impl をオーバーライドしていれば、そのクラスのオブジェクトから呼んだときには、そのクラスのコピーが作られるようにします。キャストは使わないでください。

入力例 1

Circle c; c.r = 3; c.clone()->r

出力例 1

3

入力例 2

Circle{}.clone()->clone()->r

出力例 2

1
Reference 
std::unique_ptr<Circle> Circle::clone() const {
    return std::unique_ptr<Circle>(clone_impl());
}

Circle のメンバ関数の中で clone_impl() を呼ぶと、コンパイラは *this の静的な型 Circle から Circle::clone_impl の宣言を見るので、式の型は Circle* です。そのまま std::unique_ptr<Circle> に渡せるので、キャストは要りません。呼び出し自体は仮想関数の呼び出しなので、実体が Circle を継承したクラスなら、そのクラスの clone_impl がコピーを作ります。

std::make_unique<Circle>(*this) と書いてもコンパイルは通りますが、作られるのは常に Circle で、派生クラスのオブジェクトから呼ぶと Circle の部分だけが切り出されます。仮想関数の clone が std::unique_ptr を返す形にしないのは、オーバーライドで戻り値の型を派生クラス側に変えられるのは生のポインタと参照だけだからです。std::unique_ptr<Circle> は std::unique_ptr<Shape> から派生したクラスではないので、この規則が使えません。そこで共変戻り値型（covariant return type）を使える clone_impl を private な仮想関数にし、受け取った直後に std::unique_ptr で包む公開の clone を、クラスごとに非仮想関数として持たせています。

掲載したのは参考実装で、唯一の正解ではありません。return std::unique_ptr<Circle>{clone_impl()}; のように波括弧で初期化しても同じです。
