top_up.cpp

#include <map>
#include <string>

int top_up(std::map<std::string, int>& stock, int min) {
}

stock は商品名から在庫数への対応です。在庫数が min より少ない商品をすべて min に書き換え、書き換えた商品の数を返す top_up を書いてください。min 以上の商品は変えません。stock が空なら 0 を返します。

入力例 1

stock = {{"apple", 2}, {"pear", 7}, {"plum", 0}}
top_up(stock, 5)

出力例 1

2
stock == {{"apple", 5}, {"pear", 7}, {"plum", 5}}

入力例 2

stock = {}
top_up(stock, 5)

出力例 2

0

int top_up(std::map<std::string, int>& stock, int min) {
    int changed = 0;
    for (auto& [name, qty] : stock) {
        if (qty < min) {
            qty = min;
            ++changed;
        }
    }
    return changed;
}

std::map を範囲forで回すと、要素は std::pair<const std::string, int> として1つずつ取り出されます。auto& [name, qty] と書くと、構造化束縛の名前のない変数がその要素への参照になり、qty は map の中の在庫数そのものを指します。qty = min がそのまま stock を書き換えるのはこのためです。

& を付け忘れて auto [name, qty] と書いても、コンパイルは通り、数えた件数も正しく返ります。書き換わるのは要素ごとに作られた写しのほうで、stock は何も変わりません。返り値だけを確かめるテストでは見つからない誤りです。name は使いませんが、構造化束縛では要素の数だけ名前を書く必要があります。掲載したのは参考実装で、唯一の正解ではありません。for (auto& entry : stock) として entry.second を書き換えても同じ動きになります。
