from_vector.cpp

#include <memory>
#include <vector>

struct Node {
    int value;
    std::unique_ptr<Node> next;
};

std::unique_ptr<Node> from_vector(const std::vector<int>& values) {
}

values の要素を同じ順に持つ単方向連結リストを作り、先頭のノードを返す from_vector を書いてください。末尾のノードの next は空にし、values が空なら空の std::unique_ptr を返します。from_vector({1, 2, 3}) → 1 -> 2 -> 3、from_vector({7}) → 7、from_vector({}) → nullptr

Reference 
std::unique_ptr<Node> from_vector(const std::vector<int>& values) {
    std::unique_ptr<Node> head;
    for (auto it = values.rbegin(); it != values.rend(); ++it) {
        head = std::make_unique<Node>(*it, std::move(head));
    }
    return head;
}

後ろの要素から順にノードを作り、それまでに作ったリストを新しいノードの next に渡していきます。先頭から作ると、末尾に付け足すたびにリストをたどり直すことになりますが、後ろから作れば毎回先頭に1つ足すだけで済みます。

Node はコンストラクタを持たない集成体ですが、C++20 からは集成体を丸括弧でも初期化できます。std::make_unique<Node>(*it, std::move(head)) は内部で new Node(*it, std::move(head)) を行うので、value には要素の値が、next にはそれまでの先頭が入ります。C++17 までは、丸括弧で初期化する make_unique では集成体を作れず、std::unique_ptr<Node>(new Node{...}) と書く必要がありました。

head は unique_ptr なのでコピーできず、std::move で所有権を新しいノードへ移します。values が空ならループは1回も回らず、空のまま初期化した head がそのまま返ります。

掲載したのは参考実装で、唯一の正解ではありません。先頭から作る場合も、末尾の next を指すポインタを持ち回せば、たどり直さずに書けます。
