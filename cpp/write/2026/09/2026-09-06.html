paragraph_sizes.cpp

#include <istream>
#include <string>
#include <vector>

std::vector<int> paragraph_sizes(std::istream &in) {
}

in から読んだ行を空行で区切って段落に分け、各段落の行数を順に並べて返す paragraph_sizes を書いてください。空行が続いても区切りは1つで、先頭や末尾の空行は段落を作りません。最後の行が改行で終わっていなくても、その行は段落に数えます。段落が1つもなければ空の vector を返します。in の中身が "a\nb\n\nc\n" → {2, 1}、"a\n\n\nb" → {1, 1}、"\n" → {}

Reference 
std::vector<int> paragraph_sizes(std::istream &in) {
    std::vector<int> sizes;
    int count = 0;
    std::string line;
    while (std::getline(in, line)) {
        if (!line.empty()) {
            ++count;
        } else if (count > 0) {
            sizes.push_back(count);
            count = 0;
        }
    }
    if (count > 0) {
        sizes.push_back(count);
    }
    return sizes;
}

getline が成功しているあいだは、空でない行なら count を増やし、空行なら数えていた段落を閉じます。count が 0 のときの空行は何もしないので、続く空行や先頭の空行が大きさ 0 の段落を作ることはありません。

ループを抜けるのは入力の終わりに着いたときで、そこで空行が読めるわけではありません。最後の段落は閉じる空行が来ないまま残るので、ループのあとでもう一度 count を足します。この後始末を忘れると、"a\nb\n\nc\n" から {2} しか返りません。入力の終わりを最後の空行のように扱いたくなりますが、getline にとって空行は読めた行で、入力の終わりは読めなかったことなので、ループの中では区別されます。

掲載したのは参考実装で、唯一の正解ではありません。空行で段落を閉じる代わりに、段落の最初の行(入力の先頭か空行の直後にある、空でない行)で sizes.push_back(0) して段落を始め、行ごとに ++sizes.back() する書き方なら、ループのあとの後始末は要りません。
