swap_ints.cpp

void swap_ints(int &a, int &b) {
    // write this: swap the values referred to by a and b
}

swap_intsを実装してください。参照aとbが指している値を入れ替えます。

Reference 
void swap_ints(int &a, int &b) {
    int tmp = a;
    a = b;
    b = tmp;
}

参照はすでに呼び出し元の変数そのものの別名なので、Cのポインタ版のように*で明示的に間接参照する必要がなく、a・bを直接読み書きするだけで呼び出し元に反映されます。これは参考実装であり、唯一の正解ではありません — 実務では自作せずに<utility>のstd::swap(a, b)を使うのが普通です。
