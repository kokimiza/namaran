take_stock.cpp

#include <atomic>

bool take(std::atomic<int>& stock, int n) {
}

在庫の数 stock が n 以上なら n だけ減らして true を、足りなければ stock を変えずに false を返す take を書いてください。n は 0 以上です。複数のスレッドが同じ stock に対して同時に take を呼んでも、stock が負にならず、true を返した分だけ正確に減るようにします。std::mutex などのロックは使いません。例では、呼ぶ前の stock の値を stock = 5; のように前に書き、出力には戻り値と呼んだあとの stock を並べます。

入力例 1

stock = 5; take(stock, 3)

出力例 1

true, stock = 2

入力例 2

stock = 2; take(stock, 3)

出力例 2

false, stock = 2

入力例 3

stock = 2; take(stock, 2)

出力例 3

true, stock = 0

bool take(std::atomic<int>& stock, int n) {
    int current = stock.load();
    while (current >= n) {
        if (stock.compare_exchange_weak(current, current - n)) {
            return true;
        }
    }
    return false;
}

if (stock >= n) { stock -= n; return true; } と書くと、1つのスレッドでは正しく動きます。stock の読み出しと -= はどちらも不可分ですが、その2つの間に隙間があります。stock が 1 のとき、2つのスレッドが take(stock, 1) を同時に呼ぶと、両方が stock >= 1 を確かめ終えてから両方が減らし、stock は -1 になります。確かめた時点の値と、減らす時点の値が同じだという保証はありません。

compare_exchange_weak(current, current - n) は、stock がまだ current と等しければ current - n に書き換えて true を返す、という確認と書き換えを1回の不可分な操作で行います。その間に別のスレッドが stock を変えていれば書き換えずに false を返し、そのときの stock の値を current に書き戻します。ループの条件 current >= n は、この新しい値で確かめ直されます。足りなくなっていれば false を返し、まだ足りていればもう一度書き換えを試みます。weak の版は、値が等しくても失敗することがありますが、ループで試し直すので結果は変わりません。

入力例 3 の stock = 2; take(stock, 2) は、2 >= 2 なので書き換えが成功し、stock はちょうど 0 になります。入力例 2 は最初から 2 >= 3 が偽なので、一度も書き換えずに false を返します。検証では、在庫 1000 に対して8つのスレッドが1000回ずつ take(shared, 1) を呼び、true がちょうど1000回返って在庫が 0 で止まることを確かめました。掲載したのは参考実装で、唯一の正解ではありません。compare_exchange_strong を使っても、ループの形は同じです。
