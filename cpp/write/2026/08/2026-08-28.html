shirt_index.cpp

enum class Size { S, M, L };
enum class Color { Red, Blue };

struct Shirt {
    Size size;
    Color color;
};

int index(Shirt s) {
}

Shirt の値は、3通りの size と2通りの color の組で、全部で6通りあります。この6通りに0から5までの番号を重複なく振る index を書いてください。番号は size が S、M、L の順に小さく、size が同じなら color が Red のほうを小さくします。

入力例 1

index({Size::S, Color::Red})

出力例 1

0

入力例 2

index({Size::M, Color::Blue})

出力例 2

3

入力例 3

index({Size::L, Color::Blue})

出力例 3

5
Reference 
int index(Shirt s) {
    return static_cast<int>(s.size) * 2 + static_cast<int>(s.color);
}

enum class の値は整数へ暗黙には変換されないので、static_cast<int> で取り出します。列挙子は宣言の順に0から番号を持つので、size は0から2、color は0か1になります。

同じ size の Shirt は color の数と同じ2つずつあるので、size ごとに連続した2つの番号を割り当てます。size の区画は size * 2 から始まり、その中で color を足します。最大は L と Blue の 2 × 2 + 1 = 5 で、0から5までの6個の番号が隙間なく埋まります。6は3と2の積で、組の値の数が要素ごとの数の積になることと対応しています。

掲載したのは参考実装で、唯一の正解ではありません。6通りを switch で並べても同じ番号を返せますが、Size に列挙子を1つ足すたびに書き足す行が増えます。
