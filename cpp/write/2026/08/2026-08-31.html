floor_div.cpp

int floor_div(int a, int b) {
}

a / b の値を超えない最大の整数を返す floor_div を書いてください。ここでの a / b は数学の割り算で、7 ÷ 2 = 3.5 なら3、-7 ÷ 2 = -3.5 なら -4 です。割り切れるときは商そのものを返します。b は0でなく、a と b は正にも負にもなり、答えは int に収まるものとします。

入力例 1

floor_div(-7, 2)

出力例 1

-4

入力例 2

floor_div(7, -2)

出力例 2

-4

入力例 3

floor_div(-6, 2)

出力例 3

-3

Reference

int floor_div(int a, int b) {
    int q = a / b;
    if (a % b != 0 && (a < 0) != (b < 0)) {
        --q;
    }
    return q;
}

C++ の a / b は商の小数部分を捨て、0の方向へ切り捨てます。商が正なら0の方向は小さい方なので、そのまま求める値になります。ずれるのは商が負で、しかも割り切れないときだけです。-3.5 を0の方向へ切り捨てると -3 で、求める -4 より1大きくなります。商が負になるのは a と b の符号が違うときで、割り切れないのは a % b が0でないときなので、両方がそろったときだけ q を1減らします。これは参考実装で、唯一の正解ではありません。

入力例1は -7 / 2 が -3、余りが -1 で符号も違うので -4 になります。入力例2は割る数の側が負ですが、符号が違うことに変わりはなく、同じように -3 から -4 に下がります。入力例3は -6 % 2 が0で割り切れるので補正はせず、-3 のままです。符号の比較を a * b < 0 と書くと、掛け算が int の範囲を超えるおそれがあるので、ここでは (a < 0) != (b < 0) で比べています。
