shape_clone.cpp

#include <memory>

struct Shape {
    virtual ~Shape() = default;
    virtual double area() const = 0;
    virtual std::unique_ptr<Shape> clone() const = 0;
};

struct Circle : Shape {
    double radius;
    explicit Circle(double r) : radius(r) {}
    double area() const override { return 3.14159265358979 * radius * radius; }
    std::unique_ptr<Shape> clone() const override {
    }
};

Shapeはポリモーフィックな図形の基底クラスです。値渡しやShape型の変数への代入はスライシングを起こしてしまうため、複製が必要なときは代わりにclone()を呼び、自分自身と同じ動的型を持つ複製をstd::unique_ptr<Shape>として返してもらいます(Virtual Constructor / Clone イディオム)。Circleのclone()を書いてください。radiusをそのままコピーした新しいCircleを返すだけです。Circle c(3.0); c.clone()->area() == c.area() → true、Circle c(2.0); dynamic_cast<Circle*>(c.clone().get()) != nullptr → true(複製の動的型もCircleのまま)、Circle c(0.0); c.clone()->area() → 0(境界: 半径0)

Reference 
std::unique_ptr<Shape> clone() const override {
    return std::make_unique<Circle>(*this);
}

Circle::cloneは、自分の具体的な型(Circle)を知っているCircle自身の中でstd::make_unique<Circle>(*this)のように複製を作るので、基底クラス経由で値コピーするときのようなスライシングが起こりません。呼び出し側がShape型のポインタしか持っていなくても、仮想関数clone()を通じて動的型に応じた正しい複製を得られます。これは参考実装であり、唯一の正解ではありません(std::shared_ptrを返す設計にする、CRTPでclone()の実装を使い回す、といった書き方もできます)。
