std::vector<std::string> read_names(std::istream& in) {
}

1行目に人数 n があり、続く n 行に1人ずつ名前が書かれた入力を in から読み、名前を順に並べた std::vector を返す read_names を書いてください。名前は行全体で、先頭や途中の空白も含み、空の行は空の名前として扱います。1行目の数字のあとに空白が続くこともあります。n が0なら空の std::vector を返します。入力例は、in の中身をC++の文字列リテラルで書いたものです。

入力例 1

"2\nAnn Lee\nBob\n"

出力例 1

{"Ann Lee", "Bob"}

入力例 2

"2\n  x\n\n"

出力例 2

{"  x", ""}

入力例 3

"0\n"

出力例 3

{}

#include <istream>
#include <limits>
#include <string>
#include <vector>

std::vector<std::string> read_names(std::istream& in) {
    int n = 0;
    in >> n;
    in.ignore(std::numeric_limits<std::streamsize>::max(), '\n');
    std::vector<std::string> names(n);
    for (auto& s : names) std::getline(in, s);
    return names;
}

in >> n は数字を読んだところで止まり、そのあとの空白と改行はストリームに残します。ここですぐに std::getline を呼ぶと、1行目の残りの改行までを1人目の名前として読み、入力例1は {"", "Ann Lee"} になります。

残った改行を読み飛ばすのに in >> std::ws を使うと、今度は読み飛ばしすぎます。std::ws は改行も空白も区別せず、空白でない文字が来るまで読み捨てるので、入力例2では1人目の先頭の空白まで消え、{"x", ""} になります。1人目が空の名前なら、その空の行ごと消えてしまいます。参考実装の ignore は、最初の '\n' までを読み捨てたところで止まるので、数字のあとの空白と改行だけが消え、2行目は手つかずで残ります。そこから getline を n 回呼べば、改行を除いた各行がそのまま名前になります。

掲載したのは参考実装で、唯一の正解ではありません。1行目も getline で読んで std::stoi で数に直せば、改行が残る問題はそもそも起きません。
