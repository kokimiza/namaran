WalReplay.hs

module Main where

import qualified Data.Map as Map

data Entry = Put String Int | Delete String deriving Show

replay :: [Entry] -> Map.Map String Int
replay = foldl step Map.empty
  where
    step m (Put k v) = Map.insert k v m
    step m (Delete k) = Map.delete k m

main :: IO ()
main = do
  let wal = [Put "a" 1, Put "b" 2, Put "a" 3, Delete "b", Put "c" 4]
  print (Map.toList (replay wal))

このプログラムは何を出力するでしょうか?

Answer

[("a",3),("c",4)]です。replayはログ[Entry]を先頭からfoldlで1件ずつ適用し、Mapとして持つ状態を組み立てます。これはWrite-Ahead Logging(WAL)——変更を適用する前にまず追記専用のログへ記録しておき、障害から復旧するときはそのログを最初から読み直して状態を再構築する仕組み——の「復元」の部分を、純粋なfoldlとして書いたものです。walを先頭から適用すると、Put "a" 1で{a: 1}、Put "b" 2で{a: 1, b: 2}、Put "a" 3でaの値が上書きされて{a: 3, b: 2}、Delete "b"でbが消えて{a: 3}、最後のPut "c" 4で{a: 3, c: 4}になります。Map.toListはキーの昇順で列挙するので、出力はa・cの順で[("a",3),("c",4)]になります。
