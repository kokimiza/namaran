Loops.hs

import Control.Monad (forM_)

main :: IO ()
main = do
  forM_ [1 .. 3 :: Int] $ \i ->
    putStrLn (replicate i '*')
  print (until (> 100) (* 2) (1 :: Int))
  print (until (> 100) (* 2) (200 :: Int))

これは何を出力するでしょうか?

Answer

*、**、***、128、200 の5行です。

forM_ はリストの要素を1つずつ関数に渡し、返ってきた IO アクションを順に実行します。[1 .. 3] は 1、2、3 なので、replicate i '*' で長さ1から3の行が並びます。命令型言語の for (i = 1; i <= 3; i++) にあたり、上限の 3 も範囲に含まれます。

until p f x は、p x が真になるまで x に f を繰り返し適用し、そのときの値を返します。条件は f を適用する前に調べるので、while ループと同じ順序です。1 から倍にしていくと 2, 4, … , 64, 128 と進み、初めて 100 を超えた 128 で止まります。200 は最初から (> 100) を満たすので、(* 2) は一度も適用されず、200 がそのまま返ります。
