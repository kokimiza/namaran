Reserve.hs

import Control.Monad (replicateM, when)
import Data.IORef

main :: IO ()
main = do
  stock <- newIORef (1 :: Int)
  let reserve = do
        s <- readIORef stock
        pure (when (s > 0) (modifyIORef stock (subtract 1)))
  commits <- replicateM 2 reserve
  sequence_ commits
  readIORef stock >>= print

これは何を出力するでしょうか?

Answer

-1 です。

reserve を実行して起きるのは、在庫を読むことだけです。pure (when …) は在庫を減らすIOアクションを組み立てて結果として返すだけで、その中の modifyIORef はまだ実行されていません。replicateM 2 reserve は reserve を2回実行しますが、どちらも在庫を読むだけなので、2回とも s は 1 です。

when (s > 0) の条件は、この読んだ時点の s で決まります。sequence_ commits が2つのアクションを実行するときに在庫は読み直されず、どちらも条件が真のまま subtract 1 を適用するので、1 から2回引いて -1 になります。2回目の確認で 0 を見て止まると考えると 0 と答えたくなりますが、2回目の確認は1回目の減算より前に終わっています。
