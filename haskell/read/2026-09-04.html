FlipLines.hs

flipLines :: String -> String
flipLines = unlines . reverse . lines

main :: IO ()
main = do
  print (flipLines "a\nb")
  print (flipLines "a\nb\n\n")
  print (flipLines (flipLines "a\nb"))
  print (flipLines (flipLines "a\nb\n\n"))

これは何を出力するでしょうか?

Answer

"b\na\n"、"\nb\na\n"、"a\nb\n"、"a\nb\n\n" の4行です。

lines は '\n' を行の終わりとして文字列を区切ります。最後の '\n' の後に何も残っていなければ、そこに空の行は作りません。"a\nb" は ["a","b"]、"a\nb\n\n" は ["a","b",""] です。末尾の '\n' は直前の空行を終わらせるだけなので、空文字列は1つしかできません。

unlines は各行の後ろに '\n' を1つずつ付けてつなぎます。["b","a"] は "b\na\n" になり、元の "a\nb" になかった末尾の改行が増えます。["","b","a"] は "\nb\na\n" で、空行が先頭に移ります。

2回目の flipLines は1回目の結果を区切り直します。"b\na\n" は末尾の改行を含めて ["b","a"] に戻るので、結果は "a\nb\n" で、元の "a\nb" とは一致しません。"\nb\na\n" のほうは ["","b","a"] になり、反転してつなぐと元の "a\nb\n\n" にちょうど戻ります。unlines (lines s) が s に戻るのは、s が空か '\n' で終わるときだけです。
