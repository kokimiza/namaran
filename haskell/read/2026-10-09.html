Words.hs

import Control.Monad (replicateM)

main :: IO ()
main = putStrLn (replicateM 3 "ab" !! 5)

これは何を出力するでしょうか?

Answer

bab です。

リストのモナドでは、replicateM 3 "ab" は "ab" から1文字選ぶことを3回繰り返した組み合わせを、すべて文字列にして並べます。do で書けば do { x <- "ab"; y <- "ab"; z <- "ab"; return [x, y, z] } と同じで、先に書いた選択ほど外側のループになるので、左の文字ほどゆっくり変わります。

並びは aaa、aab、aba、abb、baa、bab、bba、bbb の順です。a を0、b を1と読めば、0から7までを3桁の2進数で数えた順になります。!! の添字は0から数えるので、添字5は先頭から6番目で、2進数の 101 にあたる bab です。
