Step.hs

step :: Int -> Int -> Int
step x = (+ x) . (* 2)

main :: IO ()
main = print (foldr step 0 [1, 2, 3], foldl step 0 [1, 2, 3])

これは何を出力するでしょうか?

Answer

(17,12) です。

step の定義に書かれた引数は x の1つだけですが、右辺の (+ x) . (* 2) は関数なので、step x はもう1つ引数を受け取ります。合成は右側の関数から適用されるので、2つ目の引数を y とすると step x y = y * 2 + x です。2倍されるのは、定義に名前の出てこない2つ目の引数のほうです。

foldr は要素を1つ目の引数に、それまでの結果を2つ目の引数に渡し、右端から計算します。step 3 0 = 3、step 2 3 = 8、step 1 8 = 17 です。

foldl は逆に、それまでの結果を1つ目、要素を2つ目に渡し、左端から計算します。step 0 1 = 2、step 2 2 = 6、step 6 3 = 12 です。2倍されるのが foldr ではそれまでの結果、foldl では要素なので、同じ step と同じリストでも結果が分かれます。

定義を左から読んで step x y = x * 2 + y と取り違えると、(12,11) になります。
