CentsHalf.hs

module Main where

newtype Cents = Cents Integer deriving (Eq, Show)

half :: Cents -> Cents
half (Cents n) = Cents (n `div` 2)

main :: IO ()
main = print (half (Cents (-3)))

このプログラムは何を出力するでしょうか?

Answer

Cents (-2)です。Centsは小数(セント単位の金額)を、100分の1を単位とする整数として扱う固定小数点数の型で、halfは中身の整数をそのまま2で割っています。Haskell 2010の仕様では、divは負の無限大方向への切り捨て(floor division)と定義されており、0方向への切り捨てであるquotとは丸め方向が異なります。-3 `div` 2は、実数として-1.5をさらに小さい方向へ切り捨てるので-2になります(-3 `quot` 2なら0に近い-1になります)。固定小数点数を「ただの整数」として扱っているぶん、こうした整数除算の丸め方向の違いがそのまま計算結果に表れます。
