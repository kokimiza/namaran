Boxes.hs

{-# LANGUAGE ExistentialQuantification #-}

data Box = forall a. Show a => Box a

instance Show Box where
  show (Box x) = show x

main :: IO ()
main = do
  print ['a', 'b']
  print [Box 'a', Box 'b']
  print [Box 'a', Box "b"]

これは何を出力するでしょうか?

Answer

"ab"、['a','b']、['a',"b"] の3行です。

1行目の ['a', 'b'] の型は [Char]、すなわち String なので、print は "ab" と文字列の形で表示します。リストをどう表示するかは、要素の型の Show インスタンスが持つ showList が決めます。引用符で囲んで文字を並べる showList を定義しているのは Char のインスタンスです。

2行目の要素は Box です。Box 'a' の中身は Char ですが、リストの型は [Box] なので、showList を選ぶのは Box のインスタンスです。このインスタンスは show しか定義していないため、showList には既定の実装が使われ、要素を1つずつ show して角括弧とカンマで並べます。各要素の show は中の Char の show を呼ぶので、['a','b'] が出ます。

3行目は、Char と String という型の違う値を同じリストに入れています。[Box] は中身の型を問わないので、このように並べられます。表示の形は2行目と同じで、"b" の引用符は String の show が付けたものです。

data Box = forall a. Show a => Box a のように、型 Box の引数に現れない型変数 a を forall で導入する書き方は、Haskell 2010 の言語標準にはありません。GHC の拡張機能 ExistentialQuantification によるもので、先頭の LANGUAGE プラグマで有効にしています。Box は値と一緒に、その型の Show の実装を持ち運ぶので、中身の型が隠れていても show を呼べます。
