Frames.hs

import Data.List (mapAccumL)

split :: String -> ([String], String)
split s = case break (== '\n') s of
  (msg, _ : rest) -> let (ms, left) = split rest in (msg : ms, left)
  (partial, _) -> ([], partial)

step :: String -> String -> (String, [String])
step buf chunk = let (ms, left) = split (buf ++ chunk) in (left, ms)

main :: IO ()
main = print (mapAccumL step "" ["HE", "LLO\nWO", "RLD\n\nBY"])

これは何を出力するでしょうか?

Answer

("BY",[[],["HELLO"],["WORLD",""]]) です。

mapAccumL は、リストの要素を左から順に step に渡しながら、1つ目の引数（ここでは届いたのにまだ区切れていない残り）を次の呼び出しへ持ち越します。結果は「最後に残った持ち越し」と「各要素に対する出力のリスト」の組で、持ち越しが組の左に来ます。step は、前回の残りに今回の塊をつなげ、split で改行ごとに切り出したメッセージを出力にし、改行のあとに残った途中の部分を次へ渡します。

1つ目の塊 "HE" には改行がないので、メッセージは出ず、"HE" が持ち越されます。2つ目でつながった "HELLO\nWO" からは "HELLO" が切り出され、"WO" が残ります。3つ目の "WORLD\n\nBY" では、"WORLD" を切り出したあとの残り "\nBY" が改行で始まります。break は改行の前の空文字列と改行以降に分けるので、"" も1つのメッセージになります。最後の "BY" は改行で終わっていないので、どのメッセージにもならず、最後の持ち越しとして組の左に残ります。
