Sixths.hs

import Data.Ratio

main :: IO ()
main = do
  let xs = [n % 6 | n <- [2, 3, 4]] :: [Rational]
  print (sum xs)
  print (map numerator xs)

これは何を出力するでしょうか?

Answer

3 % 2 と [1,1,2] の2行です。

% は、分子と分母を最大公約数で割ってから値を作ります。2 % 6、3 % 6、4 % 6 は作られた時点で 1 % 3、1 % 2、2 % 3 になり、分母が 6 の形はどこにも残りません。

numerator が返すのも約分したあとの分子なので、書いたときの [2,3,4] ではなく [1,1,2] になります。和の 9/6 も同じように約分され、3 % 2 と表示されます。
