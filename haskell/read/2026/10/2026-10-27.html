Cell.hs

import Data.Char (ord)

width :: String -> Int
width = sum . map (\c -> if ord c < 0x1100 then 1 else 2)

cell :: Int -> String -> String
cell n s = take n (s ++ repeat ' ')

main :: IO ()
main = do
  let names = ["tea", "お茶", "🍵"]
      n = maximum (map width names)
  print [width (cell n s) | s <- names]

これは何を出力するでしょうか?

Answer

[4,6,5] です。

width は、コードポイントが 0x1100 より小さい文字を幅1、それ以外を幅2として足し合わせます。"tea" は3、"お茶" は2文字とも幅2なので4です。Haskell の Char は Unicode のコードポイント1つを表すので、"🍵"(U+1F375)は1つの Char で、幅は2です。n はこの最大の4になります。

repeat ' ' は空白が限りなく続くリストですが、遅延評価なので、take n が先頭から n 個を取り出したところで評価は止まり、その先の空白は作られません。take が数えるのは Char の個数で、表示幅ではありません。

cell 4 は、どの名前も4個の Char にそろえます。"tea " は幅4です。"お茶" は2個なので空白が2つ付いて、幅は2と2と1と1で6になります。"🍵" は1個なので空白が3つ付き、幅は2と3で5です。

n を表示幅で求めているので表がそろうと読むと [4,4,4] に、絵文字は UTF-16 のように2つの Char になると読むと [4,6,4] になります。
