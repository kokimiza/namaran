Counts.hs

import qualified Data.Map as M

counts :: M.Map Char Int
counts = M.insertWith (+) 'a' (error "bad") (M.fromList [('a', 1), ('b', 2)])

main :: IO ()
main = do
  print (M.keys counts)
  print (M.lookup 'b' counts)

これは何を出力するでしょうか?

Answer

"ab" と Just 2 の2行を出力し、エラーにならずに終わります。

Data.Map は、値を遅延評価する Data.Map.Lazy と同じものです。M.insertWith (+) 'a' (error "bad") は、キー 'a' の値を error "bad" + 1 という未評価の式(サンク)に置き換えるだけで、足し算はしません。

M.keys が見るのはキーだけで、M.lookup 'b' が取り出すのは 'b' の値 2 です。どちらも 'a' の値を評価しないので、error は一度も呼ばれません。キーの一覧は [Char]、つまり String なので、print は "ab" と書きます。print (M.lookup 'a' counts) を足すと、そこで初めてサンクが評価され、bad を表示して止まります1。

  1. Data.Map.Strict の insertWith は、値を表に入れる前に弱頭部正規形まで評価します。読み込むモジュールを Data.Map.Strict に替えると、最初の print が表を作ろうとした時点で bad になります。
