Snapshot.hs

import Data.IORef

main :: IO ()
main = do
  ref <- newIORef [1, 2, 3 :: Int]
  before <- readIORef ref
  modifyIORef ref (map (* 10))
  after <- readIORef ref
  print (before, after)

これは何を出力するでしょうか?

Answer

([1,2,3],[10,20,30]) です。

書き換えられるのは IORef という箱だけで、箱に入っているリストは不変な値です。readIORef ref はその時点で箱に入っているリスト [1,2,3] を返し、before はこの値に束縛されます。modifyIORef ref (map (* 10)) は、いまのリストから map で新しいリスト [10,20,30] を作り、箱の中身をそれに差し替えます。元のリスト [1,2,3] 自体はどこも書き換えられないので、before は [1,2,3] のままで、2回目の readIORef で読んだ after だけが新しいリストになります。

Java や Python のように、読み出した値が箱の中のリストと同じ可変なオブジェクトを指していると考えると、before も書き換わって ([10,20,30],[10,20,30]) と答えることになります。Haskell のリストは作ったあとに変わらないので、読み出した値は、コピーを取らなくてもその時点の中身として残ります。
