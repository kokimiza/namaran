Boxes.hs

import Data.IORef

main :: IO ()
main = do
  a <- newIORef 'x'
  b <- newIORef 'x'
  let c = a
  print (a == b, a == c)
  writeIORef c 'y'
  readIORef a >>= print

これは何を出力するでしょうか?

Answer

(False,True) と 'y' の2行です。

IORef の == は中身を比べません。比べるのは、2つの IORef が同じ書き換え可能な場所を指しているかどうかです。a と b はどちらも 'x' を入れて作りましたが、newIORef を2回呼んだので別々の場所を指し、a == b は False になります1。

let c = a は新しい IORef を作らず、同じ参照に c という名前をもう1つ付けるだけです。そのため a == c は True で、c に 'y' を書き込めば、a から読んでも 'y' が返ります。

  1. Eq (IORef a) のインスタンスは、中身の型 a に Eq を要求しません。関数を入れた IORef どうしでも == で比べられるのは、中身を見ないからです。
