Steps.hs

steps :: [Int] -> [Int]
steps (x : rest@(y : _)) = (y - x) : steps rest
steps _ = []

main :: IO ()
main = print (steps [1, 4, 9, 16])

これは何を出力するでしょうか?

Answer

[3,5,7] です。

rest@(y : _) は、x の後ろのリストに rest という名前を付けたうえで、その先頭を y と呼ぶパターンです。rest は y を含んだ後ろ全体なので、steps rest の次の呼び出しでは、今の y が x になります。

[1, 4, 9, 16] では、最初に x が1、y が4で 3 を作り、[4, 9, 16] で再帰します。次は4と9で 5、その次は9と16で 7 です。[16] は要素が1つなので最初の式に合わず、steps _ = [] でリストが終わります。
