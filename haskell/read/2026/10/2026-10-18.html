Discount.hs

data Item
  = Book { title :: String, price :: Int }
  | Pen { price :: Int, color :: String }
  deriving Show

discount :: Item -> Item
discount i = i { price = price i - 1 }

main :: IO ()
main = mapM_ (print . discount) [Book "SICP" 50, Pen 3 "red"]

これは何を出力するでしょうか?

Answer

Book {title = "SICP", price = 49} と Pen {price = 2, color = "red"} の2行です。

price は Book にも Pen にもあるフィールドなので、セレクタ price も、更新 i { price = ... } も、どちらの構成子の値にも使えます。フィールドの位置は構成子ごとに違い、Book では2番目、Pen では1番目です。そのため Pen 3 "red" の価格は 3 で、discount で1ずつ引かれた価格は 49 と 2 になります。

deriving Show で作った show は、レコード構文で定義した構成子をフィールド名つきで、宣言の順に表示します。位置が違っても、それぞれの構成子の宣言どおりに Book は title から、Pen は price から並びます。

どの値に使っても失敗しないのは、フィールドがすべての構成子にあるときだけです。title や color のように一方の構成子にしか無いフィールドは、もう一方の構成子の値に使うと、型検査は通ったまま実行時に例外になります。
