Runs.hs

import Data.List (group)

rle :: [Int] -> [(Int, Int)]
rle xs = [(x, length g) | g@(x : _) <- group xs]

main :: IO ()
main = print (take 4 (rle (cycle [1, 2, 1])))

これは何を出力するでしょうか?

Answer

[(1,1),(2,1),(1,2),(2,1)] です。

rle は、同じ値が続く区間を「値と、続く個数」の組に置き換えるランレングス圧縮(run-length encoding)です。group が隣り合う等しい要素をリストにまとめ、内包表記がそれぞれを (x, length g) にします。cycle [1, 2, 1] は終わりのない無限リストですが、group は先頭から必要な分だけグループを作るので、take 4 が4組を取った時点で評価は止まります。各グループも、値が切り替わったところで閉じる有限のリストなので、length g も終わります。

元の [1, 2, 1] だけを見ると、圧縮は (1,1),(2,1),(1,1) の繰り返しに見えます。しかし cycle は前の周の末尾の 1 のすぐ後ろに次の周の先頭の 1 を並べるので、実際のリストは 1, 2, 1, 1, 2, 1, 1, 2, ... です。継ぎ目で2つの 1 が隣り合い、1つの区間にまとまります。そのため3組目は (1,2) になり、2周目からは (2,1),(1,2) が交互に続きます。
