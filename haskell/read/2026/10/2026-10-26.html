LineFlush.hs

import System.Directory (getFileSize)
import System.IO

main :: IO ()
main = do
  h <- openFile "progress.log" WriteMode
  hSetBuffering h LineBuffering
  hPutStr h "step 1"
  getFileSize "progress.log" >>= print
  hPutStrLn h " done"
  getFileSize "progress.log" >>= print
  hPutStr h "step 2"
  hClose h
  getFileSize "progress.log" >>= print

これは何を出力するでしょうか?

Answer

0、12、18 を1行ずつ出力します。

hPutStr で書いた文字は、まずプログラムの中にある Handle のバッファに入り、バッファを空にしたときにはじめてOSへ渡されます。getFileSize はOSにファイルの大きさを問い合わせるので、バッファに残っている文字は数えません。1

LineBuffering は、改行を書いたときにバッファを空にするモードです。"step 1" には改行がないのでバッファに残り、1回目は 0 です。hPutStrLn が " done" と改行を書くとバッファが空になり、"step 1 done\n" の12バイトがファイルに届きます。続く "step 2" はまたバッファに残りますが、hClose は閉じる前にバッファを空にするので、3回目は 12 + 6 の 18 です。

書くたびにファイルへ届くと読むと 6、12、18 に、閉じるまで何も届かないと読むと 0、0、18 になります。バッファを空にしても、データはOSのメモリ上のキャッシュに移っただけで、記憶装置に書かれたとは限りません。電源が落ちても残すには、さらにOSに同期を求めます。2

  1. getFileSize は Haskell 2010 の標準ライブラリではなく、GHC に同梱の directory パッケージの関数です。
  2. Haskell 2010 の System.IO には、OSに同期を求める関数がありません。GHC では、POSIX の unix パッケージにある fileSynchronise が fsync(2) を呼びます。
