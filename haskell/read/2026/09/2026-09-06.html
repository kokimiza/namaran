Stock.hs

table :: [(Char, Maybe Int)]
table = [('a', Just 2), ('b', Nothing), ('c', Just 1)]

main :: IO ()
main = putStrLn [k | (k, Just n) <- table, _ <- [1 .. n]]

これは何を出力するでしょうか?

Answer

aac です。

内包表記の生成器は左から順に入れ子のループになり、右にある生成器ほど内側で回ります。外側の (k, Just n) <- table は、table の要素を1つずつ取り出してこのパターンに当てはめます。

パターンに合わない要素は、エラーにならずに飛ばされます1。('b', Nothing) は Just n に合わないので、'b' は結果に出てきません。case や let でパターンが外れれば実行時エラーですが、生成器の左辺では外れた要素を捨てるだけです。

内側の _ <- [1 .. n] は値を使いませんが、[1 .. n] の要素の数だけ、外側の1回分を繰り返します。'a' は n が 2 なので2回、'c' は n が 1 なので1回出て、"aac" になります。値を使わない生成器を飾りと読むと ac、Nothing の要素で止まると読むと実行時エラー、という誤答になります。

  1. Haskell 2010 の報告書では、生成器 p <- l を、p に合う要素では残りを続け、合わない要素では空リストを返す関数を l に concatMap する形に変換すると定めています。
