Cancel.hs

import Control.Monad (when)
import Data.IORef
import System.IO.Error (catchIOError)

main :: IO ()
main = do
  total <- newIORef (0 :: Int)
  let add x = do
        modifyIORef total (+ x)
        when (x == 3) $ ioError (userError "cancel")
  mapM_ add [1 .. 5] `catchIOError` \_ -> return ()
  readIORef total >>= print

これは何を出力するでしょうか?

Answer

6 です。

mapM_ add [1 .. 5] は add 1 から順に実行し、add 3 の中で ioError が例外を投げた時点で止まります。残りの add 4 と add 5 は実行されず、例外は catchIOError のハンドラに渡されて、return () で何もせずに終わります。

例外より前に行われた modifyIORef は取り消されません。add 3 は total に3を足してから例外を投げるので、total には 1 + 2 + 3 = 6 が残ります。catchIOError は例外を受け止めるだけで、それまでに IORef へ書き込んだ値を元に戻す仕組みは持っていません。

3だけを飛ばして続きが実行されると考えると12、例外で書き込みがすべて取り消されると考えると0と答えることになります。止まった処理の途中までの書き込みを残したくないなら、書き込む前に検査を済ませるか、ハンドラの中で自分で元の値に戻します。
