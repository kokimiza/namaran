import qualified Data.Map as Map

events :: [(String, String)]
events = [("ann", "a@old"), ("bob", "b@x"), ("ann", "a@new")]

main :: IO ()
main = do
  print (Map.toList (Map.fromList events))
  print (Map.toList (Map.fromListWith (++) [(k, [v]) | (k, v) <- events]))

これは何を出力するでしょうか?

Answer

1行目は[("ann","a@new"),("bob","b@x")]、2行目は[("ann",["a@new","a@old"]),("bob",["b@x"])]です。Map.fromListはリストを先頭から順にinsertしていくのと同じで、同じキーは後から来た値で上書きされます。履歴を古い順に並べておけば、これだけで「いまの値」が再構築できます。Map.fromListWith fは、同じキーが来たときf 新しい値 古い値で1つにまとめます。annでは["a@new"] ++ ["a@old"]になるので、履歴は新しい順に並びます。toListはキーの昇順なので、annがbobより先です。古い順の履歴が欲しければ、flip (++)を渡すか、できあがったリストをreverseします(flip (++)は長い履歴では遅くなります)。なおData.MapはHaskell 2010の報告書の標準ライブラリではなく、GHCに同梱されるcontainersパッケージのモジュールです(言語拡張は使っていません)。
