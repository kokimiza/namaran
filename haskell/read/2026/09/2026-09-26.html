Choose.hs

module Main (main) where

choose :: Bool -> a -> a -> a
choose True t _ = t
choose False _ e = e

main :: IO ()
main = do
  print (choose True 1 (length [1 :: Int ..]))
  print (choose False (error "never") (2 + 3 :: Int))

これは何を出力するでしょうか?

Answer

1 と 5 が1行ずつ出力されます。

Haskell の関数呼び出しは、引数を評価してから本体に入るのではなく、引数を未評価のサンクのまま渡します。引数が評価されるのは、本体がその値を必要としたときです。choose True 1 (length [1 :: Int ..]) は1つ目の等式に合い、返すのは t だけなので、無限リストの長さを数える3つ目の引数は一度も評価されずに捨てられます。2つ目の呼び出しで使われるのは e だけで、error "never" も評価されません。等式を選ぶためのパターン照合で評価されるのは、1つ目の引数の Bool だけです。

引数を先に評価する言語でこの choose を書くと、呼び出す前に両方の引数を計算するので、1行目は終わらず、2行目は例外で止まります。そうした言語では if や && を言語が特別扱いしますが、Haskell では && も Prelude の普通の関数として、choose と同じように等式で定義されています。
