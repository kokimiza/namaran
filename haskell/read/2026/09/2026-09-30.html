Shout.hs

import Data.Char (toUpper)

shout :: String -> String
shout = map toUpper

main :: IO ()
main = do
  print (length (shout "straße"))
  print (shout "straße" == shout "STRASSE")

これは何を出力するでしょうか?

Answer

6 と False の2行です。

shout は map toUpper なので、文字を1つずつ別の1文字に置き換えます。map はリストの長さを変えないので、6文字の "straße" からは6文字の文字列が返り、1行目は 6 です。

ドイツ語では ß を大文字で SS と2文字で書くのが普通ですが、toUpper の型は Char -> Char で、1文字を2文字に増やせません。一方 shout "STRASSE" は7文字の "STRASSE" のままです。長さが違うので、2行目の比較は False になります。

toUpper は、実行する環境のロケールを見ません。Unicode が文字ごとに決めた対応表だけを使うので、ドイツ語のロケールで動かしても結果は変わりません1。

  1. Unicode の1文字どうしの対応表では、ß に大文字が割り当てられていないので、toUpper 'ß' は 'ß' のままです。大文字の ẞ(U+1E9E)という文字はありますが、この表では ß から ẞ へは写しません。ß を SS にする変換は、1文字を複数の文字にする特別な対応として別に定められています。
