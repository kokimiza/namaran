Reconcile.hs

import Data.List (intersect, union)

mine, theirs :: [Int]
mine = [3, 1, 3]
theirs = [3, 2, 2]

main :: IO ()
main = do
  print (mine `intersect` theirs, theirs `intersect` mine)
  print (mine `union` theirs, theirs `union` mine)

これは何を出力するでしょうか?

Answer

1行目に ([3,3],[3])、2行目に ([3,1,3,2],[3,2,2,1]) を出力します。

Data.List の intersect と union は、名前は積集合（intersection）と和集合（union）ですが、引数をリストのまま扱い、左のリストの並びと重複をそのまま残します。intersect xs ys は、xs の要素のうち ys にも現れるものを、xs の順に残します。mine `intersect` theirs では mine の 3、1、3 を順に調べ、theirs に現れる2つの3が残って [3,3] になります。左右を入れ替えた theirs `intersect` mine は 3、2、2 のうち3だけが残り、[3] です。

union xs ys は xs を丸ごと残し、その後ろに、ys から重複を除いたうえで xs に現れない要素を足します。mine `union` theirs は [3,1,3] の後ろに、theirs の 3 と 2 のうち mine に無い2を足して [3,1,3,2] です。theirs `union` mine は [3,2,2] の後ろに1を足して [3,2,2,1] になり、左の 2,2 の重複は消えません。どちらの関数も、左に置いたリストの重複は残り、右に置いたリストの重複は結果に入らないので、引数を入れ替えると結果が変わります1。

  1. 要素の重複を持たない集合として照合したいときは、Data.Set の union と intersection を使います。こちらは引数を入れ替えても同じ集合を返します。
