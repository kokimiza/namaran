Twice.hs

twice :: (a -> a) -> a -> a
twice f = f . f

main :: IO ()
main = print (twice twice twice twice (+ 1) (0 :: Int))

これは何を出力するでしょうか?

Answer

Output

65536

関数適用は左結合なので、twice twice twice twice (+ 1) 0 は ((((twice twice) twice) twice) (+ 1)) 0 です。twice の型 (a -> a) -> a -> a の a には、使う場所ごとに別の型が入ります。一番右の twice では a が Int -> Int で、その左の twice では a が「関数を受け取って関数を返す関数」の型になり、左へ行くほど型は大きくなります。twice は中身を見ずに関数を2回呼ぶだけなので、どの型に対しても同じ1つの定義が使えます。

twice twice を (+ 1) に当てはめていくように1段ずつ展開すると、すぐに追い切れなくなります。そこで「関数 h を受け取り、h を k 回適用する関数を返す」関数を、k 回の関数と呼んで考えます。twice は 2 回の関数です。k 回の関数 g を h の m 回適用に当てはめると、m 回を k 回繰り返すので m × k 回適用の関数が返ります。g を1回使うたびに、回数は k 倍になります。twice g は g を2回使うので、g が k 回の関数なら twice g は k × k 回の関数です。同じように、n 回の関数に k 回の関数を渡すと、g を n 回使うので、k の n 乗回の関数になります。

この見方で左から順に数えます。twice twice は 2 回の関数に 2 回の関数を渡すので、2 の 2 乗で 4 回の関数です。(twice twice) twice は 4 回の関数に twice を渡すので 2 の 4 乗で 16 回、((twice twice) twice) twice は 2 の 16 乗で 65536 回の関数です。最後にこれを (+ 1) と 0 に当てはめると、0 に 1 を 65536 回足して 65536 になります。

「2回」が4つ並んでいるので 2 × 2 × 2 × 2 で 16 回と読むと、16 と答えることになります。掛け算になるのは、twice (twice (twice (twice (+ 1)))) のように、どの twice も Int -> Int の関数を受け取るときです。この問題では twice が twice そのものを受け取るので、受け取った側は「回数を2倍にする」操作を2回行い、回数は掛け算ではなく累乗で増えます。1

  1. k 回の関数で自然数 k を表す方法は、チャーチ数（Church numeral）と呼ばれます。n 回の関数に k 回の関数を渡すと k の n 乗回の関数になる、という本文の計算は、この表し方で累乗を計算する定義そのものです。
