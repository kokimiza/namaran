BitStrings.hs

import Control.Monad (replicateM)
import Data.List (elemIndex)

main :: IO ()
main =
  print (elemIndex "110" (replicateM 3 "01"))

これは何を出力するでしょうか?

Answer

Output

Just 6

リストに対する replicateM 3 "01" は、do { a <- "01"; b <- "01"; c <- "01"; return [a, b, c] } と同じ値になります。リストのモナドでは、先に書いた a の選択が外側のループ、最後の c の選択がいちばん内側のループになります。a を '0' に決めたまま b と c を回し終えてから、a が '1' に進みます。

そのため結果は ["000","001","010","011","100","101","110","111"] の順に並び、右端がいちばん速く変わります。'0' と '1' を数字として読めば、0から7までを2進数で数えた順そのものです。"110" は2進数の6なので、0から数えて6番目にあります。elemIndex は見つからない場合に備えて Maybe Int を返すので、出力は Just 6 です。

左端がいちばん速く変わると読むと、位置は文字列を右から読んだ2進数で決まることになります。"110" は逆から読むと 011 なので、Just 3 と答えることになります。
