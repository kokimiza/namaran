Checks.hs

check :: Int -> IO Bool
check n = do
  print n
  pure (n > 1)

main :: IO ()
main = do
  ok <- (&&) <$> check 1 <*> check 2
  print (ok && all (> 0) [1 :: Int ..])

これは何を出力するでしょうか?

Answer

Output

1
2
False

(&&) <$> check 1 <*> check 2 は、check 1 と check 2 を順に実行し、2つの結果がそろってから (&&) に渡す IO の動作です。<*> がつなぐのは動作そのものなので、check 1 の結果が False だと分かっても、check 2 の実行は止まりません。check 1 が 1 を、check 2 が 2 を出力し、ok は False && True で False になります。&& が省けるのは、すでに得た値の評価だけです。

最後の行では、同じ && が短絡します。&& は1つ目の引数を見て、False ならそのまま False を返す普通の関数で、2つ目の引数は遅延評価のために評価されないまま捨てられます。ok は False なので、無限のリストを最後まで調べる all (> 0) [1 :: Int ..] は評価されず、False が出力されて終わります。<*> の行も短絡すると読むと 2 の行が消え、最後の行も2つ目の引数を評価すると読むと、all が終わらずに止まらないと答えることになります。
