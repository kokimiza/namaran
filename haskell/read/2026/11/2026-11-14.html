Escape.hs

escape :: String -> String
escape = concatMap esc
 where
  esc '\\' = "\\\\"
  esc '\n' = "\\n"
  esc c = [c]

main :: IO ()
main = do
  let s = "a\\nb\n"
  putStrLn (escape s)
  print (length (escape s))

これは何を出力するでしょうか?

Answer

Output

a\\nb\n
7

s の中身は、ソースに書かれた文字の並びではなく、コンパイラが文字列リテラルのエスケープを読み終えた後の文字です。"a\\nb\n" の \\ はバックスラッシュ1文字、続く n はただの n、最後の \n は改行1文字なので、s は a、\、n、b、改行の5文字です。

escape はこの5文字を1文字ずつ置き換えます。バックスラッシュは "\\\\"、つまりバックスラッシュ2文字に、改行は "\\n"、つまりバックスラッシュと n の2文字になり、ほかの文字はそのままです。結果は a、\、\、n、b、\、n の7文字で、putStrLn はこれをそのまま a\\nb\n と出し、length は 7 です。

ソースの \\n を改行と読むと、s を a、改行、b、改行の4文字と数え、1行目を a\nb\n、長さを 6 と答えることになります。リテラルの \\ がバックスラッシュ1文字になった時点で、その後ろの n はエスケープの一部ではなくなります。
