Splits.hs

import Control.Monad ((>=>))

type M = String -> [String]

lit :: Char -> M
lit c (x : xs) | x == c = [xs]
lit _ _ = []

star :: M -> M
star p s = concatMap (star p) (p s) ++ [s]

main :: IO ()
main = do
  let a = star (lit 'a')
  print (length ((a >=> a >=> a) "aaaaaa"))

これは何を出力するでしょうか?

Answer

Output

84

M は、文字列を受け取り、パターンが先頭を食べたあとの残りを、食べ方の数だけ並べて返す関数です。lit 'a' は先頭の a を1つ食べる食べ方が1通りか、0通りです。star p は p を1回使ってから続きをまた star p に任せる食べ方と、何も食べない食べ方 [s] を並べます。a は a* に当たり、"aaaa" なら a を 4, 3, 2, 1, 0 個食べた残り5つを返します。>=> はリストのモナドでの合成で、前のパターンが返した残りの1つ1つに次のパターンを当て、結果をすべてつなげます。

候補を1つずつ追うと、どこで数え漏らしたか分からなくなります。見方を変えると、(a >=> a >=> a) "aaaaaa" が返す要素は、3つの a* がそれぞれ a を何個食べたかの組 (i, j, k) と1つずつ対応しています。食べられるのは前が残した分だけなので、組の条件は i + j + k ≦ 6 で、各値は 0 以上です。残った個数を l = 6 − i − j − k とおけば、0 以上の4つの整数で和が 6 になる組の数を数えればよく、6個の a の間に3本の仕切りを入れる並べ方として、9個の場所から仕切りの3個を選ぶ 9C3 = 84 通りです。

3つの a* がそれぞれ 0〜6 個を独立に選ぶと考えると 73 = 343 になり、文字列を食べ切った候補だけを数えると l = 0 の 8C2 = 28 になります。length は食べ残しのある候補も数えるので、どちらでもありません。a* を3つ並べたパターンが照合に失敗する入力、たとえば末尾に b を足した文字列では、この84通りすべてが試されたうえで失敗します。n 文字なら試す数は n+3C3 で、n の3乗に比例して増えます。
