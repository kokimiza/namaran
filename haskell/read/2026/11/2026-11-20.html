MergePasses.hs

runs :: Int -> Int -> Int
runs m n = (n + m - 1) `div` m

passes :: Int -> Int
passes r
  | r <= 1 = 0
  | otherwise = 1 + passes ((r + 1) `div` 2)

main :: IO ()
main =
  print
    [ passes (runs 100 n)
    | n <- [100, 300, 500, 1000]
    ]

これは何を出力するでしょうか?

Answer

Output

[0,2,3,4]

runs m n は n 件を m 件ずつに切ったときの本数で、(n + m - 1) `div` m は割り切れないときに端数の1本を数える切り上げです。メモリに 100 件しか入らないなら、100、300、500、1000 件のデータは 1、3、5、10 本の並べ済みの列になります。

passes r は、r 本の列を2本ずつ併合する周回を、1本になるまで数えます。1周で2本が1本になり、余った1本はそのまま次の周へ残るので、本数は (r + 1) `div` 2 の切り上げで減ります。3本は 2、1 と減って2周、5本は 3、2、1 で3周、10本は 5、3、2、1 で4周です。1本しかなければ併合は要らず、0周になります。

端数を切り捨てて r `div` 2 と考えると、3本は1周で1本になったことになり、余った列が併合から抜け落ちます。5本も 2、1 と減って2周と数えることになりますが、実際には余りの1本を次の周へ持ち越すので、3周かかります。
