Temperature.hs

type Celsius = Double

type Fahrenheit = Double

toF :: Celsius -> Fahrenheit
toF c = c * 9 / 5 + 32

main :: IO ()
main = print (toF (toF 10))

これは何を出力するでしょうか?

Answer

Output

122.0

type 宣言は、既存の型に別の名前を付けるだけで、新しい型は作りません。Celsius も Fahrenheit も Double そのもので、toF の型は型検査の上では Double -> Double と同じです。toF 10 が返す Fahrenheit の値を、もう一度 Celsius を受け取る toF に渡しても、型は一致しているのでコンパイルが通ります。

内側の toF 10 は 10 * 9 / 5 + 32 で 50.0、外側はその 50.0 を摂氏とみなして 50 * 9 / 5 + 32 で 122.0 を返します。print は Double の show で表示するので、出力は 122.0 です。

型に単位の名前が付いているので、華氏を摂氏の引数に渡せばコンパイルエラーになると読むと、答えを誤ります。単位ごとに別の型として区別させたいなら、newtype Celsius = Celsius Double のように、構築子を持つ新しい型を宣言する必要があります。
