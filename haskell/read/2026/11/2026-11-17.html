Describe.hs

describe :: Int -> Int -> String
describe 0 _ = "x is zero"
describe _ 0 = "y is zero"
describe x y
  | x == y = "same"
  | otherwise = "different"

main :: IO ()
main = do
  putStrLn (describe 0 0)
  putStrLn (describe 4 0)
  putStrLn (describe 2 2)
  putStrLn (describe 0 7)

これは何を出力するでしょうか?

Answer

Output

x is zero
y is zero
same
x is zero

describe は3つの式で定義されています。呼び出すと、引数を上の式から順にその式のパターンと照合し、2つの引数がどちらも合った最初の式の右辺が戻り値になります。下にある式は、上の式が合わなかったときにしか試されません。0 は引数がちょうど 0 のときだけ合い、_ と変数 x、y はどんな値にも合います。

describe 0 0 は、1つ目の式の 0 _ に合うので x is zero です。2つの引数は等しいのですが、ガードの x == y がある3つ目の式までは進みません。describe 4 0 は1つ目の 0 に 4 が合わず、2つ目の _ 0 に合って y is zero になります。describe 2 2 はどちらの 0 にも合わずに3つ目の式へ進み、ガードの x == y が真なので same です。describe 0 7 は1つ目の式で決まり、2つ目の引数の 7 は見られないまま x is zero になります。

ガードを先に見て、1行目を same と答えるのがよくある読み違えです。ガードはそれが付いた式の引数のパターンが合ったあとに調べられるので、上の式で決まった呼び出しには関係しません。
