Half.hs

half :: Int -> Int
half n = n `div` 2

main :: IO ()
main = do
  let s = "7"
  print (half (read s))
  print (read s / 2 :: Double)
  print (read s + half 4)

これは何を出力するでしょうか?

Answer

3、3.5、9 の3行です。

read の型は Read a => String -> a で、どの型として読むかは引数の文字列からは決まりません。結果をどう使うかで a が決まり、その型の読み方で "7" を読みます。

1行目の read s は half の引数なので、half の型シグネチャから Int として読まれます。7 `div` 2 は整数の割り算で、3 です。2行目は式全体に :: Double が付いていて、/ の両辺が同じ型なので read s も Double になり、3.5 です。3行目の read s は、half 4 と足されるので + の両辺をそろえる規則で Int になり、7 + 2 で 9 です。
