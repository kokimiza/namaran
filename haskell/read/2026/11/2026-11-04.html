Tax.hs

main :: IO ()
main = do
  let rate = 10 :: Int
      withTax price = price + price * rate `div` 100
  let rate = 8 :: Int
  print (withTax 1000, rate)

これは何を出力するでしょうか?

Answer

(1100,8) です。

Haskell の let は、変数に値を代入する文ではなく、名前と値を結び付ける定義です。2つ目の let rate = 8 :: Int は、1つ目の rate を書き換えるのではなく、同じ名前の新しい変数を作ります。新しい rate が見えるのはこの行より後ろだけで、外側の古い rate は、その範囲で隠れるだけで 10 のまま残ります。

withTax の本体の rate は、withTax を定義した1つ目の let の中で見えていた rate で、その値は 10 です。どの rate を指すかは定義を書いた場所で決まり、あとから同じ名前が現れても変わりません。withTax 1000 は 1000 + 1000 * 10 `div` 100 で 1100 です。* と `div` は同じ優先順位の左結合なので、掛け算が先です。組の2つ目の rate は最後の行から見える新しい方で 8 なので、(1100,8) と表示されます。税率が 8 に下がったと読んで (1080,8) と答えると、let を代入として読んだことになります。

同じ名前を内側で定義し直すことは、-Wall を付けると -Wname-shadowing の警告として知らされます。
