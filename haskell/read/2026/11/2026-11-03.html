Remaining.hs

import Control.Monad (when)
import Data.IORef

main :: IO ()
main = do
  stock <- newIORef (5 :: Int)
  let remaining = readIORef stock
  ok <- (>= 4) <$> remaining
  modifyIORef stock (subtract 3)
  when ok $ do
    r <- remaining
    writeIORef stock (r - 4)
  remaining >>= print

これは何を出力するでしょうか?

Answer

-2 です。

let remaining = readIORef stock は readIORef を実行せず、「stock を読む」という IO アクションに remaining という名前を付けるだけです。remaining は数ではなく IO Int なので、<- や >>= で使われるたびに、その時点の stock を読み直します。このコードでは3回読みます。

1回目の (>= 4) <$> remaining は 5 を読み、ok は True になります。次の modifyIORef で stock は 2 に減ります。when ok の中の2回目の remaining は、確かめたときの 5 ではなく今の 2 を読むので、r - 4 は -2 で、それが stock に書かれます。最後の remaining >>= print が3回目の読み出しで、-2 を表示します。

remaining を最初に読んだ値 5 の名前だと読むと、書き込むのは 1 になり、答えは 1 になります。実際には、確かめたときに満たしていた「4 個以上」という条件が、使うときの在庫 2 では成り立っておらず、在庫は負になります。
