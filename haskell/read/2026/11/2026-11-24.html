Choose.hs

choose :: [(Char, Int)] -> Int -> Char
choose [] _ = error "r out of range"
choose ((c, w) : rest) r
  | r < w = c
  | otherwise = choose rest (r - w)

main :: IO ()
main = putStrLn (map (choose table) [0 .. 4])
 where
  table = [('a', 2), ('b', 0), ('c', 3)]

これは何を出力するでしょうか?

Answer

Output

aaccc

choose は先頭の項目の重み w と r を比べ、r < w ならその項目を返し、そうでなければ r から w を引いて残りのリストで続けます。重みを先頭から足していった値を境目と見ると、a は r が 0 以上 2 未満、b は 2 以上 2 未満、c は 2 以上 5 未満を受け持ちます。b の範囲には整数が1つもありません。

r が 0 と 1 のときは最初のガードで a が返ります。r が 2 なら 2 < 2 は偽なので 2 を引き、b の番では r が 0 になりますが、0 < 0 も偽なので b は選ばれず、0 のまま c に進んで 0 < 3 で c が返ります。3 と 4 も同じ道筋で c になり、5文字をつないだ aaccc が出力されます。

r がちょうど 0 まで減った項目なら選ばれると考えると、r が 2 のときに b を選んで aabcc と答えることになります。比較が r < w なので、重み 0 の項目は r が何であっても選ばれず、受け持つ r の個数はそれぞれの重みと等しくなります。
