Remainders.hs

solutions :: [Int]
solutions =
  [ x
  | x <- [-20 ..]
  , x `mod` 3 == 2
  , x `mod` 5 == 3
  ]

main :: IO ()
main = print (take 2 solutions)

これは何を出力するでしょうか?

Answer

Output

[-7,8]

solutions は、-20 から1ずつ増える整数のうち、3 で割った余りが 2 で、5 で割った余りが 3 のものを順に並べたリストです。take 2 が最初の2つを取り出した時点で評価は止まるので、無限のリストでも結果は出ます。3 と 5 は1以外の公約数を持たないので、2つの条件を満たす整数は 3 × 5 = 15 ごとに1つずつ現れます。正の数で最初に条件を満たすのは 8 で、その1つ前の解は 8 - 15 = -7 です。

-7 が条件を満たすかは、負の数に対する mod の値で決まります。Haskell の mod は商を小さいほうへ切り捨てるので、割る数が正なら余りは必ず 0 以上、割る数未満になります。-7 = 3 × (-3) + 2 なので (-7) `mod` 3 は 2、-7 = 5 × (-2) + 3 なので (-7) `mod` 5 は 3 で、両方の条件を満たします。-20 から -8 までに条件を満たす数は無いので、リストは -7 から始まり、次は 8 です。

C や Rust の % のように商を 0 の側へ切り捨てると考えると、負の数の余りは 0 以下になります。-7 を 3 で割った余りは -1 で 2 にはならず、負の数はどれも条件を満たさないので、[8,23] と答えることになります。Haskell でその計算をするのは rem のほうで、(-7) `rem` 3 は -1 です。
