Lazy.hs

import qualified Data.Map as Map

main :: IO ()
main = do
  let entries = [("a", 1), ("b", undefined), ("a", 2)] :: [(String, Int)]
      m = foldr (\(k, v) -> Map.insertWith (+) k v) Map.empty entries
  print (Map.lookup "a" m)
  print (Map.size m)
  print (Map.member "b" m)

これは何を出力するでしょうか?

Answer

Output

Just 3
2
True

Data.Map は値について遅延な Map で、insertWith は渡された値も、(+) で組み合わせた結果も、評価しないまま項目に入れます。foldr は右端から挿入するので、まず "a" に 2 が入り、次に "b" に undefined が評価されないまま入ります。最後の ("a", 1) では "a" がすでにあるので、insertWith は値を 1 + 2 という未評価の式に置き換えます。

値が評価されるのは、その値を使うときだけです。Map.lookup "a" m を表示するときに 1 + 2 が計算されて Just 3 が出ます。Map.size と Map.member が調べるのは鍵と木の形だけで、値には触れません。そのため "b" の undefined は最後まで評価されず、2 と True が続けて出ます。

undefined がある時点で例外になると考えると、何も出力されずに止まると答えます。そうなるのは import を Data.Map.Strict に替えたときです。Data.Map.Strict の insertWith は、入れる値を挿入の時点で評価するので、m を使った最初の print で Prelude.undefined の例外が起きます。
