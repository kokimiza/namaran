ShowPath.hs

main :: IO ()
main = do
  let path = "C:\\tmp"
  putStrLn path
  print path
  print (length (show path))

これは何を出力するでしょうか?

Answer

Output

C:\tmp
"C:\\tmp"
9

ソースに書いた "C:\\tmp" の \\ は、文字列リテラルの中でバックスラッシュ1文字を表すエスケープです。path の中身は C、:、\、t、m、p の6文字で、putStrLn はこれをそのまま書き出すので、1行目は C:\tmp です。

print は putStrLn . show と同じで、文字列の show は、その値を作る Haskell の文字列リテラルを返します。リテラルとして読み戻せるように、前後に " を付け、中のバックスラッシュを \\ に戻すので、2行目は "C:\\tmp" です。この show path の長さは、元の6文字に引用符2つと、エスケープで増えたバックスラッシュ1つを足した 9 になります。print と putStrLn を同じものと思うと2行目も C:\tmp になり、長さを 6 と答えることになります。
