FoldOrder.hs

data Tree = Leaf | Node Tree Int Tree

insert :: Int -> Tree -> Tree
insert x Leaf = Node Leaf x Leaf
insert x (Node l v r)
  | x < v = Node (insert x l) v r
  | otherwise = Node l v (insert x r)

costOfMax :: Tree -> Int
costOfMax Leaf = 0
costOfMax (Node _ _ r) = 1 + costOfMax r

main :: IO ()
main = do
  let xs = [4, 2, 6, 1, 3, 5, 7]
  print
    (costOfMax (foldl (flip insert) Leaf xs))
  print (costOfMax (foldr insert Leaf xs))

これは何を出力するでしょうか?

Answer

Output

3
1

costOfMax は、根から右の子だけをたどって数えた節の数で、最大値を探すときに比べる回数に当たります。foldl (flip insert) Leaf xs は、Leaf から始めてリストの先頭の要素から順に挿入します。4 が根になり、2 と 6 がその左右、1 と 3 が 2 の下、5 と 7 が 6 の下に入って、どの葉も根から3つ目にある木になります。右をたどると 4、6、7 なので、1行目は 3 です。

foldr insert Leaf xs は insert 4 (insert 2 (insert 6 (… (insert 7 Leaf)))) と展開されます。最初に Leaf へ挿入されるのは一番内側の 7 で、そのあと 5、3、1、6、2、4 と、リストの後ろの要素から順に挿入されます。根の 7 はリストの最大値なので、あとから来る要素はすべて左へ入り、根の右の子は空のままです。2行目は根の1つだけを数えて 1 になります。

foldr も foldl と同じく先頭の要素から挿入すると読むと、2行とも 3 と答えることになります。foldr で先頭の 4 を受け取るのは一番外側の insert で、木に入るのは最後です。釣り合いが取れるように並べたリストでも、畳み込みの向きを逆にすると挿入の順序が逆になり、最大値を根に置いた偏った木ができます。
