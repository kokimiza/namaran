Anchors.hs

import Data.List (tails)

match :: String -> String -> Bool
match ('^' : re) s = here re s
match re s = any (here re) (tails s)

here :: String -> String -> Bool
here "" _ = True
here "$" s = null s
here (c : re) (x : xs) = c == x && here re xs
here _ _ = False

main :: IO ()
main = print [match re "ab" | re <- res]
 where
  res = ["b$", "$", "^$"]

これは何を出力するでしょうか?

Answer

Output

[True,True,False]

match は、パターンが ^ で始まれば文字列の先頭だけで here を試し、そうでなければ tails s が返す全ての位置で試します。tails "ab" は ["ab", "b", ""] で、最後に空文字列が入ります。here は、パターンを使い切れば成功し、パターンが "$" だけになったら、残りの文字列が空かどうかで決まります。

"b$" は、"ab" の位置では 'b' と 'a' が合わずに失敗し、"b" の位置では 'b' が合って、残りの "" に対して "$" が成功します。"$" は、"ab" と "b" の位置では残りが空でないので失敗しますが、tails が最後に返す "" の位置で成功します。"^$" は先頭の "ab" だけで here "$" "ab" を試すので、False です。

tails "ab" を ["ab", "b"] の2つと読むと、"$" はどの位置でも残りが空にならず、[True,False,False] と答えることになります。"b$" が成功するのは "b" を読み終えた位置で残りが空になるからで、パターンが "$" だけなら、何も読まずに空になる位置が要ります。tails の最後の "" が、その位置にあたります。
