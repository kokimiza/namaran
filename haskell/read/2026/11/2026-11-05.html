Narrow.hs

step :: (Int -> Int) -> (Int, Int) -> (Int, Int)
step f (lo, hi)
  | f m1 < f m2 = (m1 + 1, hi)
  | otherwise = (lo, m2 - 1)
 where
  m1 = lo + (hi - lo) `div` 3
  m2 = hi - (hi - lo) `div` 3

main :: IO ()
main = print (take 3 (iterate (step f) (0, 30)))
 where
  f x = negate (abs (x - 20))

これは何を出力するでしょうか?

Answer

Output

[(0,30),(11,30),(11,23)]

iterate g x は x、g x、g (g x) と続く無限のリストで、先頭は g を1回も適用していない x そのものです。take 3 が取り出すのは、初めの区間 (0,30) と、step を1回、2回適用した区間の3つです。リストは遅延評価されるので、4つ目より後ろは計算されません。

step は区間を三等分する2点 m1 と m2 で f を比べます。f は 20 で最大になり、そこから離れるほど小さくなる関数です。f m1 < f m2 なら、最大の位置は m1 より右にあるので左側を捨てて (m1 + 1, hi) に、そうでなければ m2 より左にあるので (lo, m2 - 1) に縮めます。1回目は (0,30) の幅が 30 で、div で 3 に割った 10 から m1 = 10、m2 = 20 です。f 10 は -10、f 20 は 0 で、-10 < 0 なので (11,30) になります。

2回目は幅が 19 で、19 `div` 3 は小数点以下を切り捨てた 6 なので、m1 = 17、m2 = 24 です。f 17 は -3、f 24 は -4 で、-3 < -4 は偽なので otherwise の枝に進み、(11,23) になります。最大の位置 20 は、どちらの区間にも残っています。
