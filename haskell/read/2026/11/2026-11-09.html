LongLines.hs

main :: IO ()
main = do
  let file = unlines (map show [1 :: Int ..])
  print (take 2 (filter ((> 2) . length) (lines file)))

これは何を出力するでしょうか?

Answer

Output

["100","101"]

file は "1\n2\n3\n…" とどこまでも続く文字列で、巨大なファイルの中身の代わりです。Haskell の式は値が必要になったときに、必要な分だけ評価されるので、let で束縛した時点では1文字も作られません。print が結果を表示しようとして take 2 に要素を求め、take は filter に、filter は lines に1行ずつ求めます。lines が1行を返すのに要るのは次の改行までの文字だけなので、file も1行分ずつしか作られません。

"1" から "99" までの行は長さが2以下なので filter に捨てられ、長さが3の最初の行 "100" と次の "101" が take に渡ります。2つ受け取った take 2 はそれ以上要素を求めずにリストを閉じるので、"102" から先の行も文字列も作られず、プログラムは終わります。print は String のリストを show で表示するので、各行は引用符付きで、空白なしのカンマで区切られます。unlines や lines が文字列全体を作り終えてから次へ進むと考えると、このプログラムは終わらないと答えることになります。
