OthersBits.hs

othersBits :: Int -> Int
othersBits mode = mode `mod` 8

main :: IO ()
main = print (map othersBits [0o755, 0755])

これは何を出力するでしょうか?

Answer

[5,3] です。

Haskell の整数リテラルで8進数になるのは 0o で始まる形だけで、先頭に 0 を付けただけの 0755 は10進数の 755 です。C のように先頭の 0 で8進数に切り替わる規則はありません。

0o755 は 7 × 64 + 5 × 8 + 5 = 493 で、8で割った余りは8進数の最後の桁の 5 です。0755 のほうは 755 = 8 × 94 + 3 なので、余りは 3 になります。両方が8進数なら、パーミッションの「その他」にあたる桁の 5 が2つ並んでいたところでした。
