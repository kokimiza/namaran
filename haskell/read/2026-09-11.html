Cleanup.hs

import Control.Exception (ErrorCall (..), bracket, catch, throwIO)

acquire :: IO String
acquire = do
  putStrLn "acquire"
  return "resource"

release :: String -> IO ()
release r = putStrLn ("release " ++ r)

useResource :: String -> IO ()
useResource _ = do
  putStrLn "use"
  throwIO (ErrorCall "boom")

main :: IO ()
main =
  bracket acquire release useResource
    `catch` \(ErrorCall msg) -> putStrLn ("caught: " ++ msg)

bracket acquire release useは、acquireで資源を取得し、useに渡して実行し、useが正常終了しても例外を投げても、必ずreleaseを呼びます。このコードは何を出力するでしょうか?

Answer

acquire・use・release resource・caught: boomという4行(各行の後に改行)。まずacquireが呼ばれ"acquire"が出力されます。次にuseResourceが呼ばれ"use"が出力されたあと、ErrorCall "boom"を投げます。ここでもし普通の(bracketを使わない)逐次実行なら、例外はその場で外へ伝わりreleaseは呼ばれません。しかしbracketは「useが例外を投げても、外へ伝える前に必ずreleaseを実行する」ことを保証するので、"release resource"が出力されてから、元の例外がbracketの呼び出し全体を抜けて外へ伝わります。その例外はmainのcatchで捕まり、"caught: boom"が出力されます。C++のデストラクタやRustのDropがスコープを抜けるときに自動で後始末をするのに対し、Haskellには自動で呼ばれる後始末の仕組みが無いので、bracketのような関数で明示的に「取得・使用・解放」の形を作ることで、例外が起きても解放を忘れないようにします。
