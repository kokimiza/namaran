LazyReply.hs

import System.Timeout (timeout)

parseReply :: String -> Int
parseReply body = length (filter (== 'x') body)

main :: IO ()
main = do
  let body = replicate 30000000 'x'
  r <- timeout 100000 (return (parseReply body))
  putStrLn (maybe "timed out" show r)

これは何を出力するでしょうか?

Answer

30000000 です。

timeout 100000 act は act を実行し、0.1秒以内に終われば結果を Just で包んで返し、終わらなければ打ち切って Nothing を返します。3000万文字を数える parseReply は0.1秒では終わらないかもしれませんが、ここで期限内に終える必要があるのは return (parseReply body) というアクションだけです。return は受け取った値を評価せず、未評価のまま結果として返すので、このアクションはすぐに終わります。r は、まだ数え始めていない parseReply body を包んだ Just になります。

実際に数えるのは、show が文字列にしようとして値を求めたときで、それは timeout の外です。どれだけ時間がかかっても打ち切られず、最後に 30000000 が出力されます。応答の解析まで期限に含めたいなら、Control.Exception の evaluate を使って timeout 100000 (evaluate (parseReply body)) と書き、期限の内側で値を求めさせます。
