Steps.hs

steps :: [Int] -> [Ordering]
steps xs = zipWith compare xs (drop 1 xs)

main :: IO ()
main = print (steps [3, 5, 5, 2])

これは何を出力するでしょうか?

Answer

[LT,EQ,GT] です。

zipWith compare xs (drop 1 xs) は、隣り合う2要素を前、後ろの順に compare に渡します。compare a b は a が b より小さければ LT、等しければ EQ、大きければ GT を返すので、組 (3, 5)、(5, 5)、(5, 2) からそれぞれ LT、EQ、GT が出ます。

値が増えたところが LT になるのは、結果が「前の値が後ろの値に比べてどうか」を表しているからです。「次にどう変わったか」と読むと、増えたところを GT と思ってしまいます。そちらの意味にしたければ、zipWith compare (drop 1 xs) xs と2つのリストを入れ替えます。
