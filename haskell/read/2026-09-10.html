Area.hs

main :: IO ()
main = do
  let width = 4 :: Int
      height = width
        * 3
      area = width * height
  print area

これは何を出力するでしょうか?

Answer

出力は48です。letの直後のwidthが始まる列が、このletブロックの基準になります。次の行がその列から始まれば新しい束縛、それより右から始まれば直前の行の続き、左から始まればletブロックの終わりです。

* 3の行はheightより右から始まっているので、height = width * 3の続きとして読まれ、heightは12になります。areaの行は基準の列に戻っているので新しい束縛で、4 * 12から48です。* 3をheightと同じ列に置くと、そこから新しい束縛が始まったと見なされ、構文エラーになります。
