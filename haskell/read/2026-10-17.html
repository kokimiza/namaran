Shares.hs

import Control.Monad (forM_, when)
import System.Exit (exitSuccess)

main :: IO ()
main = do
  forM_ [3, 1, 4, 0, 6] $ \n -> do
    when (n == 0) exitSuccess
    print (12 `div` n :: Int)
  putStrLn "all shares printed"

これは何を出力するでしょうか?

Answer

4、12、3 の3行です。

exitSuccess は、いま回っている forM_ の1回分を飛ばす命令ではなく、プログラム全体を終了コード 0 で終える IO アクションです。n が 3、1、4 の間は when の条件が偽なので、12 `div` n の 4、12、3 が順に出力されます。4つ目の 0 で exitSuccess が実行されると、残りの 6 も、forM_ のあとにある putStrLn も実行されずにプログラムが終わります。

0 で割るのを避けて次の要素へ進むつもりなら、when (n /= 0) (print (12 `div` n :: Int)) のように、出力する側を条件で包みます。このプログラムは途中で打ち切られても終了コードが 0 なので、呼び出したシェルスクリプトからは、すべて出力し終えたときと区別が付きません。
