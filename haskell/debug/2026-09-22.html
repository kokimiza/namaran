ToCents.hs

module Main where

newtype Cents = Cents Integer deriving (Eq, Show)

toCents :: Double -> Cents
toCents x = Cents (truncate (x * 100))

main :: IO ()
main = print (toCents 0.29)

小数(Double)を100分の1単位のセントに変換するつもりのtoCentsです。入力は0.29(29セントのつもり)。いまの出力はCents 28ですが、本来の出力はCents 29です。何が問題で、どう直せばよいでしょうか?

Answer

0.29は2進浮動小数点数では正確に表せないため、Doubleとして保持されている実際の値はわずかに0.29より小さく、x * 100を計算すると29.0ちょうどではなく28.999999999999996のような値になります。truncateは0方向への切り捨てなので、この28.999999999999996は28に切り捨てられてしまい、意図していた29より1セント少なくなります。固定小数点数を扱うときに浮動小数点数からの変換へtruncateを使うと、こうした表現誤差がそのまま「1セント少ない」バグとして現れます。直し方は、最も近い整数に丸めるroundに変えるだけです: 

toCents :: Double -> Cents
toCents x = Cents (round (x * 100))
