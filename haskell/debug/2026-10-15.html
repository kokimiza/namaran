ToSeconds.hs

toSeconds :: [Int] -> [Int]
toSeconds = map (div 1000)

main :: IO ()
main = print (toSeconds [1500, 2000, 999])

toSeconds は、ミリ秒のリストを、端数を切り捨てて秒に直したリストを返すつもりの関数です。toSeconds [1500, 2000, 999] は、いまは [0,0,1] を返します。本来は [1,2,0] です。

Answer

Wrong

toSeconds = map (div 1000)

div 1000 は div の1つ目の引数に 1000 を渡した部分適用です。残った2つ目の引数にリストの要素 ms が入るので、計算されるのは div 1000 ms、つまり 1000 を ms で割った商です。1500 と 2000 では商が 0、999 では 1 になり、[0,0,1] が返ります。割られる数と割る数が入れ替わっています。

Right

toSeconds = map (`div` 1000)

(`div` 1000) は、バッククォートで div を中置の演算子として使い、右側だけを埋めたセクションです。空いている左側に要素が入るので ms `div` 1000 が計算され、1500、2000、999 の商は 1、2、0 になります1。

  1. flip div 1000 と書いても同じ関数になります。引き算では同じ形のセクション (- 1) が -1 という数として読まれるので、1 を引く関数には subtract 1 を使います。
