FileMode.hs

import Data.Bits (complement, (.&.))
import Numeric (showOct)

parseMode :: String -> Int
parseMode = read

main :: IO ()
main = do
  let mode = parseMode "0644" .&. complement 0o027
  putStrLn (showOct mode "")

parseMode は、設定ファイルに "0644" のように8進数で書かれたファイルのモードを数値にするつもりの関数です。main は読んだモードから umask の 0o027 のビットを落とし、8進数で表示します。いまは 1200 が出ます。本来の出力は 640 です。

Answer

Wrong

parseMode :: String -> Int
parseMode = read

read は、文字列を Haskell の整数リテラルと同じ規則で読みます。Haskell では先頭の 0 は8進数の印にならないので、read "0644" は10進数の 644 です。644 を8進数で書くと 1204 で、ここから 0o027 のビットを落とすと末尾の 4 が消え、1200 が表示されます。マスクの計算は合っていて、狂っているのは読み込んだ時点の値です。

Right

parseMode s = read ("0o" ++ s)

先頭に 0o を付けると、文字列は Haskell の8進数リテラル 0o0644 になり、read は 420(8進数で 0o644)を返します。そこから 0o027 のビットを落とした 0o640 が、640 と表示されます1。

  1. Numeric の readOct でも読めます。readOct は読めた値と残りの文字列の組をリストで返し、"0644" なら [(420,"")] です。
