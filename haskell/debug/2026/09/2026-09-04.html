Memo.hs

save :: [String] -> String
save = unlines

load :: String -> [String]
load = lines

main :: IO ()
main = print (load (save ["buy milk", "call Ann\nabout Friday"]))

save はメモのリストを1つの文字列にし、load はそれを元のリストに戻すつもりの関数です。main は2件のメモを保存して読み戻します。本来は ["buy milk","call Ann\nabout Friday"] を出力するはずですが、いまは ["buy milk","call Ann","about Friday"] を出力します。

Answer

Wrong

save = unlines
load = lines

unlines はメモの後ろに '\n' を付けてつなぐだけで、メモの中にある '\n' には手を付けません。保存した文字列は "buy milk\ncall Ann\nabout Friday\n" になり、どの '\n' がメモの区切りで、どれがメモの中身だったのかを区別できなくなります。lines はすべての '\n' で区切るので、2件目のメモが "call Ann" と "about Friday" の2件に割れます。

Right

save = unlines . map show
load = map read . lines

show は文字列を引用符で囲み、中の改行を \ と n の2文字に置き換えます。2件目のメモは "call Ann\nabout Friday" という引用符付きの1行として保存されるので、本物の '\n' はメモの区切りにしか現れません。lines で区切った各行を read すると、show する前の文字列に戻ります1。

  1. read は形の合わない行を渡されると例外を投げます。人が手で編集しうるファイルなら、GHC の base にある Text.Read.readMaybe で読み、読めなかった行を別に扱う方が安全です。
