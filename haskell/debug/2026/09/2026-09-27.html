Countdown.hs

import Control.Monad (forM_)

countdown :: Int -> IO ()
countdown n = do
  forM_ [n .. 1] print
  putStrLn "liftoff"

main :: IO ()
main = countdown 3

countdown n は、n から 1 まで1つずつ減らしながら数を表示し、最後に liftoff を表示するつもりの関数です。入力は countdown 3 です。いまの出力は liftoff の1行だけですが、本来の出力は 3、2、1、liftoff の4行です。どこを直せばよいでしょうか?

Answer

[n .. 1] は、n が 1 より大きいと空のリストになります。

[a .. b] は a から1ずつ増やしながら、b を超えるまで並べる範囲です。増える向きにしか進まないので、始まりの 3 がすでに 1 を超えている [3 .. 1] には要素がなく、forM_ は一度も print を呼びません。コンパイルエラーにも実行時エラーにもならず、ループが0回回っただけに見えます。

減る向きに並べるには、2つ目の要素を書いて刻み幅を示します: 

  forM_ [n, n - 1 .. 1] print

[a, b .. c] は a から b - a ずつ進むので、[3, 2 .. 1] は 3、2、1 になります。reverse [1 .. n] と書いても同じ結果です。
