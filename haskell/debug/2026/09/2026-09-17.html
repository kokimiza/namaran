SumAll.hs

import Control.Exception
import Data.IORef

sumAll :: IORef Int -> [String] -> IO ()
sumAll ref = mapM_ (\s -> modifyIORef ref (+ read s))

main :: IO ()
main = handle (\e -> putStrLn ("crashed: " ++ show (e :: ErrorCall))) $ do
  ref <- newIORef 0
  r <- try (sumAll ref ["10", "20", "x", "40"])
  case r of
    Left e -> putStrLn ("cancelled: " ++ show (e :: ErrorCall))
    Right () -> putStrLn "done"
  readIORef ref >>= print

sumAll は、文字列の数値を ref に足していくつもりの関数です。main は、読めない文字列で処理が中断されたら try でそれを受け取って cancelled: … を表示し、そこまでの合計を表示するつもりです。入力は ["10", "20", "x", "40"]。いまの出力は done と crashed: Prelude.read: no parse の2行ですが、本来の出力は cancelled: Prelude.read: no parse と 30 の2行です。本来の出力になるよう直してください。

Answer

modifyIORef は、関数を適用した結果を評価しないまま IORef に書き込みます。sumAll の中では read "x" が一度も評価されず、ref には (((0 + read "10") + read "20") + read "x") + read "40" というサンクが積み上がるだけです。どこでも例外が起きないので、try は Right () を返し、done が表示されます。

サンクが評価されるのは、try を抜けたあとの print が値を必要としたときです。そこで初めて read "x" が ErrorCall を投げるので、受け取るのは try ではなく外側の handle になり、crashed: … が表示されます。try が捕まえられるのは、渡したアクションの実行中に起きた例外だけです。

modifyIORef を正格版の modifyIORef' に替えれば直ります。 

sumAll ref = mapM_ (\s -> modifyIORef' ref (+ read s))

modifyIORef' は新しい値を弱頭部正規形まで評価してから書き込みます。Int の足し算はその場で計算されるので、read "x" は try の中で例外を投げます。そのとき ref には 10 と 20 を足した 30 が残っており、cancelled: … のあとに 30 が表示されます。
