Groups.hs

import Data.Char (toLower)
import Data.List (group, sortOn)

groupCI :: [String] -> [[String]]
groupCI = group . sortOn (map toLower)

main :: IO ()
main = print (groupCI ["bob", "Alice", "alice", "Bob", "bob"])

groupCI は、大文字と小文字の違いを無視して、同じ名前をひとまとめにするつもりの関数です。main のとおり呼ぶと、本来は [["Alice","alice"],["bob","Bob","bob"]] を出力するはずですが、いまは [["Alice"],["alice"],["bob"],["Bob"],["bob"]] を出力します。

Answer

Wrong

groupCI :: [String] -> [[String]]
groupCI = group . sortOn (map toLower)

sortOn (map toLower) は小文字にそろえた鍵で並べるので、"Alice" と "alice" が隣り合い、3つの bob も隣り合います。ところが group は、隣り合う要素を並べ替えの鍵ではなく == で比べてまとめます。"Alice" == "alice" は偽なので、綴りの違う名前はすべて別のグループになります。

Right

groupCI :: [String] -> [[String]]
groupCI = groupBy ((==) `on` map toLower) . sortOn (map toLower)

groupBy には、等しいかどうかを決める関数を渡せます。(==) `on` map toLower は2つの名前を小文字にしてから比べるので、並べたときと同じ鍵でまとまります。on は Data.Function から、groupBy は Data.List から import します。
