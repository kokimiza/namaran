Decode.hs

import Data.Char (digitToInt, isDigit)

decode :: String -> String
decode (c : d : rest)
  | isDigit d = replicate (digitToInt d) c ++ decode rest
decode (c : rest) = c : decode rest
decode [] = []

main :: IO ()
main = putStrLn (decode "a12b")

decode は、文字の後ろにその文字の個数を10進で書いた文字列(個数が1なら数字を省く)を、元の文字列に戻す関数です。decode "a12b" は a を12個並べて b を続けた aaaaaaaaaaaab になるはずが、いまは a2b が返ります。

Answer

Wrong

import Data.Char (digitToInt, isDigit)

decode (c : d : rest)
  | isDigit d = replicate (digitToInt d) c ++ decode rest

最初の等式は、文字の直後の1文字 d だけを個数として読みます。"a12b" では d が '1' なので a を1個だけ作り、残りの "2b" を次の呼び出しに渡します。そこでは '2' が展開する文字として扱われ、続く 'b' は数字でないのでガードが偽になり、2つ目の等式が '2' をそのまま出力します。こうして12のうち1が個数に、2が文字になり、結果は a2b です。個数が9以下の入力では正しく動くので、10個以上の連続が来て初めて表に出ます。

Right

import Data.Char (isDigit)

decode (c : rest@(d : _))
  | isDigit d = replicate (read ds) c ++ decode rest'
 where
  (ds, rest') = span isDigit rest

span isDigit rest は、rest の先頭から続く数字をすべて ds に、その後ろを rest' に分けます。"12b" なら ds が "12" になり、read で12として読むので a が12個並び、展開は "b" から続きます。ガードは直後の1文字が数字かどうかだけを見るので、数字が無ければ ds は使われず、これまでどおり2つ目の等式に進みます。1桁ずつ値にする digitToInt は要らなくなるので、import の一覧からも外します。
