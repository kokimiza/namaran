FetchAll.hs

import Control.Concurrent (threadDelay)
import System.Timeout (timeout)

fetch :: Int -> IO Int
fetch n = threadDelay 200000 >> return n

fetchAll :: [Int] -> IO (Maybe [Int])
fetchAll ids = sequence <$> mapM (timeout 300000 . fetch) ids

main :: IO ()
main = fetchAll [1 .. 5] >>= print

fetchAll は、渡された番号のデータをすべて取ってくるか、0.3秒の期限までに取りきれなければ Nothing を返すつもりの関数です。fetch は応答に1件あたり0.2秒かかる遅いサーバーを模しています。fetchAll [1 .. 5] は、本来なら0.3秒で諦めて Nothing を出力するはずですが、いまは1秒待ったうえで Just [1,2,3,4,5] を出力します。

Answer

Wrong

fetchAll ids = sequence <$> mapM (timeout 300000 . fetch) ids

timeout 300000 . fetch は、fetch の1回ごとに0.3秒の期限をかけます。mapM はそれを5件に順に適用するので、期限も1件ごとに新しく0.3秒から始まります。1件の fetch は0.2秒で終わり、どの期限にも間に合うので、結果は5つの Just になり、sequence がそれを Just [1,2,3,4,5] にまとめます。待つ時間は合計で 0.2 × 5 = 1秒です。件数が増えれば待ち時間も比例して延び、呼び出し側が決めた0.3秒はどこでも守られません。

Right

fetchAll ids = timeout 300000 (mapM fetch ids)

timeout で mapM fetch ids 全体を包むと、5件をまとめた処理に0.3秒の期限が1つだけかかります。2件目の途中で0.3秒が過ぎ、そこで打ち切られて Nothing が返ります1。1件ごとの上限も欲しいなら、内側の timeout を残したうえで外側にも timeout をかけ、2つの期限を別々に持たせます。

  1. System.Timeout は Haskell 2010 の報告書が定める標準ライブラリではなく、GHC に付属する base パッケージのモジュールです。期限が来ると、timeout は実行中のスレッドに非同期例外を投げて処理を打ち切ります。
