Menu.hs

import Data.Char (ord)

width :: String -> Int
width = sum . map (\c -> if ord c < 0x1100 then 1 else 2)

pad :: Int -> String -> String
pad n s = s ++ replicate (n - length s) ' '

main :: IO ()
main = do
  let items = [("tea", 300), ("抹茶", 450), ("🍡", 200)] :: [(String, Int)]
      n = maximum (map (width . fst) items)
  mapM_ (\(name, price) -> putStrLn (pad n name ++ " | " ++ show price)) items

品名の後ろに空白を足し、| の位置を表示幅でそろえてメニューを出力するつもりのプログラムです。width は、コードポイントが 0x1100 以上の文字を幅2、それ以外を幅1として数えます。本来は3行とも品名の部分が幅4にそろい、抹茶 | 450 のように出力されるはずが、いまは2行目が 抹茶 | 450、3行目が 🍡 | 200 になり、| の位置が行ごとにずれます。

Answer

Wrong

pad n s = s ++ replicate (n - length s) ' '

n は品名の表示幅の最大で、抹茶 の4です。ところが pad が足す空白の数は n - length s で、length が数えるのは Char の個数です。抹茶 は2個なので空白が2つ付き、表示幅は6になります。🍡 は1個なので空白が3つ付き、幅は5です。tea だけは文字の個数と表示幅が同じなので、幅4で正しくそろいます。

Right

pad n s = s ++ replicate (n - width s) ' '

空白の数を、n を求めたのと同じ width で数えます。足した空白の幅と品名の幅の合計がどの行も n になるので、| は3行とも同じ桁に来ます。
