Mailing.hs

import Data.List ((\\))

subscribers :: [String]
subscribers = ["ann", "bob", "ann", "cy"]

unsubscribed :: [String]
unsubscribed = ["ann"]

recipients :: [String]
recipients = subscribers \\ unsubscribed

main :: IO ()
main = print recipients

recipients は、購読者の一覧 subscribers から配信停止した人 unsubscribed を除いた送信先を、購読者の順に並べるつもりの定義です。subscribers には、二度登録した "ann" が2回入っています。いまの出力は ["bob","ann","cy"] で、本来の出力は ["bob","cy"] です。

Answer

Wrong

recipients = subscribers \\ unsubscribed

xs \\ ys は、ys の要素1つにつき、xs に最初に現れるものを1つだけ取り除きます。unsubscribed の "ann" は1つなので、取り除かれるのは subscribers の先頭の "ann" だけで、3番目の "ann" は残ります。配信停止した人に、メールがまだ届きます。

Right

recipients = filter (`notElem` unsubscribed) subscribers

filter (`notElem` unsubscribed) は、購読者を1人ずつ調べて、unsubscribed に現れる人をすべて落とします。同じ "ann" が何回入っていても、どれも notElem が False を返すので結果に残らず、購読者の順も変わりません1。

  1. \\ が取るのは、同じ要素が何個あるかまで区別する集まりどうしの差です。このような集まりを多重集合（multiset）といい、[1,1,2] \\ [1] が [1,2] になるのは、1が2個から1個に減るからです。
