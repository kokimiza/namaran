Runs.hs

import Data.List (sort)

chunks :: Int -> [a] -> [[a]]
chunks m xs = a : chunks m b
 where
  (a, b) = splitAt m xs

runs :: Int -> [Int] -> [[Int]]
runs m = map sort . chunks m

main :: IO ()
main = print (runs 3 [5, 1, 4, 2, 8, 3, 7])

データを m 件ずつに切り、それぞれを昇順に並べたリストを返す runs です。runs 3 [5, 1, 4, 2, 8, 3, 7] を表示すると [[1,4,5],[2,3,8],[7]] になるはずが、いまは [[1,4,5],[2,3,8],[7],[],[],[],… と空のリストを表示し続け、止まりません。

Answer

Wrong

chunks :: Int -> [a] -> [[a]]
chunks m xs = a : chunks m b
 where
  (a, b) = splitAt m xs

splitAt は、リストが短くても空でも失敗しません。splitAt 3 [] は ([], []) を返すので、[7] を切り出したあとの chunks 3 [] は [] を1つ出してから、また chunks 3 [] を呼びます。xs がそれ以上短くならないので、再帰はどこにも着地しません。

それでも最初の3つが表示されるのは、chunks がリストを先頭から1つずつ作り、map sort と print も先頭から順に使うからです。chunks は切り出した列を空になるまで出し続けるので、表示も終わりません。

Right

chunks :: Int -> [a] -> [[a]]
chunks _ [] = []
chunks m xs = a : chunks m b
 where
  (a, b) = splitAt m xs

空のリストを受け取ったときは列を作らずに [] を返す式を、もとの式より前に置きます。[7] を切り出した残りは [] なので、そこで再帰が止まり、リストが閉じます。

入力の件数が m で割り切れるときも、最後に残るのは [] なので同じ式で止まり、空の列は1つも作られません。入力そのものが空なら、結果も空のリストです。
