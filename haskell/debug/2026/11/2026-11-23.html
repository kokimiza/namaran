2026-11-23

Allow.hs

allowed :: String -> String -> Bool
allowed list user = user `elem` lines list

main :: IO ()
main = print (allowed "ann\r\nbob\r\n" "bob")

allowed list user は、1行に1人ずつ名前を書いた名簿 list に user が載っているかを返すつもりの関数です。main は Windows で保存した、改行が "\r\n" の名簿 "ann\r\nbob\r\n" から "bob" を探します。本来は True を出すはずが、いまは False を出します。

Answer

Wrong

allowed list user = user `elem` lines list

lines が行を分けるのは '\n' の位置だけで、'\r' は普通の文字として行の中に残ります。lines "ann\r\nbob\r\n" は ["ann\r","bob\r"] です。elem は文字列を1文字ずつ比べるので、"bob" は末尾に '\r' の付いた "bob\r" と等しくならず、名簿に載っている名前が見つからないまま False が返ります。

Right

allowed list user =
  user `elem` lines (filter (/= '\r') list)

lines に渡す前に filter (/= '\r') で '\r' を取り除けば、"ann\r\nbob\r\n" は "ann\nbob\n" になり、lines の結果は ["ann","bob"] です。"bob" がそのまま見つかって True になり、改行が "\n" だけの名簿では何も変わりません。名前の中に '\r' が入ることは無いので、行の途中の '\r' まで消しても困りません1。

  1. GHC で readFile や getContents を使う場合、Windows 上では既定で "\r\n" が "\n" に変換されて読み込まれます。Linux や macOS では変換されないので、Windows で作ったファイルをほかの環境で読むと、このバグが表に出ます。
