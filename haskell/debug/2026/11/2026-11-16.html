SameOutput.hs

sameOutput :: [Int] -> [Int] -> Bool
sameOutput xs ys = and (zipWith (==) xs ys)

runningSum, runningSum' :: [Int] -> [Int]
runningSum = scanl1 (+)
runningSum' xs = [sum (take k xs) | k <- [1 .. length xs - 1]]

main :: IO ()
main = print (sameOutput (runningSum [1, 2, 3]) (runningSum' [1, 2, 3]))

sameOutput は、2つの実装が返したリストが同じかどうかを判定し、差分テストに使うつもりの関数です。runningSum' は [1, 2, 3] に対して [1, 3] を返し、runningSum の [1, 3, 6] と食い違うので、False が出力されるはずですが、いまは True が出力されます。

Answer

Wrong

sameOutput :: [Int] -> [Int] -> Bool
sameOutput xs ys = and (zipWith (==) xs ys)

zipWith は2つのリストを先頭から組にして関数を適用し、どちらかのリストが尽きたところで止まります。[1, 3, 6] と [1, 3] では2組しか作られず、結果は [True, True] です。runningSum だけにある 6 はどの組にも入らないので、and は True を返します。

この書き方では、片方の実装が要素を落としても、余分に付け足しても、短い方の長さまでが一致していれば見逃します。片方が空リストを返せば、もう片方が何を返しても True になります。

Right

sameOutput :: [Int] -> [Int] -> Bool
sameOutput = (==)

リストの == は、要素を先頭から比べ、片方だけが先に尽きたら False を返します。長さの違いも食い違いとして扱われるので、[1, 3, 6] == [1, 3] は False になり、runningSum' の誤り（length xs - 1 までしか数えていない）が見つかります。
