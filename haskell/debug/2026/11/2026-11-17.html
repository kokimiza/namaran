Multiples.hs

multiplesOf :: Int -> [Int] -> [Int]
multiplesOf k = filter ((== 0) . mod k)

main :: IO ()
main = print (multiplesOf 3 [1 .. 9])

multiplesOf k は、リストから k の倍数だけを順番どおりに残すつもりの関数です。multiplesOf 3 [1 .. 9] は [3,6,9] を返し、それが出力されるはずですが、いまは [1,3] が出力されます。

Answer

Wrong

multiplesOf k = filter ((== 0) . mod k)

mod は mod a b で a を b で割った余りを返す2引数の関数で、前置で引数を1つだけ渡すと、その値は1つ目の引数 a に入ります。mod k は「k を受け取った値で割った余り」を返す関数になり、要素 x について調べているのは k `mod` x == 0 で、これは x が k の約数かどうかの判定です。

k = 3 では、x = 1 と x = 3 は 3 を割り切るので残り、x = 2 では余りが 1、4 以上の x では余りが 3 なので落ちます。その結果が [1,3] です。filter ((== 0) . mod k) を左から「mod k が 0」と読むと、正しく書けているように見えます。

Right

multiplesOf k = filter ((== 0) . (`mod` k))

バッククォートで中置にした `mod` の右側に k を置いたセクション (`mod` k) は、\x -> x `mod` k と同じ関数で、k を2つ目の引数に入れます。要素 x を k で割った余りが 0 かを調べることになり、[1 .. 9] からは 3、6、9 が残って [3,6,9] が出力されます。flip mod k と書いても同じ関数です。
