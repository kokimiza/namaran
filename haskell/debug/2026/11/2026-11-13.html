Attend.hs

import Data.List (intersect)

members :: [String]
members = ["ann", "bob", "cid"]

checkins :: [String]
checkins = ["bob", "eve", "bob", "ann", "bob"]

main :: IO ()
main = print (length (checkins `intersect` members))

会員名簿 members と入館記録 checkins を照合し、来館した会員が何人いるかを表示するつもりのプログラムです。入館記録には、会員でない人も、同じ人が入館するたびに何度も記録されます。名簿に同じ名前はありません。この入力では ann と bob の2人なので、本来は 2 を出力するはずが、いまは 4 を出力します。

Answer

Wrong

main = print (length (checkins `intersect` members))

xs `intersect` ys は、xs の要素のうち ys にあるものを、xs の順に、xs にある数だけ残します。名前は集合の共通部分を思わせますが、intersect は左のリストを先頭から1つずつ調べて残すかどうかを決めるだけなので、左に3回ある bob は3回とも残ります。checkins `intersect` members は ["bob","bob","ann","bob"] になり、その長さの 4 が表示されます。

Right

main = print (length (members `intersect` checkins))

重複の無い名簿を左に置くと、名簿の名前のうち入館記録にあるものが1つずつ残ります。members `intersect` checkins は ["ann","bob"] で、長さは 2 です。入館記録に同じ人が何度あっても、右のリストは「あるかどうか」を調べるのに使われるだけなので、数には影響しません。1

  1. Data.List の union も左右で扱いが違い、xs `union` ys は xs をそのまま残して、ys からは xs に無い要素を重複を除いて足します。左に重複があれば、それも残ります。
