BlockSums.hs

blockSums :: Int -> [Int] -> [Int]
blockSums b xs = [sum (take b (drop (k * b) xs)) | k <- [0 .. length xs `div` b - 1]]

main :: IO ()
main = print (blockSums 2 [3, 9, 2, 6, 4])

リスト xs を先頭から b 個ずつの塊に分け、各塊の和を順に並べるつもりの blockSums です。最後の塊は b 個に満たなくてもかまいません。blockSums 2 [3, 9, 2, 6, 4] は本来 [12,8,4] になるはずが、いまは [12,8] が返り、最後の要素4が消えます。

Answer

Wrong

blockSums b xs = [sum (take b (drop (k * b) xs)) | k <- [0 .. length xs `div` b - 1]]

div は割り算の商を小数点以下を切り捨てて返すので、length xs `div` b は b 個ちょうどの塊がいくつ取れるかを数えます。要素が5個で b が2なら 5 `div` 2 は2で、k は [0 .. 1] の2通りしか回りません。k が0の塊は3と9で12、1の塊は2と6で8になり、1個だけ余った4の塊は k が2のときに作られるはずでしたが、その番号まで届かずに捨てられます。

Right

blockSums b xs = [sum (take b (drop (k * b) xs)) | k <- [0 .. (length xs + b - 1) `div` b - 1]]

端数の塊まで数えるには、割り算を切り上げにします。(n + b - 1) `div` b は、n が b で割り切れるときは n `div` b と同じで、余りが1以上あるときだけ1大きくなります。5個なら 6 `div` 2 で3になり、k が2の塊は drop 4 で残った [4] から take 2 して [4] になり、和の4が加わります。take は要素が足りなければあるだけを返すので、最後の短い塊もそのまま扱えます。
