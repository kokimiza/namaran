Latest.hs

latest :: a -> [a] -> a
latest = foldl const

main :: IO ()
main = do
  print (latest "default" ["blue", "green"])
  print (latest "default" [])

リストの最後の要素を返し、リストが空なら1つ目の引数の既定値を返すつもりの latest です。main は ["blue", "green"] と空リストを渡します。本来は "green" と "default" を表示するはずが、いまは "default" を2回表示します。

Answer

Wrong

latest = foldl const

const は const x _ = x と定義された関数で、2つの引数のうち1つ目をそのまま返し、2つ目は捨てます。foldl f z [a, b] は f (f z a) b と計算され、f の1つ目の引数はそれまでの畳み込みの結果、2つ目がリストの次の要素です。

この2つを合わせると、foldl const "default" ["blue", "green"] は const (const "default" "blue") "green" になります。内側の const が "blue" を捨てて "default" を返し、外側も "green" を捨てるので、要素がいくつあっても結果は最初の "default" のままです。

Right

latest = foldl (\_ x -> x)

畳み込みの関数を、1つ目の引数を捨てて2つ目を返す \_ x -> x にします。各段で新しく来た要素が前の結果に取って代わるので、最後に残るのはリストの最後の要素です。空リストでは関数が1度も呼ばれず、既定値がそのまま返ります。flip const と書いても同じ関数で、hlint はこれを \_ x -> x と書くよう勧めます。
