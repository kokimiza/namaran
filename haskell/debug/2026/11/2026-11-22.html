Longer.hs

data Len = Mm Int | Cm Int
  deriving (Eq, Ord, Show)

toMm :: Len -> Int
toMm (Mm x) = x
toMm (Cm x) = x * 10

longer :: Len -> Len -> Len
longer a b
  | a >= b = a
  | otherwise = b

main :: IO ()
main = print (toMm (longer (Mm 50) (Cm 3)))

ミリメートルかセンチメートルで表した2つの長さのうち、長いほうを返すつもりの longer です。longer (Mm 50) (Cm 3) は 50mm のほうを返し、ミリメートルに直した 50 を出力するはずが、いまは 3cm のほうを返して 30 を出力します。

Answer

Wrong

longer a b
  | a >= b = a
  | otherwise = b

a >= b が使っている Ord は、deriving で導出したものです。導出した Ord は、まず構築子を宣言した順に比べ、構築子が同じときだけ中の値を比べます。Len では Mm が Cm より先に宣言されているので、Mm の値は中身が何であっても Cm の値より小さくなります。

Mm 50 >= Cm 3 は、構築子の順だけで False に決まり、otherwise の側の Cm 3 が返ります。これを toMm で直した 30 が出力されます。

Right

longer a b
  | toMm a >= toMm b = a
  | otherwise = b

両方を toMm でミリメートルの Int にそろえてから比べます。Mm 50 は 50、Cm 3 は 30 なので、50 >= 30 が成り立ち、Mm 50 が返ります。導出した Ord は構築子が持つ単位の意味を知らないので、単位の違う値を比べるときは、同じ単位に直した値で比べる必要があります。
