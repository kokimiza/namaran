Height.hs

data Tree = Leaf | Node Tree Int Tree

height :: Tree -> Int
height Leaf = 0
height (Node l _ r) = 1 + height l + height r

leaf :: Int -> Tree
leaf x = Node Leaf x Leaf

skewed :: Tree
skewed = Node Leaf 1 (Node Leaf 2 (leaf 3))

balanced :: Tree
balanced = Node (leaf 1) 2 (leaf 3)

main :: IO ()
main = print (height skewed, height balanced)

height は、根から葉までのいちばん長い道にある節の数を返すつもりの関数で、整列済みの順に挿入して右にだけ伸びた木 skewed と、釣り合った木 balanced を比べるのに使います。どちらも 1、2、3 の3つを持ちます。main を実行すると、本来は (3,2) と出力するはずが、いまは (3,3) と出力され、2つの木の違いが見えません。

Answer

Wrong

height (Node l _ r) = 1 + height l + height r

この式は、左の部分木と右の部分木の値を両方足しています。Leaf が 0 で、節ごとに 1 を足して左右の結果を合計するので、返るのは木の中の節の総数です。skewed は節が一列に並んでいるので節の数と高さがどちらも 3 で、たまたま正しい値になります。balanced は根の左右に1つずつ節があり、1 + 1 + 1 で 3 を返しますが、根から葉までの道にある節は2つです。節が同じ数なら、どんな形の木でも同じ値が返ります。

Right

height (Node l _ r) =
  1 + max (height l) (height r)

根から葉までのいちばん長い道は、根から左右どちらかの部分木へ下りて、その中でいちばん長い道をたどるものです。だから高さは、左右の部分木の高さのうち大きいほうに、根の分の 1 を足した値になります。balanced では左右がどちらも 1 なので 2、skewed では左が 0、右が 2 なので 3 になり、(3,2) が出力されます。要素が n 個のとき、右にだけ伸びた木の高さは n、釣り合った木ではおよそ log2 n で、値を探すときに比べる回数はこの高さで決まります。
