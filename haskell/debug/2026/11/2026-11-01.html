2026-11-01

Stars.hs

average :: [Int] -> Double
average xs = fromIntegral (sum xs) / fromIntegral (length xs)

main :: IO ()
main = do
  let saved = show (average [3, 5])
      stars = read saved
  putStrLn (replicate stars '*')

[3, 5] の平均を文字列にして saved に保存し、それを読み戻した数だけ * を並べて表示するつもりのプログラムです。本来は **** と表示されるはずが、いまは何も表示せずに Prelude.read: no parse というエラーで止まります。

Answer

Wrong

let saved = show (average [3, 5])
    stars = read saved
putStrLn (replicate stars '*')

average は Double を返すので、show が作る saved は "4" ではなく "4.0" です。Double の show は、値が整数でも小数点を付けて書くからです。一方 stars には型注釈が無く、replicate の第1引数に渡されることから Int と推論されます。read saved は "4.0" を Int として読もうとし、Int の書き方に小数点は無いので読めずにエラーになります。

保存したときの型が Double でも、read はそれを知りません。読む型を決めるのは、読み戻した値を使う側です。

Right

let saved = show (average [3, 5])
    stars = round (read saved :: Double)
putStrLn (replicate stars '*')

read saved :: Double と注釈を付けて、保存したときと同じ Double として読みます。"4.0" は Double の書き方どおりなので 4.0 が読め、round で Int の 4 に変えてから replicate に渡します。
