HasNeg.hs

hasNeg :: [Int] -> Bool
hasNeg = foldl (\acc x -> acc || x < 0) False

main :: IO ()
main = print (hasNeg (5 : -2 : [1 ..]))

hasNeg は、リストに負の数が1つでもあれば True を返すつもりの関数です。リストが無限に続いても、負の数が現れたところで答えを返すようにしたいものです。main は、5 と -2 のあとに 1 から始まる無限の列が続くリストを調べ、結果を出力します。

hasNeg = foldl (\acc x -> acc || x < 0) False

foldl は foldl f z (x : xs) = foldl f (f z x) xs と、リストの残りに対して自分を呼び続け、空のリストに着いたときに初めて溜めた値を返します。-2 を見た時点で溜めた値は False || -2 < 0 で True になりますが、foldl は値を返さずに次の要素へ進みます。リストに終わりが無いので、|| が結果を確かめる時はいつまでも来ず、foldl はまだ評価していない || の式をメモリに溜めながら進み続けます。print は何も出力しないまま止まりません。

Right 時間計算量 𝒪(k) 空間計算量 𝒪(1) k は最初の負の数までの要素の個数(負の数が無ければリストの長さ) 

hasNeg = any (< 0)

any は foldr と同じ向きにたどり、p x || any p xs の形で結果を返します。|| は左が True なら右を評価しないので、-2 < 0 が True になった時点で、残りの無限の列を見ずに True が返ります。負の数が1つも無い有限のリストなら最後まで調べて False を返し、負の数が無い無限のリストでは、どんな書き方でも答えは出ません。
