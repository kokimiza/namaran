DotMatch.hs

prefix :: String -> String -> Bool
prefix "" _ = True
prefix ('.' : re) s = prefix re (drop 1 s)
prefix (c : re) (x : xs)
  | c == x = prefix re xs
prefix _ _ = False

文字列 s の先頭からパターン re を合わせ、re を最後まで使い切れたら True を返す prefix です。re は普通の文字と、どれか1文字に合う . からなります。prefix "ab." "ab" は、. に合う3文字目が無いので False になるはずが、いまは True を返します。

Answer

Wrong

prefix ('.' : re) s = prefix re (drop 1 s)

drop 1 は、リストが空なら何も捨てずに空リストを返し、失敗しません。prefix "ab." "ab" では、'a' と 'b' が合ったところで、パターンは "."、文字列は "" になります。. の節は文字列の形を問わずに選ばれ、drop 1 "" が "" を返すので、prefix "" "" に進んで True になります。

. は1文字を読んで初めて合うものですが、この節は、読む文字が無くても合ったことにしています。パターンの末尾に . がいくつあっても、文字列が尽きたあとは全部素通りします。

Right

prefix ('.' : re) (_ : xs) = prefix re xs

文字列の側を (_ : xs) というパターンにすると、この節が選ばれるのは、少なくとも1文字残っているときだけになります。文字列が空なら、この節にも次の普通の文字の節にも合わず、最後の prefix _ _ = False に落ちます。prefix "ab." "ab" は False になり、prefix "ab." "abc" では . が 'c' を読んで True のままです。
