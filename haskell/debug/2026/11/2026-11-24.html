Pick.hs

pick :: [(Char, Int)] -> Int -> Char
pick items r =
  case dropWhile ((<= r) . snd) bounds of
    ((c, _) : _) -> c
    [] -> '?'
 where
  (cs, ws) = unzip items
  bounds = zip cs (scanl (+) 0 ws)

main :: IO ()
main = putStrLn (map (pick items) [0 .. 5])
 where
  items = [('x', 3), ('y', 1), ('z', 2)]

pick items r は、0 以上で重みの合計未満の整数 r を受け取り、各項目がその重みと同じ個数の r を受け持つように項目を1つ選ぶつもりの関数です。main は重み 3、1、2 の x、y、z について、r を 0 から 5 まで渡した結果を並べて出力します。本来は xxxyzz を出力するはずが、いまは yyyz?? を出力します。

Answer

Wrong

bounds = zip cs (scanl (+) 0 ws)

出力を項目ごとに見ると、y は3回、z は1回選ばれ、残りの2回は何も選ばれていません。この回数は x と y の重みの 3 と 1 で、どの項目も1つ前の項目の受け持ちを引き継ぎ、最後の z の受け持ちは誰のものにもなっていません。項目と境目の組み合わせが1つずれていることになります。

scanl (+) 0 ws は先頭に初期値 0 を置くので、重み3つに対して [0, 3, 4, 6] の4要素を返します。zip は短いほうに合わせて余りを黙って捨てるので、bounds は [('x', 0), ('y', 3), ('z', 4)] になり、各項目には自分の上端ではなく、1つ前の項目の上端が付きます。r が 0 から 2 なら最初に r を超える境目は y の 3、r が 3 なら z の 4 で、4 と 5 を超える境目は無いので '?' になります。

Right

bounds = zip cs (scanl1 (+) ws)

scanl1 (+) ws は初期値を置かずに先頭の重みから足し始めるので、[3, 4, 6] と項目と同じ数の境目を返します。bounds は [('x', 3), ('y', 4), ('z', 6)] になり、x は r が 0 から 2、y は 3、z は 4 と 5 を受け持って、出力は xxxyzz になります。r は合計の 6 未満なので、最後の境目 6 を超える r は来ず、'?' も出ません。
