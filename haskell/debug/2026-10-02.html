2026-10-02

Prices.hs

prices :: [Double]
prices = [0.1, 0.2, 0.3]

main :: IO ()
main = print (sum (map toRational prices))

prices にある3つの値段を足し、合計を分数で正確に出力するつもりのコードです。引数も標準入力も使いません。本来は 3 % 5 と出力されるはずが、いまは 21617278211378381 % 36028797018963968 と出力されます。

Answer

Wrong

prices :: [Double]
prices = [0.1, 0.2, 0.3]

小数のリテラル 0.1 は、文脈の型での fromRational (1 % 10) として解釈されます1。prices の型が [Double] なので、0.1 は2進の浮動小数点数で表せるいちばん近い値に丸められ、ちょうど10分の1にはなりません。

toRational は、その丸められた値を誤差ごと正確に分数へ写します。3つの値はどれも分母が2の累乗の分数になり、足した結果の分母は2の55乗の 36028797018963968 です。

Right

prices :: [Rational]
prices = [0.1, 0.2, 0.3]

型を [Rational] にすると、同じリテラル 0.1 がそのまま 1 % 10 になり、途中で丸めが起きません。Rational に対する toRational は値を変えないので、和は 3 % 5 になります。

  1. Haskell 2010 の報告書 6.4.1節は、小数のリテラルを Rational の値に fromRational を適用したものと定めています。整数のリテラルが fromInteger の適用であるのと同じ仕組みです。
