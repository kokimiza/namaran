Squares.hs

squares :: String -> String -> [String]

列の名前 files と段の名前 ranks から、盤のマスの名前をすべて並べる squares を書いてください。マスの名前は列の文字と段の文字をこの順につないだ2文字で、列ごとにまとめ、同じ列の中では ranks の順に並べます。どちらかが空なら空リストです。squares "ab" "12" → ["a1","a2","b1","b2"]、squares "c" "123" → ["c1","c2","c3"]、squares "ab" "" → []

Reference 
squares :: String -> String -> [String]
squares files ranks = [[f, r] | f <- files, r <- ranks]

2つの生成器を並べると、左の f <- files が外側、右の r <- ranks が内側のループになります。f が 'a' のあいだに r が ranks を一巡してから、f が 'b' に進むので、列ごとにまとまった順に並びます。生成器を r <- ranks, f <- files の順に書くと、段ごとにまとまった ["a1","b1","a2","b2"] になります。

[f, r] は2つの Char からなるリストで、String は [Char] の別名なので、そのままマスの名前になります。どちらかが空なら、そのループが一度も回らないので結果も空です。

掲載したのは参考実装で、唯一の正解ではありません。do 記法で f <- files と r <- ranks を順に書き、return [f, r] で終える書き方も、同じリストを作ります。
