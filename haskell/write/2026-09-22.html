FormatCents.hs

module Main where

newtype Cents = Cents Integer deriving (Eq, Show)

formatCents :: Cents -> String

Centsは100分の1単位の金額を表す固定小数点数です。formatCentsは、これを小数点以下2桁の文字列にして返します(1桁しかない端数は0埋めし、負の値は先頭に-を1つだけ付けます)。formatCents (Cents 1234) → "12.34"、formatCents (Cents 5) → "0.05"(境界: 端数が1桁)、formatCents (Cents (-5)) → "-0.05"(境界: 負の値)、formatCents (Cents 0) → "0.00"

Reference 
formatCents :: Cents -> String
formatCents (Cents n) =
  sign ++ show whole ++ "." ++ pad (show frac)
  where
    sign = if n < 0 then "-" else ""
    whole = abs n `div` 100
    frac = abs n `mod` 100
    pad s = if length s < 2 then '0' : s else s

符号はn自身の正負から先に取り出し、以後はabs n(絶対値)だけを扱うことで、整数部と端数部を符号なしのまま計算できます。整数部はabs n `div` 100、端数部はabs n `mod` 100です。端数部をshowしただけだと5のような1桁の文字列になってしまうので、padで2桁に0埋めしています。これは参考実装であり、唯一の正解ではありません(Text.Printfを使う書き方もできます)。
