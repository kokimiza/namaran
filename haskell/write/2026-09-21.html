clamp :: Int -> Int -> Int -> Int

  | x < lo = lo
  | x > hi = hi
  | otherwise = x

典型的な(範囲内の)値だけを1つ検証しても、clampの本体を丸ごとxを返すだけの実装に差し替えてもそのテストは通ってしまいます。単体テストが本当に検証すべきなのは、実装を間違えやすい境界(lo・hiちょうど)と、その外側の値です。ここでは範囲外を2方向、境界を2点、それに範囲内を1点加えることで、clampの分岐(x < lo・x > hi・otherwise)をひととおりカバーしています。これは参考実装であり、テストケースの名前や順序に唯一の正解はありません。
