Describe.hs

describe :: [Int] -> String

リストが空なら"empty"、要素が1つならその数、2つ以上なら先頭と末尾を..でつないだ文字列を返すdescribeを書いてください。ただし、GHCiにそのまま貼れるよう、定義は改行を入れずに1行で書きます。describe [3,1,4] → "3..4"、describe [7] → "7"、describe [] → "empty"

Reference 
describe :: [Int] -> String
describe xs = case xs of { [] -> "empty"; [x] -> show x; (x:_) -> show x ++ ".." ++ show (last xs) }

caseの選択肢は、ふだんは改行と字下げで区切られています。ofのあとに{が来ないと、レイアウト規則は次の字句の列を基準にして暗黙の{を開き、その列から始まる行の前に;を、それより左から始まる行の前に}を補います。1行に収めるには、この{と;と}を自分で書きます。

明示した{ }の中ではレイアウト規則が働かないので、字下げを気にせずに書けます。暗黙のブロックの中に;を明示して置くこともできるため、{ }を省いて;だけで区切っても通ります。選択肢は上から順に照合されるので、[x]は(x:_)より前に置きます。逆にすると1要素のリストも(x:_)に当たり、describe [7]が"7..7"になります。これは参考実装であり、唯一の正解ではありません。
