ChunksOf.hs

chunksOf :: Int -> [a] -> [[a]]

リストを先頭から n 個ずつの塊に分けたリストを返す chunksOf を書いてください。最後の塊は n 個に満たなくてもよく、空リストには空リストを返します。無限リストを渡したときも、取り出した分の塊は有限の時間で返します。n は1以上です。

入力例 1

chunksOf 2 [1 .. 5]

出力例 1

[[1,2],[3,4],[5]]

入力例 2

chunksOf 3 []

出力例 2

[]

入力例 3

take 2 (chunksOf 2 [1 ..])

出力例 3

[[1,2],[3,4]]
Reference 
chunksOf :: Int -> [a] -> [[a]]
chunksOf n = takeWhile (not . null) . map (take n) . iterate (drop n)

iterate (drop n) xs は、xs、drop n xs、drop (2 * n) xs … と、n 個ずつ削った残りを終わりなく並べます。それぞれの先頭 n 個を map (take n) で取ると塊の無限リストになり、入力を使い切ったあとには空リストが無限に続きます。takeWhile (not . null) は最初の空リストで止まるので、塊の列はそこで終わります。

この組み合わせでは、どの段も次の段が要求した分しか計算しません。takeWhile が空リストを見つけたあと、iterate の続きは誰にも要求されないので、無限の列を作っても計算は止まります。入力が無限なら空の塊は現れず、take 2 が要求した2つの塊だけが計算されます。takeWhile の代わりに filter (not . null) を使うと、最後の塊のあとも空でない塊を探し続け、結果のリストが終わらなくなります。

掲載したのは参考実装で、唯一の正解ではありません。splitAt n で塊と残りに分け、残りに再帰する書き方でも、無限リストにそのまま使えます。
