Erase.hs

newtype Erased = Erased (Int -> ShowS)

instance Show Erased where
  showsPrec d (Erased f) = f d

erase :: Show a => a -> Erased

Show を持つどんな型の値も、表示のしかただけを残して同じ型 Erased に包む erase を書いてください。包んだ値は、元の値を同じ場所に置いたときと同じ文字列で表示されるようにします。Just の引数のように、値によっては括弧が要る位置に置いた場合も同じで、元の値に括弧が付くなら包んだ値にも付けます。

入力例 1

show [erase (1 :: Int), erase "hi", erase 'c']

出力例 1

[1,"hi",'c']

入力例 2

show (Just (erase (-3 :: Int)))

出力例 2

Just (-3)

入力例 3

show (Just (erase (Just True)))

出力例 3

Just (Just True)
Reference 
erase :: Show a => a -> Erased
erase x = Erased (\d -> showsPrec d x)

Erased が持っているのは、優先度 d を受け取って文字列を組み立てる関数だけです。erase は x を閉じ込めた関数 \d -> showsPrec d x を作るので、外からは x の型が見えず、Int も String も同じ Erased としてリストに並べられます。どの型の showsPrec を使うかは関数を作った時点で決まり、関数の中に残ります。

優先度を受け取るのは、括弧を付けるかどうかを外側の文脈が決めるからです。Just の showsPrec は引数を優先度11で表示させ、Int の showsPrec は優先度が6より大きいときに負の数を括弧で囲みます。\_ -> shows x のように優先度を捨てると、shows はいつも優先度0で表示するので、入力例 2 は Just -3 に、入力例 3 は Just Just True になります。

掲載したのは参考実装で、唯一の正解ではありません。erase x = Erased (`showsPrec` x) のように、演算子の切断で書くこともできます。どちらも拡張機能を使わず、Haskell 2010 の範囲で型を消しています。
