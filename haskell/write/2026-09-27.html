DigitCount.hs

digitCount :: Int -> Int

0以上の整数 n を10進数で書いたときの桁数を返す digitCount を書いてください。0 は1桁と数えます。digitCount 12345 → 5、digitCount 7 → 1、digitCount 0 → 1

Reference 
digitCount :: Int -> Int
digitCount n
  | n < 10 = 1
  | otherwise = 1 + digitCount (n `div` 10)

n は10で割るたびに1桁ずつ短くなるので、1桁になるまで割った回数に1を足せば桁数になります。再帰の終わりを n < 10 にすると 0 から 9 までが1桁になり、0 を特別扱いせずに済みます。

命令型言語で while (n > 0) { n /= 10; count++; } と書くと、0 では本体が一度も実行されず、桁数が 0 になります。本体を1回実行してから条件を調べる do-while なら 0 も1桁と数えられ、上の再帰はこちらと同じ形です。Haskell にはループの構文がないので、条件を本体の前で調べるか後で調べるかは、再帰をどう書くかで決まります。

掲載したのは参考実装で、唯一の正解ではありません。length (show n) でも同じ値になります。
