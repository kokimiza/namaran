ExitStatus.hs

exitStatus :: IO () -> IO Int

IO アクション act を実行し、act がそのままプログラムを終えたとしたら得られる終了コードを返す exitStatus を書いてください。act が最後まで実行されて戻ってきたら 0、途中で exitWith (ExitFailure n) を実行したら n、exitSuccess を実行したら 0 を返します。どの場合もプログラムは終わらせずに、exitStatus の呼び出し元へ戻ります。ExitCode 以外の例外は捕まえずに、そのまま外へ伝えます。

入力例 1

exitStatus (return ())

出力例 1

0

入力例 2

exitStatus (exitFailure >> putStrLn "unreachable")

出力例 2

1

入力例 3

exitStatus (exitWith (ExitFailure 3))

出力例 3

3
Reference 
import Control.Exception (try)
import System.Exit (ExitCode (..), exitFailure, exitWith)

exitStatus :: IO () -> IO Int
exitStatus act = do
  r <- try act
  return $ case r of
    Right () -> 0
    Left ExitSuccess -> 0
    Left (ExitFailure n) -> n

exitWith を実行しても、プロセスはその場では終わりません。exitWith は ExitCode 型の値を例外として投げ、その例外が main の外まで伝わったところで、ランタイムがその値を終了コードにしてプログラムを終えます。途中で捕まえれば、プログラムはそのまま続きます。

try act は act を実行し、例外が投げられなければ結果を Right に、投げられればその例外を Left に入れて返します。捕まえる例外の型は Left の中身の型で決まり、ここでは case の Left ExitSuccess と Left (ExitFailure n) というパターンから ExitCode と推論されます。それ以外の型の例外は try を素通りして外へ伝わります。exitFailure は exitWith (ExitFailure 1) と同じなので、入力例 2 は 1 を返し、続く putStrLn は実行されません。

掲載したのは参考実装で、唯一の正解ではありません。catch に ExitCode -> IO Int 型の関数を渡しても同じことができます。try と catch は GHC の base ライブラリの Control.Exception にあり、Haskell 2010 の言語報告のライブラリには含まれていませんが、言語拡張は使っていません。
