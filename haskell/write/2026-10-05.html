Ring.hs

import Data.Array

data Ring a = Ring Int Int (Array Int a)

toList :: Ring a -> [a]

Ring start size buf は、配列 buf を輪のように使うキューです。一番古い要素が位置 start にあり、そこから size 個の要素が順に入っていて、位置が配列の末尾を越えると0に戻ります。中身を古い順に並べたリストを返す toList を書いてください。buf の添字は0から始まり、size が0なら空リストを返します。

入力例 1

toList (Ring 2 3 (listArray (0, 2) "dec"))

出力例 1

"cde"

入力例 2

toList (Ring 3 2 (listArray (0, 3) "bxya"))

出力例 2

"ab"

入力例 3

toList (Ring 1 0 (listArray (0, 2) "abc"))

出力例 3

""

import Data.Array

data Ring a = Ring Int Int (Array Int a)

toList :: Ring a -> [a]
toList (Ring start size buf) = take size (drop start (cycle (elems buf)))

参考実装は、配列の中身を cycle で繰り返し、先頭から start 個を捨てて size 個を取ります。入力例1なら cycle "dec" は "decdecdec..." と続く無限リストで、2個捨てると "cdecde..."、そこから3個取ると "cde" です。遅延評価なので、無限リストは take size が求める分しか作られません。末尾から0に戻る処理を、添字の計算ではなくリストの形で表しています。

掲載したのは参考実装で、唯一の正解ではありません。添字で書くなら、cap = rangeSize (bounds buf) として [buf ! ((start + i) `mod` cap) | i <- [0 .. size - 1]] です。cycle は空リストを渡すとエラーになるので、容量0の配列もありうるなら、こちらの書き方のほうが安全です。
