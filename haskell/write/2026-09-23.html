LogReplay.hs

module Main where

import qualified Data.Map as Map

data Entry = Put String Int | Delete String deriving Show

replay :: [Entry] -> Map.Map String Int

ログ[Entry]を先頭から順に適用し、最終的な状態をMapとして返すreplayを書いてください(WAL——Write-Ahead Logging——からの復元処理です)。Put k vはキーkに値vを書き込み(既にkがあれば上書き)、Delete kはキーkを削除します(存在しなければ何もしません)。ログが空のときは空のMapです。replay [] → Map.empty(境界: 空のログ)、Map.toList (replay [Put "a" 1, Put "a" 2]) → [("a",2)](上書き)、Map.toList (replay [Put "a" 1, Delete "a", Put "b" 5]) → [("b",5)]

replay :: [Entry] -> Map.Map String Int
replay = foldl step Map.empty
  where
    step m (Put k v) = Map.insert k v m
    step m (Delete k) = Map.delete k m

ログの各エントリをstepで1件ずつMapへ適用しながらfoldlで畳み込みます。Put k vはMap.insertでその場で上書きし、Delete kはMap.deleteで取り除きます(存在しないキーの削除はMap.deleteが何もしないので、特別な分岐は要りません)。ログが空ならfoldlは初期値のMap.emptyをそのまま返すので、空リストの境界条件も自然に満たされます。これは参考実装であり、唯一の正解ではありません(実務では、正格な畳み込みであるfoldl'を使うほうが望ましいことが多いです)。
