Reconcile.hs

reconcile :: [Int] -> [Int] -> ([Int], [Int])

帳簿に載った取引の番号 ledger と、銀行の明細に載った番号 bank を突き合わせる reconcile を書いてください。帳簿にしか無い番号と明細にしか無い番号を、それぞれ昇順で重複なく並べた組を返します。同じ番号が何度現れても1つとして数えます。両方が同じ番号の集まりなら、組は空リスト2つです。

入力例 1

reconcile [3, 1, 2] [2, 4]

出力例 1

([1,3],[4])

入力例 2

reconcile [5, 5] [5]

出力例 2

([],[])

入力例 3

reconcile [] [7]

出力例 3

([],[7])

import qualified Data.Set as Set

reconcile :: [Int] -> [Int] -> ([Int], [Int])
reconcile ledger bank = (only a b, only b a)
 where
  a = Set.fromList ledger
  b = Set.fromList bank
  only x y = Set.toAscList (Set.difference x y)

Set.fromList でリストを集合にすると、重複は1つにまとまります。帳簿にしか無い番号は、帳簿の集合から明細の集合にある要素を取り除いた差集合（set difference）で、Set.difference a b がそれを返します。明細にしか無い番号は、引数を入れ替えた Set.difference b a です。

Set.toAscList は集合の要素を昇順のリストにして返すので、並べ替えを別に書く必要はありません。入力例 2 では、帳簿の [5, 5] も明細の [5] も同じ集合になり、どちらの差集合も空になります。

掲載したのは参考実装で、唯一の正解ではありません。Data.List の nub、sort、filter でも書けますが、notElem で要素ごとに相手のリスト全体を調べることになり、長いリストでは遅くなります。
