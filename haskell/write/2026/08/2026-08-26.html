Rolls.hs

rolls :: [Int] -> [[Int]]

面の数がそれぞれ違うサイコロを並べて振ったときの、目の出方をすべて返す rolls を書いてください。引数の各要素は、その位置のサイコロの面の数 k で、そのサイコロの目は1から k までです。目の出方を並べる順は問いません。面の数が0のサイコロが1つでもあれば、出方は1つも無いので空リストを返します。

入力例 1

rolls [2, 3]

出力例 1

[[1,1],[1,2],[1,3],[2,1],[2,2],[2,3]]

入力例 2

rolls [3]

出力例 2

[[1],[2],[3]]

入力例 3

rolls [2, 0]

出力例 3

[]

rolls :: [Int] -> [[Int]]
rolls = mapM (\k -> [1 .. k])

各サイコロの面の数 k を、出うる目のリスト [1 .. k] に変えれば、あとはそれぞれのリストから1つずつ選ぶ組み合わせをすべて作るだけです。リストのモナドで mapM を使うと、rolls [2, 3] は do { x <- [1, 2]; y <- [1, 2, 3]; return [x, y] } と同じ計算になります。掲載したのは参考実装で、唯一の正解ではありません。traverse でも、sequence (map (\k -> [1 .. k]) ks) でも同じ結果になります。

同じリストを n 回並べるなら replicateM で足りますが、ここでは位置ごとに候補のリストが違うので、リストのリストを順にたどる mapM を使います。入力例 3 では2つ目のサイコロの候補が空の [1 .. 0] になり、y <- で選べる値が無いため、どの x からも組み合わせが作られず、結果は [] になります。
