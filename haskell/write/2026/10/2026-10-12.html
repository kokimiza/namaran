CLiteral.hs

cLiteral :: String -> Int

C の整数リテラルを表す文字列を受け取り、その値を返す cLiteral を書いてください。0x で始まれば16進数、そうでなく 0 で始まれば8進数、どちらでもなければ10進数として読み、"0" はそのまま 0 とします。渡されるのは符号も接尾辞も付かない正しいリテラルだけで、16進数の英字は大文字と小文字のどちらもありえます。

入力例 1

cLiteral "0755"

出力例 1

493

入力例 2

cLiteral "0x1F"

出力例 2

31

入力例 3

cLiteral "0"

出力例 3

0
Reference 
import Data.Char (digitToInt)

cLiteral :: String -> Int
cLiteral ('0' : 'x' : ds) = digits 16 ds
cLiteral ('0' : ds) = digits 8 ds
cLiteral ds = digits 10 ds

digits :: Int -> String -> Int
digits base = foldl (\n c -> n * base + digitToInt c) 0

パターンは上から順に照合されるので、長い接頭辞の '0' : 'x' を先に置きます。順番が逆だと "0x1F" が先に '0' : ds に当てはまり、"x1F" を8進数として読もうとして digitToInt 'x' が例外を投げます。"0" は '0' : ds に当てはまって ds が空になり、foldl は初期値の 0 をそのまま返します。

digits は桁を左から読み、それまでの値を基数倍して次の桁を足していきます。digitToInt は 'a' から 'f' と 'A' から 'F' も 10 から 15 に変えるので、16進数も同じ関数で読めます。Haskell 自身のリテラルは8進数を 0o で書き、read "0755" は 755 になるので、C の規則で読みたいときはこうして自分で振り分けます。

掲載したのは参考実装で、唯一の正解ではありません。Numeric の readHex、readOct、readDec に振り分ける書き方もあります。
