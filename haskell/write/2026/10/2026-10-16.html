Rank.hs

rank :: [String] -> [String]

単語のリストを長い順に並べ替えて返す rank を書いてください。長さが同じ単語どうしは、compare で小さいほうを先に置きます。同じ単語が複数あればすべて残し、空のリストには空のリストを返します。

入力例 1

rank ["fig", "apple", "kiwi", "pear", "banana"]

出力例 1

["banana","apple","kiwi","pear","fig"]

入力例 2

rank []

出力例 2

[]

入力例 3

rank ["b", "a", "b"]

出力例 3

["a","b","b"]
Reference 
import Data.List (sortBy)
import Data.Ord (comparing)

rank :: [String] -> [String]
rank = sortBy (flip (comparing length) <> compare)

comparing length は2つの単語の長さを compare する比較関数です。flip で引数の順を入れ替えると、長いほうの単語が LT の側、sortBy が先に置く側になります。

2つの比較関数を <> でつなぐと、まず左で比べ、結果が EQ のときだけ右で比べる比較関数になります。関数どうしの <> は同じ2つの引数を両方の関数に渡して結果を <> でつなぎ、Ordering どうしの <> は左が LT か GT ならそれを、EQ なら右を返すからです。入力例 1 の "kiwi" と "pear" は長さが同じなので、右の compare で "kiwi" が先になります。

全体を flip して sortBy (flip (comparing length <> compare)) としたり、昇順に並べてから reverse したりすると、長さだけでなく同じ長さの単語の順まで逆になり、"pear" が "kiwi" より先に出ます。逆にしたいのは長さの比較だけなので、flip はその比較関数だけに掛けます。

掲載したのは参考実装で、唯一の正解ではありません。Data.Ord の Down を使って sortBy (comparing (Down . length) <> compare) と書いても同じです。なお <> を import なしで使えるのは GHC の base ライブラリ 4.11 以降の Prelude で、Haskell 2010 の言語報告にはありません。言語拡張は使っていません。
