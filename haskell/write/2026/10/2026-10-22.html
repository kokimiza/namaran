Encode.hs

encode :: String -> String

文字列の中で同じ文字が続く区間を、その文字と、続く個数の10進表記に置き換えた文字列を返す encode を書いてください。個数が1の区間は文字だけにして、数字を付けません。空文字列には空文字列を返します。

入力例 1

encode "aaabcc"

出力例 1

"a3bc2"

入力例 2

encode "x"

出力例 2

"x"

入力例 3

encode ""

出力例 3

""

import Data.List (group)

encode :: String -> String
encode s = concat [c : if n == 1 then "" else show n | g@(c : _) <- group s, let n = length g]

同じ値の連続を「値と個数」で表すこの方法を、ランレングス圧縮(run-length encoding)といいます。連続を見つける仕事は Data.List の group に任せられます。group "aaabcc" は隣り合う等しい文字をまとめた ["aaa","b","cc"] を返すので、あとはグループごとに文字と個数を書けば済みます。

内包表記の g@(c : _) は、グループ全体を g、その先頭の文字を c に束縛します。group が空のグループを返すことはないので、このパターンは必ず当てはまり、部分関数の head を使わずに先頭を取り出せます。let n = length g で個数を一度だけ数え、1なら空文字列、それ以外なら show n を文字の後ろに付けます。show は個数が10以上でも全部の桁を書くので、12個の連続は "12" になります。最後に concat で全グループの文字列をつなぎます。

空文字列では group が空リストを返し、結果も空文字列です。掲載したのは参考実装で、唯一の正解ではありません。concatMap と補助関数で書いても同じです。
