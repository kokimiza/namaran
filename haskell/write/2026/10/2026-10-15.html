Chain.hs

chain :: [Int -> Int] -> Int -> [Int]

関数のリスト fs と初期値 x を受け取り、x に fs の関数を先頭から順に適用していったときの途中の結果をすべて並べたリストを返す chain を書いてください。リストは x 自身から始まり、関数を1つ適用するごとに1要素増えます。fs が空なら [x] です。

入力例 1

chain [(+ 1), (* 2), subtract 3] 5

出力例 1

[5,6,12,9]

入力例 2

chain [] 7

出力例 2

[7]

入力例 3

chain [negate, abs] 4

出力例 3

[4,-4,4]
Reference 
chain :: [Int -> Int] -> Int -> [Int]
chain fs x = scanl (flip ($)) x fs

scanl は foldl と同じ順に左から畳み込みながら、途中の結果をすべてリストに残します。初期値が先頭に入るので、関数が n 個なら結果は n + 1 要素になり、fs が空なら [x] です。

scanl に渡す関数は、それまでの結果を1つ目の引数に、リストの要素を2つ目の引数に受け取ります。ここではリストの要素が関数なので、要るのは結果 acc と関数 f をこの順に受け取って f acc を返す関数です。($) は f と acc の順に受け取って f acc を返すので、flip で引数の順を入れ替えれば、ちょうどその関数になります。

掲載したのは参考実装で、唯一の正解ではありません。ラムダ式で scanl (\acc f -> f acc) x fs と書いても同じで、引数の順はこちらのほうが目で確かめやすくなります。
