FitWidth.hs

import Data.Char (ord)

charWidth :: Char -> Int
charWidth c = if ord c < 0x1100 then 1 else 2

fitWidth :: Int -> String -> String

端末で文字が占める桁数を表示幅と呼び、ここでは1文字の表示幅を charWidth で決めます。コードポイントが 0x1100 以上の文字は幅2で、漢字、かな、絵文字はこちらに入ります。文字列 s を、表示幅がちょうど n の文字列にする fitWidth n s を書いてください。s の先頭から、表示幅の合計が n を超えない範囲で文字を残し、足りない幅は末尾に空白を足して埋めます。幅2の文字が残りの幅1に収まらないときは、その文字を半分に割らず、そこから先を捨てて空白で埋めます。n は 0 以上で、n が 0 なら空文字列です。

入力例 1

fitWidth 5 "日本語"

出力例 1

"日本 "

入力例 2

fitWidth 4 "ab"

出力例 2

"ab  "

入力例 3

fitWidth 3 "🍵🍵"

出力例 3

"🍵 "
Reference 
fitWidth :: Int -> String -> String
fitWidth n (c : cs)
  | charWidth c <= n = c : fitWidth (n - charWidth c) cs
fitWidth n _ = replicate n ' '

n を残りの幅として、先頭の文字 c が残りに収まる間は c を残し、残りの幅から c の幅を引いて続きを処理します。take n s で切ると、数えるのは文字の個数なので、入力例1では3文字とも残って表示幅が6になってしまいます。

ガードが偽になったとき、Haskell は次の等式に進みます。文字列が尽きたときと、先頭の文字が残りの幅に収まらないときは、どちらも2つ目の等式に落ち、残りの幅だけ空白を返します。入力例1では 日本 で残りが1になり、語 の幅2が収まらないので、空白1つで埋まります。

掲載したのは参考実装で、唯一の正解ではありません。scanl で表示幅の累計を作り、takeWhile で n 以下の部分を取ってから、足りない幅を replicate で埋める書き方もあります。
