Average.hs

average :: [Integer] -> Maybe Rational

Integer のリストの平均を、小数に丸めずに Rational で返す average を書いてください。リストが空のときは平均が定まらないので、Nothing を返します。

入力例 1

average [1, 2, 3, 4]

出力例 1

Just (5 % 2)

入力例 2

average [-1, 1]

出力例 2

Just (0 % 1)

入力例 3

average []

出力例 3

Nothing
Reference 
import Data.Ratio ((%))

average :: [Integer] -> Maybe Rational
average [] = Nothing
average xs = Just (sum xs % toInteger (length xs))

% は、分子と分母に同じ Integral 型の値を取ります。sum xs は Integer ですが length xs は Int なので、sum xs % length xs は型が合わずにコンパイルできません。toInteger で分母を Integer にそろえれば、Integer どうしの % で Rational ができます。

空のリストを別の式で先に受けるのは、% が分母の 0 を受け付けないからです。0 % 0 を評価すると、NaN のような値にはならず、Ratio has zero denominator という例外が起きます。Maybe で返せば、平均の無いリストを呼び出し側が型で見分けられます。

例2の 0 % 1 は、和が 0 になった 0 % 2 が約分された形です。掲載したのは参考実装で、唯一の正解ではありません。結果の型を Rational にしておけば、fromIntegral (sum xs) / fromIntegral (length xs) と書いても同じ値になります。
