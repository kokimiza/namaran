SplitLines.hs

splitLines :: String -> [String]

文字列を '\n' ごとに区切った各部分を返す splitLines を書いてください。どの s についても、Data.List の intercalate "\n" (splitLines s) が s に戻るようにします。s が '\n' で終わるときは最後の要素が空文字列になり、s が空文字列なら [""] を返します。

入力例 1

splitLines "a\n\nb\n"

出力例 1

["a","","b",""]

入力例 2

splitLines ""

出力例 2

[""]

入力例 3

splitLines "a"

出力例 3

["a"]
Reference 
splitLines :: String -> [String]
splitLines s = case break (== '\n') s of
  (l, []) -> [l]
  (l, _ : rest) -> l : splitLines rest

break (== '\n') s は、s を最初の '\n' の手前とそれ以降に分けます。後ろが空なら '\n' はもう残っていないので、手前の部分が最後の要素です。後ろが '\n' で始まっていれば、その '\n' を落とした残りを同じように区切ります。

残りが空文字列になっても再帰を続けるところが、lines との違いです。"a\n" は1回目の break で "a" と "\n" に分かれ、残りの "" に対する2回目の break が ("", "") を返すので、最後に空文字列が入ります。lines は残りが空になった時点で止まるので、"a\n" と "a" をどちらも ["a"] にしてしまいます。

掲載したのは参考実装で、唯一の正解ではありません。foldr で1文字ずつ見て、'\n' のたびに新しい要素を始める書き方もできます。
