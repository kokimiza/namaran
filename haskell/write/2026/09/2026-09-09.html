Ordered.hs

ordered :: Ord a => [a] -> Bool

リストの隣り合う2要素がすべて <= の関係にあるときに True を返す ordered を書いてください。ソート関数を検証する性質 ordered (sort xs) に使うためのものです。空リストと1要素のリストは True です。ordered [1, 2, 2, 5] → True、ordered [3, 1] → False、ordered [] → True

Reference 
ordered :: Ord a => [a] -> Bool
ordered xs = and (zipWith (<=) xs (drop 1 xs))

xs と、1つずらした drop 1 xs を zipWith (<=) で並べて比べると、隣り合う組ごとの比較結果のリストができます。and はそれがすべて True かを返し、空のリストには True を返すので、比べる組のない空リストと1要素のリストはそのまま True になります。zipWith は短いほうのリストが尽きたところで止まるので、末尾の要素が相手のいない比較をすることもありません。

drop 1 の代わりに tail と書いても結果は同じです1。ただしGHC 9.8以降は tail を部分関数として警告します。

これは参考実装であり、唯一の正解ではありません。ordered (x : y : rest) = x <= y && ordered (y : rest) と、空と1要素の場合を分けた再帰で書くこともできます。述語ができれば、all (ordered . sort) inputs で、用意した入力のすべてについてソートの結果が昇順かを確かめられます。

  1. xs が空なら zipWith は2つ目の引数を見ずに [] を返すので、tail [] が評価されることはありません。
