Tally.hs

tally :: [String] -> [(String, Int)]

大文字と小文字の違いを無視して、単語ごとの出現回数を数える tally を書いてください。各単語は最初に現れたときの綴りで返し、並び順は各単語を map toLower した文字列の昇順です。空のリストには空のリストを返します。

入力例 1

tally ["Go", "rust", "go", "GO"]

出力例 1

[("Go",3),("rust",1)]

入力例 2

tally ["b", "_a", "B"]

出力例 2

[("_a",1),("b",2)]

入力例 3

tally []

出力例 3

[]
Reference 
import Data.Char (toLower)
import qualified Data.Map as Map

tally :: [String] -> [(String, Int)]
tally ws = Map.elems (Map.fromListWith keepFirst [(map toLower w, (w, 1)) | w <- ws])
  where
    keepFirst (_, n) (w, m) = (w, m + n)

キーには map toLower w を、値には元の綴りと回数の組を入れます。Map は要素をキーの順に持つので、Map.elems で取り出せば、そのまま問題の並び順になります。

同じキーの値をまとめる関数は、引数の順に気を付けます。Map.fromListWith f はリストを先頭から入れていき、キーがすでにあれば f 新しい値 すでにある値 を計算します。最初の綴りは、すでにある値の側、つまり第2引数に入っています。keepFirst がそちらの w を残すのはそのためで、第1引数の綴りを残すと、例1は最後の綴りの ("GO",3) になります。

キーを map toUpper で作っても、同じ単語どうしはまとまりますが、並び順が変わります。'_' の文字コードは大文字と小文字の間にあるので、小文字にそろえると "_a" は "b" より前に、大文字にそろえると "B" より後ろに並び、例2の順が逆になります。

この並びは文字コードの順で、ロケールの照合順序ではありません。toLower もロケールを見ずに1文字ずつ変換するので、どの環境で動かしても例と同じ結果になり、たとえば 'é' で始まる単語は 'z' で始まる単語より後ろに並びます。

掲載したのは参考実装で、唯一の正解ではありません。sortOn で並べてから、キーが同じ単語の連続をまとめる書き方もあります。
