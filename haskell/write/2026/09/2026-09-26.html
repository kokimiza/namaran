Mean.hs

mean :: [Double] -> Double

Double のリストの平均を返す mean を書いてください。リストは1回だけ走査し、要素が100万個あっても未評価の足し算を溜め込まないようにします。空リストなら 0 を返します。mean [1, 2, 3, 4] → 2.5、mean [5] → 5.0、mean [] → 0.0

Reference 
import qualified Data.List as L

mean :: [Double] -> Double
mean [] = 0
mean xs = total / fromIntegral count
  where
    (total, count) = L.foldl' step (0, 0 :: Int) xs
    step (s, c) x = let s' = s + x; c' = c + 1 in s' `seq` c' `seq` (s', c')

和と個数を同時に数えれば走査は1回で済むので、タプル (和, 個数) を畳み込みで持ち回ります。foldl は途中の値を評価しないまま次へ渡すので、各段で評価する foldl' を使います。ただし foldl' が評価するのは、途中の値を弱頭部正規形(いちばん外側の構成子が分かるところ)までです。タプルなら (,) が見えた時点で止まり、中の s + x と c + 1 は評価されません。step (s, c) x = (s + x, c + 1) と書くと、毎回評価されるのはタプルの外側だけで、中には ((0 + 1) + 2) + … のような足し算のサンクが要素の数だけ連なります。

そこで step の中で seq を使い、和と個数を評価してからタプルに入れます。a `seq` b は a を弱頭部正規形まで評価してから b を返すので、foldl' がタプルを評価するたびに、中の数も計算済みになります。Double や Int は、弱頭部正規形まで評価すればそれが値そのものです。

foldl' は Haskell 2010 の Prelude には無いので、Data.List から取り込みます。新しい base では Prelude からも見えるため、ここでは修飾付きで取り込みました1。掲載したのは参考実装で、唯一の正解ではありません。和と個数を引数に持つ補助関数を再帰で回し、各段で seq しても同じように書けます。

  1. GHC 9.10 に付属する base 4.20 から、Prelude も foldl' を公開しています。そのため import Data.List (foldl') と書くと、新しい GHC の -Wall ではこの import が不要だと警告されます。
