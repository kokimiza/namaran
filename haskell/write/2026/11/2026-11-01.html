ParseInt.hs

parseInt :: String -> Maybe Int

文字列 s 全体が1つの整数として読めるならその値を Just で包んで返し、読めなければ Nothing を返す parseInt を書いてください。整数の前後に空白があってもかまいません。空文字列や、整数のあとに別の文字が続く文字列は Nothing です。読み方は read が Int を読むときと同じで、read と違って読めなくてもエラーで止まらないようにします。

入力例 1

parseInt " -7 "

出力例 1

Just (-7)

入力例 2

parseInt "4x"

出力例 2

Nothing

入力例 3

parseInt ""

出力例 3

Nothing

import Data.Char (isSpace)

parseInt :: String -> Maybe Int
parseInt s = case reads s of
  [(n, rest)] | all isSpace rest -> Just n
  _ -> Nothing

reads は先頭の空白を読み飛ばしてから値を1つ読み、読めた値と読み残した文字列の組をリストにして返します。読めなければ空リストです。"4x" なら [(4,"x")]、" -7 " なら [(-7," ")]、"" なら [] になります。型シグネチャが戻り値を Maybe Int と決めているので、Just n の n が Int になり、reads も Int として読みます。

値が読めても、読み残しに空白以外の文字があれば文字列全体は整数ではありません。そこで、組がちょうど1つで、読み残しがすべて空白のときだけ Just n を返し、それ以外は Nothing にします。読み残しを確かめずに最初の組の値を返すと、"4x" が Just 4 になってしまいます。

掲載したのは参考実装で、唯一の正解ではありません。Haskell 2010 の標準ライブラリの範囲外ですが、GHC の base にある Text.Read.readMaybe も同じ判定をします。
