Unescape.hs

unescape :: String -> String

タブを \ と t の2文字で、バックスラッシュ1文字を \ 2文字で表した文字列を、元の文字列に戻す unescape を書いてください。入力は、元の文字列をこの規則でエスケープしたものだけで、ほかの文字はそのまま残します。例の入出力は Haskell の文字列リテラルで書きます。

入力例 1

unescape "name\\tage"

出力例 1

"name\tage"

入力例 2

unescape "C:\\\\tmp"

出力例 2

"C:\\tmp"

入力例 3

unescape ""

出力例 3

""

Reference

unescape :: String -> String
unescape ('\\' : 't' : rest) = '\t' : unescape rest
unescape ('\\' : '\\' : rest) = '\\' : unescape rest
unescape (c : rest) = c : unescape rest
unescape [] = []

エスケープされた文字は、どれもバックスラッシュで始まる2文字です。リストのパターンで先頭の2文字を見て、'\\' : 't' ならタブに、'\\' : '\\' ならバックスラッシュ1文字に置き換え、残りの rest に unescape を再帰で適用します。どちらにも当たらなければ先頭の1文字をそのまま残し、空リストで止まります。掲載したのは参考実装で、唯一の正解ではありません。

入力例2の "C:\\\\tmp" は、C、:、\、\、t、m、p の7文字です。左から読むと、先に \ 2文字の組が当たってバックスラッシュ1文字になり、続く t は普通の文字として残ります。2文字ずつ左から消費するので、2つ目の \ と t をタブの組と読み違えることはありません。出力例の "C:\\tmp" は print の表示で、中身はバックスラッシュ1文字を含む C:\tmp です。
