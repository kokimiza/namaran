SplitOn.hs

splitOn :: Char -> String -> [String]

文字 c を区切りとして、文字列を区切りの間の欄に分けたリストを返す splitOn を書いてください。区切りが k 個あれば欄はいつも k + 1 個で、intercalate [c] でつなぎ直すと元の文字列に戻ります。空文字列は空の欄が1つです。終わりの無い文字列を渡しても、欄を先頭から順に取り出せるようにします。

入力例 1

splitOn ',' "a,,b,"

出力例 1

["a","","b",""]

入力例 2

splitOn ',' ""

出力例 2

[""]

入力例 3

take 3 (splitOn ',' (cycle "ab,"))

出力例 3

["ab","ab","ab"]

splitOn :: Char -> String -> [String]
splitOn c s = case break (== c) s of
  (field, []) -> [field]
  (field, _ : rest) -> field : splitOn c rest

break (== c) s は、s を最初の c の手前で2つに分けます。前半が1つ目の欄で、後半は c から始まるか、c が無ければ空です。後半が空なら、その欄が最後の欄なので [field] を返します。後半が c で始まっていれば、その区切りを捨て、残りを分けた結果の前に field を付けます。掲載したのは参考実装で、唯一の正解ではありません。

再帰を止める条件は「入力が空になったとき」ではなく「区切りがもう無いとき」です。入力例1の最後の , を捨てると残りは "" ですが、そこにも空の欄が1つあり、break が ("", "") を返すので [""] が付きます。入力例2も同じ理由で [""] になります。splitOn c [] = [] を基底ケースに足すと、この2つの空の欄が消え、intercalate で元に戻らなくなります。入力例3では、break は最初の , を見つけた時点で ("ab", ",ab,...") を返し、field : の後ろの再帰は take が次の欄を求めるまで評価されません。欄を蓄積用の引数にためて最後に reverse する書き方では、入力の終わりに着くまで何も返せないので、無限の文字列から欄を取り出せません。
