Unescape.hs

unescape :: String -> String

文字列の中のバックスラッシュを \\ の2文字に、改行を \n の2文字に、タブを \t の2文字に置き換え、ほかの文字はそのまま残すエスケープがあります。このエスケープの結果を受け取り、元の文字列を返す unescape を書いてください。引数は必ずこのエスケープの結果で、空文字列には空文字列を返します。例の入力と出力は、どちらも Haskell の文字列リテラルで書きます。

入力例 1

unescape "x\\ny"

出力例 1

"x\ny"

入力例 2

unescape "\\\\n"

出力例 2

"\\n"

入力例 3

unescape ""

出力例 3

""

unescape :: String -> String
unescape ('\\' : c : rest) =
  unesc c : unescape rest
 where
  unesc 'n' = '\n'
  unesc 't' = '\t'
  unesc x = x
unescape (c : rest) = c : unescape rest
unescape [] = []

エスケープの結果では、バックスラッシュは必ず次の1文字と組になっていて、組の外にバックスラッシュが単独で現れることはありません。そこで参考実装は文字列を左から読み、バックスラッシュに出会ったら次の文字 c と2文字まとめて元の1文字に戻し、組の後ろから読み続けます。c が n なら改行、t ならタブで、残りの \\ の組は unesc x = x がバックスラッシュに戻します。バックスラッシュ以外の文字はそのまま残します。掲載したのは参考実装で、唯一の正解ではありません。

例はどれも Haskell のリテラルなので、まずリテラルを読んでから数えます。入力例 1 の "x\\ny" は x、バックスラッシュ、n、y の4文字で、バックスラッシュと n の組が改行に戻ります。入力例 2 の "\\\\n" はバックスラッシュ2つと n の3文字です。先頭の2文字が組になってバックスラッシュ1つに戻り、残った n は組に入らないので、結果はバックスラッシュと n の2文字、リテラルで書けば "\\n" です。2文字ずつ組で読まずに、文字列全体から \n の並びを探して改行に置き換える書き方だと、2文字目のバックスラッシュと n を組にして改行を作ってしまいます。どの順に置き換えても、この入力のどこかで組を取り違えます。
