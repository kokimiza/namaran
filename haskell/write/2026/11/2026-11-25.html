Simultaneous.hs

simultaneous
  :: (Int, Int) -> (Int, Int) -> Maybe Int

m で割った余りが a で、しかも n で割った余りが b である 0 以上の整数のうち、最小のものを Just で返す simultaneous (a, m) (b, n) を書いてください。そのような整数が無ければ Nothing を返します。m と n は 1 以上、a は 0 以上 m 未満、b は 0 以上 n 未満です。m と n が 1 より大きい公約数を持つこともあります。

入力例 1

simultaneous (2, 3) (3, 5)

出力例 1

Just 8

入力例 2

simultaneous (1, 4) (2, 6)

出力例 2

Nothing

入力例 3

simultaneous (3, 4) (5, 6)

出力例 3

Just 11

simultaneous
  :: (Int, Int) -> (Int, Int) -> Maybe Int
simultaneous (a, m) (b, n) =
  find (\x -> x `mod` n == b) candidates
 where
  count = n `div` gcd m n
  candidates = take count (iterate (+ m) a)

m で割った余りが a になる 0 以上の整数は、小さい順に a、a + m、a + 2m、…… です。iterate (+ m) a でこの並びを作り、n で割った余りが b になる最初のものを find で探します。並びは無限に続くので、解が無いときに探し続けないよう、調べる個数を n `div` gcd m n 個に区切ります。この参考実装は Data.List の find を使うので、import Data.List (find) が要ります。掲載したのは参考実装で、唯一の正解ではありません。

g を m と n の最大公約数とすると、m を (n / g) 回足した m × n / g は m と n の最小公倍数で、n で割り切れます。候補を n / g 個進めるたびに、n で割った余りは同じ並びを繰り返すので、それまでに b が出なければ、その先にも出ません。入力例2では g が 2 で、1、5、9 の3個を6で割った余りは 1、5、3 となり、2 は現れないので Nothing です。入力例3は 3、7、11 を調べ、11 を6で割った余りが 5 なので Just 11 です。m と n が1以外の公約数を持たない入力例1では、g が 1 なので5個を調べ、3 番目の 8 で見つかります。
