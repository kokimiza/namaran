AllDivide.hs

allDivide :: Int -> [Int] -> Bool

allDivide n ds が、ds のどの要素 d も n を割り切るときに True を返すように書いてください。0 はどの数も割り切らないものとし、ds に 0 があれば False です。ds が空なら True を返します。どの入力でも例外を出さずに値を返してください。

入力例 1

allDivide 12 [2, 3, 4]

出力例 1

True

入力例 2

allDivide 12 [3, 0]

出力例 2

False

入力例 3

allDivide 5 []

出力例 3

True
Reference 時間計算量 𝒪(k) 空間計算量 𝒪(1) k は ds の要素の個数

Reference

allDivide :: Int -> [Int] -> Bool
allDivide n = all divides
 where
  divides d = d /= 0 && n `mod` d == 0

n `mod` 0 は値を返さず、ゼロ除算の例外を投げます。そこで各要素を調べる divides を d /= 0 && n `mod` d == 0 とし、0 でないことを && の左側で先に確かめます。&& は左が False なら右を評価しないので、d が 0 のときは mod まで進まずに False になります。左右を入れ替えた n `mod` d == 0 && d /= 0 は、論理式としては同じでも、0 が来ると先に mod を評価して例外を投げます。これは参考実装で、唯一の正解ではありません。all を使わずに再帰で書いても、0 の判定を先にする点は変わりません。

入力例 2 では、3 が 12 を割り切ったあと、0 で d /= 0 が False になり、all も False を返します。all も False が出たところで残りを見ないので、0 の後ろにどんな要素があっても調べません。空のリストでは調べる要素が無く、all は True を返します。-1 で割る場合も、GHC の Int の mod は n が minBound でも 0 を返すので、例外もあふれも起きません。
