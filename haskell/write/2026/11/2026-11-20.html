Merge.hs

merge :: (Ord a) => [a] -> [a] -> [a]

昇順に並んだ2つのリストを受け取り、両方の要素をすべて含む昇順のリストを返す merge を書いてください。同じ値が両方にあれば、その個数ぶん残します。片方が空なら、もう片方をそのまま返します。

入力例 1

merge [1, 4, 6] [2, 3, 7, 8]

出力例 1

[1,2,3,4,6,7,8]

入力例 2

merge [] [5, 9]

出力例 2

[5,9]

入力例 3

merge [2, 2] [2]

出力例 3

[2,2,2]

merge :: (Ord a) => [a] -> [a] -> [a]
merge [] ys = ys
merge xs [] = xs
merge (x : xs) (y : ys)
  | x <= y = x : merge xs (y : ys)
  | otherwise = y : merge (x : xs) ys

両方のリストが並んでいれば、結果の先頭は2つの先頭のうち小さいほうです。参考実装は先頭どうしを比べ、小さいほうを1つ取り出して残りを再帰で併合し、片方が空になったら残ったリストをそのまま後ろにつなぎます。掲載したのは参考実装で、唯一の正解ではありません。

入力例 1 では 1 と 2、4 と 2、4 と 3、4 と 7、6 と 7 を順に比べ、[1, 4, 6] を出し切ったところで [7, 8] をつなぎます。入力例 3 で先頭が等しいときは x <= y で左の 2 を先に出し、右の 2 は次の比較に残すので、値は1つも落ちません。等しいときに両方を一度に進めると、片方の 2 が消えます。

結果のリストは先頭から順に作られ、次の要素を求めるときに見るのは各リストの先頭だけです。メモリに入りきらないデータを並べるときは、入る分ずつ並べて書き出した列を、このように先頭から少しずつ読みながら併合します。
