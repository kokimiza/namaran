data Tree = Leaf | Node Tree Int Tree
  deriving (Show)

fromSorted :: [Int] -> Tree

小さい順に並んだ、重複のない Int のリストを受け取り、その要素をすべて持つ二分探索木を返す fromSorted を書いてください。どの節でも、左の部分木の要素は節の値より小さく、右の部分木の要素は大きくなるようにします。さらにどの節でも、左右の部分木の要素数の差を 0 か 1 にし、差が 1 のときは左を多くします。空のリストには Leaf を返します。

入力例 1

fromSorted [1, 2, 3]

出力例 1

Node (Node Leaf 1 Leaf) 2 (Node Leaf 3 Leaf)

入力例 2

fromSorted [1, 2]

出力例 2

Node (Node Leaf 1 Leaf) 2 Leaf

入力例 3

fromSorted []

出力例 3

Leaf

fromSorted :: [Int] -> Tree
fromSorted xs =
  case splitAt (length xs `div` 2) xs of
    (l, v : r) ->
      Node (fromSorted l) v (fromSorted r)
    (_, []) -> Leaf

要素数が n のリストを splitAt (n `div` 2) で分けると、前半の l は n `div` 2 個、後半はその次の要素 v から始まります。v を根にすると、左に n `div` 2 個、右に残りの n - n `div` 2 - 1 個が入り、この差は n が偶数なら 1(左が多い)、奇数なら 0 です。リストは小さい順なので、l の要素はすべて v より小さく、r の要素はすべて大きくなります。l と r にも同じ作り方を再帰的に使えば、どの節でも2つの条件が成り立ちます。掲載したのは参考実装で、唯一の正解ではありません。

入力例1の [1, 2, 3] は ([1], 2 : [3]) に分かれ、2 を根に 1 と 3 が左右に入ります。入力例2の [1, 2] は ([1], 2 : []) に分かれ、左に1つ、右に0個です。空のリストは splitAt 0 [] が ([], []) を返し、2つ目の選択肢で Leaf になります。同じリストを先頭から1つずつ挿入すると、毎回最大の値を足すことになり、右にだけ伸びた高さ n の木ができます。この作り方なら高さはおよそ log2 n で、値を探すときに比べる回数もその程度に収まります。
