whole :: String -> String -> Bool

パターン re が文字列 s 全体に合えば True を返す whole を書いてください。re は普通の文字と * だけからなり、c* は直前の文字 c を0回以上繰り返したものに合います。* がパターンの先頭に来たり、2つ続いたりすることはありません。re と s がどちらも空なら True です。

入力例 1

whole "a*b" "aaab"

出力例 1

True

入力例 2

whole "a*b" "b"

出力例 2

True

入力例 3

whole "ab*" "abbc"

出力例 3

False

whole :: String -> String -> Bool
whole p@(c : '*' : re) s =
  whole re s || case s of
    x : xs -> x == c && whole p xs
    [] -> False
whole (c : re) (x : xs)
  | c == x = whole re xs
whole re s = null re && null s

パターンを先頭から読み、形ごとに節を分けます。2文字目が * なら、c* を0回で済ませて残りのパターン re を同じ s に合わせるか、s の先頭が c なら1文字食べて、c* を付けたままのパターン p で続きを合わせるか、のどちらかが成り立てば合います。* の付かない文字は、s の先頭と同じなら両方を1文字ずつ進めます。残りの節に来るのは、パターンか文字列のどちらかが尽きたか、文字が合わなかったときで、両方が空のときだけ True です。掲載したのは参考実装で、唯一の正解ではありません。

* の節は、普通の文字の節より前に置きます。節は上から順に試されるので、逆にすると 'a' と '*' を普通の文字として読んでしまいます。入力例1の whole "a*b" "aaab" では、a* が 'a' を1つずつ食べるたびに、0回で済ませて "b" を合わせる道も試し、3つ食べたところで "b" と "b" が合います。入力例2の "b" では、a* を0回で済ませる側がすぐに成功します。入力例3は、b* が "bb" まで食べても 'c' が残り、パターンだけが尽きるので False です。|| は左が True なら右を評価しないので、見つかった時点で残りの試し方は捨てられます。
