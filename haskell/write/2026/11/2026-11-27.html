Glob.hs

glob :: String -> String -> Bool

パターン p が文字列 s 全体に一致するかを返す glob p s を書いてください。パターンの ? は任意の1文字に、* は0文字以上の任意の文字の並びに一致し、それ以外の文字はその文字そのものに一致します。空のパターンは空の文字列にだけ一致します。

入力例 1

glob "*.hs" "Main.hs"

出力例 1

True

入力例 2

glob "a?c" "abbc"

出力例 2

False

入力例 3

glob "*" ""

出力例 3

True
Reference 時間計算量 𝒪(2n) 空間計算量 𝒪(n) n は p と s の長さの和

Reference

glob :: String -> String -> Bool
glob [] s = null s
glob ('*' : ps) s = any (glob ps) (tails s)
glob (p : ps) (c : cs) =
  (p == '?' || p == c) && glob ps cs
glob _ [] = False

パターンの先頭で場合を分けます。* が何文字に一致するかは、後ろが一致するかを確かめるまで決まりません。そこで tails s で s の後ろの部分を長い順にすべて作り、残りのパターン ps がどれか1つに一致すれば True とします。tails "ab" は ["ab", "b", ""] で、* が 0, 1, 2 文字を食べた場合に当たります。? とふつうの文字は先頭の1文字と比べて、両方を1文字ずつ進めます。tails を使うには import Data.List (tails) が要ります。掲載したのは参考実装で、唯一の正解ではありません。

入力例3では、* の行で tails "" が [""] を返し、空のパターンと空の文字列が一致して True になります。入力例2は ? が b を食べたあと c と b を比べて False です。パターンと文字列のどちらかが尽きた場合は、1行目と最後の行が受け持ちます。この書き方は * ごとに候補を総当たりするので、*a*a*a*b のように * の多いパターンが一致しない入力では、試す組合せが急に増えます。再帰の深さはパターンと文字列の長さの和までです。
