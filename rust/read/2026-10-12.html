monte_carlo.rs

#[derive(Clone, Copy)]
struct Weyl(f64);

impl Weyl {
    fn sample(mut self) -> f64 {
        self.0 = (self.0 + 0.618_034) % 1.0;
        self.0
    }
}

fn main() {
    let rng = Weyl(0.0);
    let mut inside = 0u32;
    for _ in 0..1000 {
        let (x, y) = (rng.sample(), rng.sample());
        if x * x + y * y <= 1.0 {
            inside += 1;
        }
    }
    println!("{}", 4.0 * f64::from(inside) / 1000.0);
}

これは何を出力するでしょうか?

Answer

4 です。

sample は self を値で受け取ります。Weyl は Copy を導出しているので、rng.sample() を呼ぶたびに rng のコピーが self に渡されます。mut self はそのコピーを書き換えてよいという宣言で、self.0 を進めても呼び出し側の rng は 0.0 のままです。rng を let mut なしで宣言してコンパイルが通るのも、rng 自体は一度も書き換えられないからです。

そのため sample は毎回 0.618034 を返し、x と y は1000回とも同じ値になります。0.618034 の2乗は約 0.382 で、2つ足した約 0.764 は1以下なので、1000個の点はすべて円の内側に数えられます。4.0 * 1000.0 / 1000.0 は 4.0 で、f64 を {} で表示すると、小数部が0のときは 4 と出ます。

状態が進んでいれば、sample は 0.618…、0.236…、0.854… と0から1の間に散らばる値を返し、結果は円周率に近づいたはずです。そうするには fn sample(&mut self) にして、rng を let mut で宣言します。
