lazy_any.rs

fn main() {
    let mut seen = 0;
    let found = [3, 8, 5, 10]
        .iter()
        .map(|&x| {
            seen += 1;
            x
        })
        .any(|x| x > 4);
    println!("{found} {seen}");
}

これは何を出力するでしょうか?

Answer

true 2 です。

map は、渡したクロージャをその場で全要素に適用するわけではありません。返すのは新しいイテレータで、クロージャが呼ばれるのは、後ろの any が次の要素を求めたときです。

any は先頭から1つずつ要素を求め、条件を満たす要素が見つかった時点で、それ以上は求めずに true を返します。3 は x > 4 を満たさず、8 で満たすので、map のクロージャが呼ばれるのは 3 と 8 の2回です。5 と 10 はクロージャに渡されず、seen は 2 で止まります。

map が先に全要素を変換し、そのあとで any が調べる、と読むと seen は 4 になります。map の結果をいったん Vec に集めてから any を呼べば、実際にそうなります。
