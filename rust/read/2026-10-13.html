shout.rs

fn shout(s: String) -> String {
    s + "!"
}

fn main() {
    let mut a = String::with_capacity(8);
    a.push_str("hi");
    let p = a.as_ptr();
    let b = shout(a.clone());
    a = shout(a);
    println!("{} {} {a} {b}", a.as_ptr() == p, b.as_ptr() == p);
}

これは何を出力するでしょうか?

Answer

true false hi! hi! です。

shout は String を値で受け取ります。String の値そのものは、ヒープ上のバッファを指すポインタと長さと容量の3つで、ムーブで移るのはこの3つだけです。a = shout(a) でも、a のバッファは中身ごとコピーされず、そのまま s に渡ります。

s + "!" は左の String を消費し、そのバッファの末尾に "!" を書き足して返します。バッファが足りなければ伸ばしますが、a は with_capacity(8) で8バイト以上の容量を持っているので、3バイトの "hi!" は今のバッファに収まり、場所は動きません。返ってきた String を a に入れ直すので、a.as_ptr() は p のままで、1つ目は true です1。

a.clone() は、a と同じ中身のバッファを新しく確保します。この時点で a のバッファはまだ使われているので、新しいバッファが p の場所に置かれることはありません。clone の容量は "hi" の分しかないこともあり、"!" を足すときにバッファが動く可能性はありますが、どこへ動いても p ではないので、2つ目は false です。

with_capacity(8) がなく String::from("hi") から始めていたら、a 側も "!" を足すときに伸ばす必要があるかどうかが容量しだいになり、1つ目が true になるとは言えなくなります。

  1. 標準ライブラリの impl Add<&str> for String のドキュメントは、左辺を消費してそのバッファを再利用すると明記しています。連結のたびに新しい String を確保して全体をコピーすると、n バイトの文字列をくり返しの連結で組み立てるのに n の2乗に比例する時間がかかるためです。
