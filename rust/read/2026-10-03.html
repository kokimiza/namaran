shared_stats.rs

use std::cell::Cell;
use std::rc::Rc;

#[derive(Clone)]
struct Stats {
    name: String,
    hits: Rc<Cell<u32>>,
}

fn main() {
    let a = Stats { name: "a".into(), hits: Rc::new(Cell::new(0)) };
    let mut b = a.clone();
    b.name.push('!');
    b.hits.set(b.hits.get() + 1);
    println!("{} {} {} {}", a.name, a.hits.get(), b.name, b.hits.get());
}

これは何を出力するでしょうか?

Answer

a 1 a! 1 です。

#[derive(Clone)] が生成する clone は、フィールドごとにそのフィールドの clone を呼び、結果を集めて新しい Stats を作ります。構造体のメモリを丸ごと写すわけではないので、各フィールドの複製のされ方は、そのフィールドの型の clone で決まります。

name の String::clone は新しいバッファを確保して中身を写します。b.name に ! を足しても、a.name は a のままです。

hits の Rc::clone が複製するのはポインタだけで、参照カウントを1つ増やし、同じ Cell<u32> を指す2つ目の Rc を作ります。b.hits.set(...) が書き換えるのは a.hits と共有しているその1つの Cell なので、a.hits.get() も 1 を返します。a.clone() で何もかも独立した複製ができたと考えると、a 0 a! 1 と読み違えます。
