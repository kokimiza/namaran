zero_div.rs

fn main() {
    let a: f64 = 1.0;
    let b: f64 = -1.0;
    let z: f64 = 0.0;
    println!("{}", a / z);
    println!("{}", b / z);
    println!("{}", z / z);
}

このコードは何を出力するでしょうか?

Answer

inf、-inf、NaN(各行の後に改行)。整数の0除算はパニックしますが、f64のような浮動小数点数の0除算はパニックしません。IEEE 754の規定どおり、正の値を正の0.0で割ると+∞(inf)、負の値を割ると-∞(-inf)、0.0同士を割ると非数(NaN)という、符号や意味の異なる3種類の値になります。Display実装がこれらをそれぞれ"inf"・"-inf"・"NaN"という文字列に整形します。整数と浮動小数点数で「ゼロ除算」の扱いがこれほど違うのは、整数には「無限大」や「非数」を表す値がなく、割り切れない結果を返せる先がパニック以外に無いのに対し、浮動小数点数はIEEE 754の一部としてこれらの特殊値をあらかじめ持っているためです。
