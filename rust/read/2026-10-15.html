lazy_bench.rs

fn timed<T>(label: &str, f: impl FnOnce() -> T) -> T {
    println!("{label}: start");
    let result = f();
    println!("{label}: stop");
    result
}

fn main() {
    let squares = timed("map", || {
        (1..=3).map(|x| {
            println!("square {x}");
            x * x
        })
    });
    let total: i32 = squares.sum();
    println!("total {total}");
}

これは何を出力するでしょうか?

Answer

map: start、map: stop、square 1、square 2、square 3、total 14 の6行です。

timed が start と stop の間で実行するのは f() の呼び出しだけで、f が返すのは (1..=3).map(...) というイテレータです。map はクロージャを抱えたイテレータを作って返すだけで、要素を取り出されるまでクロージャを1度も呼びません。そのため f() はすぐに戻り、square の行が出ないうちに map: stop が出ます。

クロージャが動くのは、timed から戻ったあとの squares.sum() です。sum が要素を1つ取り出すたびに square 1、square 2、square 3 が出て、1 + 4 + 9 の結果が total 14 になります。

timed が時間を測る関数でも同じことが起きます。測られるのはイテレータを作る手間だけで、二乗の計算は1回も入りません。計測の中で sum や collect まで済ませれば、計算が計測の区間に入ります。
