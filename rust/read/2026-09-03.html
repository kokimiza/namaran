where_builder.rs

fn main() {
    let filters = [("name", Some("O'Brien")), ("city", None), ("role", Some("admin"))];
    let mut sql = String::from("SELECT id FROM users WHERE true");
    let mut params = Vec::new();
    for (column, value) in filters {
        if let Some(v) = value {
            params.push(v);
            sql += &format!(" AND {column} = ?{}", params.len());
        }
    }
    println!("{sql}");
    println!("{params:?}");
}

これは何を出力するでしょうか?

Answer

SELECT id FROM users WHERE true AND name = ?1 AND role = ?2 と ["O'Brien", "admin"] の2行です。

filters の3組のうち、city の値は None なので if let Some(v) に合わず、SQL にも params にも何も足されません。条件になるのは name と role の2つだけです。

番号は push したあとの params.len() から作るので、name の値を積んだ時点で 1、role の値を積んだ時点で 2 です。role は filters の3番目にありますが、番号を決めるのは積んだ値の数なので ?3 にはなりません。?N は params の N 番目の値を指すので、この付け方なら SQL と値の対応はずれません。

O'Brien の ' は SQL のどこにも現れず、params の中にそのまま残ります。2行目の " は、{params:?} の Debug 書式が文字列を囲んだもので、' はエスケープされません。値が SQL の文字列に入らないので、値の中の引用符で文の形が変わることもありません。連結しているのは、コードに書いた列名の column だけです1。

  1. プレースホルダーにできるのは値だけで、列名やテーブル名には使えません。利用者の入力から列名を選ぶときは、許可した名前の一覧と照らしてから連結します。
