units.rs

use std::ptr;

fn main() {
    let units = [(); 4];
    let bytes = [0u8; 4];
    println!("{} {}", units.len(), size_of_val(&units));
    println!("{}", ptr::eq(&units[0], &units[3]));
    println!("{}", ptr::eq(&bytes[0], &bytes[3]));
}

これは何を出力するでしょうか?

Answer

4 0、true、false の3行です。

() は値が1つしかない型で、どの値なのかを区別する情報を持たないため、大きさは 0 バイトです。[(); 4] は要素を4つ持つ配列なので len() は 4 ですが、配列全体の大きさは 4 × 0 で 0 になります。

配列の n 番目の要素は、配列の先頭から n * size_of::<T>() バイト進んだ位置に置かれます1。T が () ならこの値はどの n でも 0 なので、&units[0] と &units[3] は同じ番地を指し、ptr::eq は true を返します。u8 は1バイトなので、&bytes[3] は &bytes[0] の3バイト先を指し、こちらは false です。

別々の要素なら番地も違う、という前提は大きさ0の型では成り立ちません。番地を要素の見分けに使う処理、たとえば *const T を HashSet に入れて同じ要素を2度処理しないようにするコードは、大きさ0の型の要素をすべて同じ1つの要素とみなします。

  1. The Rust Reference の Type layout の章が、配列の n 番目の要素の位置を先頭から n * size_of::<T>() バイトと定め、() の大きさを 0 と定めています。
