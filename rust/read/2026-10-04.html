lww.rs

#[derive(Clone, Copy, PartialEq, Eq, PartialOrd, Ord)]
struct Lww {
    time: u32,
    value: char,
}

fn merge(a: Lww, b: Lww) -> Lww {
    a.max(b)
}

fn main() {
    let x = Lww { time: 5, value: 'z' };
    let y = Lww { time: 7, value: 'a' };
    let z = Lww { time: 7, value: 'b' };
    let left = merge(merge(x, y), z);
    let right = merge(z, merge(y, x));
    println!("{} {}", left.value, right.value);
}

これは何を出力するでしょうか?

Answer

b b です。

#[derive(PartialOrd, Ord)] で導出した比較は、フィールドを宣言の順に比べる辞書式の比較です。Lww では先に time を比べ、等しいときだけ value を比べます。merge はこの順序で大きい方を返すので、時刻の新しい書き込みが残ります。時刻 5 の x は、どちらの式でも y に負けて消えます。

残る y と z はどちらも時刻 7 です。時刻が同じなら先に統合した方か後から統合した方が残る、と考えると、left と right では y と z を統合する順番が逆なので、結果が分かれそうに見えます。しかし時刻が等しいときは value を比べるので、'b' を持つ z が 'a' を持つ y より大きく、どちらの順番でも z が残ります。比較が時刻と値の両方で必ず決着するので、統合の結果は順番によりません1。

  1. Ord::max は、2つが等しいときは2つ目の引数を返します。このコードには time と value がどちらも同じ書き込みが無いので、この規則は出力に関わりません。
