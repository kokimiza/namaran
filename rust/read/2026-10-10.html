count_words.rs

fn main() {
    let line = "  cargo  build --release ";
    let a = line.split(' ').count();
    let b = line.split_whitespace().count();
    println!("{a} {b}");
}

これは何を出力するでしょうか?

Answer

7 3 です。

split(' ') は、空白1文字を見つけるたびにそこで切り、区切りと区切りの間にあるものを、空であってもそのまま1つの要素として返します。line の空白は、先頭に2つ、cargo と build の間に2つ、build と --release の間に1つ、末尾に1つの、合わせて6つです。6か所で切れば7つに分かれるので、要素は ""、""、"cargo"、""、"build"、"--release"、"" の7つになります。先頭の空白の前と、続いた空白の間と、末尾の空白の後に、それぞれ空文字列が入ります。

split_whitespace は空白の並びをひとまとまりの区切りとして扱い、空の要素を返しません。残るのは cargo、build、--release の3つです。人が打ったコマンド行のように空白の数がそろわない入力を単語に分けるなら split_whitespace、CSV の空欄のように空の要素にも意味がある入力なら split を使います。
