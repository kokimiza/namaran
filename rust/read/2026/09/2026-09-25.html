set_union.rs

use std::collections::BTreeSet;

fn main() {
    let a = [1, 4, 4, 9];
    let b = [2, 4, 10];
    let sa: BTreeSet<i32> = a.into_iter().collect();
    let sb: BTreeSet<i32> = b.into_iter().collect();
    let merged: Vec<i32> = sa.union(&sb).copied().collect();
    println!("{} {:?}", merged.len(), merged);
}

これは何を出力するでしょうか?

Answer

5 [1, 2, 4, 9, 10]です。BTreeSetは集合なので、collectした時点でaの中の2つの4は1つになり、saは{1, 4, 9}、sbは{2, 4, 10}です。unionは両方の木を小さい順に同時にたどる併合(merge)そのもので、昇順に値を返しますが、両方にある4は1回しか返しません。こうして7個の要素が5個になります。「整列済みの2つを併合する」のに集合を使うと、順序は手に入る代わりに重複が落ちます。重複も残したいなら、スライスを連結してsortするか(安定ソートなので同じ値の順も保たれます)、2本の添字やイテレータで自分で併合します。
