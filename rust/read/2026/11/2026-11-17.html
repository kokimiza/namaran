shout.rs

fn shout(mut s: String) -> String {
    s.push('!');
    s
}

fn main() {
    let a = String::from("hi");
    let b = shout(a.clone());
    let c = shout(b);
    println!("{a} {c}");
}

これは何を出力するでしょうか?

Answer

Output

hi hi!!

shout は String を値で受け取るので、呼び出すと引数の所有権が s へ移ります。s は mut で受けているので push で書き換えられ、書き換えた s が戻り値として呼び出し側へ所有権ごと返ります。

1回目の shout(a.clone()) に渡るのは、clone で新しく作った "hi" です。shout が書き換えるのはこの複製なので、a は "hi" のまま残り、複製に ! が付いた "hi!" が b になります。2回目の shout(b) では b そのものの所有権が移り、! がもう1つ付いた "hi!!" が c になります。最後の println! は、一度も所有権を手放していない a と、c を出力します。

a も書き換わると読めば答えは hi! hi!! になり、a の所有権が移ると読めばコンパイルエラーになります。実際に移ったのは複製の所有権だけです。一方、b は2回目の呼び出しで所有権を手放しているので、println! で b を使うとコンパイルエラーになります。
