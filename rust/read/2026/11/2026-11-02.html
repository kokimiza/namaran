arena_drop.rs

struct Noisy(&'static str);

impl Drop for Noisy {
    fn drop(&mut self) {
        print!("{}", self.0);
    }
}

fn main() {
    let mut arena = Vec::new();
    {
        let _a = Noisy("a");
        let b = Noisy("b");
        arena.push(b);
        print!("1");
    }
    let _c = Noisy("c");
    arena.push(Noisy("d"));
    print!("2");
}

これは何を出力するでしょうか?

Answer

1a2cbd です（改行はありません）。

内側のブロックでは、b を arena.push(b) で arena へムーブしています。所有者が arena に変わったので、ブロックの終わりで b は破棄されず、arena と同じだけ生き延びます。ブロックの終わりで破棄されるのは _a の値だけです。_a は先頭が _ の名前ですが、let _ = と違って値を束縛するので、値はブロックの終わりまで残ります。ここまでで出力は 1a になり、続く print! で 2 が足されます。

main の終わりでは、ローカル変数が宣言と逆の順に破棄されます。_c は arena よりあとに宣言したので先に破棄され、c が出ます。最後に破棄される arena は、持っている要素を先頭から順に破棄するので、入れた順の b、d が続きます。

ブロックを抜けるときに b も破棄されると考えると 1ba2… と答えます。arena が先に宣言されたから先に破棄されると考えると …bdc、Vec も宣言の逆順のように後ろから破棄すると考えると …cdb になります。
