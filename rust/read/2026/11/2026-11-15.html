sort_names.rs

fn main() {
    let mut names = vec!["file10", "file2", "File3", "file1"];
    names.sort();
    println!("{names:?}");
}

これは何を出力するでしょうか?

Answer

Output

["File3", "file1", "file10", "file2"]

&str どうしの比較は、先頭から1バイトずつ比べ、最初に違ったバイトの大小で決まる辞書式です。片方が先に尽きたときは短い方が前になります。数字の並びを数として読むことはなく、'0' から '9' もただの文字コード 0x30 から 0x39 として比べます。

"File3" の先頭の 'F' は 0x46 で、ほかの3つの先頭の 'f'(0x66)より小さいので、"File3" が最初に来ます。残りの3つは "file" まで同じで、5バイト目が '1'、'2'、'1' です。"file1" と "file10" は5バイト目まで同じで "file1" が先に尽きるので、"file1" が前になります。"file10" と "file2" は5バイト目の '1' と '2' で決まり、10 と 2 の大小は関係なく "file10" が前です。

数字を数として比べると考えると "file2" を "file10" の前に置き、大文字と小文字を区別せずに比べると考えると "File3" を "file2" の後ろに置いてしまいます。
