weekday_shift.rs

fn main() {
    let wednesday = 3;
    for days in [10, -11] {
        let n: i32 = wednesday + days;
        println!("{} {} {} {}", n / 7, n % 7, n.div_euclid(7), n.rem_euclid(7));
    }
}

これは何を出力するでしょうか?

Answer

1 6 1 6 と -1 -1 -2 6 の2行です。

1行目は n = 3 + 10 = 13 です。正の数どうしなら、/ と div_euclid、% と rem_euclid は同じ値になり、商 1 と余り 6 が2回並びます。日曜日を 0 と数えるなら、10 日後は翌週の土曜日です。

2行目は n = 3 - 11 = -8 です。整数の / は商の小数部分を 0 の方向へ切り捨てるので、-8 / 7 = -1.14… は -1 になります。% は n == (n / 7) * 7 + n % 7 が成り立つように決まるので、-8 - (-1) * 7 で -1 です。余りの符号は、割られる数 n の符号に合わせて負になります。

rem_euclid(7) は、余りがいつも 0 以上 7 未満になるように決めます。-8 = -2 × 7 + 6 なので、余りは 6、それに対応する div_euclid(7) の商は -2 です。日曜日を 0 と数えるなら、11 日前は2週前の土曜日です。曜日のように、0 から 6 の決まった範囲の添字に戻したい値には rem_euclid を使い、% の結果をそのまま添字にすると、負の数のとき範囲から外れます。
