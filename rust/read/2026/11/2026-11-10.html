login.rs

use std::fmt;

#[derive(Debug)]
struct Secret(String);

impl fmt::Display for Secret {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        write!(f, "<{} bytes>", self.0.len())
    }
}

#[derive(Debug)]
struct Login(String, Secret);

fn main() {
    let login = Login("ann".to_string(), Secret("hunter2".to_string()));
    println!("{} {} {:?}", login.0, login.1, login);
}

これは何を出力するでしょうか?

Answer

Output

ann <7 bytes> Login("ann", Secret("hunter2"))

println! の書式指定は、値を出すときに使うトレイトを決めます。{} は Display を、{:?} は Debug を使います。2つ目の {} に渡した login.1 は Secret なので、手で書いた Display が呼ばれ、中身の代わりにバイト数 <7 bytes> が出ます。

3つ目の {:?} には login 全体を渡しています。Login の Debug は #[derive(Debug)] が作ったもので、型の名前に続けて、各フィールドをそのフィールドの型の Debug で並べます。Secret の Debug もやはり derive で作られているので、包んでいる String を Debug で出し、引用符付きの "hunter2" がそのまま出力されます。"ann" に引用符が付くのも、String の Debug が文字列をエスケープして引用符で囲むからです。

Secret に伏せる処理を書いたのだから、Login を出したときも伏せられると考えると、Login("ann", <7 bytes>) と答えます。Display と Debug は別のトレイトで、derive(Debug) が中のフィールドに使うのは Debug だけです。ログに構造体を {:?} で出す場面で伏せたいなら、Secret の Debug を derive せずに手で実装し、そちらで中身を隠します。
