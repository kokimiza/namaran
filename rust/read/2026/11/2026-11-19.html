redo_pages.rs

fn main() {
    let mut pages = [(3, 6), (0, 0)];
    let log = [
        (1, 0, 5),
        (2, 1, 4),
        (3, 0, 1),
        (4, 1, 2),
    ];
    for (lsn, page, delta) in log {
        let (page_lsn, value) =
            &mut pages[page];
        if lsn > *page_lsn {
            *value += delta;
            *page_lsn = lsn;
        }
    }
    println!("{pages:?}");
}

これは何を出力するでしょうか?

Answer

Output

[(3, 6), (4, 6)]

log の各記録は (通し番号, ページ, 加える値) で、pages の各要素は (そのページに最後に反映した記録の番号, 値) です。ループは記録を番号順に見て、記録の番号がそのページの番号より大きいときだけ値を加え、ページの番号を記録の番号に進めます。比べる相手は記録が指すページの番号なので、どの記録を飛ばすかはページごとに決まります。let (page_lsn, value) = &mut pages[page]; はページのタプルへの可変参照を分解し、2つの要素それぞれへの &mut を作るので、*value と *page_lsn への代入は pages の中身を書き換えます。

ページ 0 の番号は 3 なので、ページ 0 を指す記録 1 と記録 3 はどちらも反映済みとして飛ばされ、値は 6 のままです。ページ 1 の番号は 0 で、記録 2 の 4 と記録 4 の 2 が加わって 6 になり、番号は 4 に進みます。ページ 0 の番号 3 を全体の基準と読むと、記録 1〜3 をすべて飛ばしてページ 1 には記録 4 の 2 だけが加わって [(3, 6), (4, 2)] と答えることになります。番号を見ずに全部を足すと、ページ 0 は 6 + 5 + 1 = 12 になります。
