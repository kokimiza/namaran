pad.rs

fn main() {
    for s in ["tea", "café"] {
        println!("{s:>6}|{}", s.len());
    }
}

これは何を出力するでしょうか?

Answer

Output

   tea|3
  café|5

s.len() は文字列のバイト数を返します。str の中身は UTF-8 で、é は2バイトなので、"café" の len() は 4 ではなく 5 です。"tea" は ASCII だけなので 3 です。

一方、{s:>6} の幅 6 は文字の個数(char の個数)で数えます。"tea" は3文字なので3つ、"café" は4文字なので2つの空白が左に付き、| の位置は2行でそろいます。2行目に 5 が出ているのを見て、幅もバイトで埋めると読むと、空白を1つしか付けず café|5 と答えてしまいます。
