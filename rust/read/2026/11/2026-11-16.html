cafe.rs

fn main() {
    let a = "caf\u{e9}";
    let b = "cafe\u{301}";
    println!("{}", a == b);
    println!("{} {}", a.len(), b.len());
    println!("{} {}", a.starts_with("cafe"), b.starts_with("cafe"));
}

これは何を出力するでしょうか?

Answer

Output

false
5 6
false true

a の最後の文字 U+00E9 は、アクセント付きの é を1文字で表す合成済みの文字です。b は普通の e のあとに U+0301 を置いています。U+0301 は直前の文字の上にアクセントを重ねて表示させる結合文字なので、どちらも画面には café と出ますが、文字の並びは a が4文字、b が5文字で違います。str の == は UTF-8 のバイト列が同じかどうかを比べるだけなので、false です。

len は文字数ではなくバイト数を返します。U+00E9 も U+0301 も UTF-8 では2バイトなので、a は caf の3バイトと合わせて5、b は cafe の4バイトと合わせて6です。starts_with もバイト列の先頭を比べるので、cafe の4バイトがそのまま並ぶ b だけが true になり、4バイト目が é の1バイト目である a は false です。

見た目で読むと true、4 4、false false と答えたくなります。同じ見た目の文字列を等しいと判定するには、比べる前に、合成済みの文字と結合文字の並びのどちらかの形へそろえる変換が要ります。この変換を Unicode 正規化と呼び1、Rust の標準ライブラリには含まれていません。

  1. Unicode 正規化（Unicode normalization）は、見た目と意味が同じ文字列を1つの決まった並びに変換する Unicode の規則です。合成済みの文字にそろえる形を NFC、基本の文字と結合文字に分ける形を NFD と呼びます。Rust では unicode-normalization クレートの nfc() などが使われます。
