lanes.rs

fn main() {
    let xs: Vec<u32> = (1..=10).collect();
    let (blocks, rest) = xs.as_chunks::<4>();
    let mut lanes = [0u32; 4];
    for block in blocks {
        for (lane, x) in lanes.iter_mut().zip(block) {
            *lane += x;
        }
    }
    println!("{lanes:?} {rest:?}");
}

これは何を出力するでしょうか?

Answer

Output

[6, 8, 10, 12] [9, 10]

xs.as_chunks::<4>() は、スライスを先頭から4要素ずつの配列 [u32; 4] に区切り、その並び blocks と、4つに満たずに余った末尾 rest の組を返します。xs は 1 から 10 の10要素なので、blocks は [1, 2, 3, 4] と [5, 6, 7, 8] の2つで、rest は [9, 10] です。

内側のループは lanes と塊を zip で組にし、同じ位置どうしを足します。1つ目のレーンには各塊の1番目、つまり 1 + 5 = 6 が、残りのレーンにも同じように 2 + 6、3 + 7、4 + 8 がたまり、lanes は [6, 8, 10, 12] になります。

ループが回るのは blocks だけで、rest の 9 と 10 はどのレーンにも足されません。端数が最後の塊として [9, 10] のまま回ると考えると、zip は短い方に合わせて止まるので、lanes を [15, 18, 10, 12] と答えることになります。
