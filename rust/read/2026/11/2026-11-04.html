signed_area.rs

fn twice_area(p: &[(i32, i32)]) -> i32 {
    p.iter().zip(&p[1..]).map(|(a, b)| a.0 * b.1 - b.0 * a.1).sum()
}

fn main() {
    let triangle = [(0, 0), (0, 4), (3, 0), (0, 0)];
    println!("{}", twice_area(&triangle) / 2);
}

これは何を出力するでしょうか?

Answer

-6 です。

triangle は最後に最初の頂点 (0, 0) をもう一度置いた閉じた並びで、p.iter().zip(&p[1..]) は隣り合う頂点の組 (a, b) を、辺の数と同じ3組作ります。各組の a.0 * b.1 - b.0 * a.1 は、原点と a と b を頂点とする三角形の面積の2倍に、原点から見て a から b へ左回りなら正、右回りなら負の符号を付けた値です。これを全部の辺について足すと、多角形の外の部分は打ち消し合い、多角形の面積の2倍だけが残ります。1

この和は面積そのものではなく、符号が付いたままです。頂点を左回りに並べれば正、右回りに並べれば負になり、twice_area はどこでも絶対値をとっていません。(0, 0) から (0, 4) へ上がり、(3, 0) へ右下に進んで戻る並びは右回りです。3組の値は順に 0 * 4 - 0 * 0 = 0、0 * 0 - 3 * 4 = -12、3 * 0 - 0 * 0 = 0 で、和は -12 です。2で割った -6 が表示されます。直角を挟む辺が3と4の三角形なので面積は 6 ですが、絶対値をとらない限り、出てくるのは向きの付いた -6 です。

  1. 頂点の座標から多角形の面積を求めるこの式は、靴紐公式(くつひもこうしき、shoelace formula)と呼ばれます。x 座標と y 座標を2列に並べ、斜めに掛けて足し引きする様子が、靴紐を交差させて通す形に似ていることからの名前です。
