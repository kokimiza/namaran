two_steps.rs

fn main() {
    let (mut a, mut b) = (1, 1);
    let (mut x, mut y) = (1, 1);
    for _ in 0..3 {
        (a, b) = (b, a + b);
        x = y;
        y += x;
    }
    println!("{a} {b}");
    println!("{x} {y}");
}

これは何を出力するでしょうか?

Answer

Output

3 5
4 8

(a, b) = (b, a + b) は、右辺のタプル (b, a + b) を先に作り終えてから、その2つの値を a と b に入れます。a + b を計算する時点の a はまだ書き換わっていないので、(a, b) は 1 回ごとに (1, 2)、(2, 3)、(3, 5) と進みます。1行目は 3 5 です。

x = y; と y += x; は別々の文なので、2つ目の文で足す x は、1つ目の文で y の値に書き換わったあとの x です。y += x は y に自分と同じ値を足すことになり、(x, y) は (1, 2)、(2, 4)、(4, 8) と、y が毎回2倍になるだけです。2つの書き方を同じ計算と読むと、2行目も 3 5 だと答えてしまいます。
