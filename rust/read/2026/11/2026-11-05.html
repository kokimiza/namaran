halve_stack.rs

fn main() {
    let mut v = vec![3, 8];
    let mut out = Vec::new();
    while let Some(x) = v.pop() {
        if x % 2 == 0 {
            v.push(x / 2);
        }
        out.push(x);
    }
    println!("{out:?}");
}

これは何を出力するでしょうか?

Answer

Output

[8, 4, 2, 1, 3]

while let Some(x) = v.pop() は、毎回の繰り返しの前に v.pop() を呼び、Some が返る間だけ本体を実行します。pop は Vec の末尾から1つ取り出し、空なら None を返すので、ループは v が空になったところで終わります。本体の中で push した値も末尾に入るので、次の pop で先に取り出されます。

最初の pop は末尾の8を返し、8は偶数なので4を積んでから out に8を足します。このとき v は [3, 4] です。次は4を取り出して2を積み、その次は2を取り出して1を積みます。1は奇数なので何も積まず、v には3だけが残ります。最後に3を取り出すと v は空になり、次の pop が None を返してループを抜けます。

vec![3, 8] を先頭から読む順番だと思うと、3が先に出て [3, 8, 4, 2, 1] になります。積み直した値が先に処理されるのは、取り出す側と積む側がどちらも末尾だからです。半分にし続けた値はいずれ奇数になるので、このループは必ず終わります。
