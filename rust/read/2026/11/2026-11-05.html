first_even_square.rs

fn main() {
    let first = (1..=6)
        .map(|x| {
            print!("m{x} ");
            x * x
        })
        .find(|x| {
            print!("f{x} ");
            x % 2 == 0
        });
    println!("{first:?}");
}

これは何を出力するでしょうか?

Answer

Output

m1 f1 m2 f4 Some(4)

map は呼んだ時点では何も計算せず、クロージャを抱えた新しいイテレータを返すだけです。値を取り出すのは最後の find で、find が next を呼ぶたびに、map は範囲から1つ受け取ってクロージャを1回だけ通し、その結果を渡します。1つの要素が map と find を通り抜けてから、次の要素が範囲から出てきます。

1つ目の要素 1 は map で m1 を表示して 1 になり、find が f1 を表示します。1 は偶数でないので、find は次を求めます。2 は m2 を表示して 4 になり、f4 を表示したところで条件を満たします。find はそこで Some(4) を返し、それ以上 next を呼ばないので、3 から 6 は範囲から取り出されず、map のクロージャも通りません。

配列の処理のように、map が6つすべてを先に変換してから find が探すと読むと、m1 から m6 が先に並びます。そう動くのは、途中で collect して Vec を作った場合です。
