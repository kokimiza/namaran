pick_five.rs

fn main() {
    let items = [2, 3, 5];
    for mask in 0..1 << items.len() {
        let sum: i32 = (0..items.len()).filter(|&i| mask >> i & 1 == 1).map(|i| items[i]).sum();
        if sum == 5 {
            println!("{mask:03b}");
        }
    }
}

これは何を出力するでしょうか?

Answer

Output

011
100

<< は .. より強く結び付くので、0..1 << items.len() は 0..8 です。mask は0から7までを順にとり、その i ビット目が1なら items[i] を選ぶ、という読み方で3要素の部分集合8通りを1つずつ表します。mask >> i & 1 == 1 は ((mask >> i) & 1) == 1 と読まれ、i ビット目を調べています。

和が5になる選び方は、items[0] と items[1] の 2 + 3 と、items[2] だけの5の2通りです。前者はビット0と1が立つ mask = 3、後者はビット2だけが立つ mask = 4 で、ループは小さい順に回るので3が先に表示されます。{mask:03b} は mask を2進数で、0で埋めた3桁にして表示します。2進数の表記は普通の数と同じく下の桁が右なので、ビット0は右端です。3は 011、4は 100 になります。配列の並びにつられてビット0を左端に置くと、110 と 001 を答えてしまいます。
