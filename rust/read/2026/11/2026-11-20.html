lomuto.rs

fn lomuto(v: &mut [i32]) -> usize {
    let hi = v.len() - 1;
    let mut i = 0;
    for j in 0..hi {
        if v[j] < v[hi] {
            v.swap(i, j);
            i += 1;
        }
    }
    v.swap(i, hi);
    i
}

fn main() {
    let mut v = [4, 7, 2, 6, 3, 5];
    let p = lomuto(&mut v);
    println!("{v:?} {p}");
}

これは何を出力するでしょうか?

Answer

Output

[4, 2, 3, 5, 7, 6] 3

基準値は末尾の v[5] = 5 です。i は「ここまでに見つけた 5 未満の値の個数」で、v[..i] にはいつも 5 未満の値だけが並びます。j が 5 未満の値を見つけるたびに v[i] と入れ替え、i を1つ進めます。

j = 0 の 4 は自分自身との交換で i = 1、7 は飛ばし、j = 2 の 2 を v[1] の 7 と入れ替えて [4, 2, 7, 6, 3, 5]、i = 2 です。6 は飛ばし、j = 4 の 3 を v[2] の 7 と入れ替えて [4, 2, 3, 6, 7, 5]、i = 3 になります。ループは hi の手前で終わり、最後の v.swap(i, hi) が v[3] の 6 と基準値の 5 を入れ替えるので、[4, 2, 3, 5, 7, 6] と 3 が表示されます。

返る 3 は 5 未満の値の個数で、基準値 5 は並べ替え終えた配列でも添字 3 に来る位置に置かれています。左の [4, 2, 3] と右の [7, 6] はそれぞれまだ並んでいませんが、どちらの側の値も基準値を越えて動くことはもうありません。
