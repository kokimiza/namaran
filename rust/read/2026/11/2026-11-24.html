charge.rs

use std::collections::HashSet;

fn main() {
    let reqs = [
        ("k1", 100),
        ("k2", 50),
        ("k1", 120),
        ("k2", 50),
    ];
    let mut seen = HashSet::new();
    let mut total = 0;
    for (key, amount) in reqs {
        if seen.insert(key) {
            total += amount;
        }
    }
    println!("{total}");
}

これは何を出力するでしょうか?

Answer

Output

150

HashSet::insert は、値がまだ集合に無ければ追加して true を返し、すでにあれば集合を変えずに false を返します。このループは、その戻り値が true のとき、すなわち初めて見たキーのときだけ金額を足します。

1件目の "k1" と2件目の "k2" は初めてのキーなので、100 と 50 が足されて 150 になります。3件目は金額が 120 に変わっていますが、キーは1件目と同じ "k1" で、insert は false を返すので足されません。4件目の "k2" も同じ理由で飛ばされ、出力は 150 です。

集合にはキーしか入れていないので、同じキーの2回目は金額が違っていても再送として捨てられます。同じキーなら後から来た請求が前の請求を置き換えると読むと、120 と 50 で 170 と答えることになります。
