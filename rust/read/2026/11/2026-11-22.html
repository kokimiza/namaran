lower_bound.rs

fn main() {
    let v = [2, 4, 4, 4, 7, 9];
    let (mut lo, mut hi) = (0, v.len());
    while lo < hi {
        let mid = (lo + hi) / 2;
        print!("{mid} ");
        if v[mid] < 4 {
            lo = mid + 1;
        } else {
            hi = mid;
        }
    }
    println!("-> {lo}");
}

これは何を出力するでしょうか?

Answer

Output

3 1 0 -> 1

lo と hi は、答えが lo 以上 hi 未満にあることを表します。v[mid] が 4 より小さければ mid までは答えではないので lo を mid + 1 に進め、4 以上なら mid が答えの候補として残るので hi を mid に縮めます。usize の割り算は切り捨てなので、mid は区間の真ん中か、真ん中より1つ左です。

最初は lo = 0、hi = 6 で、mid は 3 です。v[3] は 4 で、4 より小さくないので hi = 3 になります。次の mid は (0 + 3) / 2 の 1 で、v[1] も 4 なので hi = 1 です。最後の mid は 0 で、v[0] の 2 は 4 より小さいので lo = 1 になり、lo と hi が等しくなってループを抜けます。

4 を見つけた時点で止まると読むと、最初の mid の 3 を答えにします。このループは 4 を見つけても止まらず、4 以上の値が始まる位置まで hi を左へ寄せ続けるので、lo は 4 が並ぶ区間の先頭の 1 で止まります。
