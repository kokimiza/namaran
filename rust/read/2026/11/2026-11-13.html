bump.rs

fn bump(n: &mut i32) -> &mut i32 {
    *n += 1;
    n
}

fn main() {
    let mut x = 0;
    let r = &mut x;
    let a = bump(r);
    *bump(a) *= 10;
    bump(r);
    println!("{x}");
}

これは何を出力するでしょうか?

Answer

Output

21

&mut i32 は Copy ではないので、bump(r) で r がムーブされ、2回目の bump(r) はコンパイルエラーになる、と読めそうです。しかし、仮引数の型が &mut i32 と決まっている場所に r を渡すと、コンパイラは r そのものではなく &mut *r を渡します。これが再借用で、r は手元に残り、再借用が終われば再び使えます。

再借用がいつ終わるかは、戻り値で決まります。bump の戻り値は、ライフタイム省略の規則で引数と同じライフタイムを持つので、let a = bump(r); の再借用は a が使われる間続きます。a を最後に使うのは次の行の bump(a) で、借用はそこで終わります。そのため3つ目の bump(r) は通ります。a がスコープの終わりまで r を借り続けると考えると、ここでコンパイルエラーと答えてしまいます。

値は順に、1つ目の bump(r) で x が1、bump(a) で2になり、返された参照を通して *= 10 で20、最後の bump(r) で21です。bump(a) も a の再借用なので、a と r と戻り値はどれも同じ x を指しています。println! の時点では r の使用も終わっているので、x を読めます。
