drop_pair.rs

struct Noisy(&'static str);

impl Drop for Noisy {
    fn drop(&mut self) {
        println!("{}", self.0);
    }
}

struct Pair(Noisy, Noisy);

fn main() {
    let _x = Noisy("x");
    let _p = Pair(Noisy("a"), Noisy("b"));
    let _y = Noisy("y");
}

これは何を出力するでしょうか?

Answer

Output

y
a
b
x

main の終わりで、ローカル変数は宣言と逆の順に drop されます。最後に宣言した _y が最初で、次が _p、最後が _x です。_x のように _ で始まる名前は、使わなくても警告が出ないだけの普通の変数で、値はスコープの終わりまで生きています。

_p の drop では、Pair 自身は Drop を実装していないので、フィールドが drop されます。構造体のフィールドは、変数とは逆に、宣言した順に drop されます。タプル構造体では .0 が先で .1 が後なので、a、b の順です。出力は y、a、b、x になります。

変数と同じ「後に作ったものから捨てる」規則をフィールドにも当てはめると、y、b、a、x と答えることになります。変数を逆順に捨てるのは、後から宣言した変数が先の変数を借用していることがあるからです。フィールドについては、The Rust Reference が「宣言した順に drop する」と別に定めていて、変数の規則は及びません。
