fn main() {
    let bytes = "é".as_bytes();
    let s: String = bytes
        .iter()
        .map(|&b| b as char)
        .collect();
    println!("{} {}", s, s.len());
}

これは何を出力するでしょうか?

Answer

Output

Ã© 4

"é" は UTF-8 で 0xC3 と 0xA9 の2バイトになり、as_bytes はこの2バイトを返します。u8 を as char で変換すると、バイトの値がそのまま Unicode の符号位置になります。0xC3 は U+00C3 の Ã、0xA9 は U+00A9 の © なので、s は "Ã©" の2文字になります。前後のバイトを組み合わせて1文字に戻す処理は、どこにもありません。

String は中身を UTF-8 で持ちます。U+0080 から U+07FF までの文字は UTF-8 で2バイトなので、Ã と © はどちらも2バイトになり、s.len() はバイト数の 4 を返します。é 2 と読むのは、as char が UTF-8 をデコードすると考えたときの答えです。バイト列を文字列に戻すには、std::str::from_utf8 や String::from_utf8 で、列全体をまとめてデコードします。
