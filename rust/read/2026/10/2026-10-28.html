default_port.rs

struct Port(u16);

impl Default for Port {
    fn default() -> Self {
        println!("default port");
        Port(80)
    }
}

#[derive(Default)]
struct Server {
    port: Port,
    workers: u8,
}

fn main() {
    let server = Server { port: Port(8080), ..Default::default() };
    println!("{} {}", server.port.0, server.workers);
}

これは何を出力するでしょうか?

Answer

default port と 8080 0 の2行です。

構造体更新記法の .. の後ろに書く Default::default() は、Server 型の値をまるごと1つ作る、ふつうの式です。Rust はまずこの式を評価して Server の値を作り、そこから { } の中で指定しなかったフィールドだけを取り出して使います1。

#[derive(Default)] が作る Server::default() は、すべてのフィールドについて、その型の Default::default() を呼びます。port には Port(8080) を指定してありますが、まるごとの値を作る段階ではそれと関係なく Port::default() が呼ばれ、default port が表示されます。こうして作った Port(80) は使われずに捨てられ、server.port は指定した Port(8080) になります。workers は u8 の既定値の0を受け取ります。

既定値が作られるのは指定しなかったフィールドだけだと読むと、Port::default() は呼ばれないことになり、8080 0 の1行だけと答えてしまいます。

  1. The Rust Reference はこの書き方を functional update syntax、.. の後ろの式を base expression と呼びます。
