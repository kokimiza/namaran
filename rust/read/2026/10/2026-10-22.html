shape.rs

fn shape(v: &[u8]) -> &'static str {
    match v {
        [] => "empty",
        [.., 0] => "ends with 0",
        [0, ..] => "starts with 0",
        [_] => "single",
        _ => "other",
    }
}

fn main() {
    let inputs: [&[u8]; 4] = [&[0], &[0, 1], &[1, 0], &[2]];
    for v in inputs {
        println!("{}", shape(v));
    }
}

これは何を出力するでしょうか?

Answer

ends with 0、starts with 0、ends with 0、single の4行です。

match は腕を上から順に試し、最初に当てはまった腕だけを実行します。スライスパターンの .. は0個以上の要素に当てはまるので、[.., 0] は「最後の要素が0」、[0, ..] は「最初の要素が0」を表し、どちらも要素が1つのスライスにも当てはまります。

1つ目の [0] は、要素が1つなので [_] の single に入りそうに見えます。しかし [0] の最後の要素は0で、[.., 0] が先に当てはまるので ends with 0 です。[0, 1] は最後が1なので2つ目の腕を外れ、3つ目の腕の starts with 0 に入ります。[1, 0] は2つ目の腕で ends with 0 になります。0を含まない [2] だけが [_] まで進み、single です。腕の順に並べた条件は、上の腕に当てはまらなかった値だけが下の腕に届くという意味になります1。

  1. どの値も上の腕に先に取られて、決して届かない腕があると、コンパイラは unreachable pattern の警告を出します。この [_] には [2] が届くので、警告は出ません。
