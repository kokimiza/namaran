fn_item.rs

fn double(x: i32) -> i32 {
    x * 2
}

fn main() {
    let item = double;
    let ptr: fn(i32) -> i32 = double;
    println!("{} {}", size_of_val(&item), item(ptr(3)));
    println!("{}", size_of_val(&ptr) > 0);
}

これは何を出力するでしょうか?

Answer

0 12 と true の2行です。

Rust では、関数の名前 double は、その関数だけのための型を持つ値です。この型を関数アイテム型(function item type)といい、型そのものがどの関数を呼ぶかを表しているので、値には番地を入れておく必要がありません。Rust Reference も関数アイテム型の値は大きさ0だと定めています。let item = double; は型を注釈していないので、item はこのゼロサイズ型のままで、size_of_val(&item) は 0 です。

ptr は fn(i32) -> i32 と注釈されているので、代入のときに関数アイテムが関数ポインタへ変換されます。関数ポインタは同じシグネチャのどの関数でも指せる型で、どれを指しているかを実行時の番地として持つため、大きさは0になりません。呼び出し方は2つとも変わらず、item(ptr(3)) は double(double(3)) の 12 です。
