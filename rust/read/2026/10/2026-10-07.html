frames.rs

struct Frame(u32);

impl Drop for Frame {
    fn drop(&mut self) {
        println!("{}", self.0);
    }
}

fn walk(n: u32) {
    let _f = Frame(n);
    if n < 3 {
        let _ = Frame(n * 10);
        walk(n + 1);
    }
}

fn main() {
    walk(1);
}

これは何を出力するでしょうか?

Answer

10、20、3、2、1 の5行です。

let _f = Frame(n); は値を変数 _f に束縛するので、Frame(n) はその呼び出しから戻るときまで生きます。一方、let _ = Frame(n * 10); の _ は何も束縛しないワイルドカードパターンです。どの変数にも入らなかった Frame(n * 10) は一時的な値として文の終わりで捨てられるので、次の行の walk(n + 1) を呼ぶ前にドロップされます。

そのため walk(1) は 10 を、walk(2) は 20 を出力してから次の段を呼びます。walk(3) は if に入らずに戻り、そこで _f の 3 が出ます。各段の _f はそれぞれの呼び出しの中で生きているので、戻るたびに walk(2) の 2、walk(1) の 1 の順でドロップされます。呼び出しとは逆の順です。

_ も _f のように値を持ち続けると読むと、Frame(n * 10) は if のブロックを抜けるときにドロップされることになり、3、20、2、10、1 と答えてしまいます1。

  1. _f のように _ で始まる名前は、使わなくても警告が出ないだけの普通の変数です。ロックのガードを let _ = m.lock(); と書くとその場でロックが外れてしまうので、ガードは let _guard = … のように名前を付けて持ちます。
