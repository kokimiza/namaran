where_len.rs

fn words<T>() -> usize {
    size_of::<T>() / size_of::<usize>()
}

fn main() {
    println!("{}", words::<&[u8; 4]>());
    println!("{}", words::<&[u8]>());
    println!("{}", words::<Vec<u8>>());
    println!("{}", words::<&Vec<u8>>());
}

これは何を出力するでしょうか?

Answer

1、2、3、1 の4行です。

usize はポインタと同じ大きさなので、words はその型の値がポインタ何個分の大きさかを返します。どの型も、長さを誰が覚えているかで大きさが決まります。&[u8; 4] の長さ 4 は型の一部で、コンパイル時に決まっているので、参照が実行時に持つのはアドレス1つだけです。&[u8] の型には長さが無く、同じ型の参照が2要素のスライスも100要素のスライスも指すので、参照自身がアドレスと要素数の2つを持ちます1。

Vec<u8> は要素を足すたびに長さが変わるので、長さを型にも参照にも預けられず、値そのものがバッファへのポインタ、確保済みの容量、長さの3つを持ちます。&Vec<u8> はその Vec を指すだけで、長さは指した先の Vec が覚えているので、アドレス1つ分です。

  1. The Rust Reference は、大きさが型で決まらない型（dynamically sized type）へのポインタが、普通のポインタの2倍の大きさを持つと定めています。Vec がポインタ、容量、長さの3つ組であることは、標準ライブラリのドキュメントが保証しています。
