concat.rs

fn main() {
    let mut s = String::with_capacity(8);
    let p = s.as_ptr();
    for w in ["ab", "cd", "ef"] {
        s = s + w;
    }
    let t = s.clone() + "gh";
    println!("{} {} {}", s, s.as_ptr() == p, t.as_ptr() == p);
}

これは何を出力するでしょうか?

Answer

abcdef true false です。

String の + は、左の String をムーブで受け取り、そのバッファの後ろに右の &str を書き足して、同じ String を返します。s = s + w は新しい文字列を作って s に入れ直しているように見えますが、実際には s のバッファをそのまま使い回しています。with_capacity(8) で8バイト以上の容量を確保してあるので、合わせて6バイトを書き足すあいだに再確保は起きず、s.as_ptr() は最初に取った p と同じです。

s.clone() は、同じ中身を新しく確保したバッファにコピーします。+ "gh" が使い回すのはこのコピーのバッファなので、t は s とは別の場所にあります。s もまだ生きていて自分のバッファを持っているので、t.as_ptr() が p と同じになることはありません。

左のバッファを使い回すので、ループの中で s = s + w と連結しても、毎回かかる手間は足した w の長さの分だけです。s.clone() + w のように足す前にコピーすると、それまでの全体を毎回コピーするので、n バイトの文字列を作るのに n の2乗に比例する時間がかかります1。

  1. 標準ライブラリのドキュメントは、String の + が左のバッファを使い回す理由を、連結を繰り返したときに O(n²) になるのを避けるためだと説明しています。s += w も同じく s のバッファに書き足します。
