quotes.rs

fn main() {
    let csv = r#""1,2",""""
x""y,"say ""hi"""
"#;
    let (mut field, mut quoted) = (String::new(), false);
    let mut chars = csv.chars().peekable();
    while let Some(c) = chars.next() {
        match (quoted, c) {
            (true, '"') if chars.peek() == Some(&'"') => field.push(chars.next().unwrap()),
            (_, '"') => quoted = !quoted,
            (false, ',') => print!("[{}]", std::mem::take(&mut field)),
            (false, '\n') => println!("[{}]", std::mem::take(&mut field)),
            _ => field.push(c),
        }
    }
}

これは何を出力するでしょうか?

Answer

[1,2]["] と [xy][say "hi"] の2行です。

このループは、quoted と読んだ文字の組で腕を選びます。2つ重ねた "" を1つの " としてフィールドに入れるのは1つ目の腕で、quoted が true のときにしか選ばれません。それ以外の引用符はすべて2つ目の腕に来て、quoted を反転させるだけで、フィールドには入りません。

1行目の "1,2" は、最初の引用符で quoted が true になるので、間のカンマは3つ目の腕に当たらずフィールドに入ります。続く """" は、1つ目の引用符で引用符の中に入り、2つ目と3つ目が重ねた引用符として " になり、4つ目で外に出ます。

2行目の x""y では、x の次の引用符が引用符の外にあるので、重ねた引用符としては読まれず、quoted を true にするだけです。次の引用符は中にありますが、その後ろは y なので1つ目の腕のガードが成り立たず、quoted を false に戻します。2つの引用符はどちらもフィールドに残らず、xy になります1。最後の "say ""hi""" は引用符の中で "" が2回現れるので、say "hi" です。

  1. CSVの書式を定めた RFC 4180 は、引用符を含むフィールドは全体を引用符で囲むとしており、x""y のような書き方を想定していません。こうした入力をどう読むかは、パーサによって違います。
