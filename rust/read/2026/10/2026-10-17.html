reset_bounds.rs

fn main() {
    let mut lo = 5;
    let mut hi = 9;
    println!("{lo} {hi}");
    lo = hi = 0;
    println!("{lo} {hi}");
}

これは何を出力するでしょうか?

Answer

コンパイルエラーになり、何も出力されません。

代入演算子は右結合なので、lo = hi = 0 は lo = (hi = 0) と読まれます。内側の hi = 0 は hi に 0 を入れますが、Rust の代入式の値は代入した値ではなく、空のタプル () です。外側では i32 の lo に () を代入することになり、型が合わないので expected integer, found `()` というエラーで止まります。コンパイルが通らないので、最初の println! も実行されません。

C や C++ では代入式の値が代入したあとの左辺なので、同じ書き方で両方が 0 になり、5 9 と 0 0 が出ます。Rust は代入式に値を持たせないことで、if x = 0 のような書き間違いもコンパイルエラーにしています。両方を 0 にするなら、hi = 0; と lo = 0; の2文に分けるか、(lo, hi) = (0, 0); と書きます。
