frames.rs

struct Frame(u32);

impl Drop for Frame {
    fn drop(&mut self) {
        print!("{}", self.0);
    }
}

fn down(n: u32) {
    let _frame = Frame(n);
    if n > 0 {
        down(n - 1)
    }
}

fn main() {
    down(3);
    println!();
}

これは何を出力するでしょうか?

Answer

0123 です。

_frame は、down の本体のブロックを抜けるときに drop されます。down(n - 1) は本体の最後の式ですが、この呼び出しが戻ってきたあとにも、_frame を drop する仕事が残っています。

down(3) は Frame(3) を作ってから down(2) を呼び、同じように down(0) まで進みます。down(0) は if の中に入らずに本体を抜けるので、最初に 0 が出力されます。そこから呼び出しが1段ずつ戻るたびに、その段の _frame が drop され、1、2、3 と続きます。呼び出しのあとに drop が残っているので、この呼び出しは末尾呼び出しにはならず、4段のスタックフレームは down(0) を実行する間すべて積まれたままです。

_frame は作ったあと一度も使われないので、再帰呼び出しの前に片付くと考えると 3210 と答えてしまいます。借用は最後に使った位置で終わりますが、値の drop は最後に使った位置まで早まらず、スコープの終わりで行われます1。

  1. let _frame = Frame(n); を let _ = Frame(n); と書くと、値はどの変数にも束縛されず、その文の終わりですぐに drop されます。そのときの出力は 3210 です。
