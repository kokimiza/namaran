skip_and_stop.rs

fn main() {
    let mut sum = 0;
    for n in [4, -1, 7, 0, 2] {
        match n {
            0 => break,
            n if n < 0 => continue,
            _ => sum += n,
        }
        sum *= 10;
    }
    println!("{sum}");
}

これは何を出力するでしょうか?

Answer

470 です。

match はループではないので、腕の中の break と continue は外側の for に効きます。continue は match の後ろの sum *= 10; も飛ばして次の要素へ進み、break は for そのものを抜けます。C の switch の中の break が switch だけを抜けるのとは違います。

要素を順に追うと、4 は3つ目の腕で sum を4にし、sum *= 10; で40にします。-1 はガードの付いた2つ目の腕に入り、continue で掛け算をせずに次へ進むので、sum は40のままです。7 で47になってから470になり、0 の腕の break でループを抜けます。最後の 2 は読まれないので、println! が出力するのは 470 です。
