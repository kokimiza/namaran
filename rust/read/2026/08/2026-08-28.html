rows.rs

fn main() {
    let rows = ["ann,30", "bob,25,", "cy,41,cy@example.com"];
    for row in rows {
        let mut fields = row.split(',');
        let name = fields.next().unwrap();
        let email = fields.nth(1);
        println!("{name} {email:?}");
    }
}

これは何を出力するでしょうか?

Answer

ann None、bob Some("")、cy Some("cy@example.com") の3行です。

row.split(',') は、カンマで区切った部分を前から1つずつ返すイテレータです。next() で名前を取り出したあと、イテレータは2つ目の列（年齢）の手前にいます。nth(1) はそこから数えて0始まりの1番目を返すので、年齢を読み飛ばし、3つ目の列を返します。行の先頭から数えた1番目と読むと、年齢の "30" などが出ると答えることになります。

3つ目の列の中身は行によって違います。"ann,30" は年齢を読み飛ばした時点で部分が尽きるので、nth(1) は None を返します。"bob,25," では、末尾のカンマの後ろに長さ0の部分が1つあるとみなされ、Some("") になります。列をあとから足したデータでは、列が足される前に書かれた行と、列はあるが空の行が、None と Some("") に分かれます。
