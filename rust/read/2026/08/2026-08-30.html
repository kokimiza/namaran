event_log.rs

static mut LOG: Vec<&str> = Vec::new();

fn main() {
    unsafe {
        LOG.push("start");
    }
    let n = unsafe { LOG.len() };
    println!("{n}");
}

これは何を出力するでしょうか?

Answer

Output

コンパイルエラー

Rust 2024 エディションでは、static mut への参照を作ると、unsafe の中でもコンパイルエラーになります。&LOG や &mut LOG と書いていなくても同じです。LOG.push("start") の Vec::push は &mut self を受け取るメソッドなので、呼び出しの際にコンパイラが &mut LOG を作って渡します。LOG.len() も &self を受け取るので、&LOG が作られます。どちらの行も、可変な参照と共有の参照をそれぞれ static mut に作ったとして拒否されます。1

同じコードは、いまのコンパイラでも 2021 エディションを指定すれば警告だけでコンパイルでき、1 を出力します。static mut はどのスレッドからも、どの関数からも名前だけで触れるので、ある場所で作った &mut LOG が生きている間に、別の場所が LOG を読み書きしないことをコンパイラは確かめられません。&mut はほかに誰も触れないことを前提にした参照なので、そうした重なりは未定義動作になります。2024 では参照を作ること自体が禁じられたので、static mut を使い続けるなら、&raw mut LOG で参照ではなく生ポインタを作って扱います。

  1. このエラーは static_mut_refs という名前のリントで、2024 エディションでは既定で deny（エラー扱い）です。u32 の static mut に COUNT += 1 と書くような、参照を作らない読み書きは、2024 でも unsafe の中なら書けます。
