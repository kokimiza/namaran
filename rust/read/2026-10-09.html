counter.rs

fn main() {
    let mut count = 0;
    let mut bump = move || {
        count += 1;
        count
    };
    bump();
    println!("{} {}", bump(), count);
}

これは何を出力するでしょうか?

Answer

2 0 です。

move を付けたクロージャは、使う変数を値で取り込みます。count は i32 で、i32 は Copy を実装しているので、この取り込みは移動ではなくコピーになります。bump が持つのは count の写しで、count += 1 が書き換えるのもその写しです。

bump() を2回呼ぶと写しは1、2と増え、2回目の戻り値の 2 が出力されます。外側の count は一度も書き換わらないので、0 のままです。

取り込む変数が String のような Copy でない型なら、move で値が本当に移動するので、あとから外側で読む行はコンパイルエラーになります。Copy の型ではそのエラーが出ないまま、別々の値が2つ残ります。Clone だけを実装した型は、clone() と書かない限り複製されません。
