fixed.rs

use std::fmt;

struct Fixed(i64); // value * 100

impl Fixed {
    fn times(self, rhs: Fixed) -> Fixed {
        Fixed(self.0 * rhs.0 / 100)
    }
}

impl fmt::Display for Fixed {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        write!(f, "{}.{:02}", self.0 / 100, self.0 % 100)
    }
}

fn main() {
    println!("{}", Fixed(199).times(Fixed(50)));
    println!("{}", Fixed(-199).times(Fixed(50)));
}

これは何を出力するでしょうか?

Answer

0.99 と 0.-99 の2行です。

Fixed は値を100倍した整数で持つので、Fixed(199) は 1.99、Fixed(50) は 0.5 を表します。times は内部の整数どうしを掛けてから100で割り、スケールを戻します。199 * 50 は 9950 で、100で割ると 99.5 ですが、整数の除算なので小数部が落ちて Fixed(99) になり、0.99 と表示されます。

2行目の掛け算は -199 * 50 で -9950 です。Rust の整数除算はゼロの方向へ切り捨てるので、100で割った -99.5 は -100 ではなく -99 になります。ここまでは1行目と符号が違うだけです。

ずれるのは表示です。-99 / 100 もゼロ方向への切り捨てで 0 になり、整数部から符号が消えます。一方 -99 % 100 は、割られる数と同じ符号を持つ -99 です。{:02} は幅が2に満たないときだけ 0 を詰める指定で、-99 はすでに3文字あるのでそのまま出ます。こうして 0 と . と -99 がつながり、2行目は -0.99 ではなく 0.-99 になります。

負の値を正しく表示するには、符号を先に書き出してから、絶対値を整数部と小数部に分けます。self.0.unsigned_abs() を使えば、i64::MIN でも溢れません。
