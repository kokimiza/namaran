line_lengths.rs

fn main() {
    let text = "one\r\ntwo\nthree\r\n";
    let a: Vec<usize> = text.lines().map(str::len).collect();
    let b: Vec<usize> = text.split('\n').map(str::len).collect();
    println!("{a:?}");
    println!("{b:?}");
}

これは何を出力するでしょうか?

Answer

[3, 3, 5] と [4, 3, 6, 0] の2行です。

str::lines は \n と \r\n のどちらも行の終わりとして扱い、行の中身から取り除きます。"one\r\n" と "three\r\n" からは \r\n の2バイトが、"two\n" からは \n が消えるので、長さは 3、3、5 です。最後の \r\n のあとには何もありませんが、lines は末尾の改行のあとに空の行を作りません。

split('\n') は \n の位置で切るだけです。\r は区切りではないので "one\r" と "three\r" に残り、長さはそれぞれ 4 と 6 になります。さらに、文字列が \n で終わっているため、その後ろの空文字列も1つの要素になり、最後に 0 が付きます。

Windows で作ったファイルと Unix で作ったファイルが混ざった入力でも、lines なら行の中身は同じになります。ただし後ろに \n が続かない単独の \r は、lines でも行の区切りにならず、行の中に残ります。
