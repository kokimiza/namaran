digits.rs

fn add(a: &[u8], b: &[u8]) -> Vec<u8> {
    let mut out = Vec::new();
    let mut carry = 0;
    for (x, y) in a.iter().zip(b) {
        let s = x + y + carry;
        out.push(s % 10);
        carry = s / 10;
    }
    if carry > 0 {
        out.push(carry);
    }
    out
}

fn main() {
    // 987 + 45, least significant digit first
    let sum = add(&[7, 8, 9], &[5, 4]);
    println!("{sum:?}");
}

これは何を出力するでしょうか?

Answer

[2, 3, 1] です。

zip は2つのイテレータから1つずつ取り出して組にし、どちらかが尽きた時点で止まります。b は [5, 4] の2桁しかないので、ループは2回で終わり、a の3桁目の 9 は一度も読まれません。

1回目は 7 + 5 = 12 で 2 を積み、繰り上がりが 1 になります。2回目は 8 + 4 + 1 = 13 で 3 を積み、繰り上がりはまた 1 です。ループを抜けたあと、残った繰り上がりの 1 が最上位の桁として積まれます。

結果を上の桁から読むと 132 で、本来の 987 + 45 = 1032 から百の位の 0 が抜けています。読まれなかった 9 に繰り上がりの 1 を足せば 10 になり、0 を積んで 1 を繰り上げるはずでした。
