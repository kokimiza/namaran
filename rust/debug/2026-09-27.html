read_items.rs

use std::io::BufRead;

fn read_items(mut reader: impl BufRead) -> Vec<String> {
    let mut items = Vec::new();
    let mut line = String::new();
    while reader.read_line(&mut line).unwrap() > 0 {
        if line.ends_with('\n') {
            line.pop();
        }
        if line == "end" {
            break;
        }
        items.push(line.clone());
        line.clear();
    }
    items
}

fn main() {
    let input = "apple\r\nbanana\nend\r\ncherry\n";
    println!("{:?}", read_items(input.as_bytes()));
}

read_items は、1行に1つずつ書かれた品名を end の行の手前まで読み、Vec<String> にして返す関数です。入力は "apple\r\nbanana\nend\r\ncherry\n" です。いまの出力は ["apple\r", "banana", "end\r", "cherry"] ですが、本来の出力は ["apple", "banana"] です。どこを直せばよいでしょうか?

Answer

read_line は、読んだ行を改行まで含めて line に足します。\r\n で終わる行なら \r\n の2文字が付いてきますが、line.pop() が取り除くのは最後の \n 1文字だけです。そのため apple の行は "apple\r" として items に入ります。end の行も "end\r" になって "end" と一致しないので、ループは止まらずに cherry まで読み進めます。

直すには、行末の \r と \n をまとめて取り除きます: 

        let item = line.trim_end_matches(['\r', '\n']);
        if item == "end" {
            break;
        }
        items.push(item.to_string());

trim_end_matches に文字の配列を渡すと、そのどれかに当てはまる文字を末尾から続く限り削ります。\n で終わる行も \r\n で終わる行も同じ結果になるので、改行コードが混在していても品名だけが残ります。BufRead::lines で読むこともでき、こちらは各行から \n や \r\n を取り除いた String を返します。
