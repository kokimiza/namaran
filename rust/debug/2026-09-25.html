merge_pending.rs

fn merge(a: &[i32], b: &[i32]) -> Vec<i32> {
    let mut out = Vec::with_capacity(a.len() + b.len());
    let mut xs = a.iter();
    let mut ys = b.iter();
    let mut x = xs.next();
    let mut y = ys.next();
    while let (Some(&p), Some(&q)) = (x, y) {
        if p <= q {
            out.push(p);
            x = xs.next();
        } else {
            out.push(q);
            y = ys.next();
        }
    }
    out.extend(xs);
    out.extend(ys);
    out
}

fn main() {
    println!("{:?}", merge(&[1, 5], &[2, 3]));
}

mergeは、昇順の2つのスライスを1つの昇順のVecにまとめるつもりの関数です。入力はmerge(&[1, 5], &[2, 3])。いまの出力は[1, 2, 3]ですが、本来の出力は[1, 2, 3, 5]です。どこを直せばよいでしょうか?

Answer

5は、1を押し込んだ直後のx = xs.next()で、すでにxsから取り出されてxに入っています。yがNoneになってループを抜けたとき、5はxの中にだけあり、xsにはもう何も残っていません。out.extend(xs)が足すのは「まだ取り出していない残り」だけなので、手に持っている1個が落ちます。nextは覗くのではなく取り出す、という1つの規則です。直し方は、残りを足す前に手元の1個を足すことです:

out.extend(x);
out.extend(xs);
out.extend(y);
out.extend(ys);

Optionは0個か1個の要素を持つIntoIteratorなので、そのままextendに渡せます(ループを抜けた時点でSomeなのは多くとも片方だけです)。要素が&i32でも、i32がCopyなのでVec<i32>にextendできます。そもそも取り出さずに先頭を見たいなら、peekable()とpeekを使えばこの状態を持たずに済みます。
