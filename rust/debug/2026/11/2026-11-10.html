mask.rs

fn mask(email: &str) -> String {
    let at = email.find('@').unwrap();
    format!("{}***{}", &email[..1], &email[at..])
}

fn main() {
    for email in ["ann@example.com", "élise@example.com"] {
        println!("{}", mask(email));
    }
}

mask は、ログに出すメールアドレスを、先頭の1文字と @ から後ろだけ残して伏せるつもりの関数です。このプログラムは本来 a***@example.com と é***@example.com の2行を出力するはずが、いまは1行目の a***@example.com を出したあと、2つ目のアドレスで panic して止まります。

Answer

Wrong

    format!("{}***{}", &email[..1], &email[at..])

&email[..1] の 1 は文字の個数ではなく、UTF-8で書かれた文字列の中のバイト位置です。a は1バイトなので "ann@example.com" では先頭の1文字がちょうど取れます。é はUTF-8で2バイトなので、"élise@example.com" のバイト位置1は é の途中です。&str のスライスは文字の境目でしか切れず、境目でない位置を渡すと実行時に panic します。メッセージは「end byte index 1 is not a char boundary」です。

Right

    let first = email.chars().next().unwrap();
    format!("{first}***{}", &email[at..])

先頭の1文字は chars() で文字として取り出します。chars() はUTF-8のバイト列を文字ごとに区切って返すので、é も2バイトまとめて1つの char になります。&email[at..] はそのままで構いません。find が返すのは見つけた @ の先頭のバイト位置で、それは必ず文字の境目だからです。
