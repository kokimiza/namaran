sort2.rs

fn sort2<'a>(mut a: &'a mut i32, mut b: &'a mut i32) {
    if *a > *b {
        std::mem::swap(&mut a, &mut b);
    }
}

fn main() {
    let mut x = 5;
    let mut y = 2;
    sort2(&mut x, &mut y);
    println!("{x} {y}");
}

sort2 は、2つの変数の値を小さい順に並べ替えるつもりの関数です。x = 5、y = 2 で呼んだあとに表示すると、本来は 2 5 になるはずが、いまは 5 2 のままで、値が入れ替わりません。

Answer

Wrong

fn sort2<'a>(mut a: &'a mut i32, mut b: &'a mut i32) {
    if *a > *b {
        std::mem::swap(&mut a, &mut b);
    }
}

std::mem::swap は、受け取った2つの &mut T が指す先の値を入れ替えます。a の型は &mut i32 なので、&mut a は &mut &mut i32 で、T は &mut i32 になります。入れ替わるのは関数の中の変数 a と b が持つ参照で、a が y を、b が x を指すようになるだけです。x と y の値には触れないまま関数が終わるので、5 2 が表示されます。仮引数の mut と、2つの参照にそろえたライフタイム 'a は、参照どうしを入れ替えるために要ったものです。

Right

fn sort2(a: &mut i32, b: &mut i32) {
    if *a > *b {
        std::mem::swap(a, b);
    }
}

a と b をそのまま渡すと、T は i32 になり、x と y の値が入れ替わって 2 5 が表示されます。&mut i32 は Copy ではありませんが、型が &mut T と決まっている引数に渡すと再借用 &mut *a になるので、a はムーブされず、関数の中で続けて使えます。値を入れ替えるのに仮引数を mut にする必要はなく、mut もライフタイムの注釈も消せます。
