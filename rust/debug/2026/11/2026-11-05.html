quantity.rs

fn split_quantity(s: &str) -> (String, String) {
    let mut chars = s.chars();
    let digits: String = chars.by_ref().take_while(|c| c.is_ascii_digit()).collect();
    let unit: String = chars.collect();
    (digits, unit)
}

fn main() {
    println!("{:?}", split_quantity("15kg"));
}

"15kg" のような文字列を、先頭に続く数字の部分と、残りの単位の部分に分ける split_quantity です。split_quantity("15kg") を表示すると、いまは ("15", "g") と表示されます。本来は ("15", "kg") と表示されるはずです。

Answer

Wrong

    let mut chars = s.chars();
    let digits: String = chars.by_ref().take_while(|c| c.is_ascii_digit()).collect();
    let unit: String = chars.collect();

take_while は、条件を満たさない要素を見た時点で止まります。ところが、満たすかどうかを調べるには、その要素を元のイテレータから next で取り出すしかありません。"15kg" では '1' と '5' を通したあと、'k' を取り出して条件が偽になったところで終わり、'k' は戻されずに捨てられます。

by_ref のおかげで chars は take_while のあとも使えますが、読む位置はもう 'k' の後ろです。続く chars.collect() が集めるのは 'g' だけで、単位は "g" になります。

Right

    let mut chars = s.chars().peekable();
    let digits: String = std::iter::from_fn(|| chars.next_if(|c| c.is_ascii_digit())).collect();
    let unit: String = chars.collect();

peekable で包んだイテレータの next_if は、次の要素を先に覗き、条件を満たすときだけ取り出して Some で返します。満たさなければ None を返し、その要素は取り出さずに残します。std::iter::from_fn で next_if を繰り返し呼ぶと、'k' の手前で止まって "15" が集まり、chars.collect() は 'k' から読み始めて "kg" を返します。数字だけの "3" なら、単位は空文字列です。

文字列のまま分けるなら、s.find(|c: char| !c.is_ascii_digit()) で最初の数字でない文字の位置を求め、split_at で2つに切る書き方もあります。こちらは要素を取り出さずに位置だけを求めるので、取り出しすぎる心配がありません。
