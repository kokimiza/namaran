first_late.rs

fn main() {
    let late = |t: u32| t >= 3_000_000_000;
    let (mut lo, mut hi) = (0, u32::MAX);
    while lo < hi {
        let mid = (lo + hi) / 2;
        if late(mid) {
            hi = mid;
        } else {
            lo = mid + 1;
        }
    }
    println!("{lo}");
}

u32 の時刻のうち、late が true になる最初の時刻を二分探索で探して出力するつもりのプログラムです。3000000000 を出力するはずが、いまは Debug ビルドで attempt to add with overflow というメッセージを出して panic し、何も出力しません。

Answer

Wrong

        let mid = (lo + hi) / 2;

1回目の mid は (0 + 4294967295) / 2 で 2147483647 です。この時刻では late が false なので、lo は 2147483648 に進みます。2回目の lo + hi は 2147483648 + 4294967295 で、u32::MAX の 4294967295 を超えます。Rust の Debug ビルドは整数のオーバーフローを検査しているので、この足し算で panic します。

中点そのものは lo と hi の間にあり、u32 に必ず収まります。あふれるのは途中の和だけで、lo と hi がどちらも型の最大値の半分を超えると起きます。

Right

        let mid = lo + (hi - lo) / 2;

区間の幅 hi - lo を先に求め、その半分を lo に足します。ループの中では lo < hi なので引き算は 0 より小さくならず、lo + (hi - lo) / 2 は hi を超えないので、どの途中の値も u32 に収まります。値は (lo + hi) / 2 を数学的に計算したものと同じで、探索の進み方は変わりません。
