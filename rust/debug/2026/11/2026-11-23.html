shorten.rs

fn shorten(s: &str, max: usize) -> String {
    if s.len() <= max {
        return s.to_string();
    }
    let t: String =
        s.chars().take(max - 1).collect();
    t + "…"
}

fn main() {
    println!("{}", shorten("coffee", 4));
    println!("{}", shorten("café", 4));
}

shorten(s, max) は、s が max 文字以下ならそのまま返し、超えていれば先頭 max - 1 文字に … を付けて、ちょうど max 文字に切り詰めるつもりの関数です。main は "coffee" と "café" を、どちらも max を 4 にして渡します。本来は cof… と café を出すはずが、いまは2行目も caf… になり、4文字に収まっている "café" の最後の文字が消えます。

Answer

Wrong

    if s.len() <= max {
        return s.to_string();
    }

切り詰める側の s.chars().take(max - 1) は文字を数えていますが、判定の s.len() は文字ではなく UTF-8 のバイト数を返します。"coffee" は ASCII だけなので文字数とバイト数がどちらも 6 で、正しく切り詰められます。"café" は4文字でも、é が2バイトなので len() は 5 です。5 <= 4 は偽なので、切り詰める必要のない文字列が先頭3文字 caf と … に置き換わります。

Right

    if s.chars().count() <= max {
        return s.to_string();
    }

判定を s.chars().count() にすると、判定と切り詰めが同じ単位(char の個数)で数えるようになります1。"café" の文字数は 4 なので 4 <= 4 が真になり、そのまま返ります。"coffee" は6文字なので、これまでどおり cof… です。chars().count() は文字列を先頭から最後まで読むので、len() と違って長さに比例した時間がかかります。

  1. char の個数は、画面に並ぶ文字の数とも一致しないことがあります。e の後ろにアクセント記号だけの文字を続けて書いた é は、見た目は1文字でも char は2個です。
