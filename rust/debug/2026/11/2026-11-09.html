wallet.rs

struct Wallet {
    balance: i64,
    log: Vec<i64>,
}

impl Wallet {
    fn deposit(&mut self, x: i64) {
        self.log.push(x);
        self.balance += x;
    }

    fn restart(&mut self) {
        self.balance = 0;
        for x in self.log.clone() {
            self.deposit(x);
        }
    }
}

入金をログ log に記録し、再起動したときはログを読み直して残高を作り直すつもりの財布です。Wallet { balance: 0, log: Vec::new() } から始めて deposit(100)、restart()、deposit(50)、restart() の順に呼ぶと、最後の balance は本来 150 のはずが、いまは 250 です。

Answer

Wrong

    fn restart(&mut self) {
        self.balance = 0;
        for x in self.log.clone() {
            self.deposit(x);
        }
    }

250は100 + 100 + 50で、2回目の restart の時点で、ログに100が2つ入っていたことになります。100を2つにしたのは1回目の restart です。restart は残高を作り直すのに deposit を呼びますが、deposit は入金を self.log に書き足してから残高を増やします。ループが回っているのは clone で作った複製なので、書き足してもループの回数は変わりません。そのかわり self.log には元の記録と、再生で書き足した記録の両方が残ります。1回目の restart のあとの残高は100で正しく見えますが、ログは [100, 100] になっており、deposit(50) で [100, 100, 50]、2回目の restart で残高250になります。再起動のたびにログが倍に増えるので、回数を重ねるほど残高はずれていきます。

Right

    fn restart(&mut self) {
        self.balance = 0;
        for x in std::mem::take(&mut self.log) {
            self.deposit(x);
        }
    }

std::mem::take(&mut self.log) は、self.log を空の Vec と入れ替え、それまでの中身を返します。ループは古い記録を受け取って回り、deposit はそれを空になった self.log へ1つずつ戻すので、restart のあとのログは前と同じ [100] になります。何度再起動してもログと残高は変わらず、2回目の restart は [100, 50] から150を作ります。

clone が書かれていたのは、for x in &self.log のまま self.deposit(x) を呼ぶと、self.log を共有で借りている間に self を可変で借りることになり、コンパイルが通らないからです。このエラーは、読んでいるログと書き足すログが同じものだと指摘しています。clone は複製を作ってエラーを消しますが、二重になった記録はそのまま残ります。take は記録を複製せずに取り出すので、借用は衝突せず、ログに同じ記録が2つ並ぶこともありません。
