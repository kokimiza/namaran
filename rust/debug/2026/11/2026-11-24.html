payments.rs

use std::collections::HashSet;

fn main() {
    let reqs = [(1, 23, 500), (12, 3, 700)];
    let mut done = HashSet::new();
    let mut total = 0;
    for (user, seq, amount) in reqs {
        let key = format!("{user}{seq}");
        if done.contains(&key) {
            continue;
        }
        done.insert(key);
        total += amount;
    }
    println!("{total}");
}

(利用者番号, 要求番号, 金額) の支払い要求を順に処理し、同じ利用者の同じ要求番号が再送されてきたら二重に処理しないよう飛ばして、処理した金額の合計を出すつもりのコードです。入力は reqs の2件で、利用者 1 の要求 23 と利用者 12 の要求 3 は別々の支払いです。本来は 1200 を出力するはずが、いまは 500 を出力します。

Answer

Wrong

let key = format!("{user}{seq}");

format!("{user}{seq}") は2つの数を区切りなしで文字列につなぐので、利用者 1 の要求 23 も、利用者 12 の要求 3 も、キーは同じ "123" になります。1件目で "123" が done に入るので、2件目は contains が真になって再送とみなされ、continue で飛ばされます。合計は1件目の 500 だけになり、別人の 700 の支払いは黙って捨てられます。

Right

let key = (user, seq);

キーを (user, seq) のタプルにすると、2つの値は別々の要素として比べられ、(1, 23) と (12, 3) は等しくなりません。タプルの要素は Eq と Hash を持つ整数なので、そのまま HashSet に入れられます。同じ利用者の同じ要求番号の再送だけが同じキーになり、2件とも処理されて合計は 1200 になります。"{user}:{seq}" のように区切りを入れても、この入力では直りますが、つなぐ値が文字列なら、区切りの文字が値の中に現れたときにまた衝突します。値の組はタプルのまま持つほうが確実です。
