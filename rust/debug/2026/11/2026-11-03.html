clock_format.rs

fn hms(secs: u64) -> String {
    let h = secs / 3600;
    let m = secs / 60;
    let s = secs % 60;
    format!("{h}:{m:02}:{s:02}")
}

fn main() {
    println!("{}", hms(3725));
}

秒数 secs を「時:分:秒」の文字列にし、分と秒を2桁で表すつもりの hms です。hms(3725) は 1:02:05 を返すはずが、いまは 1:62:05 を返し、プログラムは 1:62:05 を表示します。

Answer

Wrong

let h = secs / 3600;
let m = secs / 60;
let s = secs % 60;

secs / 60 は、3725 秒が全部で何分かを数えるので 62 になります。そのうち 60 分は h の 1 時間としてすでに数えてあるのに、m には同じ 60 分がまだ入ったままです。秒のほうは secs % 60 で分に繰り上げた分を取り除いているので 5 になり、分だけが時に繰り上げた分を取り除かれずに残ります。1 時間を超える秒数では、どれも分が 60 以上になります。

Right

let h = secs / 3600;
let m = secs / 60 % 60;
let s = secs % 60;

全部で何分かを数えた secs / 60 を、さらに 60 で割った余りにすると、時に繰り上げた分が取り除かれて 0 から 59 の値になります。/ と % は同じ優先順位で左から結合するので、secs / 60 % 60 は (secs / 60) % 60 と同じで、62 を 60 で割った余りの 2 が分になります。これで分は秒と同じく「その桁の単位で割り、上の桁へ繰り上げた分を余りで捨てる」形になります。時は一番上の桁なので、捨てる分がなく secs / 3600 のままです。
