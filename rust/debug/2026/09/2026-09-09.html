page.rs

fn page(ids: &[u32], number: usize, per_page: usize) -> &[u32] {
    let start = (number - 1) * per_page;
    &ids[start..start + per_page]
}

fn main() {
    let ids: Vec<u32> = (101..=107).collect();
    for number in 1..=3 {
        println!("page {number}: {:?}", page(&ids, number, 3));
    }
}

page は、ids を per_page 件ずつに区切り、1から数えて number 番目のページをスライスで返すつもりの関数です。入力は main のとおり、101 から 107 までの7件を3件ずつに分けて、1ページ目から3ページ目までを表示します。いまは1ページ目と2ページ目を表示したあと、3ページ目を取るところでパニックして止まります。本来は3行が出力され、最後の行は page 3: [107] です。どこを直せばよいでしょうか?

Answer

終わりの位置を ids.len() で切り詰めます。let end = (start + per_page).min(ids.len()); を足し、&ids[start..end] を返します。

3ページ目の start は6で、start + per_page は9です。ids は7件しかないので &ids[6..9] は範囲外を指し、Rustのスライスの添字は範囲を確かめてパニックします。1ページ目と2ページ目は3件ちょうどに収まるので、端数のある最後のページで初めて起きます。

end を切り詰めると、3ページ目は &ids[6..7] になって [107] が返ります。存在しない4ページ目を頼まれると、今度は start が長さを超えてパニックします。その場合も空を返したいなら、ids.chunks(per_page).nth(number - 1).unwrap_or(&[]) と書く方法もあります。
