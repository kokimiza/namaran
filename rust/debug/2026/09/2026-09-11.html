divide_evenly.rs

fn divide_evenly(total: u32, groups: u32) -> u32 {
    total / groups
}

fn main() {
    let items = 10;
    let bins = 0;
    println!("{}", divide_evenly(items, bins));
}

divide_evenlyはtotal個をgroups個のグループに均等に分けたときの1グループあたりの個数を求めるつもりです。groupsが0(分ける先が無い)のとき、いまの出力は何も表示されないまま、実行時にパニックしてクラッシュします(終了コード101)。本来は0を出力するべきです(分ける先が無いなら、1グループあたりの個数は0とみなします)。何が問題で、どう直せばよいでしょうか?

Answer

total / groupsは、整数の/演算子をガードなしで使っています。Rustの整数除算はgroupsが0だとパニックします(これはC/C++の未定義動作とは違い、言語仕様で定められた挙動です)。groupsはリテラルの0ではなく呼び出し元から渡された値なので、コンパイル時には検出されず、実行時に初めてパニックします。total / groupsを呼び出す前にprintln!の引数として評価されるため、パニックした時点では何も出力されていません。checked_divを使えば0除算をNoneとして受け取れるので、unwrap_orで「分ける先が無ければ0」というフォールバックを与えられます: 

fn divide_evenly(total: u32, groups: u32) -> u32 {
    total.checked_div(groups).unwrap_or(0)
}
