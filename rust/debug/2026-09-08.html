to_cents.rs

fn to_cents(dollars: f64) -> i64 {
    (dollars * 100.0) as i64
}

fn main() {
    for price in [0.5, 19.99, 1.15] {
        println!("{}", to_cents(price));
    }
}

ドル単位の価格を、セント単位の整数に変換する to_cents です。main のとおり 0.5、19.99、1.15 を順に変換して出力すると、いまは 50、1998、114 の3行が出ます。本来は 50、1999、115 です。どこを直せばよいでしょうか?

Answer

(dollars * 100.0) as i64 を (dollars * 100.0).round() as i64 に変えます。

19.99 は2進数の f64 では正確に表せず、わずかに小さい値として格納されます。100倍した結果も1999ちょうどにはならず、1998.9999999999998 です。浮動小数点数から整数への as による変換は小数部をゼロの方向へ切り捨てるので、これが 1998 になります。1.15 も同じで、114.99999999999999 が 114 になります。

0.5 は2進数で正確に表せるので、100倍しても 50.0 ちょうどで、切り捨てても値は変わりません。3つのうち1つだけが正しく出るのはこのためです。

round で最も近い整数に丸めてから変換すれば、このわずかな誤差は吸収され、1999 と 115 になります。いったんセント単位の整数にしてしまえば、そこから先の足し算や比較に誤差は入りません。
