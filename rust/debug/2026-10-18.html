first_seen.rs

use std::collections::HashMap;

fn first_seen<'a>(words: &[&'a str]) -> Vec<&'a str> {
    let mut seen: HashMap<&str, ()> = HashMap::new();
    words
        .iter()
        .copied()
        .filter(|&w| seen.insert(w, ()).is_some())
        .collect()
}

fn main() {
    println!("{:?}", first_seen(&["a", "b", "a", "c", "b", "a"]));
}

first_seen は、単語の列から重複を除き、それぞれの単語を最初に現れた順に並べて返すつもりの関数です。入力は main の ["a", "b", "a", "c", "b", "a"] です。いまの出力は ["a", "b", "a"] です。本来の出力は ["a", "b", "c"] です。

Answer

Wrong

        .filter(|&w| seen.insert(w, ()).is_some())

HashMap::insert が返すのは、そのキーに前から入っていた値です。初めてのキーなら None、既にあったキーなら Some(()) が返るので、is_some() が真になるのは2度目以降に現れた単語です。filter はその単語だけを残すため、3番目の a、5番目の b、6番目の a が残って ["a", "b", "a"] になります。

値の型 () は大きさ0の型なので、Option<()> が伝えるのは Some か None かだけで、実質は真偽値です。中身の値を見ないまま真偽値として読むと、「入れられたら Some」と向きを逆に取りやすく、このコードもそう読んでいます。

Right

        .filter(|&w| seen.insert(w, ()).is_none())

is_none() にすると、前に入っていなかった単語だけが、insert で記録されると同時に残ります。値が () の HashMap は集合として使えますが、標準ライブラリにはそのための HashSet があります1。HashSet::insert は新しく入ったときに true を返すので、.filter(|&w| seen.insert(w)) と書けば戻り値の向きを取り違えません。

  1. 標準ライブラリの HashSet<T> は、値が () のハッシュ表として実装されています。Go では map[string]struct{} が集合の定番の書き方で、値の struct{} も Rust の () と同じく大きさが0の型です。
