purge.rs

use std::collections::HashMap;

fn purge(cache: &mut HashMap<String, (i32, u64)>, now: u64) -> usize {
}

キャッシュ cache から期限切れの要素を取り除き、取り除いた数を返す purge を書いてください。値は (値, 期限) の組で、時刻 now が期限と同じか、それより後なら期限切れです。期限切れが1つもなければ、cache を変えずに 0 を返します。例では cache の中身を {"a": (1, 10)} のように書きます。

入力例 1

cache = {"a": (1, 10), "b": (2, 20)}; purge(&mut cache, 15)

出力例 1

1, cache = {"b": (2, 20)}

入力例 2

cache = {"a": (1, 10)}; purge(&mut cache, 10)

出力例 2

1, cache = {}

入力例 3

cache = {}; purge(&mut cache, 0)

出力例 3

0, cache = {}
Reference 
fn purge(cache: &mut HashMap<String, (i32, u64)>, now: u64) -> usize {
    let before = cache.len();
    cache.retain(|_, &mut (_, expires)| expires > now);
    before - cache.len()
}

HashMap::retain は、クロージャが true を返した要素だけを残します。残すのは、期限がまだ来ていない expires > now の要素です。retain は取り除いた数を返さないので、呼ぶ前と後の len() の差で求めます。

クロージャはキーへの参照と値への可変参照を受け取ります。パターン &mut (_, expires) で値の組から期限だけを取り出しており、u64 は Copy なので、参照を外して値のまま受け取れます。

掲載したのは参考実装で、唯一の正解ではありません。期限切れのキーを Vec に集めてから1つずつ remove しても同じ結果になります。ただし、HashMap を走査している最中にその HashMap から消すことは借用の規則が許さないので、いったん別の場所に集める必要があります。
