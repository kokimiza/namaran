escape.rs

fn escape_field(s: &str) -> String {
}

文字列 s を、CSVの1つのフィールドとして書き出せる形にして返す escape_field を書いてください。s がカンマ・引用符 "・改行 \n のどれかを含むときは、中の引用符をそれぞれ2つ重ねたうえで、全体を引用符で囲みます。どれも含まないときは、空文字列も含めて s をそのまま返します。入出力例の r#"…"# は、引用符をエスケープせずに書ける生文字列リテラルです。

入力例 1

escape_field("1,000")

出力例 1

r#""1,000""#

入力例 2

escape_field(r#"6" pipe"#)

出力例 2

r#""6"" pipe""#

入力例 3

escape_field("")

出力例 3

""

fn escape_field(s: &str) -> String {
    if s.contains([',', '"', '\n']) {
        format!("\"{}\"", s.replace('"', "\"\""))
    } else {
        s.to_string()
    }
}

参考実装は、contains に文字の配列を渡して、3つの文字のどれかを含むかを一度に調べます。含むときは replace で引用符を "" に置き換えてから、format! で前後に引用符を付けます。引用符で囲んだフィールドの中では、カンマと改行は区切りではなく文字として読まれます。中の引用符を重ねるのは、フィールドを閉じる引用符と区別するためです。

掲載したのは参考実装で、唯一の正解ではありません。戻り値を Cow<str> にすれば、囲む必要のない文字列では新しい String を作らずに済みます。
