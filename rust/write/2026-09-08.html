split.rs

fn split(total_cents: u64, n: u64) -> Vec<u64> {
}

セント単位の整数で表した金額 total_cents を n 人で分け、各人の取り分を並べた Vec を返す split を書いてください。取り分どうしの差は1セント以内にし、割り切れないときは先頭の人から順に1セント多くします。取り分の合計は total_cents に一致させます。n は1以上とします。split(1000, 3) → [334, 333, 333]、split(2, 3) → [1, 1, 0]、split(0, 2) → [0, 0]

Reference 
fn split(total_cents: u64, n: u64) -> Vec<u64> {
    let (q, r) = (total_cents / n, total_cents % n);
    (0..n).map(|i| q + u64::from(i < r)).collect()
}

total_cents を n で割った商 q を全員に配ると、余りの r セントが残ります。r は n 未満なので、先頭の r 人に1セントずつ足せばちょうど配り切れます。

参考実装では、添字 i が r 未満かどうかを表す bool を u64::from で 0 か 1 に変え、q に足しています。1000 / 3 なら商が 333、余りが 1 なので、先頭の1人だけが 334 になります。

金額を f64 のドル単位で持ち、10.0 / 3.0 を丸めて配ると、丸めた3つの値の合計が元の金額に戻る保証はありません。セント単位の整数にしておけば、商と余りだけで1セントも失わずに分けられます。

掲載したのは参考実装で、唯一の正解ではありません。vec![q; n as usize] を作ってから、先頭の r 要素に1を足す書き方でも同じ結果になります。
