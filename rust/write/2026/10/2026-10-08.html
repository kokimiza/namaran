indent.rs

fn indent(lines: &[&str], depth: usize) -> String {
}

lines の各行の先頭に depth 段分の字下げ(1段は空白2つ)を付け、行末に改行を付けて順につないだ String を返す indent を書いてください。かかる時間は、できあがる文字列の長さに比例するようにします。lines が空なら空の文字列を返します。

入力例 1

indent(&["a", "b"], 1)

出力例 1

"  a\n  b\n"

入力例 2

indent(&[], 3)

出力例 2

""

入力例 3

indent(&["x", "  y"], 0)

出力例 3

"x\n  y\n"
Reference 
fn indent(lines: &[&str], depth: usize) -> String {
    let pad = "  ".repeat(depth);
    let mut out = String::new();
    for line in lines {
        out.push_str(&pad);
        out.push_str(line);
        out.push('\n');
    }
    out
}

参考実装は、字下げの文字列 pad を最初に1度だけ作り、out の末尾に字下げ、行、改行の順で書き足していきます。push_str は out のバッファの後ろに書き足すだけで、それまでの中身には触りません。容量が足りなくなったときは確保し直して中身を移しますが、そのたびに容量を大きく(今の実装ではおよそ倍に)広げるので移す回数は少なく、移すバイト数を合計してもできあがる長さに比例する量に収まります。

同じ処理を out = format!("{out}{pad}{line}\n") と書くと、format! は毎回新しい String を作り、それまでの out を丸ごとそこへコピーします。行が増えるほどコピーする量も増えるので、全体の時間は長さの2乗に比例します。

掲載したのは参考実装で、唯一の正解ではありません。lines.iter().map(|line| format!("{pad}{line}\n")).collect::<String>() も、各行の文字列を1度ずつ末尾に足すだけなので、長さに比例する時間で済みます。
