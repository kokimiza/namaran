path.rs

fn path(leaf_first: &[&str]) -> String {
}

leaf_first は、パスの部品となる名前を、いちばん深いものから根の直下のものへ向かって並べたスライスです。これを根の側から順に / でつないだ絶対パスを返す path を書いてください。かかる時間は、できあがる文字列の長さに比例するようにします。空のスライスなら "/" を返します。

入力例 1

path(&["c", "b", "a"])

出力例 1

"/a/b/c"

入力例 2

path(&["notes.txt", "home"])

出力例 2

"/home/notes.txt"

入力例 3

path(&[])

出力例 3

"/"
Reference 
fn path(leaf_first: &[&str]) -> String {
    if leaf_first.is_empty() {
        return "/".to_string();
    }
    let mut s = String::with_capacity(leaf_first.iter().map(|p| p.len() + 1).sum());
    for p in leaf_first.iter().rev() {
        s.push('/');
        s.push_str(p);
    }
    s
}

根に近い名前ほど後ろにあるので、leaf_first.iter().rev() で後ろから取り出し、/ と名前を末尾に足していきます。String の末尾への追加は、容量が足りている限り、足す文字数ぶんの手間で済みます。最初に with_capacity で名前の長さと / 1文字ずつの合計を確保しておけば、途中でバッファを伸ばすこともありません。

前から順に読み、s.insert_str(0, ...) で先頭に足していく書き方でも、結果は同じになります。ただし先頭への挿入は、それまでに組み立てた文字列を全部後ろへずらします。部品が n 個あれば、ずらす量の合計は n の2乗に比例して増えるので、長さに比例するという条件を満たしません。

空のスライスではループが1回も回らず、空文字列が返ってしまうので、先に "/" を返しておきます。掲載したのは参考実装で、唯一の正解ではありません。+ は左辺のバッファを使い回すので、leaf_first.iter().rev().fold(String::new(), |acc, p| acc + "/" + p) と書いても、時間は長さに比例します。
