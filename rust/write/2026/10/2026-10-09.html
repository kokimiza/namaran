fn pad_with_last<T: Clone>(mut v: Vec<T>, n: usize) -> Vec<T> {
}

v の長さが n に足りないとき、最後の要素を繰り返し後ろに足して長さを n にした Vec を返す pad_with_last を書いてください。要素型は String のように Copy でない型でも使えるようにします。v の長さがすでに n 以上ならそのまま返し、v が空なら繰り返す要素がないので空のまま返します。

入力例 1

pad_with_last(vec!["a", "b"], 4)

出力例 1

["a", "b", "b", "b"]

入力例 2

pad_with_last(vec![1, 2, 3], 2)

出力例 2

[1, 2, 3]

入力例 3

pad_with_last(Vec::<String>::new(), 3)

出力例 3

[]

fn pad_with_last<T: Clone>(mut v: Vec<T>, n: usize) -> Vec<T> {
    if let Some(last) = v.last().cloned() {
        v.resize(n.max(v.len()), last);
    }
    v
}

参考実装は、v.last() で最後の要素への参照 Option<&T> を取り、cloned() で中身を複製して Option<T> にします。v が空なら None なので何もしません。取り出した値を resize に渡すと、resize は足りない分をその値の clone() で埋めます。n が今の長さより小さいと resize は切り詰めてしまうので、長さは n.max(v.len()) にしています。

v.last() が返すのは要素への参照なので、resize に渡す T の値はそこから作ります。*last のように参照の先から値をそのまま持ち出せるのは T が Copy のときだけで、String のような型では clone() で複製するしかありません。

境界を T: Copy にすると、整数や &str は渡せても String は渡せなくなります。Copy を実装できるのはビットを写すだけで複製できる型に限られ、ヒープに文字列を持つ String は、新しい領域を確保して中身を写す clone() でしか複製できないからです。Copy の型はどれも Clone も実装しているので、T: Clone にしておけば両方を受け取れます。

掲載したのは参考実装で、唯一の正解ではありません。while v.len() < n の中で最後の要素を clone() して push する書き方でも、同じ結果になります。
