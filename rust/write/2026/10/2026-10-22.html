combine.rs

fn combine(a: Option<i32>, b: Option<i32>) -> Option<i32> {
}

2つの Option<i32> を受け取る combine を書いてください。両方が Some なら2つの値の和を Some で、片方だけが Some ならその値を Some で返し、両方が None なら None を返します。和は i32 に収まるものとします。

入力例 1

combine(Some(2), Some(3))

出力例 1

Some(5)

入力例 2

combine(None, Some(4))

出力例 2

Some(4)

入力例 3

combine(None, None)

出力例 3

None
Reference 
fn combine(a: Option<i32>, b: Option<i32>) -> Option<i32> {
    match (a, b) {
        (Some(x), Some(y)) => Some(x + y),
        (Some(x), None) | (None, Some(x)) => Some(x),
        (None, None) => None,
    }
}

a と b を別々に if let で調べると、分岐が入れ子になります。2つを (a, b) のタプルにまとめて match すれば、2つの値の形の組み合わせ4通りを、1段の腕として並べられます。片方だけが Some の2通りは、| でつないだ or パターン1つで書けます。| の両側で同じ名前の x を同じ型に束縛しているので、どちらに当てはまっても腕の中では x を使えます。

4通りのどれかを書き忘れると、match が網羅的でないとしてコンパイルエラーになるので、「両方 None」の扱いを決めずに済ませることはできません。掲載したのは参考実装で、唯一の正解ではありません。a.zip(b).map(|(x, y)| x + y).or(a).or(b) のように Option のメソッドをつないでも書けますが、3つの形を並べて読めるのは match のほうです。
