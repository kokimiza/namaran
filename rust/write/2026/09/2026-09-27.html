parse_rows.rs

fn parse_rows(text: &str) -> Vec<Vec<&str>> {
}

カンマ区切りのテキストを、行ごとにフィールドの並びへ分ける parse_rows を書いてください。行の終わりには \n と \r\n が混在していることがあり、どちらも行の中身に含めません。最後の行は改行で終わっていてもいなくてもよく、空のテキストなら空の Vec を返します。引用符で囲んだフィールドは考えません。parse_rows("a,b\r\nc,d\n") → [["a", "b"], ["c", "d"]]、parse_rows("x\r\n\r\ny,z") → [["x"], [""], ["y", "z"]]、parse_rows("") → []

Reference 
fn parse_rows(text: &str) -> Vec<Vec<&str>> {
    text.lines().map(|line| line.split(',').collect()).collect()
}

lines が \n と \r\n の両方を行の終わりとして取り除くので、各行を split(',') で分ければ、最後のフィールドに \r が残ることはありません。行を split('\n') で分けると、\r\n で終わる行の最後のフィールドは "b\r" になり、"b" との比較が何も言わずに失敗します。

戻り値の &str はどれも text の一部を指していて、新しい文字列は作っていません。シグネチャでは省略していますが、ライフタイムは引数の text と同じです。内側の collect() が Vec<&str> を作ることは、戻り値の型から推論されます。

空行が [""] になるのは、"".split(',') が空文字列を1つ返すからです。掲載したのは参考実装で、唯一の正解ではありません。空行を飛ばしたいなら、filter を挟みます。
