average.rs

fn average(xs: &[i32]) -> Option<i32> {
}

スライス xs の平均を整数で返す average を書いてください。合計を要素数で / で割り、端数は 0 の方向へ切り捨てます。xs が空なら None です。if も match も使わず、bool のメソッドを使った1つの式で書きます。average(&[1, 2, 6]) → Some(3)、average(&[-3, 4]) → Some(0)、average(&[]) → None

Reference 
fn average(xs: &[i32]) -> Option<i32> {
    (!xs.is_empty()).then(|| xs.iter().sum::<i32>() / xs.len() as i32)
}

bool::then は、self が真のときだけ渡したクロージャを呼び、その結果を Some で包みます。偽なら None を返してクロージャは呼ばないので、空のスライスで 0 による割り算が行われることはありません。

よく似た then_some は、クロージャではなく値そのものを受け取ります。(!xs.is_empty()).then_some(xs.iter().sum::<i32>() / xs.len() as i32) と書くと、関数の引数なので割り算は then_some を呼ぶ前に必ず評価されます。空のスライスでは 0 / 0 を計算することになり、None を返す前に panic します。

掲載したのは参考実装で、唯一の正解ではありません。bool のメソッドを使うという条件がなければ、if xs.is_empty() { None } else { Some(...) } と書くのが素直です。
