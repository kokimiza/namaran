fn take<'a>(s: &mut &'a str, n: usize) -> &'a str {
}

*s の先頭 n バイトを返し、呼び出し側の &str を残りの部分に進める take を書いてください。n は *s の長さ以下で、文字の区切りに当たっているものとします。n が0なら空文字列を返して *s はそのまま、n が長さと等しければ全体を返して *s は空になります。例では、入力例に呼び出す前の s と n を、出力例に戻り値と呼び出したあとの s を書きます。

入力例 1

s = "2026-11-13", n = 4

出力例 1

"2026", s = "-11-13"

入力例 2

s = "abc", n = 0

出力例 2

"", s = "abc"

入力例 3

s = "xy", n = 2

出力例 3

"xy", s = ""

fn take<'a>(s: &mut &'a str, n: usize) -> &'a str {
    let (head, rest) = s.split_at(n);
    *s = rest;
    head
}

s は呼び出し側の変数を指す &mut で、その中身 *s が文字列を指す &'a str です。&str のような共有参照は Copy なので、*s を読み出しても s から何かがムーブされることはありません。s.split_at(n) は自動参照外しで *s のコピーに対して呼ばれ、ライフタイム 'a のままの head と rest を返します。あとは *s = rest で呼び出し側の変数を残りに付け替え、head を返します。これは参考実装で、唯一の正解ではありません。

入力例1では split_at(4) が "2026" と "-11-13" に分け、呼び出し側の s は "-11-13" を指すようになります。n が0なら head は空で rest は元と同じ文字列、n が長さと等しければ rest が空になるので、入力例2と3もこのまま正しく動きます。文字列そのものはどこにもコピーされず、変わるのは呼び出し側が持つ参照だけです。仮引数を s: &'a str にすると、付け替えるのは関数の中のコピーだけになり、呼び出し側の s は進みません。
