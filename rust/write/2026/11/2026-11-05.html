countdown.rs

fn countdown(from: u32, step: u32) -> Vec<u32> {
}

from から始めて step ずつ減らした値を、0以上のものだけ大きい順に並べて返す countdown を書いてください。step は1以上です。from が0なら [0] を返します。

入力例 1

countdown(10, 3)

出力例 1

[10, 7, 4, 1]

入力例 2

countdown(6, 2)

出力例 2

[6, 4, 2, 0]

入力例 3

countdown(0, 5)

出力例 3

[0]

fn countdown(from: u32, step: u32) -> Vec<u32> {
    std::iter::successors(Some(from), |&n| n.checked_sub(step)).collect()
}

符号付き整数なら「引いてから、負になったら止める」と書けますが、u32 には負の値がありません。1 - 3 のように0を下回る引き算は、デバッグビルドでは panic し、リリースビルドでは大きな正の値に折り返します。while n >= 0 と書いても条件は常に真で、終了条件になりません。止めるかどうかは、引く前に「引けるか」で決める必要があります。

checked_sub は、引き算の結果が0以上なら Some に包んで返し、0を下回るなら None を返します。std::iter::successors は最初の値 Some(from) から、直前の値をクロージャに渡して次の値を作り、None が返ったところで終わるイテレータです。入力例1では10、7、4、1と進み、1.checked_sub(3) が None なので1で止まります。入力例2では 2 - 2 = 0 がまだ引ける値なので0まで並び、入力例3では最初の0から5を引けずに [0] になります。これは参考実装で、唯一の正解ではありません。loop の中で checked_sub の結果を match し、None で break しても同じものが書けます。
