fn to_utc(local: i32) -> Vec<i32> {
}

夏時間が終わる日の現地時刻 local を受け取り、それに当たる UTC の時刻をすべて、早い順に並べた Vec で返す to_utc を書いてください。この地域は、夏時間のあいだは UTC より120分、標準時では60分進んでいます。この日は、夏時間の現地 3:00 になった瞬間に時計を 2:00 に戻し、そこから標準時になります。時刻はどれも、その日の 0:00 からの分で表します。local は 0 以上 1440 未満で、UTC の時刻が前の日にかかるときは負の数になります。

入力例 1

to_utc(150)

出力例 1

[30, 90]

入力例 2

to_utc(60)

出力例 2

[-60]

入力例 3

to_utc(180)

出力例 3

[120]

fn to_utc(local: i32) -> Vec<i32> {
    match local {
        ..120 => vec![local - 120],
        120..180 => {
            vec![local - 120, local - 60]
        }
        _ => vec![local - 60],
    }
}

現地時刻から UTC を求めるには、その時点で UTC より進んでいる分を引きます。2:00（120分）より前は夏時間なので 120 を引き、3:00（180分）以降は標準時なので 60 を引きます。2:00 から 2:59 までは、時計を戻す前の夏時間で一度、戻したあとの標準時でもう一度現れるので、120 を引いた値と 60 を引いた値の両方を返します。夏時間で読んだほうが UTC では60分早いので、この順に並べれば早い順になります。掲載したのは参考実装で、唯一の正解ではありません。

入力例1の 150 は 2:30 で、夏時間の 2:30 は UTC の 0:30（30分）、標準時の 2:30 は UTC の 1:30（90分）です。入力例2の 1:00 は夏時間だけで、UTC では前の日の 23:00 に当たるので -60 になります。入力例3の 3:00 は、夏時間の時計が 3:00 を指した瞬間に 2:00 へ戻されるため夏時間としては現れず、標準時の 3:00 として UTC の 2:00（120分）が1つだけ返ります。
