fn counterexample(prop: impl Fn(u8) -> bool) -> Option<u8> {
}

u8 の値について成り立つはずの性質 prop を受け取り、u8 のすべての値で調べる counterexample を書いてください。prop が false を返す値があれば、そのうち最も小さい値を Some で返します。すべての値で true なら None を返します。

入力例 1

counterexample(|x| x < 200)

出力例 1

Some(200)

入力例 2

counterexample(|x| x.wrapping_add(1) > x)

出力例 2

Some(255)

入力例 3

counterexample(|x| x.wrapping_mul(2) / 2 == x % 128)

出力例 3

None

fn counterexample(prop: impl Fn(u8) -> bool) -> Option<u8> {
    (0..=u8::MAX).find(|&x| !prop(x))
}

u8 は256通りしかないので、乱数で入力を作らなくても全部を試せます。0..=u8::MAX は0から255までを小さい順に並べる範囲で、find は先頭から調べて、条件を満たす最初の要素を Some で、最後まで見つからなければ None を返します。条件を「prop が成り立たない」にすれば、最も小さい反例か None がそのまま戻り値になります。これは参考実装で、唯一の正解ではありません。for 文で回して、反例を見つけたところで return Some(x) する書き方もあります。

範囲を 0..u8::MAX と書くと上端の255を含まず、254までしか調べません。入力例2の性質は「1を足すと大きくなる」で、255だけが wrapping_add(1) で0に戻って反例になるので、この書き方では None を返してしまいます。0..256 と書こうとしても、256は u8 に収まらないので書けません。入力例1は200が最初に x < 200 を満たさない値です。入力例3は、2倍して桁あふれした分を捨ててから2で割ると最上位ビットが消えるので、どの値でも128で割った余りに等しく、反例はありません。
