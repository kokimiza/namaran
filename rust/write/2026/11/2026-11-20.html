hoare.rs

fn hoare(v: &mut [i32]) -> usize {
}

v の先頭の値を p として、次の手順で v を並べ替え、最後の右の位置を返す hoare を書いてください。左の位置を先頭、右の位置を末尾から始め、左は p 以上の値に出会うまで右へ、右は p 以下の値に出会うまで左へ進みます。止まった左の位置が右の位置より前なら2つの値を入れ替え、左右とも1つ内側へ動かしてから、また同じように進めます。前でなければ、そこで右の位置を返します。v は1要素以上です。例では、入力に v の中身を、出力に呼び出し後の v と返り値を書きます。

入力例 1

[5, 3, 8, 1, 9, 2]

出力例 1

[2, 3, 1, 8, 9, 5] 2

入力例 2

[4]

出力例 2

[4] 0

入力例 3

[7, 7, 7, 7]

出力例 3

[7, 7, 7, 7] 1

fn hoare(v: &mut [i32]) -> usize {
    let p = v[0];
    let (mut i, mut j) = (0, v.len() - 1);
    loop {
        while v[i] < p {
            i += 1;
        }
        while v[j] > p {
            j -= 1;
        }
        if i >= j {
            return j;
        }
        v.swap(i, j);
        i += 1;
        j -= 1;
    }
}

左の添字 i と右の添字 j は、それぞれ自分の側に置いてはいけない値で止まります。止まった2つを入れ替えれば、どちらも正しい側へ移ります。返る j は、v[..=j] がすべて p 以下、v[j + 1..] がすべて p 以上になる境目です。掲載したのは参考実装で、唯一の正解ではありません。

入力例 1 では、まず i が先頭の 5 自身で、j が末尾の 2 で止まり、入れ替えて [2, 3, 8, 1, 9, 5] になります。次は i が 8、j が 1 で止まって [2, 3, 1, 8, 9, 5]、その次は i が添字 3 の 8、j が添字 2 の 1 で止まり、左が右より前ではないので 2 を返します。基準値の 5 は末尾へ移っていて、返した位置にはありません。

while の2つのループに範囲の検査が無いのは、p と等しい値でも止まるからです。最初の周回では先頭の p 自身が j の止まり場所になり、入れ替えたあとは、相手の側へ移した値が次の周回の止まり場所になります。入力例 3 のように全部が等しくても毎回止まって入れ替えるので、境目は真ん中の 1 にでき、要素が1つの入力例 2 では、すぐに i >= j になって 0 を返します。
