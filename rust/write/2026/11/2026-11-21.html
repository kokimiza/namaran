Vec を受け取り、その要素を最後のものから先頭へ向かって1つずつ drop する drop_rev を書いてください。要素が無ければ何もしません。例では、要素の型を、drop されるときに自分の番号を改行なしで表示する N とします。

入力例 1

drop_rev(vec![N(1), N(2), N(3)])

出力例 1

321

入力例 2

drop_rev(vec![N(7)])

出力例 2

7

入力例 3

drop_rev(Vec::<N>::new())

出力例 3

fn drop_rev<T>(v: Vec<T>) {
    for x in v.into_iter().rev() {
        drop(x);
    }
}

Vec を何もせずに捨てると、要素は先頭から順に drop されます。逆の順にするには、要素を後ろから1つずつ取り出し、取り出したものをその場で捨てます。into_iter() は v を消費して要素を所有権ごと返すイテレータで、rev() を付けると後ろから返します。ループ変数 x は1周ごとに要素を1つ所有し、drop(x) がそれを捨ててから次の要素を取り出します。掲載したのは参考実装で、唯一の正解ではありません。let mut v = v; として while let Some(x) = v.pop() で取り出しても同じ順になります。

drop(x) を書かずに本体を空にしても、x は1周の終わりでスコープを抜けて drop されるので、結果は変わりません。drop を書くのは、ここで捨てていることを読む人に見せるためです。入力例1では N(3)、N(2)、N(1) の順に捨てられて 321 と表示されます。入力例3の空の Vec では、ループが1回も回りません。要素の型を T のままにしておけるのは、要素を取り出して捨てるだけで、中身には触れないからです。
