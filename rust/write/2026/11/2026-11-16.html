strip_marks.rs

fn strip_marks(s: &str) -> String {
}

Unicode の U+0300 から U+036F までの文字は、直前の文字の上や下にアクセントなどの記号を重ねて表示させる結合文字です。たとえば "e\u{301}" は、e と U+0301 の2文字で é と表示されます。s からこの範囲の文字だけを取り除き、残りの文字を元の順に並べた String を返す strip_marks を書いてください。s が空なら空の String を返します。

入力例 1

strip_marks("cafe\u{301}")

出力例 1

"cafe"

入力例 2

strip_marks("nai\u{308}ve")

出力例 2

"naive"

入力例 3

strip_marks("")

出力例 3

""

fn strip_marks(s: &str) -> String {
    s.chars().filter(|c| !('\u{300}'..='\u{36f}').contains(c)).collect()
}

chars は UTF-8 のバイト列を1文字ずつの char に区切って返すので、2バイトで書かれた U+0301 も1つの char として受け取れます。'\u{300}'..='\u{36f}' は両端を含む char の範囲で、contains がその文字が範囲に入るかを答えます。filter で範囲の外の文字だけを残し、collect で String に集めます。掲載したのは参考実装で、唯一の正解ではありません。matches!(c, '\u{300}'..='\u{36f}') で判定しても同じです。

入力例 1 では U+0301 だけが範囲に入り、c、a、f、e が残ります。入力例 2 の U+0308 は上に点を2つ重ねる結合文字で、これも範囲に入ります。空の文字列では chars が何も返さないので、collect は空の String を作ります。"caf\u{e9}" のように é を1文字の U+00E9 で書いた文字列は範囲に入る文字を含まないので、そのまま返ります。アクセントを外したいなら、この関数を呼ぶ前に é を e と U+0301 に分ける変換が別に要ります。
