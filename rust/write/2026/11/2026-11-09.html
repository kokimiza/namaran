records.rs

fn records(mut log: &[u8]) -> Vec<&[u8]> {
}

ログ log には、レコードが「本体の長さを表す1バイト」と「その長さ分の本体」の組で、隙間なく並んでいます。書き込みの途中でプロセスが落ちると、最後のレコードは途中で切れていることがあります。書き終えたレコードの本体を、先頭から順に log の一部として返す records を書いてください。途中で切れた最後のレコードは捨て、そのときもパニックしてはいけません。長さが0のレコードは、空の本体を持つ1つのレコードです。

入力例 1

records(&[2, 7, 7, 1, 9, 3, 4])

出力例 1

[[7, 7], [9]]

入力例 2

records(&[0, 1, 5])

出力例 2

[[], [5]]

入力例 3

records(&[])

出力例 3

[]

fn records(mut log: &[u8]) -> Vec<&[u8]> {
    let mut out = Vec::new();
    while let Some((&n, rest)) = log.split_first() {
        let Some(body) = rest.get(..n as usize) else {
            break;
        };
        out.push(body);
        log = &rest[n as usize..];
    }
    out
}

split_first は、スライスが空でなければ先頭の要素と残りのスライスを Some で返し、空なら None を返します。while let で受ければ、先頭の1バイトを長さ n として読み、ログを読み切ったところでループが終わります。本体は rest.get(..n as usize) で取り出します。添字の rest[..n as usize] は範囲が長さを超えるとパニックしますが、get は同じ範囲を Option で返し、足りなければ None になります。let-else でこの None を受けて break すれば、切れたレコードを捨ててそこで止まれます。本体を取れたら out に入れ、log を本体の次へ進めます。返す &[u8] は log の一部を指すだけなので、本体を複製せずに返せます。これは参考実装で、唯一の正解ではありません。

入力例1では、長さ2の [7, 7]、長さ1の [9] を取り出したあと、長さ3に対して残りが [4] の1バイトしかないので get が None を返し、2つで止まります。入力例2の先頭の0は長さ0のレコードで、get(..0) は空のスライスを Some で返すので、[] が1つのレコードとして入ります。空のログの入力例3では、最初の split_first が None を返し、ループは1回も回りません。
