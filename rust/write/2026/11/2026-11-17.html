fn take_longest(
    v: &mut Vec<String>,
) -> Option<String> {
}

v の中で最も長い文字列を v から取り除き、Some に包んで返す take_longest を書いてください。長さはバイト数で比べ、最も長いものが複数あれば最も前にあるものを取り出します。残りの要素の順番は変えません。v が空なら None を返します。例では、入力に呼び出す前の v を書き、出力に戻り値と呼び出したあとの v を並べます。

入力例 1

["ab", "cde", "f", "xyz"]

出力例 1

Some("cde") ["ab", "f", "xyz"]

入力例 2

["solo"]

出力例 2

Some("solo") []

入力例 3

[]

出力例 3

None []

fn take_longest(
    v: &mut Vec<String>,
) -> Option<String> {
    let i = (0..v.len())
        .rev()
        .max_by_key(|&i| v[i].len())?;
    Some(v.remove(i))
}

返したいのは v の中にある String そのもので、その所有権は v が持っています。v は &mut で借りているだけなので、Some(v[i]) と書いて添字の先から値をムーブすることはできず、コンパイルエラーになります。Vec::remove(i) は i 番目の要素を Vec から外し、後ろの要素を1つずつ前へ詰めたうえで、外した要素を所有権ごと返します。v には穴が残らず、取り出した String は呼び出し側のものになります。掲載したのは参考実装で、唯一の正解ではありません。

取り出す位置は、添字の範囲 0..v.len() から長さが最大のものを選んで決めます。max_by_key は最大のものが複数あると最後のものを返すので、rev() で後ろから並べ、最も前にある添字が最後に来るようにしています。入力例 1 では "cde" と "xyz" がどちらも3バイトで、前にある添字1が選ばれます。v が空なら max_by_key が None を返し、? がそのまま None を返すので、入力例 3 のように何も取り出しません。順番を気にしないなら、最後の要素を穴へ移す swap_remove を使うと詰める手間が省けます。
