fn take_chars(s: &str, n: usize) -> &str {
}

s の先頭から n 文字(char で n 個)を、s の一部を指す &str として返す take_chars を書いてください。s が n 文字に満たないときは s 全体を、n が 0 のときは空文字列を返します。新しい String は作りません。

入力例 1

take_chars("héllo", 2)

出力例 1

"hé"

入力例 2

take_chars("日本語", 5)

出力例 2

"日本語"

入力例 3

take_chars("abc", 0)

出力例 3

""

fn take_chars(s: &str, n: usize) -> &str {
    match s.char_indices().nth(n) {
        Some((i, _)) => &s[..i],
        None => s,
    }
}

&s[..i] の i は文字の番号ではなく、UTF-8 のバイト位置です。"héllo" の é は2バイトなので、先頭2文字 "hé" は &s[..2] ではなく &s[..3] です。&s[..2] と書くと é の途中で切ることになり、文字の境界ではない位置で切ったとして panic します。そこで文字数をバイト位置に直します。char_indices() は各文字を、その文字が始まるバイト位置と組にして返すので、nth(n) で得られる n + 1 文字目の開始位置が、先頭 n 文字の終わりの位置になります。掲載したのは参考実装で、唯一の正解ではありません。

入力例1では、char_indices() が (0, 'h')、(1, 'é')、(3, 'l') と進むので、nth(2) は (3, 'l') で、&s[..3] が "hé" になります。入力例2は3文字しかないので nth(5) が None を返し、s 全体を返します。入力例3は nth(0) が先頭の (0, 'a') なので、空文字列の &s[..0] を返します。s.chars().take(n).collect::<String>() でも同じ文字列は得られますが、戻り値が新しい String になるので、この問題のシグネチャには合いません。
