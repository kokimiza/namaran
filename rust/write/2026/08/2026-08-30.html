fn reversal_holds(f: fn(&[i32]) -> i32, xs: &[i32]) -> bool {
}

関数 f に xs を渡した結果と、xs の要素を逆の順に並べた列を渡した結果が等しければ true、違えば false を返す reversal_holds を書いてください。f の正しい結果は分からないものとし、2つの結果どうしを比べるだけにします。xs が空なら、空の列どうしで比べます。

入力例 1

reversal_holds(|xs| xs.iter().sum(), &[1, 2, 3])

出力例 1

true

入力例 2

reversal_holds(|xs| xs[0], &[1, 2, 3])

出力例 2

false

入力例 3

reversal_holds(|xs| xs.len() as i32, &[])

出力例 3

true

fn reversal_holds(f: fn(&[i32]) -> i32, xs: &[i32]) -> bool {
    let reversed: Vec<i32> = xs.iter().rev().copied().collect();
    f(xs) == f(&reversed)
}

xs は借りたスライスなので、その場で並べ替えることはできません。xs.iter().rev() で後ろから要素の参照をたどり、copied() で i32 の値にしてから collect で新しい Vec<i32> に集めます。&reversed は &Vec<i32> ですが、f の引数の &[i32] へ自動で変換されるので、そのまま渡せます。あとは元の列と逆順の列で f を呼び、2つの戻り値を == で比べるだけです。

入力例 1 の和は、どちらの順でも 6 なので true です。入力例 2 の先頭要素は、元の列では 1、逆順では 3 になるので false を返し、f が要素の順に左右されることを見つけます。空の列は逆にしても空のままなので、f が空の列を扱える限り結果は等しくなります。引数の型 fn(&[i32]) -> i32 は関数ポインタで、例のように何も捕まえないクロージャも渡せます。掲載したのは参考実装で、唯一の正解ではありません。let mut ys = xs.to_vec(); ys.reverse(); と写してから逆にしてもかまいません。
