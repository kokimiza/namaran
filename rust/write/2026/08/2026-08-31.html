coords.rs

fn coords(i: usize, w: usize, h: usize) -> (usize, usize, usize) {
}

横 w、縦 h のマスを重ねた立体の格子があり、座標 (x, y, z) のマスを一次元の添字 i = x + w * (y + h * z) の位置に並べています。0 <= x < w、0 <= y < h、z は0以上です。添字 i から座標 (x, y, z) を返す coords を書いてください。w と h は1以上とします。

入力例 1

coords(5, 4, 3)

出力例 1

(1, 1, 0)

入力例 2

coords(23, 4, 3)

出力例 2

(3, 2, 1)

入力例 3

coords(12, 4, 3)

出力例 3

(0, 0, 1)

fn coords(i: usize, w: usize, h: usize) -> (usize, usize, usize) {
    (i % w, i / w % h, i / (w * h))
}

i = x + w * (y + h * z) は、x を一の位とする位取りの書き方に似ています。ただし桁ごとに基数が違い、一の位は w 進、その上は h 進です。w * (y + h * z) は w の倍数で、x は w 未満なので、i % w が x、i / w が y + h * z になります。この y + h * z を同じように h で割れば、余りが y、商が z です。i / w / h は i / (w * h) と等しいので、参考実装では z をまとめて割っています。これは参考実装で、唯一の正解ではありません。

入力例1は 5 % 4 = 1、5 / 4 = 1 を3で割った余りが1、5 / 12 = 0 で (1, 1, 0) です。入力例2は 23 % 4 = 3、23 / 4 = 5 の 5 % 3 = 2、23 / 12 = 1 になります。入力例3の12はちょうど1段分のマスの数で、x と y が0に戻り、z だけが1になる境目です。y を i / w のままにすると、ここで y が3になり、h の範囲を越えます。
