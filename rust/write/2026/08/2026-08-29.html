0以上の整数 n に、偶数なら2で割り、奇数なら1を引く操作を繰り返します。n が0になるまでの操作の回数を返す steps_to_zero を書いてください。n が最初から0なら、0回です。

入力例 1

steps_to_zero(14)

出力例 1

6

入力例 2

steps_to_zero(8)

出力例 2

4

入力例 3

steps_to_zero(0)

出力例 3

0
Reference 
fn steps_to_zero(mut n: u32) -> u32 {
    let mut steps = 0;
    while n > 0 {
        n = if n.is_multiple_of(2) {
            n / 2
        } else {
            n - 1
        };
        steps += 1;
    }
    steps
}

n が正のあいだ、偶奇で分けて n を書き換え、回数を数えます。if は値を返す式なので、どちらの枝の結果もそのまま n に代入できます。入力例 1 では 14 が 7、6、3、2、1、0 と変わり、6回で止まります。

このループが必ず止まるのは、正の n に対して n / 2 も n - 1 も n より小さく、n が1回ごとに真に減るからです。u32 は0より小さくなれないので、減り続けるうちに必ず0に着きます。n が0になればループの本体には入らないので、0から1を引いて u32 の範囲を下に外れることもありません。

掲載したのは参考実装で、唯一の正解ではありません。2で割る操作は2進数で1桁右へずらすこと、1を引く操作は一番下の桁の1を0にすることなので、正の n の回数は「2進数の桁数 − 1」と「1の桁の個数」の和です。32 - n.leading_zeros() - 1 + n.count_ones() と書けば、ループを使わずに求められます。
