fn add(a: &str, b: &str) -> String {
}

0 以上の整数を10進で書いた文字列 a と b を受け取り、その和を同じ形の文字列で返す add を書いてください。入力は空でなく、数字だけからなり、"0" 以外は先頭に 0 が付きません。桁数に上限はないので、整数型に変換してから足すことはできません。

入力例 1

add("987", "45")

出力例 1

"1032"

入力例 2

add("999", "1")

出力例 2

"1000"

入力例 3

add("0", "0")

出力例 3

"0"

fn add(a: &str, b: &str) -> String {
    let mut x = a.bytes().rev();
    let mut y = b.bytes().rev();
    let mut digits = Vec::new();
    let mut carry = 0;
    loop {
        let (p, q) = (x.next(), y.next());
        if p.is_none() && q.is_none() && carry == 0 {
            break;
        }
        let s = p.map_or(0, |c| c - b'0') + q.map_or(0, |c| c - b'0') + carry;
        digits.push(b'0' + s % 10);
        carry = s / 10;
    }
    digits.into_iter().rev().map(char::from).collect()
}

筆算と同じく、下の桁から順に足します。bytes().rev() で両方の文字列を1の位から取り出し、c - b'0' で数字の文字を値に戻します。

ループを続ける条件は、どちらかの文字列に桁が残っているか、繰り上がりが残っていることです。短い方が先に尽きたら、その桁は map_or で 0 として足します。zip で組にすると短い方で止まるので、例1では "987" の百の位の 9 が読まれません。

桁は下の位から digits に積んだので、最後に逆順にして文字列にします。1桁の和は最大でも 9 + 9 + 1 = 19 なので、u8 のまま計算できます。

掲載したのは参考実装で、唯一の正解ではありません。短い方の左を 0 で埋めて桁数をそろえてから、2つの文字列を同時に後ろから読む書き方もあります。
