fn parse_count(input: &str) -> u32 {
    let input = input.trim();
    let input: u32 = input.parse().unwrap_or(0);
    input
}

再代入は同じ型の値でしか使えず、しかもmutが必要です。ここではinputの型が&strからu32へと変わるので、そもそも再代入では書けません。シャドーイングならmutなしで、しかも型が変わってもそのままletで新しい束縛を作れます。let input = input.trim();で前後の空白を取り除いた&strに置き換え、続くlet input: u32 = input.parse().unwrap_or(0);でそれを数値にパースし直しています。2つのinputは見た目は同じ名前ですが、型も値も別のメモリ上の変数であり、前のinputはもう参照できません。これは参考実装であり、唯一の正解ではありません。
