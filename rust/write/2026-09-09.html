next_page.rs

fn next_page(ids: &[u64], after: Option<u64>, limit: usize) -> &[u64] {
}

ids は重複のない昇順のidの並びです。after が Some(a) なら a より大きいidを、None なら先頭から、最大 limit 件を ids の部分スライスとして返す next_page を書いてください。条件に合うidがなければ空のスライスを返します。next_page(&[2, 4, 6, 8], Some(4), 2) → [6, 8]、next_page(&[2, 4, 6, 8], None, 3) → [2, 4, 6]、next_page(&[2, 4, 6, 8], Some(8), 2) → []

fn next_page(ids: &[u64], after: Option<u64>, limit: usize) -> &[u64] {
    let start = after.map_or(0, |a| ids.partition_point(|&id| id <= a));
    let end = (start + limit).min(ids.len());
    &ids[start..end]
}

開始位置は partition_point で求めます。ids は昇順なので id <= a を満たす要素は先頭にかたまっており、partition_point はその境目の添字を二分探索で返します。a そのものが ids に無くても、Some(5) なら 5 より大きい最初の要素の位置が返ります。None のときは map_or で0にします。

終わりの位置は min(ids.len()) で切り詰めるので、残りが limit 件に満たなくても範囲外を指しません。戻り値の &[u64] は、参照の引数が ids だけなのでライフタイムを省略でき、ids と同じ寿命のスライスとして要素をコピーせずに返せます。

これは参考実装であり、唯一の正解ではありません。ids.iter().position(|&id| id > a) で先頭から探し、見つからなければ ids.len() を使っても結果は同じです。
