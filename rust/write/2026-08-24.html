is_sorted.rs

fn is_sorted(nums: &[i32]) -> bool {
    // write this: true if nums is sorted in non-decreasing order
}

is_sortedを実装してください。numsが非減少順(non-decreasing order)にソートされていればtrueを返します(空のスライスや要素が1つだけの場合もソート済みとみなします)。

Reference 
fn is_sorted(nums: &[i32]) -> bool {
    nums.windows(2).all(|w| w[0] <= w[1])
}

.windows(2)は隣接するすべてのペアを返します。どのペアも順序が逆転していなければ、スライス全体がソートされていることになります。これは参考実装であり、唯一の正解ではありません — 自分の実装と比較してみてください(素朴なインデックスループでも同様に書けます)。
