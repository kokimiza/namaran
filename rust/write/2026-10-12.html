}

呼ぶたびに0以上1未満の乱数を返すクロージャ rand を使い、1辺が1の正方形に n 個の点を打って円周率を推定する estimate_pi を書いてください。点は1個につき rand を2回呼び、1回目を x 座標、2回目を y 座標とします。x² + y² ≤ 1 となった点の割合を4倍した値を返し、n が0のときは 0.0 を返します。

入力例 1

let mut v = [0.5, 0.5, 0.9, 0.9].into_iter(); estimate_pi(2, || v.next().unwrap())

出力例 1

2.0

入力例 2

estimate_pi(3, || 0.5)

出力例 2

4.0

入力例 3

estimate_pi(0, || 0.0)

出力例 3

0.0

fn estimate_pi(n: u32, mut rand: impl FnMut() -> f64) -> f64 {
    if n == 0 {
        return 0.0;
    }
    let inside = (0..n)
        .filter(|_| {
            let (x, y) = (rand(), rand());
            x * x + y * y <= 1.0
        })
        .count();
    4.0 * inside as f64 / f64::from(n)
}

乱数を返すクロージャは、ふつう呼ぶたびに自分の状態を書き換えます。入力例 1 のクロージャなら、捕捉したイテレータ v を1つずつ進めます。そういうクロージャを受け取れるのは Fn ではなく FnMut で、FnMut を呼ぶには可変の借用が要るため、引数の束縛を mut rand にしています。filter に渡したクロージャはその中で rand() を呼ぶので、rand を可変で借用したまま、count が数え終わるまで持ち続けます。

タプル (rand(), rand()) の要素は左から順に評価されるので、1回目の値が x、2回目が y に入ります。数えた個数は usize なので、f64 に変えてから割ります。整数のまま 4 * inside / n と割ると小数部が切り捨てられ、推定値が整数にしかなりません。n が0のまま割り算まで進むと 0.0 / 0.0 で NaN になるので、先に 0.0 を返しています。

掲載したのは参考実装で、唯一の正解ではありません。for ループで内側の点の数を数える書き方でも同じ結果になります。
