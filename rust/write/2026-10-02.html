time_it.rs

use std::time::Duration;

fn time_it<T>(f: impl FnOnce() -> T) -> (T, Duration) {
}

引数のクロージャ f を1回だけ呼び、その戻り値と、呼び出しにかかった時間の組を返す time_it を書いてください。測っている途中で OS の時刻が NTP などで合わせ直されても、かかった時間が狂わないようにします。f がすぐに戻るときは、0 に近い時間を返します。

入力例 1

time_it(|| 6 * 7).0

出力例 1

42

入力例 2

time_it(|| std::thread::sleep(Duration::from_millis(50))).1 >= Duration::from_millis(50)

出力例 2

true

入力例 3

time_it(|| "done").0

出力例 3

"done"

use std::time::Duration;
use std::time::Instant;

fn time_it<T>(f: impl FnOnce() -> T) -> (T, Duration) {
    let start = Instant::now();
    let value = f();
    (value, start.elapsed())
}

f を呼ぶ前に Instant::now() で時点を取り、呼んだあとで elapsed() を取ります。Instant は OS の単調増加時計を読むので、OS の時刻が合わせ直されても値は戻りません。elapsed() は、呼び出しにかかった時間そのものを返します。

同じことを SystemTime::now() で書くと、測っている間に時刻が戻ったときは elapsed() が Err を返し、進んだときは実際より長い時間が返ります。SystemTime は「いま何時か」を記録するための壁時計で、2つの時点の間隔を測るのには向きません。

f は FnOnce で受けるので、捕まえた値をムーブして消費するクロージャも渡せます。

掲載したのは参考実装で、唯一の正解ではありません。戻り値を変数に受けずに (f(), start.elapsed()) と書いても、タプルの要素は左から順に評価されるので、同じ結果になります。
