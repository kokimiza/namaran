文字列の並び parts を1つの String にまとめる encode と、それを元の並びに戻す decode を書いてください。どんな parts についても、decode(&encode(parts)) が parts と同じ要素を同じ順に返すようにします。要素は空でもよく、, や \ を含んでもかまいません。parts が空なら、decode も空の Vec を返します。

入力例 1

decode(&encode(&[]))

出力例 1

[]

入力例 2

decode(&encode(&[""]))

出力例 2

[""]

入力例 3

decode(&encode(&["a,b", "", "c\\"]))

出力例 3

["a,b", "", "c\\"]
Reference 
fn encode(parts: &[&str]) -> String {
    let mut out = String::new();
    for part in parts {
        for c in part.chars() {
            if c == ',' || c == '\\' {
                out.push('\\');
            }
            out.push(c);
        }
        out.push(',');
    }
    out
}

fn decode(s: &str) -> Vec<String> {
    let mut parts = Vec::new();
    let mut cur = String::new();
    let mut chars = s.chars();
    while let Some(c) = chars.next() {
        match c {
            '\\' => cur.extend(chars.next()),
            ',' => parts.push(std::mem::take(&mut cur)),
            _ => cur.push(c),
        }
    }
    parts
}

最初に思いつくのは parts.join(",") と s.split(',') の組ですが、これでは元に戻りません。split は区切りが1つもない文字列からも要素を1つ返すので、"".split(',') は [""] です。空のスライスも [""] も join すると同じ "" になり、decode にはどちらだったかを知る手がかりが残りません。さらに要素に , が含まれると、["a,b"] と ["a", "b"] も同じ "a,b" になります。

参考実装は、この2つの衝突を別々の手で解いています。1つ目は、, を要素の間に置く区切りではなく、各要素の後ろに付ける終端として使うことです。空のスライスは ""、[""] は ","、["", ""] は ",," になり、要素の数と終端の , の数がいつも一致します。2つ目は、要素の中の , の前に \ を付けて、終端の , と見分けられるようにすることです。すると今度は、要素にもともとあった \ と目印として足した \ が紛れるので、\ 自身の前にも \ を付けます。

こうしてエスケープした文字列は、もう split(',') では戻せません。\, の , は終端ではなく、\\, の , は終端です。, が終端かどうかは直前に続く \ の数で決まるので、decode は先頭から1文字ずつ読み、\ を見たら次の1文字を無条件に要素へ入れます。cur.extend(chars.next()) は Option を0個か1個の要素の並びとして足すので、\ が最後の文字でも止まりません。終端の , を読むたびに std::mem::take で要素を確定させ、cur を空に戻します。

掲載したのは参考実装で、唯一の正解ではありません。各要素の前にバイト数を書く 3:a,b0: のような長さ付きの形式にすれば、エスケープを使わずに空の要素も , を含む要素も区別できます。
