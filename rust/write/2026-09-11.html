safe_div.rs

// write this: divide a by b; return None instead of panicking when b is 0
fn safe_div(a: i32, b: i32) -> Option<i32> {
}

safe_divを実装してください。aをbで割った結果を返しますが、bが0のときは(/演算子のようにパニックせず)Noneを返すこと。safe_div(10, 2) → Some(5)、safe_div(7, 0) → None、safe_div(0, 5) → Some(0)

Reference 
fn safe_div(a: i32, b: i32) -> Option<i32> {
    a.checked_div(b)
}

標準ライブラリのchecked_divは、通常どおり割り切れればSome(結果)を、割り算が失敗する場合(bが0のとき、またはi32::MIN / -1のようにオーバーフローする場合)はNoneを返します。if b == 0 { None } else { Some(a / b) }のように自分で条件分岐を書いても0除算は防げますが、checked_divを使えば0除算に加えてオーバーフローという、もう1つのパニック原因も同じ書き方で一緒に防げます。これは参考実装であり、唯一の正解ではありません。
